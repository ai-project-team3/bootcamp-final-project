# 초안 B — 같이 짓는 책

> 2026-09-17 · 조장 · 비교 기준과 판정 방법은 `docs/초안_비교.md`

초안 A(안치영)와 **같은 대본으로 다른 선택을 한** 두 번째 초안이다.
A를 개선한 것이 아니라, 회의에서 나란히 놓고 고르려고 일부러 다르게 만들었다.

## 여는 법

```
cd prototype-b
python -m http.server 8778
```
→ `http://127.0.0.1:8778/index.html`

## A와 다르게 잡은 것 넷

| # | 축 | 초안 A | **초안 B** |
|---|---|---|---|
| 1 | 그림체 | 펠트·종이공예 3D (krea2 turbo) | **손으로 오린 색종이** (SDXL base 1.0) |
| 2 | 책이 보이는 시점 | 대화가 끝난 뒤 한 번에 | **말할 때마다 왼쪽에 한 쪽씩 쌓인다** |
| 3 | 어른 자리 | 1칸, 건너뛸 수 있음 | **어른이 답해야 넘어가는 자리 1개** + 마무리 자리 1개 |
| 4 | 턴 수 | 8턴 | **5턴** (장소 · 사건 · 까닭 · 해결 · 제목) |

**같게 둔 것**: 미션 2개 · 부모 리포트 6축과 원그래프 · 가로 화면 · 열린 질문만 · 답 후보 5개 · 마스코트 3조각 턴.
한 번에 여러 개를 바꾸면 무엇 때문에 좋았는지 알 수 없어서 고정했다.

## 그림

`assets/` 20장은 **이 PC에서 직접 렌더링**했다.

| | |
|---|---|
| 모델 | SDXL base 1.0 (CreativeML OpenRAIL++-M) |
| 설정 | 28 steps · cfg 6.5 · dpmpp_2m / karras · 배경 1344×768 · 인형 1024×1024 |
| GPU | RTX 3060 12GB · 장당 약 21초(1024) · 약 45초(1344×768) |
| 배경 제거 | `tools/cutout.py` — **채도와 밝기로 배경을 가르고, 이어진 덩어리 중 가장 큰 것만 남긴다** |

왜 A의 krea2 turbo를 안 썼나 — 그 모델은 `nvfp4` 양자화판이라 50번대 GPU에서만 돈다.
이 PC는 RTX 3060이다. 그리고 **어차피 다른 그림체를 얻는 것이 이 초안의 목적**이다.

프롬프트를 고치며 배운 것(짧게 쓸 것 · `die-cut sticker` 금지 등)은 `tools/render.py` 맨 위에 적어 두었다.

왜 자르는 후처리가 따로 필요했나 — SDXL은 "흰 배경에 하나만"이라고 해도 주변에 색종이 조각을 흩뿌리고,
배경도 순백이 아니라 **회색 그라데이션**이라(hero_a 네 귀퉁이가 204~234) 밝기만으로는 잘리지 않았다.
그래서 `채도가 낮고 밝으면 배경`으로 보고, 남은 덩어리 중 가장 큰 것만 남기는 방식으로 잘랐다.

다시 만들려면 ComfyUI를 띄우고
```
python tools/render.py    # 그리기 (있는 파일은 건너뜀)
python tools/cutout.py    # 인형만 남기고 자르기
```
자르기 전 원본은 `assets_raw/`에 있다 (git에는 올리지 않는다).


## 배경 소품 (2026-09-17 추가)

배경을 통째로 생성하지 않는다. **분위기만 있는 배경판 한 장 + 소품 14종**을 얹는다.

| | |
|---|---|
| 배경판 | 하늘·바다·들판만. 뚜렷한 물체를 넣지 않는다 |
| 소품 | 나무·덤불·풀·바위 둘·구름·별·달·행성·집·건물·새·토끼·해초 = **14종** |
| 세계 | 같은 14종을 색과 배치만 바꿔 돌려 쓴다. 별은 우주에선 별, 바닷속에선 불가사리 |

붙여넣은 티를 없애는 규칙 일곱 (index.html의 `scatter`)

1. 깊이 세 띠 — 멀수록 작고 흐리고 채도가 낮다
2. 자리의 3할은 일부러 비운다
3. 좌우 뒤집기 · 기울이기 ±7°
4. 색상 ±12° · 밝기 ±6% 흔들기
5. 가끔 옆에 작은 것을 하나 더 붙여 무리를 만든다
6. 같은 소품은 한 띠에 3번까지 (무리 짓기 포함)
7. **세계마다 씨앗 고정** — 같은 세계를 다시 열면 같은 배치라야 "내 세계"가 된다

배경 소품은 눌러도 살짝 흔들릴 뿐 이야기를 바꾸지 않는다. 미션 물체만 은은하게 빛난다.

## 이 초안의 약한 곳 (알고 있다)

- 화면의 42%를 책이 가져가서 무대가 좁다. 인형 연출이 A보다 답답하다.
- 어른을 강제로 세우면, 어른이 잠깐 자리를 비운 사이 놀이가 멈춘다.
  1순위 사용자가 '짧게 봐주는 이모·삼촌'이라는 설정과 충돌한다. **이게 이번 비교의 핵심 쟁점이다.**
- 5턴이라 칸이 덜 차고 이야기가 얇다.
- 인형이 상반신 위주로 잡힌다. SDXL이 `full body`를 자주 무시해서, 깨끗한 한 덩어리를 얻는 쪽을 택한 결과다.
- 배경판에서 뚜렷한 물체를 빼는 대신 소품을 얹는 방식이라, **그림 한 장의 밀도와 구성은 전보다 옅다.**
  풍부함을 얼마나 포기하고 만질 거리를 얻을지가 판단할 지점이다.
