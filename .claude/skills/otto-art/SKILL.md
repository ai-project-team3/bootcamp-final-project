# 오또 그림 공방

앱 그림은 `android/tools/otto_art.py` 하나로 뽑는다. 그림체 문장 · 모델 · 크기가 그 안에 고정돼 있어서
누가 뽑아도 같은 결이 나온다. 사람이 읽는 설명은 `android/tools/ART.md`.

## 순서

1. **서버 확인** — `android` 폴더에서 `python tools/otto_art.py check`.
   닿지 않으면 사용자에게 `start_otto_comfy.bat`(ART.md §2)을 켜 달라고 하고 멈춘다. 설치가 안 돼 있으면 ART.md §1 을 안내한다.
   에뮬레이터가 켜져 있으면 끄자고 먼저 말한다 — 그래픽카드를 나눠 써서 PC가 멈춘다.
2. **종류와 이름 정하기**
   - 배경(가로 화면 전체) → `bg`, 화면 위에 얹는 물건 · 인물 · 아이콘 → `cut`(배경을 빼 투명 PNG)
   - 이름은 영어 소문자 · 숫자 · `_`. 비슷한 그림이 이미 있으면 `res/drawable` 의 앞머리를 따른다 (`bg_` · `coop_el_` · `hero_` …)
   - 같은 이름이 이미 있으면 바꿀지 사용자에게 묻는다 (바꾸면 `pick --replace`)
3. **설명 쓰기** — 사용자가 한국어로 말해도 **영어로, 무엇이 있는지만** 쓴다. 그림체 말(felt, cute, pastel …)은 붙이지 않는다 — 자동으로 붙는다.
   배경에는 사람 · 동물을 넣지 않는다. 글자 · 무섭거나 어두운 것은 피한다(아이 앱).
4. **뽑기** — `python tools/otto_art.py bg|cut 이름 "설명"` (기본 3장, 한 장에 1분쯤). 오래 걸리면 백그라운드로 돌린다.
5. **보여 주고 고르게 하기** — `tools/art_out/이름_시드(_cut).png` 를 열어 보고, 시드별로 짧게 설명해 사용자에게 고르게 한다.
   글자가 생겼거나, 오려 낸 그림에 배경이 남았거나, 무서운 것이 보이면 그 시드는 빼고 말한다. 마음에 드는 게 없으면 설명을 고쳐 다시 뽑는다.
6. **넣기** — `python tools/otto_art.py pick 이름 시드` → `python tools/shrink_assets.py`.
   그림을 쓰는 코드가 필요하면 그다음에 고친다.
7. **올리기** — 사용자의 브랜치(`feature/<이름>`)에 `res/drawable/이름.png` 와 `tools/art_recipes/이름.json` 을 같이 커밋한다. main 에 직접 올리지 않는다(PR).

## 하지 않는 것

- `otto_art.py` 의 `STYLES` · 모델 · 샘플러를 바꾸지 않는다. 사용자가 원하면 "팀과 먼저 정해야 한다"고 말한다 — 새 그림만 결이 달라진다
- 옛 `gen_*.py` 로 새 그림을 만들지 않는다 (레시피가 남지 않는다)
- `tools/art_out/` 을 커밋하지 않는다
- 사람이 보지 않은 그림을 앱에 넣지 않는다 — 모델에 안전 필터가 없다

## 다시 뽑기

`tools/art_recipes/이름.json` 이 있으면 `python tools/otto_art.py again 이름` 으로 같은 그림이 나온다.
조금 바꾸고 싶으면 레시피의 `text` 를 고쳐 `bg`/`cut` 으로 새로 뽑는다.
