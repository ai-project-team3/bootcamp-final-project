## 여는 법

`file://`로 열면 그림이 안 보입니다. 로컬 서버로 여세요.

```
cd prototype
python -m http.server 8777
```

브라우저에서 `http://127.0.0.1:8777/index.html`. 가로 화면 기준이고 창 너비에 맞춰 줄어듭니다.

## 그림

`assets/`의 PNG 96장은 **안치영님이 자기 PC의 ComfyUI로 만든 것**을 그대로 가져온 것입니다.
모델은 krea2 turbo(nvfp4), 그림체는 펠트·종이공예 3D, 배경 제거는 BiRefNet.
만든 스크립트와 프롬프트 원본은 `Desktop/finalproject_demo/tools/gen_assets.py` · `gen_heroes.py` · `gen_icons.py`에 있습니다.

**이 폴더에서 새로 만든 그림은 없습니다.** HTML에 필요한 96장이 이미 전부 있어서, 다시 렌더링하면 그림체만 어긋납니다.

`assets/`는 91MB이라 git에 올리지 않습니다(`.gitignore`). 받은 사람은 위 데모 폴더의 `res/drawable`에서 복사하거나 생성 스크립트를 돌리면 됩니다.

## 이 초안에 없는 것

음성 인식 · 실제 LLM 호출 · ComfyUI 실시간 생성 · 저장 · 결제 · 책장 · 업적 화면.
전부 **데모용 대역**으로 대체했습니다. 시연 서랍의 "이 초안에 없는 것"에도 같은 목록이 있습니다.

## 안드로이드 데모와의 관계

안치영님의 `finalproject_demo`(Kotlin + Compose)가 같은 흐름을 이미 앱으로 만들어 두었고 APK도 빌드돼 있습니다
(`app/build/outputs/apk/debug/app-debug.apk`). 이 HTML은 **앱을 대체하려는 것이 아니라**,
설치 없이 링크로 열어 흐름을 보여주고 대본을 검증하는 용도입니다.
