# 말로 짓는 인형극 — 안드로이드 데모 (Kotlin + Compose)

부트캠프 최종 프로젝트 "말로 짓는 인형극"의 **흐름 확인용 데모 앱**입니다.
근거 문서: `말로짓는인형극/엔드픽처_초안.md` · `정렬회의_결정안건.md`(9/16 결정이 초안보다 우선) · `말로짓는인형극_기획안.md` 화면 2·4·5.

## 여는 법 · 돌리는 법

Android Studio에서 이 폴더를 `Open` → 에뮬레이터나 폰에서 실행. 터미널만으로도 됩니다.

```
gradlew installDebug
adb shell am start -n com.example.finalproject_demo/.MainActivity
```

- **가로 전용**(`sensorLandscape`) · 전체 화면 · 글꼴 Jua(OFL).
- **백엔드 · 네트워크 · 권한 · 저장소를 쓰지 않습니다.** 앱을 끄면 상태가 초기화됩니다.

## 아이가 고른 것이 그대로 책이 된다

| 아이가 고르는 것 | 어디에 쓰이나 |
| --- | --- |
| 장소 (우주 · 바닷속 · 공룡 나라) | 세계 배경 · 탈것(로켓 · 거북이 · 기차) · 사건 · 새 친구 후보 · 책 자막 · 제목 |
| 새 친구 (외계인 · 운석 · 바람 …) | 장면 5 창문 · 그림판에서 그릴 대상 · 책 3·5쪽 |
| 그림판에 그린 그림 | 그대로 저장돼 입 위치 · 장면 10 · 책 표지 · 3쪽 · 6쪽에 (AI로 다시 그리지 않음, 27) |
| 이름 (마이크) | 이름 사전 · 책 자막 · 부모 기록 |
| 공룡 (티라노 · 긴목공룡 · 뿔공룡) · 색 | 장면 8 소리 · 장면 9 확인 · 책 6쪽 (색은 생성 없이 색상만 바꿈, ⭐26) |
| 까닭 · 해결 방법 | 책 5·6쪽 자막 · 해결 방법 도감 |
| 제목 (마이크) | 표지 · 책장 · 부모 기록 |

## 마이크

🎤는 **온/오프**입니다 — 누르면 듣고(파형), 다시 누르면 끝. 시간 제한이 없습니다. ➡️는 "말 없이 넘김"(무응답).
데모에는 진짜 음성 인식이 없어서, 마이크를 끄는 순간 **그 질문의 답 후보 5개 중 하나가 무작위로** 들어갑니다.
답마다 뜻하는 값(장소 · 새 친구 · 까닭 · 공룡 · 소리 · 해결 방법 · 이름 · 제목)이 붙어 있어 책이 그 답대로 만들어집니다.
시연 서랍의 대본 버튼으로 특정 답을 고를 수도 있습니다.
실제 앱 규칙(⭐5 · 쉬운 5초 · 어려운 8초 · 선택지 7초)은 시연 서랍의 **"무응답 타이머 켜기"** 로 볼 수 있습니다.

## 시연 서랍

아이 화면을 깨끗하게 두려고 시연 조작은 숨겨 뒀습니다. **화면 오른쪽 위 구석을 1.5초쯤 길게 누르면** 오른쪽에서 서랍이 열립니다.

| 탭 | 무엇 |
| --- | --- |
| 🎮 조작 | 가짜 아이 3명 · 마이크 온/오프 vs 무응답 타이머 · 시간 배속 · 첫날 모드 · 장면 이동 15개 · 처음부터 · 아이 반응 대본 버튼 |
| ⚙️ 뒤에서 | 이 장면에서 실제로 무슨 일이 일어나는지 + 근거 문서 번호 |
| 📊 상태 | 이야기 칸 6개 · 제목 · 수준 · S1/S2 신호 · 어른만 말한 횟수 · 생성 이미지 수 · 최근 로그 |
| ✅ 체크 | 기능 체크리스트 18개 |
| 🚫 금지 | 절대 하지 않는 것 |

## 그림 — ComfyUI로 만든 것과 아닌 것

`res/drawable/`의 PNG는 **우리 PC의 ComfyUI(krea2 turbo · 펠트 3D 그림체)** 로 만들고 BiRefNet으로 배경을 뺀 것입니다.
만든 스크립트: `tools/gen_assets.py`(배경·캐릭터) · `gen_heroes.py`(주인공 27장) · `gen_icons.py`(아이콘·소품) — ComfyUI HTTP API, 프롬프트가 안에 있음, 서버가 켜져 있어야 함. 에뮬레이터는 끄고 돌릴 것(GPU 메모리).

| 파일 | 무엇 |
| --- | --- |
| `bg_start` · `bg_space` · `bg_sea` · `bg_dino` | 시작 화면 무대 · 세계 배경 3장 |
| `mascot` | 마스코트 (앱 아이콘도 이걸로) |
| `hero_glasses` · `hero_blue` | 도감 프리셋 주인공 2명 |
| `hero_{short,long,tied}_{red,blue,yellow}_{none,round,square}` | 골라서 · 말로 만든 주인공 27장 (머리 × 옷 × 안경). 눈(반달 · 별)은 스티커 오버레이 — 위치는 `tools/find_eyes.py`가 찾아 `ui/HeroEyes.kt`에 씀 |
| `prop_*` | 책 미션 소품 — 장소별: 우주 불·물대포·비구름·별 우물 / 바닷속 진흙·스펀지·진주·조개 / 공룡 나라 용암·물대포·비구름·연못, 연기·거품·우산·반짝 |
| `ic_*` | 앱 아이콘 30개 — 마이크 · 다이얼 · 도구 4종 · 좋아/싫어 · 색/크기/표정 · 기분 3 · 해결 3 · 머리/옷/안경 옵션 · 스피커 · 책 · 크레용 · 화살표 (이모지 대신) |
| `dino_trex` · `dino_long` · `dino_horn` | 공룡 3종 (색 바꾸기는 색상 회전, 생성 없음) |
| `rocket` · `turtle` · `train` | 탈것 3종 |
| `nc_*` | 새 친구 카드 9장 |
| `gift_book` · `gift_crayon` | 선물 2개 |

**그림이 없어도 앱은 돕니다** — `ui/Assets.kt`가 이름으로 찾고, 없으면 `ui/Art.kt`의 벡터 그림(웹 데모 SVG 이식)으로 대신 그립니다.
골라서 · 말로 만든 주인공도 프리셋과 같은 펠트 그림(27장 + 눈 스티커)으로 보입니다. 아이가 그린 그림은 원본 그대로 + 흰 테두리.

## 구조

```
demo/
├── Model.kt      ← 장면 · 상태 · 장소 3곳(Theme) · 공룡 3종 · 아이 그림(Stroke) · 조사(이/가) 도우미
├── Director.kt   ← 질문 엔진. ask()가 마이크 온/오프 · 무응답 흐름 · 수준 신호를 맡는다
├── Scenes.kt     ← 장면 15개 대본 + 책 6쪽 자막(bookCaption)
└── Behind.kt     ← 장면별 "뒤에서" · 체크리스트 · 금지 목록
ui/
├── Assets.kt     ← 생성 그림 찾기(없으면 벡터) · 색상 회전
├── Art.kt        ← SVG 경로 파서 + 벡터 그림(마스코트 · 주인공 · 공룡 3종 · 로켓 · 외계인)
├── Theme.kt · Type.kt ← 색 · Jua 글꼴
└── Screen.kt     ← 무대 · 아래 띠(마스코트 · 말풍선 · 🎤 · ➡️) · 시연 서랍 · 그림판 · 책 · 미션 2종
MainActivity.kt   ← 가로 고정 · 전체 화면 · 길게 눌러 서랍 열기
tools/gen_assets.py ← ComfyUI로 그림 뽑는 스크립트
```

## 규칙 (근거 문서)

- **선택형 질문**(장면 3 장소 · 장면 7 공룡): 그림 카드 3장이 질문과 함께 처음부터 뜨고 마이크도 켜져 있음 (엔드픽처 초안 장면 3 · 25번 B안). 탭한 답은 수준 신호가 아니고, 고르기형 첫 턴 탭은 무응답이 아님 (⭐6).
- **열린 질문**(왜 · 어떻게 · 이름 · 제목): 카드 없이 마이크로만. 말이 없을 때만 더 쉬운 질문 → 그림 카드 (기획안 화면 4·5). 무응답: 다시 읽기 1 · 교체 2 → 마스코트 (⭐5 · ⭐22).
- 장면 4: '왜'에 이유를 말하면 S1, 되묻기 "그래서 어떻게 됐어?" — 물어본 결과는 S2가 아니고 마음 말하기는 판단에 안 씀. 장면 5: 이모가 먼저 말하면 "○○는 어떻게 생각해?" 한 번.
- 주인공 만들기(＋): 말로(머리 → 옷 → 안경 질문 → 녹음 → 답할 때마다 인형 미리보기 → 생성 → 좋아/싫어 → "뭘 바꿀까" 수정 2회 → 이대로/골라서) / 골라서(머리·옷·눈·안경 토글 12개 + 실시간 미리보기). 둘 다 같은 펠트 그림 27장 + 눈 스티커. 이야기 중 고정 (⭐20 · ⭐21).
  ※ 초안의 세 번째 질문 "공룡·자동차·별(좋아하는 것)"은 그림에 보이지 않아(옷 프린트가 전부 공룡) 데모에서는 "안경"으로 바꿨음 — 회의에서 확인 필요.
- 중간 확인: 색 · 크기 · 표정은 생성 없이 즉시, 모양 바꾸기만 재생성 2회 (⭐26 · 24).
- 책: 세계 배경 위에 확정 그림을 얹은 6쪽 · ◀ ▶ 넘기기 · 자막 띠 + 🔊 · 도구 4종(손 · 뿅망치 · 깃털 · 돋보기, 캐릭터를 누르면 반응) · **장소에 맞는 미션 2개** — 4쪽 문지르기(우주: 로켓 엔진 불을 물대포로 / 바닷속: 거북이 등 진흙을 스펀지로 / 공룡 나라: 기차 용암을 물대포로, 도구가 손가락을 따라옴, 3개가 줄어들다 연기·거품으로) → 5쪽 끌어다 놓기(비구름 → 별 우물·연못에 물이 차오름 / 진주 → 조개가 반짝, 도와주기면 톡톡 탭) · 장난 반응(공룡에 도구 · 주인공 위에 놓으면 우산) · 6쪽 공룡을 누르면 아이가 녹음한 소리 (⭐7 · 16).
- 끝: 선물 2개 차례로 → 책장 → 어두워짐, 다음 책을 권하지 않음 (⭐2 · ⭐9). 부모 모드: 오늘 대화로 채운 기록, 등급 · 비교 · 수준 이름 없음 (16).
