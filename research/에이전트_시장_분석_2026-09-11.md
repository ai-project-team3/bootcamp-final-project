## 0. 한 줄 결론

**우리 엔드 픽처를 구성하는 부품은 하나만 빼고 전부 시장에 이미 있다. 그런데 그것들을 한 제품에 합친 곳이 없다.** 화면을 보는 온디맨드 어시스턴트는 빅테크 전원이 유료 티어에 넣었고(전부 세션 한정), 상시 관찰 + 선제안은 Highlight AI 하나가 상용이며(월 $35~200, 유료는 클라우드 처리), 구석의 캐릭터는 OpenAI Codex Pets가 2026-05에 냈지만 화면을 보지 않는다(에이전트 상태 표시기). 페르소나 채팅은 완전히 범용화됐고, 출처가 달린 페르소나는 Delphi 하나, "원칙 대비 하루 채점"을 검증한 제품은 없다. 빈 자리는 **"상시 관찰 + 로컬 우선 + 규칙 기반 선제안 + 출처 있는 페르소나 렌즈 + 성장 추적"의 결합**이고, 그 결합은 6주 팀 범위 안에 들어온다. 단, **화면을 대신 조작하는 자동 실행은 넣지 않는다.** 그 영역은 이미 $20 티어 상품이면서 사고의 진원지다.

## 1. 엔드 픽처 수정 사항 (이번 회차 결정)

### 1-1. 멘토는 1인칭으로 말한다

"게이츠라면 ~할 거야" → **"나라면 지금 메모부터 쓸 거야."** 몰입이 목적이다. 단, 두 가지를 같이 둔다.

- **근거 줄은 3인칭으로 분리**한다. 말풍선은 1인칭, 카드 하단의 `근거:` 줄은 "2019 인터뷰, p.3"처럼 출처만 적는다. 1인칭 발화가 "그 사람이 실제로 한 말"로 오인되는 것을 막는 장치이자 환각 방어선이다.
- 1인칭은 **공유지 인물·본인 동의 인물·그릴링 커스텀**에서만 자연스럽다. 생존 유명인의 이름·초상으로 1인칭 발화를 시키는 것은 §5의 법제상 가장 위험한 조합이라 하지 않는다.

### 1-2. 펫 메뉴 이름 (5개)

원칙: 명사형 2어절, 명령형·구어 배제, 기능이 이름만 보고 드러날 것.

| # | 이름 | 하는 일 | 입력 |
|---|---|---|---|
| 1 | **업무 조언** | 현재 화면을 보고 상황 · 적용 원칙 · 다음 한 걸음 카드 | S1 스냅샷 (전역 단축키 병행) |
| 2 | **오늘의 기록** | 오늘 관찰 요약과 원칙 실천율 | S2 롤링 요약 |
| 3 | **성장 리포트** | 원칙별 추세, 지난주의 나와 비교 | 일일 로그 누적 |
| 4 | **멘토와 대화** | 현재 화면 맥락을 붙인 채 메인 창 대화 열기 | S1 + 대화 이력 |
| 5 | **관찰 일시정지** | 30분 / 1시간 / 오늘 종료 | — |

이전 초안의 "지금 도와줘 / 오늘 어땠어 / 나 vs 과거의 나 / 대화하기 / 잠시 조용히"는 폐기.

### 1-3. 제외

- **TTS 음성** — 제외. 말풍선 텍스트만.
- 나머지 엔드 픽처(메인 창 4탭, 펫 상태 4종, 하루 흐름)는 이전 회차 그대로.

**교차 관찰**
- 빅테크는 전원 **"사용자가 시작하고 끝내는 세션"**이다. Microsoft는 문서에 "user-initiated and session-bound"라고 명시했다. Recall 논란 이후 모두 이 선으로 후퇴했다.
- 상시 관찰 + 선제안을 하는 상용 제품은 **Highlight AI 하나**. 그마저 로컬 처리는 무료 티어에만 있다. "상시 + 로컬 + 선제안" 셋을 다 갖춘 상용 제품은 확인되지 않았다.
- 프라이버시 설계는 다섯 가지로 수렴했다: 옵트인 · 시각 표시등 · 앱/사이트 제외 목록 · 민감 카테고리 자동 차단 · 짧은 보관. **이 다섯을 다 갖추면 업계 표준을 충족한다.**
- 스크린샷 보관 기간을 공개한 곳은 Microsoft뿐. OpenAI·Google·Anthropic은 **미확인**.

**교차 관찰**

## 4. 재사용할 것

| 용도 | 후보 | 라이선스·비고 |
|---|---|---|
| 투명 always-on-top 창 골격 | **BongoCat** (Tauri + Vue + Rust, 23.1k★) | MIT, 3 OS 검증. Tauri를 고르면 이것 |
| 같은 용도, Electron | **clawd-on-desk** (6.2k★) | Codex Pets 애니팩 호환 → 스프라이트 에셋 재사용 가능 |
| 넛지 플러그인·알림 쿼터 모델 | openpets SDK v3 (Electron) | 스케줄·알림·쿼터 내장 |
| 발화 예산 구조 | pet-mochi (Tauri 2 + Svelte 5 + SQLite) | 로컬 룰 3초 + LLM 90초 쿨다운. 별 2개지만 구조가 정확히 우리 것 |
| 화면 감지 → LLM 행동 선택 예제 | Desktop-Virtual-buddy (Electron + TS) | N초마다 스크린샷 → LLM. **통제가 없으니 구조만 참고** |
| 로컬 화면 인덱싱 | Screenpipe | 로컬 SQLite, 우리 S2 대체재로 검토 가치. 다만 원본 저장이라 우리 원칙과 충돌 |
| 아바타 | Live2D (Open-LLM-VTuber, MIT) | VRM(Mate-Engine)은 AGPL 혼합이라 회피. Unity는 6주 밖 |
| 비전 모델 | 벤더 API (스냅샷은 온디맨드, S2는 규칙 우선이라 호출 수가 묶임) | 비용은 W1 스파이크에서 실측 |

Electron vs Tauri: 팀이 React를 이미 쓰므로 Electron + clawd-on-desk가 진입이 빠르다. Tauri는 바이너리가 작고 Rust 캡처 코드를 쓸 수 있지만 팀에 Rust 경험이 없으면 W1을 잃는다. **W1 스파이크에서 둘 다 "투명 창 + 전역 단축키 + 스크린샷" 데모를 만들어 보고 하루 안에 결정.**

## 5. 위험 — 시장이 이미 보여준 것

1. **캐릭터만으로는 안 남는다.** Mico·Grok Companions·Dot이 1년 안에 죽었다. 발표에서 펫을 앞세우면 "귀엽네요"로 끝난다. 앞세울 것은 **같은 화면, 멘토 셋, 다른 다음 걸음** 장면과 페르소나 판별률 숫자다.
2. **선제안은 조종 가능해야 산다.** Pulse 종료 사유가 "steerable by the user". 관찰 일시정지·빈도 상한·트리거별 토글 없이 선제안을 내면 Rize처럼 "mostly annoying"이 된다.
3. **유휴 타이머 트리거는 오탐한다.** CHI 2025가 "가만히 있음 = 생각 중"을 오판한 것이 방해의 주원인이라고 보고. 정체 트리거는 태스크 경계와 결합할 것.
4. **Highlight AI가 가장 가까운 경쟁자**다. 상시 + 선제안 + 초안까지 한다. 우리가 다른 점은 로컬 우선 요약 · 페르소나 렌즈 · 성장 추적 세 가지뿐이고, 발표 때 이 셋을 명시해야 "Highlight 축소판"으로 안 읽힌다.
5. **Microsoft Scout가 프리뷰 중**이다. 캘린더·메일 상시 관찰 + 자율 행동. 우리가 캘린더 연동을 스트레치로 두는 이유 중 하나. 핵심을 거기 두면 W6 전에 GA가 나올 수 있다.
6. **법제는 움직이는 중.** 부경법 전면 개정 위원회가 2026-04에 출범했고 "디지털 페르소나 생성"을 명시했다. 6주 안에 바뀔 확률은 낮지만, 발표 자료에 "안전 경로만 사용"을 한 줄 넣는 것이 방어.
7. **AI 기본법 고지 의무** (2026-01 시행). 멘토 발화가 AI 생성임을 UI에 표시. 말풍선 하단 한 줄이면 된다.

## 6. 결론 — 무엇을 짓고 무엇을 소비하나

**짓는 것**: 원칙 루브릭 컴파일러, 규칙 기반 S2 관찰과 선제안 예산, 페르소나 렌즈를 통한 업무 조언 카드, 성장 리포트와 그 재현성 검증, 프라이버시 5종. 이 다섯이 이전 회차의 역할 5개와 일치한다.

**소비하는 것**: 비전 모델 API, 투명 창 골격(OSS), 스프라이트 에셋 포맷(Codex Pets 호환).

**절대 안 짓는 것**: 브라우저·OS 조작 에이전트, "인젝션에 안전한" 에이전트, 자체 computer-use 모델, 생존 유명인 페르소나.

시장 지도에서 우리 위치는 **Highlight AI(상시·선제·클라우드)와 Codex Pets(펫·상태만) 사이의 빈 칸**이고, 그 칸의 이름은 "누구의 눈으로 내 화면을 보는가"다.
