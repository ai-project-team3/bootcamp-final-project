# [P1] #8 항목이 30~50개로 닫히나

**티어**: P1 · 외부 검증 — 담당자 조사 → 전원 판단
**담당**: 역할 2 담당
**마감**: #5는 9/11(금), 나머지 9/18(목)
**출처**: §10-4
**영향**: 항목 풀 스키마(#2) · 매칭 난이도
**실패 시**: 영업 유형을 더 좁혀야 함

**왜 공백인가**
항목 풀이 닫히지 않으면 §2-1의 설계 원칙("만들지 않고 고른다")이 무너집니다. 실제로 템플릿 초안을 써봐야 알 수 있습니다.

**힌트**: 보험 상담 한 종만 끝까지 써보기. 50개를 넘으면 유형을 쪼개는 신호

---

## 결정서

### ① 결정
한 문장으로. "무엇을 이렇게 한다"

> 보험 상담 한 종을 기준으로 항목 풀 초안을 실제로 끝까지 써본 결과 **39개 항목**으로 닫힘을 확인했고, 이 개수(30~50 범위)를 1차 기준으로 채택한다.

### ② 근거
왜 그렇게 정했나. 조사했으면 출처를 남기세요

- 인터뷰·현장 확인이 불가능해 힌트대로 "보험 상담 한 종을 끝까지 써보는" 방식으로 직접 초안을 작성함. 보험 판매 프로세스(니즈분석 → 상품설명 → 반론처리 → 청약 → 컴플라이언스)를 기준으로 항목을 나열함:

| 카테고리 | 항목 수 | 예시 |
|---|---|---|
| A. 오프닝/라포 | 3 | 자기소개, 상담시간 안내, 개인정보 동의 안내 |
| B. 니즈분석-기본정보 | 7 | 나이/직업, 가족구성, 소득수준, 기존보험 유무·내용 |
| C. 니즈분석-리스크 | 6 | 건강상태/병력, 가족력, 흡연여부, 재무목표, 예산, 보장 우선순위 |
| D. 상품설명 | 8 | 상품종류, 주계약/특약, 보험료 산출근거, 납입·보험기간, 해지환급금, 면책사항, 상품비교 |
| E. 반론처리 | 5 | 보험료 부담, 필요성 의문, 타사 비교 요청, 가족상의 필요, 가입시기 보류 |
| F. 청약/클로징 | 6 | 청약의사 확인, 필요서류, 서명절차, 청약철회 안내, 첫납입 안내, 후속조치 |
| G. 컴플라이언스(법정 필수) | 4 | 상품설명서 교부, 적합성 진단, 중요사항 설명 확인, 완전판매 모니터링 안내 |
| **합계** | **39** | |

- 특히 G(컴플라이언스) 파트는 임의로 만든 게 아니라, 실제 금융당국 규제인 **"3대 기본지키기"**(청약서 부본 전달·약관 전달 및 중요내용 설명·계약자 자필서명 — 이행 안 하면 계약일로부터 3개월 이내 청약철회·환급 가능)가 근거임. 이게 항목 풀이 임의로 "너무 적게" 수렴하지 않게 하는 하한선 역할을 함.

### ③ 탈락 대안
무엇을 안 골랐고 왜. 최소 하나

- **"항목 개수를 추정/역산으로 결정한다"** — 기각. 힌트가 명시한 대로 "실제로 써봐야 알 수 있는" 항목이라 리서치나 추정으로는 답이 안 나옴. 직접 초안을 끝까지 작성하는 방법 외엔 대안이 없었음.

### ④ 계약 영향
P0 4개(화자 분리 / 항목 풀 스키마 / 상태 전이표 / 미팅 연결키)를 건드리나?

☑ 건드리지 않음 — 담당자가 결정합니다
☐ P0 계약을 건드립니다 — 결정하지 말고 조장에게 올립니다

> 항목 풀 스키마(P0 #2, 조장 결정)가 정한 "필드 구조" 안에서 "몇 개가 채워지는지" 확인한 것뿐, 스키마 자체(필드 정의)를 바꾸는 결정은 아님. 단, **50개를 넘겼다면** 힌트대로 "영업 유형을 쪼개라"는 신호라서 조장에게 올려야 했을 텐데, 이번엔 39개로 범위 안에 들어와서 에스컬레이션 불필요.

### ⑤ 첫 구현 스텝
이 결정대로면 W1(9/14~)에 내가 무엇부터 만드나

> 위 39개 초안을 팀 내부 검수(특히 보험 도메인 용어 정확도) 받은 뒤 fixture 데이터로 확정하고, 매칭 알고리즘(#2 항목 풀 스키마와 연동) 1차 테스트에 바로 투입한다.

**추가 조사 결과 (2차)**
39개 초안의 신뢰도를 더 올리려고 두 방향으로 추가 검색함:
1. 실제 보험사 상담 스크립트/체크리스트 원문 — 검색으로는 못 찾음(보험사 내부 교육자료라 비공개인 것으로 보임). 다만 "설계사 상담 시 확인해야 할 질문 리스트"류 정리 글에서 "보장범위·제외항목·갱신조건·청구난이도"를 꼭 물어야 한다는 조언을 확인 — 이미 D(상품설명)·E(반론처리) 카테고리에 대응 항목이 있어 초안과 어긋나지 않음.
2. 금융위 "온라인 설명의무 가이드라인"(공식 PDF, 20페이지)을 직접 내려받아 확인 시도 — 텍스트 추출 도구(poppler) 미설치로 이번 세션에서는 못 읽었음. 이건 진짜 1차 규제 자료라 확인 가치가 커서, **이어서 다시 시도하거나 팀이 직접 열어보는 걸 추천**: [원문 링크](https://www.fsc.go.kr/comm/getFile?srvcId=BBSTY1&upperNo=78276&fileTy=ATTACH&fileNo=6)

**결론**: 39개 초안은 간접 근거로는 계속 뒷받침되지만, **보험사 실제 스크립트 원문 대조**는 여전히 못 함(비공개 자료라 온라인 리서치의 구조적 한계). 팀에서 실제 상담 스크립트나 설계사 확인을 거쳐야 최종 확정 가능하다는 결론은 그대로 유지.
