# assets — 미리 만든 그림

**데모용으로 미리 만들어 둔 그림이다.** 앱이 이것을 겹쳐서 책을 만든다.

⚠️ **제품에서 그림을 언제·무엇으로 만들지는 아직 안 정했다.** 여기 있는 것은 초안 단계에서
ComfyUI로 뽑은 것이고, **그 방식이 확정됐다는 뜻이 아니다.** 한 장에 몇 초 걸리는지 재고 정한다.

- **부적절한 그림은 사람이 검수한다.** 자체 호스팅 모델에는 안전 필터가 없다.
  세션 중에 만드는 쪽으로 가면 **무엇이 대신 거를지가 새 숙제**가 된다
- FLUX 비상업 라이선스도 **오프라인 제작 도구로는 허용**된다 (모델의 서비스 투입만 금지)

| | |
|---|---|
| `tools/render.py` | **ComfyUI HTTP API 호출.** SDXL base 1.0 · 28 steps · cfg 6.5 · dpmpp_2m/karras. **주석에 프롬프트 요령 7개**가 있다 |
| `tools/cutout.py` | **배경 제거** (BiRefNet 없이). 흰 배경 → 투명 PNG. ⚠️ **이미 자른 RGBA를 또 자르지 않게** 가드가 있다 |
| `tools/gen_*.py` | 에셋 일괄 생성 |

근거: 노션 「기능별 모델선정」 §2-3
