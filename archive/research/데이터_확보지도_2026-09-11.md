|---|---|
| **AI Hub** (aihub.or.kr) | 휴대폰 본인인증 후 신청하면 일반·외부 데이터는 **자동승인**됨 [확인 — AI Hub FAQ 검색 요약] · 대부분 데이터셋에 "**내국인만 데이터 신청이 가능합니다**" 문구가 있음 [확인 — 개별 데이터셋 페이지 여러 곳] · **국외 반출**과 **제3자 제공·양도·판매**는 수행기관과 NIA의 별도 합의 없이 금지 [확인 — 이용정책] · 판매 등 상업적 이용은 수행기관과 별도 협의 필요, 일부(대회·KETI 등)는 비상업 연구만 허용 [확인] · 다운로드는 PC에서만 되고, 분할 압축이라 리눅스 명령으로 병합해야 함 [확인] |
| **AI Hub 안심존** | 원데이터를 **다운로드할 수 없음**. 원격 GPU(V100 32GB)에서만 분석하고, 모델 반출은 따로 신청 [확인] · 보건의료 데이터는 **IRB 심의 결과 통지서 + IRB 승인 연구계획서 + 소속 증빙**이 필요 [확인] · 심사 최대 2주 [확인] |
| **공공데이터포털** (data.go.kr) | 대부분 **개발계정 자동승인**이고 1~2시간 안에 호출 가능, 일부는 24시간 이상 걸림 [확인] · 개발계정 트래픽은 API마다 **1,000~10,000건/일**이고, 운영계정으로 늘리려면 활용사례를 등록해야 함 [확인 — 개별 API 페이지] · 이용허락범위는 API마다 다름("제한 없음"이 많음) [확인 — e약은요, 약국 API] |

## 2. Red flags — 데이터가 있어 보이지만 실제로는 못 쓰는 경우

1. **AI Hub 헬스케어 = 안심존 + IRB.** 수면(71400), 피부상태(71645), 영유아 행동(631), 웰니스 상담(267)은 다운로드가 안 되고 IRB 승인서가 필요합니다 [확인]. 부트캠프 팀은 IRB를 받을 소속 기관이 없어서, 6주 안에는 **사실상 불가**합니다.
2. **AI Hub '국외 반출 금지'와 외부 LLM API.** 원데이터를 해외 LLM API(Claude·OpenAI)에 보내거나 해외 클라우드에 올리는 것이 "국외 반출"에 해당할 수 있습니다 [미확인 — 해석 문제]. 학습 데이터로 로컬에서만 쓰고, 원문을 프롬프트에 넣지 않는 편이 안전합니다. 팀원 중 외국 국적자가 있으면 신청할 수 없습니다 [확인 — 내국인만].
3. **AI Hub 상업 이용.** B2C 서비스로 운영하려면 수행기관과 별도 협의가 필요합니다 [확인]. 데모·포트폴리오 수준은 문제없지만, "실제 출시"를 내세우면 막힙니다.
4. **Spotify는 2026년에 사실상 막혔습니다.** 개발 모드는 사용자 5명·Premium 필수이고, audio features와 추천이 사라졌으며, 확장하려면 MAU 25만 법인이어야 합니다 [확인]. **음악 추천·분석 주제는 Spotify에 기댈 수 없습니다.** 멜론·지니는 공개 API가 없습니다 [미확인].
5. **iOS 스크린타임 데이터는 앱 밖으로 나오지 않습니다.** DeviceActivityReport 샌드박스 때문에 서버 분석이나 LLM 코칭이 불가능합니다 [확인]. 디지털 웰빙 주제는 **Android 전용**으로 가야 합니다.
6. **건강 데이터 과거 이력.** Health Connect는 기본 30일까지만 [확인], iOS Screen Time은 약 한 달까지만 [확인] 읽을 수 있습니다. "1년 추세 분석"은 데모 첫날에 불가능합니다. 삼성 헬스 직접 연동은 배포 전 파트너 승인이 필요합니다 [확인].
7. **Google Calendar.** Testing 모드는 refresh token이 7일마다 만료되고 사용자 100명 제한이 있습니다 [확인]. 데모는 되지만, 발표 주간에 토큰이 끊기지 않게 관리해야 합니다.
8. **"가짜"이거나 연구 전용인 공개 데이터.** Kaggle 수면 데이터는 **합성** 데이터라 성능 주장의 근거가 되지 않습니다 [확인]. MovieLens는 비상업 전용 [확인], Food-101은 연구 fair use 전용 [확인], Amazon Reviews 2023은 라이선스 표기가 없습니다 [확인].
9. **개인 금융 거래내역.** 마이데이터와 오픈뱅킹은 사업자 자격이 필요합니다 [확인]. 가계부·소비 분석은 **직접 입력이나 영수증 OCR**로만 가능합니다.
10. **호출 한도가 병목입니다.** YouTube는 하루 검색 100회 [확인], 서울 실시간 지하철은 1,000건/일 [확인], 정보나루는 IP 미등록 시 500건/일 [확인], data.go.kr 개발계정은 1,000~10,000건/일 [확인]입니다. 사용자당 실시간 호출 구조라면 **캐싱이나 배치 적재가 필수**입니다.
11. **Reddit·해외 커뮤니티 데이터**는 2026년 정책상 모든 접근에 사전 승인이 필요합니다 [확인 — 2차 출처]. 국내 커뮤니티 크롤링은 약관·저작권 위험이 있습니다 [미확인].
12. **정신건강 주제**는 공개된 감정 대화 말뭉치(86)는 쓸 수 있지만 [확인], 임상 상담 데이터는 안심존입니다 [확인]. 게다가 사용자 상담 로그를 수집하는 순간 민감정보 처리 동의가 필요합니다 [미확인 — 개인정보보호법 제23조 해석].
13. **Open Food Facts의 한국 커버리지**는 확인하지 못했습니다 [미확인]. 바코드 스캔 주제라면 첫 주에 국내 제품 50개로 적중률을 먼저 측정해야 합니다.
