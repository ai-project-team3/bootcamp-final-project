# 10. 기능별 현황 — 무엇을 쓰기로 했고, 어디까지 됐나 (2026-09-22 밤)

**다른 세션에서 깃만 읽고 바로 이어 일하기 위한 문서다.** 기능마다 「정해진 것 · 근거 · 아직 아닌 것」을 적는다.
근거가 없는 줄은 없다 — 전부 `eval/results.md` 절 번호나 커밋으로 잇는다. **표를 바꾸는 것은 측정값뿐이다** (`CLAUDE.md`).

⚠️ **앱은 아직 전부 대본이다.** `android/`에는 `INTERNET` 권한이 없고, `backend/`의 `/stt` · `/judge` · `/story`는
`NotImplementedError`다. 아래 「정해진 것」은 **붙일 때 이렇게 붙인다**는 결정이지 붙었다는 뜻이 아니다 (`9_역할과_작업.md` §9-2).

## 기능별

### 1. 받아쓰기 (STT)

| | |
|---|---|
| **쓴다** | **자체 GPU `faster-whisper large-v3-turbo` (int8_float16)**. 낱말 편향(`initial_prompt`)은 **안 쓴다** |
| 음성 경로 | 폰 → 우리 서버까지만. **외부 STT 로 안 보낸다.** 전사 직후 삭제 |
| 근거 | 성인·폰 마이크·프리셋 문장에서 **편향 없이 23/23**, p50 0.31초 (`results.md` 09-22 저녁). 09-19 폰 온디바이스 65%는 **폰 인식기의 숫자**였다 |
| 편향을 안 쓰는 이유 | 프리셋 100%→100%로 얻은 것 없고, 무음에 넣어 준 낱말을 그대로 적었다(5회) |
| Grok Voice Transcribe 2.0 | 측정했다 — 프리셋 96~100%, p50 0.65초, 무음 5/5 빈칸. **앞선 것은 무음 처리 하나**이고 그건 우리가 막았다. 외부 전송 근거 없음 → **후보로만 남긴다** (`docs/조사_받아쓰기_후보검토.md`) |
| 파인튜닝 | whisper 는 된다(가중치 공개). Grok 은 문서에 없다. 아이 음성 파인튜닝 전례 120.8%→19.1%는 **base 모델** 기준 |
| **아이 목소리 — 7세 (09-23 오전)** | AI-Hub 샘플 7세 여아 1명 2,000발화: CER 8.1% · 어절 보존 80% (`results.md` 09-23). 전례 120.8% 는 whisper **base** 였다 |
| **아이 목소리 — 3~6세 (09-23 오후)** | **화자 260명 3,681발화** · 같은 클립을 두 모델로 (`results.md` 09-23 오후):<br>CER **turbo → large-v3**: 3세 57 → **37%** · 4세 35 → **28%** · 5세 26 → **15%** · 6세 17 → **12%**<br>어절 보존: 3세 32 → **53%** · 5세 63 → **76%** · 6세 72 → **81%** · 지연 p50 0.33 → **0.56초**<br>한 살마다 약 10%p. 한글 아닌 출력 3.7%(모델 크기로 안 줄어듦 — 필터가 버린다). **우리 대상 한가운데(4~5세)가 키워드 보존 합격선 90% 와 멀다.** 오전의 「파인튜닝 전제가 안 선다」는 7세에만 맞는 말이었다 |
| **권고 (조장 결정 대기)** | **받아쓰기 기본값을 `large-v3`(원본) 로.** 0.23초를 내고 3~5세 CER 이 절반. VRAM +0.5GB 로 조합 A 안. 결정되면 `CLAUDE.md` 모델 표를 고친다 |
| 다음 순서 | ① 나이별 합격선 다시 정하기 → ② 3~6세 **프리셋 문장** 매칭률 (자유 문장보다 쉬울 것) → ③ v3 LoRA 파인튜닝 가능 여부(3060 12GB) — 전례 120.8→19.1% 가 이 데이터셋이다 |
| **아직 아닌 것** | **3~6세** — 샘플에 없다. AI-Hub 108 의 3~6세 묶음을 받아 여러 화자로 다시 잰다(조장). 짧은 답 · 거실 소음 · 핵심 키워드 30발화 손표시. `/stt` 구현. `DiagnosticsActivity.kt`의 VAD 코드를 본체로 옮기기 |

### 8. GPU 한 장에 무엇이 올라가나 (RTX 3060 12GB)

| | |
|---|---|
| **정했다** | **조합 A** — 그림(8.6GB) + 받아쓰기(+1.0GB) + 화자분리(+0.8GB) = 10.4GB, 15분 세션 동안 안 는다 (`results.md` 09-21 조합 A) |
| ⚠️ 시간은 나눈다 | 겹쳐 돌리면 **받아쓰기가 0.71→2.54초(3.6배)**. 그래서 **아이가 말하는 동안 그림을 만들지 않는다** (`results.md` 09-21 겹쳐 돌리면) |
| 화자 분리 | `pyannote 3.1` 측정은 했다(+783 MiB, 15분 1.3초). **협업 모드에서는 필요 없어졌다** — 부모 질문은 화면이 알고 있어 모델이 가릴 일이 없다(09-22). **동화·일기 모드는 다르다** — 어른이 옆에서 말할 수 있고 그건 미리 설계돼 있지 않다. 그래서 **범위 밖이지 삭제가 아니다** (`9_역할과_작업.md` §9-8). GPU 자리(조합 A)와 `stt_eval.py` 의 화자 열은 그대로 둔다 |
