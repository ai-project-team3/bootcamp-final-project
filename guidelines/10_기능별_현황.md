# 10. 기능별 현황 — 무엇을 쓰기로 했고, 어디까지 됐나 (2026-09-22 밤)

**다른 세션에서 깃만 읽고 바로 이어 일하기 위한 문서다.** 기능마다 「정해진 것 · 근거 · 아직 아닌 것」을 적는다.
근거가 없는 줄은 없다 — 전부 `eval/results.md` 절 번호나 커밋으로 잇는다. **표를 바꾸는 것은 측정값뿐이다** (`CLAUDE.md`).

⚠️ **앱은 아직 전부 대본이다.** `android/`에는 `INTERNET` 권한이 없고, `backend/`의 `/stt` · `/judge` · `/story`는
`NotImplementedError`다. 아래 「정해진 것」은 **붙일 때 이렇게 붙인다**는 결정이지 붙었다는 뜻이 아니다 (`9_역할과_작업.md` §9-2).

 │ 백엔드  규칙 금칙어 (blocklist.py) → LLM 안전 필터

 │ 폰      수준·미션·이벤트 집계는 규칙이 (규칙 4)
 │ OpenAI  낭독 gpt-4o-mini-tts — 아이 말을 되비추는 본 대사          리액션 6마디는 미리 구워 폰에 (0ms)
 │ 우리GPU 그림 ComfyUI + SDXL-Lightning 8스텝 — 배경·캐릭터           검사 없이 아이 화면에 안 보낸다 (규칙 8)
 └ story_ready → /story (luna) → 장면 6개 + 자막 → 책

## 기능별

### 1. 받아쓰기 (STT)

| | |
|---|---|
| **쓴다** | **자체 GPU `faster-whisper large-v3-turbo` (int8_float16)**. 낱말 편향(`initial_prompt`)은 **안 쓴다** |
| 음성 경로 | 폰 → 우리 서버까지만. **외부 STT 로 안 보낸다.** 전사 직후 삭제 |
| 근거 | 성인·폰 마이크·프리셋 문장에서 **편향 없이 23/23**, p50 0.31초 (`results.md` 09-22 저녁). 09-19 폰 온디바이스 65%는 **폰 인식기의 숫자**였다 |
| 편향을 안 쓰는 이유 | 프리셋 100%→100%로 얻은 것 없고, 무음에 넣어 준 낱말을 그대로 적었다(5회) |
| Grok Voice Transcribe 2.0 | 측정했다 — 프리셋 96~100%, p50 0.65초, 무음 5/5 빈칸. **앞선 것은 무음 처리 하나**이고 그건 우리가 막았다. 외부 전송 근거 없음 → **후보로만 남긴다** (`docs/조사_받아쓰기_후보검토.md`) |
| 파인튜닝 | whisper 는 된다(가중치 공개). Grok 은 문서에 없다. 아이 음성 파인튜닝 전례 120.8%→19.1%는 **base 모델** 기준 |
| **아직 아닌 것** | **아이 목소리로 한 번도 안 쟀다** (AI-Hub 승인 대기). 거실 소음·거리. `/stt` 구현. `DiagnosticsActivity.kt`의 VAD 코드를 본체로 옮기기 |

### 2. 헛문장 거르기 (STT 뒤)

| | |
|---|---|
| **쓴다** | `backend/app/filters/hallucination.py` — 전사가 **통째로** 알려진 헛문장(「감사합니다」「다음 영상에서 만나요」「아멘」…)이면 버린다. 버리면 폰은 「대답 없음」 |
| 근거 | whisper 는 무음 5/5에서 유튜브 자막 문장을 지어냈고 **금칙어 필터에 안 걸린다** (규칙 5). 목록만으로 폰 녹음 무음 5/5 걸러냄, 맞게 받아쓴 말 0건 버림 (`results.md` 09-22 밤) |
| 안 쓰는 것 | `no_speech_prob`(turbo 는 늘 0) · 서버 말소리 길이 재기(폰 VAD 판단을 뒤집을 뿐, 진짜 말 4건 버림) |
| **아직 아닌 것** | 소음이 평범한 낱말(「고춧가루」)로 된 경우는 통과. 아이 음성에서 헛출력 모양 확인 |

### 3. 이름 가리기 · 금칙어 · 안전

| | |
|---|---|
| **쓴다** | 이름 가리기 **폰**(매핑표 폰에만) → 백엔드 규칙 금칙어 `blocklist.py`(`8_금칙어.md`, 허용 목록이 이긴다) → LLM 안전 필터 |
| 원칙 | 과차단이 놓치는 것보다 위험하다 — *무섭다·괴물·싸웠다* 는 이야기 재료 (규칙 7) |
| **아직 아닌 것** | 폰 이름 가리기 구현. LLM 안전 필터 프롬프트 측정 |

### 4. 판정 (어느 칸이 찼나 · 다음 질문 · 끝났나)

| | |
|---|---|
| **쓴다** | **`gpt-5.6-luna`** (OpenAI) — 16필드 평면 JSON. 프롬프트 `eval/judge_prompt_demo.md`, 스키마 `judge_schema_demo.json`. **id 는 프롬프트에 안 넣는다** (09-22) |
| 근거 | JSON 100% · 21.6원/권 (`results.md` 09-20 저녁). `claude-haiku-4-5` 품질 동률·7배 비쌈. `gpt-5-nano` · `ministral-3-3b` 탈락, `mistral-small` 실행 불가 |
| ⚠️ 지연 | p95 가 **2.389초(09-20) → 3.789초(09-22)** 로 흔들린다. 여러 날 다시 재야 한다 |
| **Jev (TypeSafe)** | **판정 모델이 아니다. 조사만 했다.** 16필드 중 9개만 물을 수 있고(Choice·Score·Noul), 그 9개는 루나보다 낫고 5배 빠르다(p95 0.73초, 88.6%). **쓰려면 호출이 둘로 갈라진다.** 아동 데이터 조건(ZDR 없음·18세 미만 배제)이 먼저 막는다. **발표에 넣지 않는다** (`docs/조사_Jev_판정모델_검토.md`) |
| **아직 아닌 것** | `/judge` 구현 · 앱은 Kotlin `when` 대본(`StoryBank.kt judge()`). 모드별 평가 20건 gold 라벨(사람이 붙인다, `eval/fixtures_mode.jsonl`) |

### 5. 이야기 · 대사 생성

| | |
|---|---|

### 6. 목소리 (TTS)

| | |
|---|---|
| **쓴다** | **`gpt-4o-mini-tts` API (voice `coral`)** — 본 대사는 아이 말을 되비추므로 **매번 API**. **리액션 6마디(「음~」「그랬구나」…)는 같은 목소리로 미리 구워 폰 번들에** — VAD 가 말 끝을 잡는 즉시 0ms 재생 |
| 근거 | 폰 TTS 탈락(9/19 귀 판정 3연속 「아니오」). Clova 탈락(값). 리액션 한 마디로는 구멍을 못 덮고 **두 마디(4.11초)** 를 잇는다 (`results.md` 09-21 리액션) — ⚠️ 판정 p95 가 3.79초면 **두 마디로도 부족(5.11초)** |
| 원칙 | 구운 리액션은 **내용 중립** — 판정 전에 나가므로 아이 말을 모른다 |
| **아직 아닌 것** | `coral` 귀 판정(마스코트 목소리로 쓸 만한가). 목소리 후보 비교. 앱 연결 |

### 7. 그림

| | |
|---|---|
| **쓴다** | **우리 GPU · ComfyUI + SDXL + Lightning 8스텝 LoRA, cfg 1.0**. 세션 중 **배경**(장소 칸이 차면 뒤에서) 과 **캐릭터**(아이 말대로) 를 만든다. 만지는 소품은 프리셋을 **배경을 읽어 계산한 자리**에 얹는다 (`assets/tools/place_props.py` — 지평선·평탄도·원근) |
| 근거 | 배경 3.74초 · 캐릭터 2.67초 · 입 인페인트 2.32초 (`results.md` 09-21). 4스텝은 7.5배 빠르지만 화풍이 바뀌어 탈락 |
| 움직임 | 관절 분리는 **못 한다**(통짜로 나온다). **입만 인페인트로 다시 그리고** 몸통은 흔들어 걷기 표현 |
| 안전 | 자체 모델에는 필터가 없다 — **검사 없이 아이 화면에 안 보낸다.** 8초 안 오면 「조금 뒤에」, 15초 넘으면 프리셋 |
| **아직 아닌 것** | 모델 비교(SDXL 하나만). 검사 방법. 앱 연결(지금 `pause(2400)`) |

### 8. GPU 한 장에 무엇이 올라가나 (RTX 3060 12GB)

| | |
|---|---|
| **정했다** | **조합 A** — 그림(8.6GB) + 받아쓰기(+1.0GB) + 화자분리(+0.8GB) = 10.4GB, 15분 세션 동안 안 는다 (`results.md` 09-21 조합 A) |
| ⚠️ 시간은 나눈다 | 겹쳐 돌리면 **받아쓰기가 0.71→2.54초(3.6배)**. 그래서 **아이가 말하는 동안 그림을 만들지 않는다** (`results.md` 09-21 겹쳐 돌리면) |
| 화자 분리 | `pyannote 3.1` 측정은 했으나 **설계에서 뺐다** (09-22, 협업 모드가 「부모가 질문을 미리 넣는」 방식이 되어 매 턴 화자 판정이 필요 없어짐) |

### 9. 부모 리포트 · 협업 모드

| | |
|---|---|
| **정했다** | 점수·등급·또래 비교 **없음** — 횟수와 원문 인용만 (규칙 9). LLM 문장에 금지어가 하나라도 있으면 버리고 미리 만든 문장 |
| 협업 모드 | **부모가 부모 모드에서 질문을 미리 넣고, 마스코트가 읽고, 아이가 답한다.** LLM 은 질문 추천 정도. 부모는 칸을 채우지 않는다 → 「누가 지었나」 표시는 지웠다 (09-22) |
| 출처 | `by` 는 `child · card · mascot` 셋뿐. 부모 질문은 `speaker=adult` 이벤트로만 |
| **아직 아닌 것** | 보호자 열람·정정·삭제 · 보존 수명주기 · AI 음성 고지 · 아이/부모/AI 분리 표시 — **설계는 조장, 화면은 진웅** (`docs/멘토조사_여섯.md`) |
