# 1. 시스템 개요

---

## 1-1. 한 세션이 도는 순서

```
🧒 아이가 말한다
   │
   ├─ 폰      말소리 구간만 자른다 (Silero VAD)
   ├─ GPU     글자로 바꾼다 — 음성 사본 즉시 삭제
   ├─ 폰      이름을 가린다 {주인공} {친구1} — 매핑표는 폰에만
   ├─ 백엔드  규칙 금칙어 → LLM 안전 필터
   ├─ LLM     판정 — 어느 칸이 채워졌나 · 다음에 뭘 물을까 · 이야기가 다 찼나
   ├─ 폰      수준·미션 난이도·이벤트 집계는 규칙이 한다
   └─ 앱      마스코트가 받아주고 · 되돌려주고 · 다음을 묻는다
              │
              └─ story_ready → 장면 6개 + 자막 → 미리 만든 그림을 겹쳐 책이 된다
```

**그림은 세션 중에 만든다.** 배경은 아이 말대로 만들고, 만지는 것들은 미리 만들어 두고 얹는다.
아이가 중간에 좋아/싫어를 고르고, 싫으면 **최대 2회** 다시 만든다.

## 1-2. 화면

| # | 화면 | 무엇 |
|---|---|---|
| 1 | 시작 | 앱 이름 · [같이 만들자] |
| 2 | 함께하기 | 누구와 하는지 고른다 |
| 3 | 주인공 만들기 | 프리셋 또는 그림판 |
| 4 | **이야기 짓기** | **턴 엔진이 도는 곳.** 마스코트 질문 → 아이 말 → 판정 → 반응 |
| 5 | 확인 카드 | 모호한 낱말을 좁힌다 (3장) |
| 6 | 그림판 | 아이가 직접 그린다 — **AI가 다시 그리지 않는다** |
| 7 | 소리 녹음 | 울음소리 — **폰 밖으로 안 나간다** |
| 8 | 미션 | 손으로 문제를 푼다 (탭 · 문지르기 · 당겼다 놓기 등 5종) |
| 9 | 친구 평가 | 좋아 / 싫어 — 다음에 또 볼지 |
| 10 | **책 읽기** | 그 자리에서 바로 펼쳐 읽는다 |
| 11 | 책장 | 만든 책이 쌓인다 |
| 12 | 부모 모드 | 비밀번호 4자리 → 오늘의 기록 |
| 13 | **신고** | **Play 스토어 필수.** 부모 모드와 책 읽기 화면에서 부른다 — *"이 내용을 신고할게요"* |

**「친구 평가」(9)는 「책 읽기」(10) 다음이다** (9/18 확정). 책을 읽고 나서 좋아/싫어로 다음에 또 볼지 정한다.
**「신고」(13)는 빼지 못한다** — AI 생성 콘텐츠 앱의 Play 스토어 필수 요건이고 온디바이스여도 면제되지 않는다.

## 1-3. 모듈

**역할 배정은 아직 확정하지 않았다.** 모듈 경계만 정해 두고, 누가 맡을지는 나중에 붙인다.

| 모듈 | 무엇 | 어디 |
|---|---|---|
| **A 대화** | 턴 엔진 · 무응답 흐름 · 확인 카드 · MASCOT_PICK | `android/` |
| **B 이야기** | 판정 프롬프트 · 스키마 · 템플릿 A~G · 자막 | `guidelines/7` · `backend/` |
| **C 음성** | VAD · STT · 이름 필터 · TTS 번들 | `android/` · `backend/routers/stt.py` |
| **D 그림** | 사전 제작 · 부품 합성 · 레이어 | `assets/` · `android/` |
| **E 기록** | 이벤트 11종 · 수준 계산 · 부모 리포트 | `android/` |
| **F 평가** | 픽스처 · 러너 · 채점 · 측정 기록 | `eval/` |

**맞물리는 자리 셋** — 여기만 담당끼리 직접 맞춘다.
- **A ↔ B**: 판정 응답(`next_slot`·`story_ready`)을 턴 엔진이 어떻게 쓰는가
- **C ↔ B**: 이름을 가린 문장이 판정으로 넘어가는 모양
- **A ↔ E**: 이벤트를 언제 남기는가 — **안 남기면 리포트가 빈칸이 된다**

## 1-4. 남을 깨뜨리는 규칙 아홉

**하나라도 어기면 다른 사람 코드가 조용히 깨진다.**

**1. 슬롯 이름은 고르는 것이지 만드는 것이 아니다.**
목록 12개(`2_공통_데이터_모델` §1) 밖은 전부 `extra`에 원문 그대로. 새 이름이 들어오면 앱이 렌더링도 집계도 못 한다.

**2. 필수 슬롯은 고정이 아니다.**
아이가 *"혼자 갔어"*라고 하면 `companion`이 빠지고, *"친구랑 싸웠어"*라고 하면 화해 방법이 새로 필요해진다. **"필수 6칸이 다 찼으니 끝"을 쓰지 않는다.** 끝나는 기준은 `story_ready`.

**3. 턴 상한을 두지 않는다.**
8턴 상한은 우리 핵심 지표인 **「주고받기 횟수」를 스스로 깎는다.** 아이가 신나서 계속 말하는 건 제품이 원하는 일이다.

**4. 수준은 규칙이 계산한다. LLM은 신호만 표시한다.**
LLM에게 *"이 아이의 수준은?"*이라고 묻지 않는다. S1·S2만 받고 계산은 우리가 한다.

**5. 발화 출처 `by` 3종을 끝까지 구분한다.**
`child` · `card` · `mascot`. **아이가 한 말과 우리가 채운 말이 섞이면 부모 리포트가 거짓말을 시작한다.** `mascot`은 주고받기 횟수·수준 신호·리포트 인용에서 전부 빠진다.

**6. 실명은 폰에서 가리고, 매핑표도 폰에만 둔다.**
백엔드가 가리려면 백엔드가 실명을 먼저 받아야 하고, 그러면 필터의 의미가 절반 사라진다.

**7. 필터는 놓치는 것보다 과차단이 위험하다.**
*무섭다 · 괴물 · 싸웠다 · 울었다*는 다섯 살 이야기의 **갈등 재료**다. 판단 기준 한 줄 — *"이 말이 그림책 한 쪽에 들어가도 되는가"*. 아이 말버릇을 교정하는 필터가 아니다.

**8. 그림은 세션 중에 만들되, 아이를 기다리게 하지 않는다.**
장소 칸이 차는 순간 배경을 **뒤에서** 만들기 시작한다. 만지는 것(바위·나무·집·별)은 **미리 만들어
두고 얹는다 — 생성 0초.** 8초 안 오면 *"그림은 조금 뒤에 올 거야"*, **15초 넘으면 취소하고 프리셋**.
색·크기·표정은 **생성하지 않는다** — 레이어 교체라 0초이고 다시 그리기 횟수에 세지 않는다.
⚠️ **검사 없이 아이 화면에 보내지 않는다.** 자체 호스팅 모델에는 안전 필터가 없다.

**9. 부모 리포트에 점수·등급·또래 비교를 쓰지 않는다.**
대신 **횟수와 원문 인용.** LLM이 만든 문장에 금지어(`8_금칙어` §3)가 하나라도 있으면 그 답을 버리고 미리 만든 문장을 쓴다.

## 1-5. 아이를 다루기 때문에 지키는 것

| | |
|---|---|
| **아이가 녹음한 소리**(화면 7 · 울음소리 등) | **폰을 떠나지 않는다.** 원본 그대로, 변조 없음 |
| **말한 음성**(전사용) | **폰을 떠난다 — 우리 GPU까지.** 외부 업체로는 안 보낸다. 전사 직후 삭제, **글자만 남는다** |
| 실명 | 폰에서 가리고 매핑표도 폰에만 |
| 만 14세 미만 | **법정대리인 동의** — 개인정보보호법 제22조의2. 단말 내 처리도 처리라 면제 없음 |
| 국외 이전 | 해외 LLM을 쓰는 한 고지 대상 |
| **Play 스토어** | AI 생성 콘텐츠 앱은 **앱 내 신고 기능이 필수**다. 온디바이스여도 면제되지 않는다 |

⚠️ **위 두 줄을 뭉뚱그려 「아이 목소리는 폰을 떠나지 않는다」로 쓰지 않는다 (09-21 정정).**
말한 음성은 §1-1대로 **GPU로 가서 전사된다.** 자체 서버라도 폰은 떠난다.
이 한 줄이 한정어 없이 적혀 있어서 §1-1과 부딪혔고, **발표에서 바로 반박당할 문장**이었다.

우리가 말할 수 있는 것은 이것뿐이다 —
**「아이 음성을 외부 AI 업체로 보내지 않는다. 우리 서버에서 글자로 바꾼 뒤 바로 지운다.」**
*"폰을 떠나지 않는다"*고 말하려면 **온디바이스 STT여야 하는데, 프리셋 매칭 65%로 합격선 미달이다**
(`eval/results.md` §2).
