① 아이 발화 입력 필터(규칙 1겹) · ② 동화 자막 출력 채점 · ③ 부모 리포트 문장 가드

## 0. 절대 차단하지 않는다 — 허용 목록

**감정과 갈등은 이야기의 재료다.** 아래는 어떤 필터에도 걸리면 안 된다.

| 갈래 | 낱말 |
|---|---|
| **감정** | 무섭다 · 무서워 · 슬프다 · 울었다 · 화났다 · 짜증나 · 싫어 · 밉다 · 억울해 · 외로워 · 부끄러워 · 놀랐어 |
| **갈등** | 싸웠다 · 다퉜다 · 화냈다 · 안 놀아줬다 · 뺏었다 · 밀었다 · 넘어졌다 · 다쳤다 · 아프다 |
| **동화 단골** | 괴물 · 귀신 · 도깨비 · 마녀 · 용 · 공룡 · 외계인 · 어둠 · 밤 · 숲속 · 길을 잃다 |
| **실패** | 못했다 · 틀렸다 · 졌다 · 떨어뜨렸다 · 부서졌다 |

**판단 기준 한 줄** — *"이 말이 그림책 한 쪽에 들어가도 되는가"*. **아이의 말버릇을 교정하려는 목록이 아니다.**

## 1. 아이 발화 입력 필터 (규칙 1겹)

**LLM을 부르기 전에 백엔드에서 자른다.** 통과한 것만 §6 LLM 안전 필터(2겹)로 간다.

### 1-1. 즉시 차단 (`block: true`) — 순화하지 않고 통째로 뺀다

| 갈래 | 낱말 (시작 목록 — 팀이 늘린다) |
|---|---|
| **성** | 섹스 · 야동 · 자지 · 보지 · 딸딸이 · 벗어 · 벗겨 · 만져줘 · 가슴 만져 |
| **자해·자살** | 죽고 싶다 · 자살 · 목매 · 뛰어내려 · 손목 · 칼로 그어 |
| **혐오·차별** | 장애인(비하 용법) · 병신 · 등신 · 짱깨 · 쪽바리 · 깜둥이 · 거지새끼 |
| **심한 욕설** | 씨발 · 시발 · 좆 · 개새끼 · 씹 · 지랄 · 엠창 |
| **약물·범죄** | 마약 · 필로폰 · 대마 · 훔쳐 오자 · 유괴 · 납치해 |

### 1-2. 순화 (`soften`) — 뜻은 살리고 표현만 바꾼다

| 아이 말 | 자막에 넣을 말 |
|---|---|
| 죽여 · 죽였어 · 죽어라 | **쓰러뜨렸어 · 잠들게 했어** |
| 때려 · 패 · 발로 차 | **밀었어 · 부딪혔어** |
| 칼로 찔러 · 총으로 쏴 | **막대기로 막았어 · 빛을 쐈어** |
| 피가 나 · 피투성이 | **아파했어** |
| 목 잘라 · 팔 잘라 | **붙잡았어** |
| 불 질러 · 태워 죽여 | **불이 났어** |

⚠️ **아이에게 알리지 않는다.** 경고를 띄우지 않고 부모 기록에도 표시하지 않는다.
⚠️ **순화한 문장은 리포트 인용 후보에서 뺀다.** 인용은 아이가 실제로 한 말이어야 한다.

### 1-3. 걸렸을 때 앱이 하는 일

| | |
|---|---|
| `block` | 그 발화를 **칸에 안 채우고** 마스코트가 자연스럽게 다른 걸 묻는다. *"음, 다른 얘기도 해 줄래?"* |
| `soften` | 순화한 값으로 칸을 채운다. **이야기는 계속된다** |
| 둘 다 | **주고받기 횟수에는 센다.** 아이가 말한 것은 사실이다 |

## 2. 동화 자막 출력 채점 (자동)

**최민우 자동 채점기에서 쓴다. `금지 표현 0건`이 합격선이고 타협 없다.**

- **§1-1 전체** + **§1-2의 원래 표현**(죽여·때려·칼·총·피·잘라·불 질러)
- 추가: 협박 · 유괴 · 납치 · 자살 · 마약 · 술 · 담배 · 도박
- 추가: 특정 종교·정당·실존 인물 이름
- 추가: 상표명 (뽀로로 · 디즈니 · 포켓몬 등) — **저작권**

**⚠️ §0 허용 목록은 여기서도 통과다.** 무섭다·괴물·싸웠다가 자막에 있어도 **합격**이다.

## 3. 부모 리포트 문장 가드

**LLM이 만든 부모용 문장에 아래가 하나라도 있으면 그 답을 버리고 미리 만든 문장을 쓴다.**

| 갈래 | 낱말 |
|---|---|
| **비교** | 또래 · 평균 · 백분위 · 정상 · 상위 · 하위 · 보통 아이 |
| **등급** | 등급 · 레벨 · 수준 · 단계 · 발달지수 · ○○세 수준 |
| **판정** | 진단 · 평가 · 선별 · 검사 · 지연 · 장애 · 의심 |
| **가치판단** | 부족 · 늦다 · 떨어진다 · 문제가 있다 · 걱정된다 |
| **과장** | 향상 · 증진 · 발달했다 · 좋아졌다 · 뛰어나다 |

**대신 쓰는 말** — `부모리포트_설계.md` §11 표 그대로. 예: *"향상됐습니다"* ✗ → *"지난번보다 3번 더"* ✓

⚠️ **§3은 이미 `프롬프트_모음.md` §7과 `부모리포트_설계.md` §11에 있던 것을 여기로 모은 것이다.** 앞으로 고칠 때는 **이 파일만** 고친다.

## 4. 운영 규칙

| | |
|---|---|
| **목록은 코드에 박지 않는다** | `backend/filters/` 아래 텍스트 파일로 두고 읽는다. 배포 없이 고칠 수 있어야 한다 |
| **부분 문자열로 안 찾는다** | "시발" 때문에 "시발점"이 걸리면 안 된다. **어절 경계**로 찾는다 |
| **자모 분해 후 한 번 더 본다** | 음성 인식이 "씨발"을 "시발"·"씨바"로 낼 수 있다. **자모 편집거리 ≤ 1**이면 같은 말로 본다 (§오늘_모델검증_역할 §3-4 로직 재사용) |
| **걸린 것을 기록한다** | 무엇이 몇 번 걸렸는지만. **원문은 저장하지 않는다** |
| **과차단을 재라** | 9/18 아이 관찰에서 **§0 허용 목록이 실제로 안 걸리는지** 확인한다. 걸리면 목록이 아니라 필터가 잘못된 것이다 |
