# 까닭 표지 전수 조사 — `s1_reason` 함정이 실제로 몇 개인가

> 2026-09-21 · 안치영 · 박진웅이 `fixtures_judge_labeling_notes.md` 에서
> *"숨은 함정으로 남겨둠, 안치영·최민우에 공유 필요"* 라고 남긴 것에 대한 답이다.
> 재현: 이 문서 §5

---

## 0. 한 줄로

**함정은 층 표시가 말하는 5개가 아니라 10개다.** `type` 이 `S1-순차함정` 인 문항은 2개뿐이지만,
까닭 표지가 있으면서 `s1_reason = false` 인 문항은 **10개**다. 확정 gold 는 10개 전부 일관되게 맞다.

`results.md` 에서 `s1_reason` F1 을 읽을 때 **"함정 5개"가 아니라 "표지 28개 중 함정 10개"** 로 읽는다.

---

## 1. 표지별 전수 (100문항)

| 표지 | `s1_reason` 참 | 거짓 | 거짓인 문항 |
| --- | --- | --- | --- |
| **`-서`** | 11 | **8** | j007 j010 j020 j038 j046 j061 j092 j100 |
| `-니까` | 6 | 0 | — |
| **`"그래서"`** | 0 | **6** | j006 j007 j010 j038 j061 j092 |
| `"그러면"` | 1 | **1** | j034 |
| `-거든` | 1 | 0 | — |
| `때문에` · `왜냐하면` | 0 | 0 | 평가셋에 없다 |

문항이 겹친다 — *"발자국이 있었어. 그래서 따라가 봤어"* 는 `-서` 와 `"그래서"` 에 둘 다 걸린다.

**까닭 표지가 실제로 있는 문항 28개 · 그중 함정 10개**
→ `j006 j007 j010 j020 j034 j038 j046 j061 j092 j100`

`-니까` 6개와 `-거든` 1개는 **전부 참**이다. 이 둘은 인과 전용 어미라 함정이 없다.
`"그래서"` 6개는 **전부 거짓**이다. 지침 §2-2 가 이걸 규칙으로 못 박았다.

## 2. ⚠️ 처소격 2개는 표지가 아니다

| 문항 | 아이 말 | 왜 |
| --- | --- | --- |
| j019 | "커다란 야자나무 숲! **거기서** 친구들이 기다릴 것 같아." | `거기서` 는 장소다 |
| j044 | "어제 **어린이집에서** 블록 쌓았어." | `에서` 는 장소다 |

`-서` 로 문자열 검색만 하면 21개가 잡히는데 그중 2개가 이것이다. **정규식으로 함정을 세면 틀린다.**
둘 다 gold 는 `s1_reason = false` 로 맞다.

## 3. `type` 표시를 라벨로 쓰면 안 된다

`type` 은 **어느 층에서 뽑았나**이지 정답이 아니다. `type` 이 `S1` 인데 gold 가 `false` 인 문항이 4개다.

| 문항 | `type` | gold | 아이 말 | 왜 거짓인가 |
| --- | --- | --- | --- | --- |
| j034 | S1 | false | "트리케라톱스 등에 태워 줄래! **그러면** 높은 데 별도 딸 수 있어." | 조건이다 |
| j085 | S1 | false | "친구한테 물어봐야 돼." | 방법이지만 까닭이 아니다 |
| j092 | S1 | false | "화산이 부글부글해. **그래서** 땅이 뜨거워." | 결과 접속사 |
| j100 | S1 | false | "엄마한테 달려**가서** 말해." | 순차 |

**원인은 더미답 원본이다.** 앱 더미답에 붙여 둔 `s1` 표시가 조건·순차·`"그래서"` 까지 S1 으로 세고 있었다.
`make_fixtures.py` 의 `stratum_of()` 가 그 표시를 그대로 믿고 층을 나눈다.
**층은 표본을 고르게 뽑기 위한 것이므로 이 자체는 문제가 아니다.** 문제가 되는 것은 `type` 을 라벨로 쓸 때다.

박진웅이 *"유형 라벨을 그대로 믿지 않고 문장 자체를 다시 판정"* 한 것이 옳았다.

## 4. 그래서 누가 무엇을 하나

| 누구 | 무엇 |
| --- | --- |
| **최민우** | `results.md` 의 `s1_reason` 해석. 함정이 5개가 아니라 **10개**다. 층 이름(`S1-순차함정`)으로 함정을 세지 않는다 |
| **최민우** | `s1_reason` 을 **표지 있는 28문항만**으로 따로 내면 판별력이 더 잘 보인다. 표지가 없는 72문항은 대개 자명하게 false 라 전체 F1 을 부풀린다 |
| **박진웅** | 공유 완료. gold 는 10개 전부 일관되게 맞아서 **고칠 것이 없다** |
| **안치영** | 지침 §2-2 에 `"그래서"` · `"그러면"` 규칙 반영 완료. 층 표시를 라벨로 쓰지 말라는 경고는 이 문서 §3 |

## 5. 다시 돌리는 법

```

python - <<'PY'
import json, re
rows=[json.loads(l) for l in open('fixtures_judge.jsonl',encoding='utf-8') if l.strip()]
LOC=re.compile(r"(에서|거기서|여기서|어디서)")
SEO=re.compile(r"[가-힣]서[ ,.!?]|[가-힣]서$")
def marks(u):
    out=[]
    if SEO.search(u) and SEO.search(LOC.sub("", u)): out.append("-서")
    for m in ("니까","때문에","왜냐하면","그래서","그러면","거든"):
        if m in u: out.append(m)
    return out
marked=[x for x in rows if marks(x['utterance'])]
trap=[x for x in marked if not x['gold'].get('s1_reason')]
print(f"표지 {len(marked)}개 · 함정 {len(trap)}개")
print(" ".join(x['id'] for x in trap))
PY
```
