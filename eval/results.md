# results — 측정 누적

**날짜 · 조건 · 값만 쌓는다.** 해석은 짧게, 추정은 쓰지 않는다.
모델 판정 결과표는 최민우가 같은 파일 아래에 덧붙인다.

## 2026-09-19 · 안드로이드 기기 음성 인식 · 합성

측정: 이종훈 · 도구: `DiagnosticsActivity` (레포 `android/`)

### 조건

| | |
|---|---|
| 기기 | samsung SM-S936N (갤럭시 S25+) |
| OS | Android 16 (API 36) |
| 인식기 | `SpeechRecognizer` — 오프라인(`EXTRA_PREFER_OFFLINE`) · 온라인 각각 |
| 화자 | **성인 남성 1명** |
| 환경 | **조용한 방, 혼자** |
| 시도 | 100회 (오프라인 50 · 온라인 50) |

> ⚠️ **조건이 §6 「하지 말 것」에 걸린다.** *"조용한 방에서 녹음하는 것 — 우리 앱이 쓰이는 환경이 아니다."*
> 아래 정확도는 **낙관적 상한**으로 읽는다. 측정자는 소음이 섞이면 발화 종료 감지가 더 자주
> 실패한다고 보고했다. 아이 음성도 아니므로 **모델 순위 결정에는 쓰지 않는다.**

### 1. 인식 지연 — `onEndOfSpeech` → `onResults`

버튼을 누른 시점이 아니라 **말이 끝난 순간부터** 잰 값이다.
전체 소요에는 사람이 말을 시작하기까지의 시간과 엔드포인터 대기가 들어가므로 예산에 세지 않는다.

| 경로 | p50 | p95 | 최대 |
|---|---:|---:|---:|
| 오프라인 | **1ms** | 4ms | 4ms |
| 온라인 | **140ms** | ~270ms | 402ms |

**판정 — 둘 다 통과.** §5-③ 탈락선이 `p95 > 2000ms`다. 오프라인은 500배, 온라인은 7배 여유.
오프라인이 1ms인 것은 온디바이스 인식이 발화 중에 계속 돌아 종료 시점에 결과가 이미 있기 때문이다.
온라인의 140ms는 네트워크 왕복이다.

### 2. 정확 일치율

| 묶음 | 오프라인 | 온라인 |
|---|---:|---:|
| 세계 프리셋 3종 (우주 · 바닷속 · 공룡 나라) · 20회 | 13 (65%) | 12 (60%) |
| **프리셋 밖 장소 — "눈 나라 갈래"** · 5회 | 3 | **0** |
| 짧은 답 (응 · 몰라 · 싫어 · 또 · 아니) · 25회 | 24 (96%) | 22 (88%) |

프리셋별 편차가 크다 — `우주로 가자` 9/10, `바닷속 갈래` 8/10, `공룡나라 갈래` 8/20.

### 3. 환각률 — **0%**

짧은 답 50회에서 **없는 말이 붙은 경우 0건.** 실패는 전부 `오류 7`(못 알아들음)이며 지어내기가 아니다.

**판정 — 둘 다 통과.** §5-③ 탈락선이 `환각률 10% 초과`다.
Whisper 환각을 염두에 두고 만든 방어선인데, 안드로이드 기본 인식기에는 이 실패 모드가 없다.

### 4. 발화 종료 감지 실패 — 오프라인 14%

`발화ms`가 3초를 넘은 경우가 **7건, 전부 오프라인** (온라인 0건).

| 말한 것 | 발화 시간 |
|---|---|
| 응 | 4,745 · 4,838ms |
| 또 | 5,011 · 4,601 · 4,610ms |
| 바닷속 갈래 | 5,886ms |
| (할래) | 3,948ms |

같은 `"응"`이 다른 시도에서는 486 · 583ms였다. **0.5초 아니면 4.8초로 갈리고 중간이 없다.**
7건 중 5건이 `응` · `또` — 짧은 답일수록 자주 걸린다.

**인식은 1ms인데 사람이 5초를 기다린다.** VAD로 발화 종료를 직접 잡아야 하는 근거다.

### 5. 오인식 패턴 — 경로마다 다르다

| 경로 | 패턴 | 예 | 자모 매칭으로 복구 |
|---|---|---|---|
| 온라인 | **음소 치환** | 나라→날아 · 눈→누나 · 나라→따라 | **가능** — 자모 거리가 가깝다 |
| 오프라인 | **어절 누락** | "공룡나라 갈래"→"갈래" · "바닷속 갈래"→"바닷속" | **어렵다** — 통째로 빠진다 |

→ 최민우 `corrupt.py`가 만드는 손상은 음소 치환 계열이라 **온라인 오류는 재현하지만 오프라인의
어절 누락은 재현하지 못한다.** 손상 모델에 어절 탈락을 추가할지 검토가 필요하다.

### 6. 음성 합성 (TextToSpeech)

| | |
|---|---|
| 한국어 지원 | `0` LANG_AVAILABLE |
| 목소리 | `ko-KR-language` |
| 오프라인 동작 | 예 |
| API 품질 점수 | **400** (척도 최고값) |

**귀 판정 — 세 문항 모두 「아니오」**

| 물은 것 | 답 |
|---|---|
| 다섯 살이 끝까지 들을 만한가 | 아니오 |
| 사람 목소리로 들리는가 | 아니오 |
| 마스코트 캐릭터로 느껴지는가 | 아니오 |

**API 품질 점수를 신뢰 지표로 쓰면 안 된다.** 400점과 귀 판정 3연속 「아니오」가 공존한다.
`ko-KR-language`는 특정 음성이 아니라 **로케일 단위 오프라인 경량 음성**이며, 점수는
"이 언어를 지원한다"는 뜻이지 "잘 읽는다"는 뜻이 아니다.

에뮬레이터(Google sdk_gphone64 · API 35)도 같은 목소리 · 같은 점수였다. 기기 문제가 아니다.

### 7. VAD 발화 종료 감지 — silero, 28회

같은 기기 · 같은 조용한 방 · 같은 말(`응` · `또`). 버튼 ③은 인식기를 띄우지 않고
**VAD만** 돌리므로 마이크를 다투지 않는다. `발화`에는 VAD가 종료를 확정하기 위해
기다리는 **무음 300ms가 포함**돼 있다.

설정: `SAMPLE_RATE_16K` · `FRAME_SIZE_512` · `Mode.NORMAL` · `speechDurationMs 50` · `silenceDurationMs 300`

| 발화 종료 감지 | 내장 엔드포인터 | **silero VAD** |
|---|---:|---:|
| p50 | 4,601ms | **550ms** |
| p95 | — | 880ms |
| 최대 | 5,011ms | **1,139ms** |
| 5초 근처 멈춤 | 9회 중 5회 | **28회 중 0회** |

**p50 기준 8.4배 빠르다.** 더 중요한 것은 분포다. 내장 엔드포인터는 0.5초 아니면 4.8초로
갈리는 이봉형이었는데, **VAD에는 그 4.8초 봉우리가 없다.** 28회가 359~1,139ms 안에 모인다.

**오탐 — 조용한 방에서 0건.** 입을 다문 채 기다린 4회가 전부 `말을 못 잡았다 (12초)`로 끝났다.
단 `말 시작 11446ms` 한 건은 늦게 말한 것인지 막판 헛잡음인지 로그로 가릴 수 없다. `[미확인]`

**판정 — VAD 채택.** 인식은 이미 1ms였으므로, 남아 있던 체감 지연은 전부 종료 감지였다.

**아직 안 잰 것** — 소음 조건, 긴 문장에서 어절 사이 숨에 끊기는지(`silenceDurationMs 300`이
한국어에 충분한지). 둘 다 채택 여부가 아니라 **설정값을 다듬는 문제**다.

### 이 측정이 닫은 것

- **온디바이스 한국어 오프라인 팩** — 이 기기에는 **있다.** §4-2의 `[확인 실패]`가 닫혔다.
  에뮬레이터는 `오류 12`(팩 미설치)였으므로 기기마다 다르다는 것도 같이 확인됐다.
- **STT 지연 예산** — 두 경로 다 통과. 지연을 이유로 후보를 떨어뜨릴 근거가 없다.
- **환각률** — 두 경로 다 통과.
- **고정 대사 사전 합성** — 확정. 폰 TTS로는 마스코트를 못 만든다.

### 이 측정이 연 것

- ~~VAD~~ — **닫혔다. §7 참조.** 채택. p50 550ms로 내장 엔드포인터보다 8.4배 빠르다.
- **프리셋 이름 선정** — 인식률이 이름마다 크게 다르다. 템플릿을 고르는 것만으로 인식률이 오른다.
- **프리셋 밖 발화** — 맞출 목록이 없어 자모 매칭이 못 구한다. `extra`에 들어갈 원문이 오염된다.
- **책 낭독 음성** — 자막은 가변이라 사전 합성이 안 되고, 폰 TTS는 방금 탈락했다. 미결.

### 남은 것

- 아이 음성으로 재측정 (AI-Hub 108번 · 3~6세). 성인 측정은 **순위 결정에 쓰지 않는다.**
- 거실 소음 조건에서 재측정.
- 픽셀 등 다른 제조사 기기 — 오프라인 팩 탑재가 기기마다 다른 것이 확인됐으므로.
- VAD 소음 조건 · 긴 문장 — `silenceDurationMs 300`이 한국어 어절 사이 숨에 안 끊기는지.
