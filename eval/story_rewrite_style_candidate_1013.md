# 윤문 문체 후보 B — 실행 전 준비

기준 A는 `65396751` 코드의 `story_prompt.md`에서 추출한 시스템 블록이다. 운영 서버의 실제 배포 버전을 가정하지 않는다. B는 **A의 문구를 바꾸지 않고 아래 블록만 덧붙인 조건**이다. 이 파일은 런타임이 읽는 프롬프트가 아니며 모델 실행은 0회다. 직접 작성한 일반 문체 지시이고 특정 작가나 상업 동화책의 문장을 가져오지 않았다.

## 추가 블록

```text
[문체 변형 B]
- 사건을 들려주는 동화 문장으로 써요. 같은 뜻의 표현 중에서는 보고서처럼 소개하는 말보다 동작을 직접 서술하는 말을 골라요.
- 한 문장 안의 절과 접속어를 소리 내어 읽기 편한 호흡으로 다듬어요. 기존에 정한 문장 길이와 '-어요'체를 유지해요.
- 기존에 주어진 의성어·의태어는 또렷하게 읽히는 자리에 배치해요. 기존에 주어진 직접 대사는 소개말의 길이와 위치를 다듬어요.
```

## 비교 범위

핵심 정보·결말·고유 표현 보존 100%, 의미 반전·잘못된 귀속·근거 없는 핵심 사실 추가 0건, 페이지별 이해 가능성 2점 이상이라는 사전 기준은 A/B 모두 같다. 이 기준과 fixture의 정답 목록은 평가용이다. **B에만 정답 목록이나 새로운 정보 보존 지시를 보내지 않는다.** 입력 구성과 출처 계약을 고치는 조건 C는 추후 별도로 설계한다.

직접 대사가 아닌 사건 설명을 새 인물 대사로 바꾸는 것, 소리를 새로 만드는 것, 반복을 위해 행동 횟수를 늘리는 것은 문체 변경으로 통과시키지 않는다. 이런 차이는 기존 내용 보존 기준으로 양쪽에 동일하게 판정한다.

## 독창적인 설명 예시 — 모델 출력 아님

이 표는 사람이 문체 방향을 이해하도록 직접 작성한 합성 예시다. B의 추가 블록이나 잠금 평가 입력에는 이 표를 넣지 않는다.

| 합성 원문 | 의미를 유지한 설명 예시 |
|---|---|
| 포포가 정원에서 오리를 만났어. 집으로 돌아왔어. | 포포는 정원에서 오리를 만나고 집으로 돌아왔어요. |
| 준이가 “같이 가자”라고 말했어. 물결은 찰랑찰랑 소리를 냈어. | 준이가 “같이 가자”라고 말하고 물결은 찰랑찰랑 소리를 냈어요. |
| 루루는 빵집으로 돌아가서 쿠키를 만들 거야. 케이크 만들기는 그만둘 거야. | 루루는 빵집으로 돌아가 쿠키를 만들고 케이크 만들기는 그만둘 거예요. |

마지막 원문을 “루루는 빵집에서 쿠키를 만들며 행복해졌어요”로 바꾸면 복귀·중단·미래 시점을 잃고 감정을 추가하므로 실패다. 말투가 좋아 보여도 내용 실패를 덮지 않는다.
