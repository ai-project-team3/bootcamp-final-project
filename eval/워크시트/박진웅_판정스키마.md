## 0. 왜 이걸 하나 (한 줄)

어제 판정 설계를 크게 바꿨다 — **슬롯 전체를 주고, 다음 질문까지 LLM이 정하고, 필수 칸이 동적으로 바뀌게.**
**되는지 한 번도 안 재봤다.** 안 되면 오늘 안에 되돌려야 한다.

## 3. 제출 양식 ①  `eval/judge_schema.json`

```json
{
  "type": "object",
  "additionalProperties": false,
  "required": ["reason","slot_1","value_1","slot_2","value_2",
               "contradiction","contradiction_with",
               "s1_reason","s2_addition","emotion",
               "unclear","unclear_of",
               "next_slot","next_reason","no_longer_needed","story_ready"],
  "properties": {
    "reason":             { "type": "string" },
    "slot_1":             { "type": ["string","null"] },
    "value_1":            { "type": ["string","null"] },
    "slot_2":             { "type": ["string","null"] },
    "value_2":            { "type": ["string","null"] },
    "contradiction":      { "type": "boolean" },
    "contradiction_with": { "type": ["string","null"] },
    "s1_reason":          { "type": "boolean" },
    "s2_addition":        { "type": "boolean" },
    "emotion":            { "type": ["string","null"] },
    "unclear":            { "type": "boolean" },
    "unclear_of":         { "type": ["string","null"] },
    "next_slot":          { "type": ["string","null"] },
    "next_reason":        { "type": ["string","null"] },
    "no_longer_needed":   { "type": ["string","null"] },
    "story_ready":        { "type": "boolean" }
  }
}
```

**슬롯 필드에 `enum`을 넣을지는 벤더가 받아주는지 보고 정한다.** 안 받으면 빼고 백엔드가 거른다.

## 4. 제출 양식 ②  벤더 통과 기록 — **이 표를 채워서 제출**

| 벤더 | 호출 방식 | 통과? | 안 되면 무엇 때문에 |
|---|---|---|---|
| OpenAI | `response_format: json_schema, strict: true` | | |
| Anthropic | 제약 디코딩 | | |
| Mistral | `response_format: json_object` + 프롬프트에 스키마 | | |

**스키마 강제 등급을 여기서 판정한다**
- **(a) 강제** — 위반이 불가능하다
- **(b) JSON만** — JSON이긴 한데 값이 스키마를 벗어날 수 있다
- **(c) 프롬프트 의존** — 지킬 수도 안 지킬 수도

## 5. 제출 양식 ③  `eval/fixtures_judge.jsonl` 한 줄 모양

```jsonl
{"id":"j004","slots":{"place":null,"companion":null},"asked":"place","template":"C",
 "utterance":"공룡나라 갈래 근데 뿌뿌도 데려갈래",
 "gold":{"slot_1":"place","value_1":"공룡나라","slot_2":"companion","value_2":"뿌뿌",
         "s1_reason":false,"s2_addition":true,"emotion":null,
         "next_slot_ok":["problem","newcomer"],
         "no_longer_needed":null,"story_ready":false},"type":"S2-다중채움"}
```

**`next_slot_ok`는 허용 집합이다.** 정답 하나를 강요하면 정상 답을 오답으로 센다.

## 6. 제출 양식 ④  라벨 기준 — **고친 것을 적어서 제출**

## 7. 막히면

| | |
|---|---|
| 키가 없다 | **Mistral만 있다.** 그걸로 통과 확인하고 나머지 두 줄은 비워 둔다 |
| 스키마가 거부당한다 | 필드를 빼서 공통분모로 줄인다. `minimum`·중첩·`$ref`가 원인일 가능성이 높다 |
| 라벨이 애매하다 | **§6에 적어 두고 넘어간다.** 멈추지 말 것 |
| 시간이 모자란다 | **스키마와 프롬프트만** 끝낸다. 라벨은 내일도 된다 — 다만 최민우가 채점을 못 한다 |
