# 워크시트

**각자 자기 파일만 읽는다.** 채워서 그대로 제출하면 된다.

| 파일 | 받는 사람 | 오늘 내놓는 것 |
|---|---|---|
| `박진웅_판정스키마.md` | 박진웅 | `judge_schema.json` · `judge_prompt.md` · **라벨 100개** |
| `안치영_평가셋과일기모드.md` | 안치영 | `fixtures_judge.jsonl`(라벨 없음) · `fixtures_story.jsonl` · 일기 모드 흐름 |
| `최민우_러너와채점.md` | 최민우 | `run_judge.py` · `corrupt.py` · **결과표 2개** |
| `조장_기기점검.md` | 이종훈 | 기기 점검 결과 · 키 · AI-Hub |

**의존 관계 — 셋뿐이다**

```
박진웅 스키마 ┐
              ├→ 최민우 예측 수집 ─┐
안치영 100개  ┘                    ├→ 채점 → 저녁에 표 보고 결정
박진웅 라벨 ───────────────────────┘
```

- 박진웅·안치영은 **오전 중**에 최민우에게 넘긴다
- 최민우는 **라벨을 기다리지 않는다.** 예측 수집과 라벨링은 병렬
- 키는 **Mistral만 있다.** 러너가 `--model`을 받으므로 키가 생긴 날 다시 돌린다

**오늘의 목적은 모델 선정이 아니다.** 어제 바꾼 판정 설계(슬롯 전체 · 다음 질문을 LLM이 · 동적 필수)가
**실제로 되는지** 보는 것이다. 다중채움·필수해제 F1이 낮으면 **오늘 안에 되돌린다.**
