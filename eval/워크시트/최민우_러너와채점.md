## 3. ⚠️ TTFT — 여기만 틀리면 실험 전체가 무의미하다

**우리 1순위 기준이 TTFT다.** 논스트리밍으로 재면 **총 소요를 잰 것**이지 TTFT가 아니다.

```python
t0 = time.perf_counter()
# stream=True 로 호출
for chunk in stream:
    if first_content_token(chunk):
        ttft = time.perf_counter() - t0   # ← 여기
        break
# ... 끝까지
total = time.perf_counter() - t0
```

**기록 한 줄** (`eval/raw/<model>.jsonl`)
```json
{"id":"j001","model":"mistral-small-4","ok":true,"ttft":0.71,"total":1.62,
 "pred":{"reason":"...","slot_1":"place","value_1":"공룡나라","...":"..."},
 "in_tok":880,"out_tok":74}
```

**실패도 기록한다** — `{"id":"j007","ok":false,"error":"JSONDecodeError"}`. **실패율 자체가 지표다.**

## 4. ⭐ 자모 손상 — 오늘 가장 값진 실험 (API 불필요)

**"STT가 틀려도 게임이 도는가"를 오디오 없이 잰다.**

**한글 분해** (라이브러리 불필요)
```python
BASE, CHO, JUNG = 0xAC00, 588, 28
c = ord(ch) - BASE
cho, jung, jong = c // CHO, (c % CHO) // JUNG, c % JUNG
합성 = chr(BASE + cho*CHO + jung*JUNG + jong)
```

**한국어 STT가 실제로 내는 오류만 넣는다** (무작위 아님)

| 자리 | 바꾸는 쌍 |
|---|---|
| 초성 | ㄹ↔ㄴ · ㄱ↔ㅋ · ㅂ↔ㅍ · ㄷ↔ㅌ · ㅅ↔ㅆ · ㅈ↔ㅊ |
| 중성 | ㅐ↔ㅔ · ㅗ↔ㅜ · ㅓ↔ㅗ · ㅑ↔ㅕ |
| 종성 | **탈락(→0)** · ㄴ↔ㅇ · ㄱ↔ㅋ |

| 강도 | 손상률 | 추가 | 예 |
|---|---|---|---|
| 0 | 0% | — | 공룡나라 |
| 1 | **10%** | — | 공**뇽**나라 |
| 2 | **25%** | 음절 탈락 + 띄어쓰기 오류 | 고뇽 나과 |

**그다음 자모 편집거리로 프리셋을 맞춘다** — 손상된 문자열을 자모로 펼쳐 후보들과 편집거리를 재고 가장 가까운 것.

### 제출 양식 — **이 표를 채워서 제출**

| 강도 | 매칭 **안 쓸 때** 정답률 | 매칭 **쓸 때** 정답률 | 합격선 |
|---|---|---|---|
| 0 (손상 없음) | | | — |
| **1 (10%)** | | | **≥ 95%** |
| 2 (25%) | | | ≥ 85% |

> **이 표가 그대로 발표 슬라이드가 된다.** "음성 인식이 틀려도 게임은 돈다"를 한 장으로 보여준다.

## 5. 생성 자동 채점 (30분 · LLM도 사람도 필요 없다)

| 항목 | 방법 | 합격선 |
|---|---|---|
| **−어요체** | 종결이 `요[.!?]?$` 또는 `어요`·`예요`·`에요` | ≥ 95% |
| **15어절 이하** | `len(자막.split()) <= 15` | ≥ 95% |
| **금지 표현** | `guidelines/8_금칙어.md` §2 목록 대조 | **0건** |
| **이름 무결성** | `{주인공}`·`{친구1}`이 **원형 그대로** 남아 있고 실명이 없다 | **100%** |
| 장면 수 | 정확히 6 | 100% |

⚠️ **`guidelines/8_금칙어.md` §0 허용 목록은 통과시킨다.** *무섭다·괴물·싸웠다*가 자막에 있어도 **합격**이다.

## 6. 제출 양식 — 판정 결과표

| 모델 | JSON 성공률 | slot_1 F1 | **다중채움 F1** | **필수해제 F1** | s1 F1 | s2 F1 | **next_slot 적중** | TTFT p50/p95 | 세션 원가 |
|---|---|---|---|---|---|---|---|---|---|
| `mistral-small-4` | | | | | | | | | 6.1원 |
| `ministral-3-3b` | | | | | | | | | 2.2원 |
| *(키 오면)* `gpt-5.6-luna` | | | | | | | | | 10.9원 |
| *(키 오면)* `claude-haiku-4-5` | | | | | | | | | 49.7원 |

**⚠️ 가운데 셋이 오늘의 목적이다.** 슬롯 하나만 주는 방식으로는 **원리적으로 못 잡는** 항목이라, **여기 숫자가 어제 바꾼 설계를 정당화하거나 뒤집는다.**

**채점 규칙 셋**
- **`next_slot`은 정답 하나가 아니라 `next_slot_ok` 집합**에 들어가면 정답
- **`value_1`은 완전 일치가 아니라 자모 편집거리 ≤ 0.3** (§4 로직 재사용)
- **필드별 F1**: `TP=gold✓&pred✓`, `FP=gold✗&pred✓`, `FN=gold✓&pred✗`, `F1=2TP/(2TP+FP+FN)`
