## 2. 진단 화면 띄우는 법

**이미 빌드돼 있다.** 런처에 안 뜨고 adb로만 띄운다 — 치영님 앱 화면을 안 건드린다.

```bash
cd android
set JAVA_HOME=C:\Android\jdk-17.0.20.1+1
gradlew.bat assembleDebug

C:\Android\sdk\platform-tools\adb.exe install -r app\build\outputs\apk\debug\app-debug.apk
C:\Android\sdk\platform-tools\adb.exe shell am start -n com.example.finalproject_demo/.DiagnosticsActivity
```

화면이 뜨면 **①이 자동으로 찍히고 한국어 문장이 들린다.**
그다음 **[말해 보기]**를 누르고 **"공룡나라 갈래"** 라고 말한다.

⚠️ **에뮬레이터로도 TTS는 되지만 음질 판단은 실기기로** 해야 한다. 마이크도 실기기가 정확하다.

|---|---|

| 기기 내 인식 가능 | |

| 걸린 시간 | ms |

### 기기 ②

*(같은 표)*

### 이게 답하는 것

| 결과 | 뜻 |
|---|---|
| TTS가 **-1**이면 | 설정에서 한국어 팩을 받아야 한다. **기기마다 다르면 가변 자막도 사전 합성으로** |
| TTS 음질이 나쁘면 | 가변 자막까지 **미리 합성해 번들**한다 |
| 인식 오류가 **12**면 | 한국어 오프라인 팩 미설치 → **서버 STT 폴백.** 기능은 안 빠지고 세션당 8원 는다 |
| 인식 오류가 **2(네트워크)**면 | **오프라인이 아니라는 뜻.** 온디바이스 STT 경로가 닫힌다 |
| 정상 인식되면 | **오프라인 폴백 확보.** 인터넷 끊겨도 게임의 절반이 돈다 |

## 4. 2단계 — VAD 붙이기 (①이 끝난 뒤)

**새 의존성이라 빌드가 깨질 수 있어 따로 한다.**

`android/settings.gradle.kts` → `dependencyResolutionManagement { repositories { ... } }` 안에
```kotlin
maven { url = uri("https://jitpack.io") }
```

`android/app/build.gradle.kts` → `dependencies { ... }` 안에
```kotlin
implementation("com.github.gkonovalov.android-vad:silero:2.0.10")
```

**빌드가 되면** 말할 때 구간이 잡히는지만 본다.

⚠️ **파라미터는 `guidelines/4_모듈_브리프.md` C절에 있다.** 특히 **`redemptionMs`는 1000이 아니라 1500~2000**으로 시작한다 — 어른 기준값이라 **아이 말이 중간에 끊긴다.**

## 6. 막히면

| | |
|---|---|
| adb가 기기를 못 찾는다 | 개발자 옵션 → USB 디버깅. `adb devices`로 확인 |
| 진단 화면이 안 뜬다 | 패키지명 확인 — `com.example.finalproject_demo` |
| 마이크 권한을 안 묻는다 | 앱 정보 → 권한에서 직접 켠다 |
| VAD 빌드가 깨진다 | **되돌리고 넘어간다.** 오늘 결론에 영향 없다 |
| 시간이 모자란다 | **팀 공지와 노션 1~3번만** 한다. 나머지는 내일도 된다 |
