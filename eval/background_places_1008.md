# 배경 장소 6종 평가 — 사전 기준 (2026-10-08)

이슈 [#218 조장 요청](https://github.com/ai-project-team3/bootcamp-final-project/issues/218#issuecomment-6052674977)에 따라 공개 `/image`의 영어 장면 문장과 원본 PNG를 함께 확인한다. 앱의 테마·키트·책 표시 경로는 이 평가에서 실행하지 않는다. 아래 기준은 6개 이미지 요청 전에 작성했다.

- 요청: `kind=background`, `mode=story`, `style=felt`. 장소별 1회, 순차 실행, 요청 사이 2초.
- 서버: `https://otto-back.shelldocs.cloud`. `/health`가 200이고 `mock=false`일 때만 이미지 요청.
- 실제 운영 모델·배포 커밋·seed는 공개 응답으로 확인할 수 없다. 로컬 기준은 `eabde487c34edb1953dd1997985607536bcffb7f`이며 운영 버전과 같다고 가정하지 않는다.
- **응답:** HTTP 오류, 프리셋, mock, 빈 scene, PNG 누락은 생성 성공과 별도로 센다.
- **장면 문장:** 입력 장소와 아래 핵심 단서가 영어 scene에 유지되는지 직접 읽는다. 합성 장소에서 수식어가 빠지고 일반 장소만 남으면 누락이다.
- **그림:** 장소 이름·scene에 기대지 않고 원본 PNG에서 핵심 단서가 보이는지 본다. 보임/부분/안 보임/판정 불가로 기록하고 보이는 사물을 근거로 적는다.
- **단계 가름:** scene 누락은 장면 변환 단계의 증거다. scene은 맞는데 PNG에 특징이 없으면 그림 생성 단계의 미반영 증거다. 후자는 모델·스타일·seed 중 하나가 원인이라는 확정은 아니다.

| 장소 | 문장과 그림에서 볼 핵심 단서 |
|---|---|
| 공원 | 야외 녹지와 산책길·벤치·놀이 시설 중 하나 |
| 바닷속 | 수중 공간과 산호·해초·기포 중 하나 |
| 우주 | 별·행성·달 표면 등 지구 밖 공간 단서 |
| 할머니 집 | 집과 포근한 생활·정원 단서. 특정 집의 실제 모습은 입력에 없어 평가하지 않는다 |
| 미래 도시 | 도시 건물과 미래적 건축·공중 교통 등 일반 도시와 구별되는 단서 |
| 피자마을 | 마을과 피자·치즈·토핑 모양의 건축/지형 단서. 일반 집만 있으면 특징 미반영 |

한 장소 한 장으로 성공률·일관성·원인을 확정하지 않는다. 명확한 수정 후보가 생겼을 때 같은 6개 묶음, 같은 기준으로 전후 비교하고 실제 운영에 반영한 결과와 로컬 결과를 구분한다. 이번 요청은 운영 설정 변경이나 배포를 포함하지 않는다.

재실행 도구: `python -m eval.bench_background_places --base-url https://otto-back.shelldocs.cloud --out eval/image_out/background_places_<새 실행 ID>`.
기존 폴더는 덮어쓰지 않는다. 결과 JSON에는 응답 base64 대신 원본 PNG 파일명·크기·SHA-256을 남긴다. 다시 실행하면 실제 생성 요청 6건이 발생한다.
