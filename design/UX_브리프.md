# 오또(OTTO) 디자인 브리프 — 사용자와 UX 원칙

pen.dev AI 채팅(`Ctrl+K`)에 아래 「붙여 넣을 브리프」를 그대로 넣고 요청을 이어 쓰면 됩니다.
출처는 기획·설계 문서(2026-09-28 기준)이고, 문서끼리 어긋나는 것은 맨 아래 「미정」에 따로 적었습니다.

## 붙여 넣을 브리프

```
[서비스] 「오또 — 말로 만드는 그림책」. 만 3~7세 아이가 마스코트와 말을 주고받으며
종이 인형극 그림책(6~8쪽, 만지면 반응)을 한 권 만든다. 끝나면 부모에게 "오늘 아이가 한 말 그대로"가 남는다.
모드: 이야기 만들기(동화) · 오늘 이야기(일기) · 같이 만들기(부모 협업).

[주 사용자: 아이, 만 3~7세(평균 5세)]
- 글을 못 읽는다고 가정한다. 모든 안내는 소리·그림·손가락 시연으로 한다. 아이 화면에 글자에 기대는 UI는 없다.
- 화면 밖에 숨은 것을 못 찾는다. 스크롤·페이지 넘김 없이 한 화면에 다 보이게 한다.
- 끌어다 놓기는 어려운 동작이다. 탭 위주로 설계한다.

[보조 사용자: 부모·어른]
- 동의 · 설정 · 기록 보기를 맡는다. 부모 모드는 비밀번호 4자리 뒤에 있다.
- 같이 만들기 모드: 폰 한 대, 아이는 위쪽 그림을 보고 부모는 아래쪽 띠의 글자를 읽는다.
- 부모 입력은 탭하는 템플릿으로 한다(직접 타이핑하지 않음).

[UX 원칙]
1. 목소리가 먼저: 질문은 소리로, 선택은 큰 그림 카드 3장. 확인은 예/아니오 대신 "좋아/싫어" 그림 카드.
2. 틀림이 없다: 오류 표시·빨간 X·실패 화면·타이머 없음. 못 알아들으면 마스코트가 다시 묻고, 미션은 결국 성공한다.
3. 기다림을 보이지 않는다: 스피너만 있는 화면 금지. 기다리는 동안 마스코트가 말하거나 움직인다.
4. 아이 화면에서 빼는 것: 점수 · 기록 · 잠긴 버튼 · 결제 문구 · "일기"라는 낱말. 이런 것은 부모 모드에만 둔다.
5. 말투: 따뜻한 동화 말투, 지적하지 않는다. 부모 화면에도 또래 · 수준 · 등급 · 진단 같은 말을 쓰지 않는다.
6. 광고 · 회원가입 · 결제가 없다. 신고 버튼은 부모 모드와 책 읽기 화면에 둔다.

[화면 틀 · 시각 스타일] — 자세한 값은 design/디자인시스템.md, 컴포넌트는 otto_design_system.pen
- 가로 전용 800×360dp. 첫 화면은 버튼 없이 「오또의 방」 — 인형극 무대=이야기 만들기, 창문=오늘 이야기,
  소파=같이 만들기, 책장=내 책.
- 이야기 짓기는 오또와 마주 보고(왼쪽 오또, 오른쪽 책 한 쪽). 마이크 버튼 없음 — 오또의 몸짓 + 발밑 물결 색
  (분홍 말함 · 청록 들음 · 겨자 생각)으로 차례를 알린다. 말이 없으면 고르기 방울 3개.
- 왼쪽 위 🏠 · 🔒(2초 길게), 위 가운데 별 모으기 진행(쪽마다 작은 별, 끝 큰 별). 넘어가기 화살표 없음.
- 재료: 양모 펠트 인형극. 단색 + 양모 결 + 안쪽 바느질선 + 부드러운 그림자. 누르면 꾹 눌림.
- 무대(배경)는 차분한 크림·나무·커튼 색, 누를 수 있는 것만 선명한 펠트 색(코랄·겨자·하늘·풀).
- 글꼴: 아이 Jua, 부모 Noto Sans KR. 모서리 12/20/28/원, 뾰족한 모서리 없음.
- 누르는 곳: 핵심 96dp, 아이 최소 64dp, 부모 최소 48dp.
```

## 화면 목록

스플래시 · 동의 · 시작 · 함께하기 · 주인공 만들기 · 이야기 짓기 · 확인 카드 · 그림판 · 소리 녹음 · 미션 ·
친구 평가 · 책 읽기 · 책장 · 선물 · 부모 모드 · 신고.
일기 모드는 새 화면 없이 질문만 바뀌고, 같이 만들기는 부모 띠 하나만 더해진다.

## 미정 — 문서끼리 어긋나는 것 (시안 그리기 전에 정할 것)

| 항목 | 어긋남 |
|---|---|
| 대상 연령 | 3~7세 유지(정렬회의 결정) vs "만 5세 전후"(프로토타입 계획) |
| 진행 표시 | 아이 화면에 진행 막대 없음(초안·프로토) vs 맨 위 진행 별(안드로이드 설계) — 브리프는 설계를 따름 |
| 선택지 제시 | 선택지를 먼저 말하기(초안) vs 무응답 뒤에만 카드(안드로이드 설계·동화 모드) |
| 핫스팟 표시 | 금빛 고리 vs 고리 없이 안 만지면 반짝(0928 멘토링 준비) |
| 도감 | 2×3 여섯 칸 vs 가로 4칸 + 점선 ＋ |
| 친구 평가 문구 | 좋아/싫어 vs 또 만날래/안녕 |
| 태블릿 | 가로 전용인데 600dp 이상에서 세로로 돌아가 배치가 깨짐 |
