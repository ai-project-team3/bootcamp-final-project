# 오또 디자인 시스템 — 양모 펠트 인형극

파일: `otto_design_system.pen` (만드는 스크립트: `tools/build_design_system.py`)
작성: 2026-09-28 · 기존 앱 디자인(`Theme.kt` · Jua · 종이 인형극)을 잇지 않고 새로 정했다.
대상: 가로 전용 안드로이드, 화면 틀 **800×360dp**.

## 한 줄 방향

**버튼 대신 오또의 방과 오또의 몸짓.** 첫 화면은 방 안 물건이 메뉴이고, 이야기는 오또와 마주 보고 말로 짓는다.
차분한 펠트 무대 위에서 누를 수 있는 것만 선명하게 튀어나온다.
재료는 마스코트 **오또(청록 펠트 후드를 쓴 고양이)**와 로고(펠트 글자)에서 가져왔다.

## 참고한 앱과 가져온 것

| 앱 | 근거 | 가져온 것 |
|---|---|---|
| Pok Pok (2021 Apple 디자인상) | 앱 전체 11색 + 흰색, 손으로 만든 불완전함, 반복해도 지치지 않는 실물 소리 | 색을 16개 토큰으로 제한, 펠트 결의 불완전함, 차분한 소리 |
| Duolingo · Duolingo ABC (2021 Webby) | 둥근 도형만 사용, "누를 수 있음"이 보이는 입체 버튼, 모든 안내를 소리로, 읽는 동안 아이콘이 맥박처럼 뜀 | 둥근 형태 언어, 누르면 꾹 눌리는 버튼, 목소리에 맞춰 출렁이는 표시 |
| Sago Mini (2026 Apple 디자인상) | 읽기 없이 쓰는 조작, 느린 애니메이션 | 아이 화면에 글자에 기대는 UI 없음, 느린 움직임 |
| Toca Boca (2020 Webby) | 점수 · 레벨 · 글 튜토리얼 없음 | 점수 · 실패 · 타이머 없음 |
| Khan Academy Kids | 캐릭터가 안내를 맡음, 홈이 집(공간) | 오또가 방에서 다음 할 일을 가리킴 |
| Buddy.ai | 마이크 버튼 없이 캐릭터가 귀를 댈 때만 들음, 막히면 조수 캐릭터 | 마주 보고 대화 |
| Moxie · Miko | 듣는 중을 색 불빛 · 물결로 표시 | 발밑 물결 3색 |
| Pok Pok · Apple Kids 가이드 | 부모 영역은 구석의 작은 회색 아이콘 + 어른용 과제 | 오른쪽 위 작은 🔒, **2초 길게 누르기 → PIN** |
| NN/g 아동 UX 연구 | 어린아이 터치 대상은 어른보다 훨씬 커야 함, 드래그는 어려움 | 누르는 곳 크기 4단계, 드래그는 탭으로도 되게 |

## 1. 색 (16개)

**무대 — 차분하게**

| 토큰 | 값 | 쓰임 |
|---|---|---|
| `--wool` | `#FFF7EC` | 기본 배경 |
| `--wool-cream` | `#F3E7D3` | 카드 · 말풍선 · 아이콘 버튼 |
| `--stage-wood` | `#D9A56B` | 무대 바닥 · 책장 |
| `--stage-wood-deep` | `#A8733F` | 나무 그림자 · 털실 |
| `--curtain` | `#B8322E` | 커튼 · 책 표지 |
| `--curtain-deep` | `#7A1E1E` | 커튼 주름 |
| `--ink` | `#3A2A20` | 글자 · 아이콘 |
| `--ink-soft` | `#8A735F` | 보조 글자 · 비활성 |

**펠트 강조 — 누르는 것 · 브랜드**

| 토큰 | 값 | 쓰임 |
|---|---|---|
| `--felt-coral` | `#E8604C` | 주 버튼(다음 · 고름 · 부모 주 버튼), 로고 「오」 |
| `--felt-mustard` | `#F2B232` | 진행 방울 · 보상 · 도구 고름, 로고 「또」, 오또 후드 단추 |
| `--felt-teal` | `#4FAF98` | **마이크 전용.** 오또의 후드 색 — "오또와 말한다". 따뜻한 무대에서 유일한 차가운 초록 |
| `--felt-sky` | `#5B8ED6` | 같이 만들기 모드 (후드 안감) |
| `--kitten` | `#F2955A` | 오또 털 · 작은 포인트 |
| `--cheek` | `#F48C92` | 좋아 · 칭찬 (발바닥 · 볼) |
| `--white` | `#FFFFFF` | 펠트 위 아이콘 · 부모 카드 |

규칙: 선명한 펠트 색은 **누를 수 있는 것과 브랜드에만** 쓴다. 배경 · 장식에 쓰지 않는다.

## 2. 글자

| 역할 | 글꼴 | 크기 |
|---|---|---|
| 아이 · 큰 제목 | Jua | 40 |
| 아이 · 말풍선 | Jua | 22 |
| 아이 · 카드 이름 | Jua | 20 |
| 부모 · 제목 | Noto Sans KR 700 | 22 |
| 부모 · 본문 | Noto Sans KR 400 | 16 |
| 부모 · 작은 글 | Noto Sans KR 400 | 13 |

아이 화면의 글자는 **읽지 못해도 괜찮은 보조**다. 모든 안내는 소리로 하고, 글자만으로 뜻이 전달되는 버튼은 만들지 않는다.
Jua는 펠트 로고 글자와 가장 비슷한 둥근 획이라 남겼다. 부모 화면은 긴 글을 읽어야 해서 본문용 고딕을 따로 둔다.

## 3. 크기 · 간격 · 모서리

| 토큰 | 값 | 쓰는 곳 |
|---|---|---|
| `--touch-hero` | 96dp 이상 | 고르기 방울 · 방 물건 |
| `--touch-kid` | 80dp | 다음 · 좋아/다시 |
| `--touch-kid-min` | 64dp | 아이 화면의 모든 누르는 것의 최소 |
| `--touch-parent` | 48dp | 부모 화면 최소 (Material 기준) |
| `--space-*` | 4 · 8 · 12 · 16 · 24 · 32 | 간격 |
| `--radius-*` | 12 · 20 · 28 · 원 | 모서리. 뾰족한 모서리는 쓰지 않는다 |

연구 권장치(아이 2cm ≈ 126dp)는 가로 폰 높이 360dp의 3분의 1이라 그대로 쓸 수 없다. 핵심 버튼 96dp, 최소 64dp로 타협했다.

## 4. 재료 — 펠트 조각

모든 아이용 누르는 요소는 같은 네 겹으로 만든다.

1. **단색** — 펠트 색 하나
2. **양모 결** — `assets/felt_texture.png`를 위에 겹친다(투명 PNG, 밝고 어두운 섬유)
3. **바느질선** — 가장자리 안쪽 5dp에 옅은 흰 선. *앱에서는 점선으로 그린다* (pen.dev는 점선을 지원하지 않아 실선으로 대신함)
4. **부드러운 그림자** — 아래로 5dp, 흐림 10dp, `#3A2A20` 20%. 가장자리에는 1.5dp 밝은 번짐(보송함)

**누를 때:** 96%로 꾹 눌리고 그림자가 2dp로 얕아진다(120ms). 떼면 스프링으로 톡 돌아온다.
부모 화면은 1 · 3만 쓰고 질감과 큰 그림자를 뺀다.

## 5. 화면 구조 — 두 가지를 섞었다

### A. 오또의 방 = 첫 화면 (Toca Boca · Pok Pok · Khan Academy Kids)

버튼 화면이 없다. 방 안의 물건이 곧 메뉴다.

| 물건 | 들어가는 곳 | 근거 |
|---|---|---|
| 🎭 작은 인형극 무대 | 이야기 만들기 | Toca: 장소를 눌러 들어감 |
| 🪟 창문 (해 · 구름) | 오늘 이야기 | 〃 |
| 🛋 소파 + 쿠션 두 개 | 같이 만들기 ("둘이 앉는 자리") | 〃 |
| 📚 책장 | 내 책 | Khan Kids: 왼쪽 위 Library |
| 오또 (가운데) | 말을 걸면 추천 물건을 몸으로 가리킴 | Khan Kids: Kodi가 "다음 할 일"을 안내 |

- 모든 물건은 살짝 떨린다(Pok Pok의 "everything could jitter"). **반짝임은 새것 · 추천 하나에만** 쓴다(Toca: 수집 보석만 반짝).
- 아무것도 안 누르고 5~8초가 지나면 오또가 물건 하나를 보며 이름을 말한다.
- 글자 · 메뉴 · 축하 팝업이 없다(Pok Pok).

### B. 이야기 짓기 = 오또와 마주 보고 (Buddy.ai · Moxie · Miko)

**마이크 버튼이 없다.** 왼쪽에 오또가 크게(280dp) 아이를 마주 보고, 오른쪽에 지금 짓는 책 한 쪽이 있다.

| 상태 | 오또의 몸짓 | 발밑 물결 | 녹음 |
|---|---|---|---|
| 말하는 중 | 입을 움직임 | 분홍 `--cheek` | 안 함 |
| **듣는 중 (네 차례)** | 귀를 쫑긋 · 몸을 앞으로 기울임 | 청록 `--felt-teal` | **이때만** |
| 생각하는 중 | 고개를 갸웃 | 겨자 `--felt-mustard` | 안 함 |

- 차례를 **몸짓 + 색 물결 두 겹**으로 알린다. Buddy는 "귀를 화면에 댈 때만 듣는다"를 몸짓으로만, Moxie · Miko는 색 불빛으로 알린다. 몸짓만으로는 모호하다는 리뷰가 있어 둘을 겹쳤다.
- 들리는 동안 청록 목소리 막대가 출렁이고, 끝나면 오또가 **들은 말을 되받아 말한다**("빨간 공룡이구나!", Lingokids 방식). 그 말이 바로 오른쪽 쪽에 그려진다.
- 말이 없으면: 한 번은 더 쉽게 다시 묻고, 그래도 없으면 **고르기 방울 3개**가 쪽 위에 떠서 탭으로도 답할 수 있다.
- 막혀도 따로 "힌트" 버튼을 두지 않는다. 말이 없으면 오또가 더 쉽게 다시 묻고, 그래도 없으면 고르기 방울이 뜬다.
- 칭찬은 팝업 없이 오또의 몸짓과 목소리로만.

### 모드마다 다른 배경

오또의 방에서 누른 물건이 그대로 그 모드의 배경이 된다. 방 → 물건 → 그 안으로 들어가는 느낌이다.
화면 짜임(왼쪽 오또 · 오른쪽 책 한 쪽 · 위 별 진행)은 같고 **배경만 바뀐다.**

| 모드 | 방의 물건 | 배경 |
|---|---|---|
| 이야기 만들기 | 🎭 인형극 무대 | **인형극 무대** — 벨벳 커튼 · 조명 · 나무 바닥 |
| 오늘 이야기 | 🪟 창문 | **아침 창가** — 하늘색 벽 · 펠트 깃발 줄 · 햇살 · 밝은 나무 바닥 |
| 같이 만들기 | 🛋 소파 | **저녁 거실** — 복숭아색 벽 · 스탠드 불빛 · 소파 · 아래 부모 띠 |

### 별 모으기 진행 (맨 위 가운데)

지금 앱의 「막대가 차고 끝 별이 빛나는」 느낌을 살려 펠트로 다듬었다.

- 크림 펠트 길 위로 겨자 펠트가 차오르고, 윗면에 윤기 한 줄, 1.6초마다 빛이 한 번 지나간다.
- 쪽마다 작은 별: 지난 쪽은 흰 별, 남은 쪽은 흐린 별. 몇 쪽째인지 글자 없이 셀 수 있다.
- 끝의 큰 별(60dp)은 안쪽부터 조금씩 차오르고, 다 차면 금빛 · 빛 원 · 반짝이와 함께 커졌다 작아졌다 숨 쉰다.

### 공통 자리

- **왼쪽 위 = 시스템**: 🏠 방으로 · 🔒 부모 문(2초 길게 누르기). Toca는 한쪽 위 모서리에 시스템 버튼을 모으고, Sago는 부모 입구를 왼쪽 위에 둔다.
- **위 가운데 = 별 모으기 진행.** 이야기 짓기 화면에는 넘어가기 화살표를 두지 않는다 — 차례는 오또가 몸짓으로 넘긴다.

화면 순서: ① 스플래시 → ② 로그인 1/3 → ③ 동의 2/3 → ④ 마이크 3/3 → ⑤ 아이에게 건네기 → ⑥ 튜토리얼(눌러 보기 · 말해 보기) → ⑦ 기능 소개 → ⑨ 오또의 방. ("어른 불러 줄래?" · "보호자 확인" 화면은 뺐다.)

## 7. 화면 흐름 (`.pen` 의 「05 화면 흐름도」 판)

**처음 한 번** — 보호자가 먼저 본다(Duolingo ABC · Khan Kids)
⓪ CLAP(팀 이름, 켤 때마다) → ① 타이틀 → ② 보호자 환영 → ③ 로그인 / 회원가입(카카오 · 네이버 · Google · 이메일) → ④ 보호자 동의(만 14세 미만 법정대리인)
→ ⑤ 마이크 켜기(아이가 권한 창을 보지 않게) → ⑥ 부모 비밀번호 4자리 → ⑦ 오또 인사 · 방 둘러보기(Toca) → ⑨
이미 계정이 있으면 ③ 로그인 뒤 바로 ⑧.

**매일**
⑧ 실행(자동 로그인, 프로필 고르기 없음) → ⑨ 오또의 방 → 인형극 무대 · 창문 · 소파 중 하나
→ ⑩ 책 만드는 중 → ⑪ 책 읽기 → ⑫ 친구 평가 → ⑬ 선물(방 장식으로 쌓임, Khan Kids) → ⑭ 책장에 꽂기 → ⑨로 돌아옴.
⑮ 하루 한도에 닿으면 오또가 "오늘은 여기까지" — 연장은 부모 비밀번호로만(Lingokids). ⑯ 종료.

**어디서든** — 🔒 2초 → 비밀번호 → 부모 영역: 기록 · 같이 만들기 질문 · 설정 · 신고 · 동의 철회 · **계정**
계정: 로그인 정보 · 로그아웃(데이터 유지, ③으로) · **회원 탈퇴 · 데이터 삭제**
→ 탈퇴 안내(폰 안의 책 · 그림 · 녹음도 지울지 고름) → 본인 다시 확인 → 삭제(서버 계정 즉시 삭제 · 폰 데이터 삭제) → ①

**예외** — 마이크 거부(고르기 방울로 진행) · 못 알아들음 · 오프라인(책장 · 읽기만) · 로그인 만료(아이에게 "어른 불러 줘") · 다시 설치(기록만 돌아옴)

### 화면 30개 (`.pen` 의 「06 화면 — 흐름도 순서대로」 판)

흐름도 번호 순서로 4열 격자에 놓았다. 화면마다 아래에 **흐름도 단계 · 참고한 앱과 규칙**을 적었다.

| 구역 | 화면 |
|---|---|
| 처음 한 번 | ⓪ CLAP(팀 이름, 매번) · ① 타이틀 · ② 보호자 환영 · ③ 로그인 / 회원가입 · ③ 이메일로 시작 · ④ 보호자 동의 · ⑤ 마이크 켜기 · ⑥ 부모 비밀번호 · ⑦ 오또 인사 · 방 둘러보기 |
| 매일 | ⑨ 오또의 방 · 주인공 고르기 · 오또가 말해요 · 네 차례야 · 골라 줘 · ⑩ 책 만드는 중 · ⑪ 책 읽기 · ⑫ 친구 평가 · ⑬ 선물 · ⑭ 책장 · ⑮ 하루 한도 |
| 어디서든 | 부모 문 → 비밀번호 · 부모 영역 기록 · 부모 영역 계정 · 탈퇴 ① 안내 · 탈퇴 ② 최종 확인 |
| 예외 | 오프라인 · 마이크가 꺼져 있을 때 · 로그인이 풀렸을 때 |

### 마스코트를 넣는 곳 · 빼는 곳

**기준: 오또가 아이에게 말을 거는 화면에만 넣는다.** 오또가 모든 화면에 있으면 아무 데서도 눈에 띄지 않고,
화면마다 주인공(친구 · 선물 · 책 · 입력 칸)과 시선을 다툰다.

| 넣는다 (오또가 말하거나 이끈다) | 뺀다 |
|---|---|
| ① 타이틀 — 커튼 뒤에서 인사 | ⓪ CLAP — 팀 이름만 |
| ② 보호자 환영 — "어른 불러 줄래?" | ③~⑥ 보호자 설정 — 대신 왼쪽에 **설정 단계 1/4~4/4** |
| ⑦ 방 둘러보기 · ⑨ 오또의 방 | 주인공 고르기 — 주인공 카드가 주인공 |
| 이야기 짓기 대화 3상태 · 마이크 꺼짐 | ⑪ 책 읽기 — 그림과 자막이 주인공 |
| ⑩ 책 만드는 중 — 그리는 몸짓 | ⑫ 친구 평가 — 친구가 주인공 |
| ⑮ 하루 한도 — 하품하며 인사 | ⑬ 선물 · ⑭ 책장 — 선물 · 책이 주인공 |
| 예외: 오프라인 · 로그인 풀림 (아이에게 설명) | 부모 문 · 부모 영역 · 탈퇴 — 보호자 화면은 모두 뺌 |

마스코트를 뺀 아이 화면에서도 오또의 **목소리는 계속 들린다** — 왼쪽 아래 분홍 스피커 표시가 그 자리다.

**화면 공통 규칙** (상위 앱 조사에서 뽑음)
1. 아이 영역과 어른 영역을 나눈다. 로그인 · 동의 · 권한 · 설정 · 탈퇴는 모두 어른 확인 뒤에 (Google Play Families 정책).
2. 아이 버튼은 크게(64dp 이상), 닫기 · 나가기는 주 버튼과 떨어뜨린다.
3. 아이 화면의 글은 한 줄 이내로, 반드시 오또 목소리와 함께. 누른 곳은 반드시 움직임이나 소리로 반응.
4. 막다른 화면이 없다. 오프라인 · 권한 거부 · 한도 도달 때도 아이가 할 일 하나 + 어른 경로 하나.
5. 점수 · 조급함 · 광고로 붙잡지 않는다. 소셜 로그인 버튼은 각 사 규격 그대로.

**로그인 버튼 규격** — 카카오 `#FEE500` · 모서리 12 · 말풍선 심볼 필수 · 레이블 검정 85% / 네이버 `#03C75A` /
Google 흰 바탕 · `#747775` 1px 테두리 · 공식 G 로고 · **다른 버튼보다 덜 눈에 띄게 만들면 안 됨**.
시안의 카카오 심볼 · 네이버 N · Google G 는 자리만 잡은 것이라, **앱에 넣을 때 각 사가 배포한 공식 이미지로 바꾼다.**
네이버 버튼 높이 · 모서리 수치는 developers.naver.com 원문에서 다시 확인해야 한다.

## 8. 아직 안 정한 것

- **귀 쫑긋 자세**는 네 번 뽑아도 손이 귀로 가지 않아, 입을 다문 집중하는 얼굴로 대신했다. 손을 귀에 댄 그림이 꼭 필요하면 직접 그리거나 다른 모델로 다시 시도한다.
- 방 물건은 지금 펠트 도형으로만 그렸다. 실제 그림(펠트 사진풍)으로 바꿀지 정한다.
- 조용한 곳이 아니면 듣기가 실패한다(Buddy 리뷰에 "안 들린다" 불만이 많음) — 실패 시 고르기 방울로 넘어가는 시간을 정해야 한다.
- 아이 이름 없이 오또가 아이를 어떻게 부를지 (예: 주인공 이름으로 · "친구야").
- 아이콘은 lucide 선 아이콘 임시. 그림판 · 주인공 꾸미기 · 소리 녹음 · 미션 화면은 아직 없음.
- 탈퇴용 웹 삭제 요청 페이지(Google Play 필수)를 따로 만들어야 한다.
