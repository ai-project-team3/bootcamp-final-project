# 말로 짓는 인형극

> 만 3~7세 아이와 어른이 **말을 주고받으며** 종이 인형극 그림책을 한 권 만든다.
> 끝나면 부모에게 **오늘 아이가 한 말 그대로**를 남긴다.

부트캠프 최종 프로젝트 · 2026-09 ~ 2026-10 · 4명

📋 **[노션 — 기획 · 발표 · 조사 문서](https://app.notion.com/p/3-3c60c9f77f88800ca1d4eb509331b03d)**

---

## 무엇이 다른가

그림책 앱은 **읽어 준다**. 이 앱은 **아이가 짓게 한다.**

```
🗣  마스코트  "오늘은 어디로 가 볼까?"
🧒  아이      "공룡나라 갈래! 근데 뿌뿌도 데려갈 거야."
                └ 묻지 않은 걸 스스로 덧붙였다  ← 이게 기록된다
🗣  마스코트  "공룡 나라구나! 거기서 누굴 만났어?"
```

**세 가지를 다르게 했다.**

**① 아이가 만든 건 AI가 다시 그리지 않는다.** 아이 그림은 그대로 책에 들어간다. 아이 목소리 녹음은 **폰을 떠나지 않는다.**

**② 질문 순서가 고정이 아니다.** 아이가 *"혼자 갔어"*라고 하면 "누구랑?" 칸이 사라지고, *"친구랑 싸웠어"*라고 하면 화해 방법이 새로 필요해진다. **무엇을 물을지는 방금 한 말이 정한다.**

**③ 부모 리포트에 점수가 없다.** 등급·또래 비교·"발달했습니다"를 쓰지 않는다. 대신 **횟수와 아이가 한 말 그대로**를 보여준다.

```
까닭을 말한 것    4번   "무서워서 도망갔어."

"오늘은 어디로 가 볼까?"
  9/10  "우주!"
  9/14  "바닷속에 가 볼래."
  9/17  "로켓 타고 우주 갈래! 별 보러 가고 싶어서."
```

같은 질문에 대한 답을 나란히 놓는다. **단계 이름을 한 글자도 쓰지 않고** 무엇이 달라졌는지 보인다.

## 어떻게 도는가

```
🧒 말한다
   ↓  폰에서 말소리 구간만 자른다 (Silero VAD)
   ↓  글자로 바꾼다 (자체 GPU · 음성 사본 즉시 삭제)
   ↓  폰에서 이름을 가린다 ({주인공} · {친구1})  ← 실명이 폰을 안 떠난다
   ↓  규칙 금칙어 → LLM 안전 필터
   ↓  판정 — 어느 칸이 채워졌나 · 다음에 뭘 물을까 · 이야기가 다 찼나
🗣 마스코트가 받아주고, 되돌려주고, 다음을 묻는다
   ↓  칸이 다 차면
📖 장면 6개 + 자막 → 미리 만들어 둔 그림을 겹쳐 책이 된다
```

**세션 중에 그림을 만들지 않는다.** 전부 미리 만들어 APK에 넣고 앱에서 조합한다.
지연 0초, 부적절한 그림이 나올 일 없음(사람이 전수 검수), 비행기 모드에서도 돈다.

## 폴더

| | |
|---|---|
| `android/` | 앱 본체 — Kotlin + Compose, 가로 전용 |
| `backend/` | FastAPI 프록시 — 키 보관 · 규칙 필터 · LLM 호출 |
| `eval/` | 평가 하네스 — 프롬프트 · 픽스처 · 러너 |
| `assets/` | 미리 만든 그림 + 만드는 도구 (ComfyUI) |
| `guidelines/` | **코드가 지켜야 하는 것 — 이름 · 구조 · 프롬프트 · 금칙어** |
| `prototype/` · `prototype-b/` | HTML 초안 A · B |

## 시작하기

```bash
# 백엔드
cd backend
cp .env.example .env          # 키를 채운다. .env는 커밋하지 않는다
pip install -r requirements.txt
uvicorn main:app --reload     # http://127.0.0.1:8000/health

# 앱
cd android
set JAVA_HOME=C:\Android\jdk-17.0.20.1+1
gradlew.bat assembleDebug
```

## 아이를 다루기 때문에 지키는 것

| | |
|---|---|
| **아이 목소리 녹음은 폰을 떠나지 않는다** | 원본 그대로, 변조 없음 |
| **실명은 폰에서 가린다** | 매핑표(`{주인공}` ↔ 지호)도 **폰에만** |
| **음성 사본은 전사 직후 삭제** | 글자만 남는다 |
| **만 14세 미만은 법정대리인 동의** | 개인정보보호법 제22조의2 |
| **필터는 과차단을 더 경계한다** | *무섭다 · 괴물 · 싸웠다*는 **이야기의 재료다.** 막으면 이야기가 안 만들어진다 |
| **점수를 매기지 않는다** | 등급 · 또래 비교 · "발달했습니다"를 쓰지 않는다 |
