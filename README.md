# 영업 어시스턴트 AI

> 미팅 중 **상대가 아직 무엇 때문에 막혀 있는지**를 항목별로 들고 있다가,
> 풀렸다가 다시 막히는 순간을 잡고, 그 상태를 **차수를 넘어 이어 붙이는** 도구.

부트캠프 최종 프로젝트 · `ai-project-team3` · 2026-09 ~ 2026-10

## 무엇이 다른가

회의록 제품은 **말한 것**을 남깁니다. 이 제품이 앞세우는 건 **아직 안 끝난 것**입니다.

```
18:40  고객 "예산이 좀 부담되는데…"     ← 나왔다      🔴
26:05  고객 "아 그 정도면 됐네요"        ← 끝난 듯     🟢
31:20  고객 "근데 위에서 좀…"           ← 다시        🔴 재발
```

**녹취록에는 두 문장이 따로 적혀 있을 뿐입니다.**
26:05 → 31:20은 미팅 내내 이 항목의 상태를 들고 있어야만 보입니다.

그리고 미팅을 낱개로 남기지 않고 이어 붙입니다.
**3차 리포트는 1·2차를 이 제품으로 해야만 나옵니다.**

```
━━ 3회 누적 ━━━━━━━━━━━━━━━━━
예산 승인   1차 🔴  2차 🔴  3차 🔴
            ↑ 이 고객의 핵심 장벽
```

## 팀

다섯 명이 병렬로 만듭니다. **각자 백엔드와 자기 화면, 그리고 자기 지표 하나를 소유합니다.**

| 역할 | 담당 | 소유 | 지표 |
|---|---|---|---|
| 1 음성·실시간·배포 | **이재환** | 오디오 · STT · 화자 분리 · WebSocket · 백채널 · 배포 | 한국어 WER · p95 지연 · 드롭률 |
| 2 항목 매칭 | **박진웅** | 표현사전 + 임베딩 하이브리드 · 임계값 | 매칭 F1 · 기타 오분류율 |
| 3 상태 추적 | **안치영** | 상태 전이 · 재발 판정 · 평가 러너 | 상태 정확도 · **재발 재현율** |
| 4 생성 | **최민우** | 카드 규칙 + LLM 문장 · 차수별 리포트 | 카드 채택률 · 근거 인용률 |
| 5 템플릿·누적 | **이종훈** (조장) | 항목풀 저작 · 이월 규칙 · 딜 연결 | 이월 정확도 · 템플릿 커버리지 |

각자 **자기 이름 브랜치**에서 작업하고 PR을 올립니다 — `main`에 직접 push하지 않습니다.
배정 근거와 Q&A 답변자는 [`docs/역할_배정_결과.md`](docs/역할_배정_결과.md).

## 스택

**React + Vite** / **FastAPI + SQLAlchemy** / **MySQL** / FastAPI WebSocket 단일 채널 /
`claude-opus-5`

배포는 **Cloudflare Pages**(프론트) + **Railway**(백엔드·DB).
STT 제공자와 임베딩 모델은 W1 스파이크로 확정합니다 — 인터페이스만 먼저 동결했습니다.

## 시작하기

```bash
git clone https://github.com/ai-project-team3/bootcamp-final-project.git
cd bootcamp-final-project

# 백엔드 — backend/ 에서. 포트 8000 고정
pip install -r requirements.txt
cp .env.example .env          # 값은 각자 채웁니다. .env는 커밋하지 않습니다
uvicorn main:app --reload     # GET /health → {"status":"ok"}

# 프론트 — frontend/ 에서. 포트 5173
npm install
npm run dev                   # /api · /ws 는 :8000으로 프록시됩니다
```

**뼈대는 이미 있습니다.** `backend/`·`frontend/` 폴더 구조가 `guidelines/5` §5-2 그대로 깔려 있고,
파일마다 **누가 주인인지 docstring에 적혀 있습니다.** 자기 파일만 채우면 됩니다.

**먼저 읽을 것** — [`guidelines/0_목적_사용법.md`](guidelines/0_목적_사용법.md) →
자기 역할의 [`guidelines/4`](guidelines/4_프롬프트_브리프.md) 절.
