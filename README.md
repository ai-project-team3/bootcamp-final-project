# 영업 어시스턴트 AI

> 미팅 중 **상대가 아직 무엇 때문에 막혀 있는지**를 항목별로 들고 있다가,
> 풀렸다가 다시 막히는 순간을 잡고, 그 상태를 **차수를 넘어 이어 붙이는** 도구.

부트캠프 최종 프로젝트 · `ai-project-team3` · 2026-09 ~ 2026-10

---

## 무엇이 다른가

회의록 제품은 **말한 것**을 남깁니다. 이 제품이 앞세우는 건 **아직 안 끝난 것**입니다.

```
18:40  고객 "예산이 좀 부담되는데…"     ← 나왔다      🔴
26:05  고객 "아 그 정도면 됐네요"        ← 끝난 듯     🟢
31:20  고객 "근데 위에서 좀…"           ← 다시        🔴 재발
```

**녹취록에는 두 문장이 따로 적혀 있을 뿐입니다.**
26:05 → 31:20은 미팅 내내 이 항목의 상태를 들고 있어야만 보입니다.

그리고 미팅을 낱개로 남기지 않고 이어 붙입니다.
**3차 리포트는 1·2차를 이 제품으로 해야만 나옵니다.**

```
━━ 3회 누적 ━━━━━━━━━━━━━━━━━
예산 승인   1차 🔴  2차 🔴  3차 🔴
            ↑ 이 고객의 핵심 장벽
```

## 팀

다섯 명이 병렬로 만듭니다. **각자 백엔드와 자기 화면, 그리고 자기 지표 하나를 소유합니다.**

| 역할 | 소유 | 지표 |
|---|---|---|
| 1 음성·실시간 | 오디오 · STT · 화자 분리 · WebSocket · 백채널 | 한국어 WER · p95 지연 · 드롭률 |
| 2 항목 매칭 | 표현사전 + 임베딩 하이브리드 · 임계값 | 매칭 F1 · 기타 오분류율 |
| 3 상태 추적 | 상태 전이 · 재발 판정 · 평가 러너 | 상태 정확도 · **재발 재현율** |
| 4 생성 | 카드 규칙 + LLM 문장 · 차수별 리포트 | 카드 채택률 · 근거 인용률 |
| 5 템플릿·누적 | 항목풀 저작 · 이월 규칙 · 딜 연결 | 이월 정확도 · 템플릿 커버리지 |

## 스택

**React + Vite** / **FastAPI + SQLAlchemy** / **MySQL** / FastAPI WebSocket 단일 채널 /
`claude-opus-5`

배포는 **Cloudflare Pages**(프론트) + **Railway**(백엔드·DB).
STT 제공자와 임베딩 모델은 W1 스파이크로 확정합니다 — 인터페이스만 먼저 동결했습니다.

```bash
# 백엔드 — backend/ 에서
uvicorn main:app --reload

# 프론트 — frontend/ 에서
npm run dev
```
