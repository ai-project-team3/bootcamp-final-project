# 발화 계산기 검수 안내 — 10-12

## 이번에 확인할 것

아이가 한 말을 글로 옮긴 **전사문을 계산기가 어떻게 나누고 세는지** 확인한다. 실제 아이의 발음 인식(STT), 연령별 발달, 오또 사용 효과를 한 검사로 판정하지 않는다.

계산·제외·집계 검사 25개는 통과했다. 실제 전사문 50개에서는 분석 결과를 얻었지만 독립적인 사람 정답과의 일치율은 아직 없다. 자동 분석표를 그대로 정답으로 삼지 않는다.

## 민우님이 직접 해야 하는 일

1. **형태소를 나누는 기준을 적용할 수 있는 검수자를 정한다.** 익숙하지 않다면 민우님이 숫자를 억지로 채울 필요는 없다. 형태소 분절에 익숙한 검수자에게 기준과 표를 함께 전달한다. 전문가 검증이라고 발표하려면 실제 자격과 검수 범위가 확인돼야 한다.
2. **기존 자동 표를 봤는지 밝힌다.** 이미 본 50개를 고치면 자동 분석을 참고한 검수로 기록한다. 독립적인 정확도를 재려면 자동 답을 보지 않은 검수자가 먼저 정답을 작성하거나, 새 표본을 미리 정해 별도로 검수한다.
3. **원문은 승인된 로컬 범위에서만 다룬다.** CSV·전사문·화자 ID를 GitHub나 채팅에 올리지 않는다. 외부 검수자에게 보내는 것은 AI-Hub 이용 조건과 제공 권한을 먼저 확인해야 한다.

검수자가 준비되면 정답 입력과 자동 비교를 분리해 진행한다. AI는 표 준비·합계·비교를 도울 수 있으나 사람 검수자 이름으로 정답을 채우지 않는다.

## 검수 시작 전 기준 맞추기

- 이번 계산 단위는 **한 답변**이다. 한 답변에 문장이 둘 있어도 분모는 하나다. 연구의 발화 경계 규칙과 동일하다고 가정하지 않는다.
- 조사·어미는 포함하고 문장부호는 제외한다. 반복·말실수를 임의로 고치지 않는다.
- 설명용 고정 예: `곰이 잤어.`는 `곰 / 이 / 자 / 았 / 어`로 5개다. 이것은 실제 검수 대상의 정답을 보여 주는 예가 아니다.
- `요`를 포함한 종결 표현, 축약·복합 형태소, 불완전한 말의 분절 기준을 **검수 전에** 정한다. 여러 분석이 가능한 항목을 어느 한 자동 출력에 맞추지 않는다. 확신이 없으면 미확정으로 남긴다.
- 우리 내용어 유형 수는 `(기본형, 품사)` 조합이다. 모든 연구의 NDW와 같은 정의가 아니므로 형태소 수 검수만으로 NDW까지 검증했다고 보고하지 않는다.

## 로컬 CSV 입력 칸

| 칸 | 입력 방법 |
|---|---|
| 번호·나이·구분·전사문 | 원본 보존 |
| 사람_분절 | 검수자가 판단한 형태소를 `/`로 구분 |
| 사람_형태소수 | 위 분절 개수 |
| 판단불가_이유 | 뜻·분절이 모호하면 이유. 임의 숫자를 넣지 않음 |
| 검수자 | 실제 검수한 사람의 이름 또는 정해 둔 별칭 |

50개 전체를 확인한 뒤 확정·미확정 개수를 함께 보고한다. 쉬운 것만 남겨 정확도를 높이지 않는다. 분절 수와 숫자 칸이 다르면 자동 비교 전에 입력 오류부터 확인한다.

## 정답 확보 뒤 계산할 결과

- 답변별 형태소 수 완전 일치율과 평균 절대오차.
- 전체 평균 형태소 길이의 차이. 평균만 같아 서로 반대 방향의 오류가 가려지는지 확인한다.
- 숫자는 같지만 분절이 다른 경우와 오류 유형. 분절 일치율을 따로 주장하려면 경계·기본형 대응 기준도 먼저 정한다.
- 미확정 수, 자동 결과를 미리 보았는지, 검수자 수, 표본 선정 기준과 분석기 버전.

정답이 없는 현재는 정확도 수치를 쓰지 않는다. 10-12 마침표 진단의 변화 1/50은 **오류율 2%나 정확도 98%가 아니다.** 서로 다른 두 분절 중 무엇이 맞는지 판정하지 않았기 때문이다.

## 연령별 증가와의 관계

653명의 현재 표본에서 3세·6세 차이는 뚜렷하지 않았다. 다른 과제의 짧은 답을 섞으면 정확한 계산기라도 평균이 비슷할 수 있다. 반대로 분석기의 편향도 확인해야 한다. 따라서 자료 전체를 불량이라고 하거나, 아동의 언어가 발달하지 않는다고 결론내리지 않는다.

연령 차이를 다시 검증할 때는 비교 가능한 자발화 과제·발화 경계·분절 규칙을 맞추고 분석 계획을 먼저 정한다. 현재 결과와 사전 기준을 지우거나 통과하도록 표본을 고르지 않는다.
