# 스토어판 서버 연결 계획 (10-01 · 보관 — 아직 하지 않는다)

작성 이종훈(조장) · **보관용.** 조건(§3)이 채워지면 이 순서대로 한다.

## 1. 지금 상태

- 스토어판(비공개 테스트 · 버전 5 `0.3-closed`)은 **서버에 붙지 않는다** — 대본으로 돈다
  - `Server.base` 기본값이 비어 있다(개발 때 `adb -e server` 로만 채움)
  - 출시용 빌드는 http 를 막는다(`src/debug/AndroidManifest.xml` 에만 `usesCleartextTraffic`)
- 공개 https 주소가 생겼다(강사님 · 10-01): **`https://otto-back.shelldocs.cloud`** → Cloudflare → PC1 Docker 백엔드(바깥 8000)
  - `/health` → `mock:false` · 0.7초. 치영이 이 주소로 실기기 한 바퀴 성공(#47)
  - ⚠️ **인증이 없다** — `/docs` 공개, `/judge` 등이 아무 확인 없이 요청을 받는다
  - Cloudflare 가 파이썬 기본 User-Agent(`Python-urllib`)를 403(`1010`)으로 막는다 — 시험 스크립트는 UA 를 넣는다

## 2. 하려는 것 (조장 결정 10-01)

**스토어판은 동화만 서버에 붙이고 횟수를 제한한다. 팀 개발용 빌드는 제한하지 않는다.**

**앱 (`net/Server.kt`)**
- 출시용 빌드에만 기본 주소 `https://otto-back.shelldocs.cloud` · 서버 모드는 `STORY` 하나(일기 · 협업은 대본)
- 출시용 빌드는 요청에 「스토어판」 표시 헤더와 **기기별 익명 ID**(설치 때 만든 UUID)를 붙인다
- 개발용 빌드는 그대로 — `-e server … -e live all`

**서버**
- 스토어판 요청에만 **기기별 하루 상한** — 첫 값(측정 전): `/turn` 150 · `/tts` 150 · `/image` 15 · `/story` 5. 넘으면 `429` → 앱은 대본으로 떨어진다. 숫자는 #30 대로 단가를 잰 뒤 고친다
- 팀 요청(개발용 빌드 · 내부망)은 제한 없음
- 바깥 주소에서는 `/docs` · `/openapi.json` 을 끈다
- 나중(앱 키): 앱만 아는 키 헤더 확인 — 팀원 빌드도 같이 바뀌므로 스토어판과 묶어서

## 3. 하기 전에 채워야 할 조건 — 빠지면 정책 위반

스토어판이 붙는 순간 **실제 사용자의 아이 음성이 우리 서버로, 마스코트 대사가 TypeCast 로** 나간다.

| 문서 | 지금 | 고칠 것 |
|---|---|---|
| Play 데이터 보안 양식 | 「공유 없음」 | 음성 → 우리 서버(처리 후 삭제) · 대사 텍스트 → TypeCast · Cloudflare 경유 |
| 공개 처리방침 | 「서버에 연결되지 않아 전송 없음」 | 전송 항목 · 위탁 / 제3자 표 · 국외 이전(OpenAI · Cloudflare · TypeCast) |
| 동의 화면 | 필수 / 선택 미정 | TypeCast 제공을 필수로 둘지 |

- ⏳ **TypeCast 답신**(09-29 메일 · 옵트아웃 · 보관 기간 · DPA) — 위탁인지 제3자 제공인지가 여기서 갈린다
- ⏳ **멘토님 답**(필수 동의 여부)
- ⚠️ **Cloudflare 는 https 를 한 번 풀어서 넘긴다** — 아이 음성이 Cloudflare(미국) 구간을 지난다. 차별점 1 「우리 서버까지만」의 표현과 처리방침에 영향 → 멘토님께 같이 묻는다
- 아동 대상(가족 정책) 앱은 데이터 보안 양식이 실제와 다르면 **반려 · 삭제**될 수 있다 — 테스터 14일 중에 내려가면 날짜가 무의미해진다
