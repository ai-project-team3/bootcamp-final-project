# 연령별 연구 참고자료 연결 — #343, 10-13

## 구현 결정

민우님이 중간 승인 대기 없이 할 수 있는 구현·검증을 진행하도록 승인했다. #343의 첫 버전 포함 결정을 유지하면서, 현재 자료의 단위 불일치를 숨기지 않는 **연령별 연구 참고 카드**를 구현한다. 검증된 직접 또래 비교의 완료로 표현하지 않는다.

현재 앱은 마이크 답 한 번의 공백 낱말 수를 센다. 논문은 별도 발화 경계와 제외 규칙을 적용한 발화당 어절 수를 센다. 같은 축의 그래프·차이 점수·백분위·정상 범위를 만들지 않는다. 수치를 구해 놓고 승인만 기다리는 상태에서 나아가, 부모가 출처와 방법까지 직접 확인할 수 있게 한다.

## 원문 확인

연구 전체는 2~5세 240명, 6개월 구간별 30명이다. 여기에는 앱 대상과 겹치는 3~5세 여섯 구간만 옮겼다. 6~7세 값을 만들거나 5세 값을 빌려 쓰지 않는다.

가족·어린이집 등의 반구조화 대화에서 도입·마무리를 제외하고 주제 비중을 고려한 연속 50발화를 분석했다. 문장·구·단단어의 경계는 쉼·억양·주제 변화 및 복문·인용·도치 규칙을 사용한다. 자기수정·무의미 반복·간투어·불명료 발화 등을 제외하고 특정 응답의 첫 사용과 반복 사용을 구분한다. 형태소 분석 도구를 쓰더라도 사람 검토가 포함된다. 앱 답 50개가 쌓였다는 사실만으로 이 조건과 같아지지 않는다.

## 화면·데이터

- 최초 맞춤 설정과 부모 설정에 **선택 입력**을 제공한다. 만 3~7세와 생일 뒤 6개월 구간만 받으며 생년월일은 받지 않는다. 구간은 모름을 허용한다.
- `동의하고 나이 저장`을 눌러야 저장된다. 선택 없이 설정 완료·앱 이용이 가능하다. 나이를 안 받았다고 질문을 쉬운 단계로 내리지 않는다.
- 나이는 자동으로 증가하지 않는다. 입력 화면에서 생일·6개월 구간 변경 때 수정하도록 알린다. 카드 제목은 ‘입력한 나이의 연구 참고’다.
- 현재 아이의 `answer_history`에만 저장한다. 서버 요청·책 내용·보고서 업로드 필드에 추가하지 않는다. 답 기록이 하나도 없을 때 저장해도 같은 아이 ID가 재실행 후 유지된다.
- 같은 아이의 호칭만 바꾸면 유지, 다른 아이·말 기록 새로 시작·기기 데이터 삭제 때 제거한다. 개별 책 삭제로 나이를 지우지는 않는다. 나이만 삭제해도 책과 말 기록은 남는다.
- 동의 철회·탈퇴에서는 나이를 제거한다. 말 기록이 손상돼도 나이 키만 지울 수 있다.
- 현재 아이의 동화 직접 답 50개 미만에는 연구 숫자를 숨긴다. 카드 선택·확인·오또·다른 모드 답으로 문턱을 채우지 않는다. 50은 제품의 표시 조건이며 규준 호환성 인증이 아니다.
- 기존 책별 리포트에는 현재 아이의 나이를 끼워 넣지 않는다. 누적 동화 기록 아래에서만 현재 설정과 참고자료를 표시한다.
- 평균과 표준편차를 이름 그대로 표시하고 출처로 연결한다. 6~7세·미입력·6개월 구간 미상은 각각 이유를 알려 준다.

## 안내·동의

앱 약관 판을 2026-10-13으로 올리고 변경 안내에 선택 나이·기기 보관·수정/삭제·미입력 이용 가능을 기록한다. 공개용 처리방침의 저장·파기 내용도 맞췄다. 공개 사이트 배포와 스토어 게시를 이 PR에서 실행하지 않는다. 저장소의 과거 개인정보 초안은 과거 기록임을 명시한다.

## 완료 판정

기준표 출처 대조, 49/50답 경계, 연령 구간·미지원 연령, 기기 저장·재로드·아이 분리·초기화, 화면 조작·표시, 기존 맞춤 질문 실제 HTTP 응답부터 저장 및 다음 책 첫 요청까지 확인한다. 합성 HTTP 응답은 LLM의 실제 판정 정확도나 아동 사용 효과를 측정하지 않는다.

직접 또래 비교까지 하려면 앱 발화 수집·분절·제외 기준을 연구와 맞춘 별도 검증이 필요하다. 이번 카드를 그 검증의 대용으로 사용하지 않는다. 기존 AI-Hub의 연령 방향 미충족 결과는 유지한다.
