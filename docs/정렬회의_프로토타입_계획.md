## 0. 이번에 정한 방향

| 항목 | 방향 | 이전 기획안과 달라진 점 |
|---|---|---|
| **타깃** | **평균 연령 만 5세** (5세만 대상은 아님) | 이전 기획안 3~7세. 연령 범위는 정렬 회의에서 확인. 질문 · 템플릿 · 미션 난이도는 5세를 가운데에 두고 위아래로 조절 |
| **말을 안 할 때** | 무응답이거나 음성 판별이 안 되면 **아이 성향에 맞춘 선택지를 최대 3번** 바꿔 보여준다 | 선택지 1회에서 3회로, 성향 반영 추가 |
| **중간 이미지 확인** | 만드는 도중에 그림을 보여주고 "이렇게 생겼어?"를 묻는다. 티라노인지 트리케라톱스인지 확인하고, 기다리는 틈을 없앤다 | "결과물은 마지막에 한 번에" 원칙을 바꿈 |
| **질문 → 발달 추정 → 템플릿** | 동화 패턴에서 질문을 뽑고, 답을 보고 아이의 현재 이야기 수준을 추정해, **수준에 맞는 동화 템플릿**을 고른다 | 슬롯 고정 1종에서 수준별 템플릿 여러 개로 |
| **주인공 도감** | 프리셋 조합으로 만들기 + **말로 설명해서 만들기**("이렇게 생긴 게 맞아?"). 둘 다 도감에 쌓이고 이야기를 시작할 때 고른다 | 말로 만들기 추가 |
| **해금** | 업적 보상 방식. 세부 규칙은 §1-2 검토 참고 | 요금제 해금에서 업적 해금으로 |
| **인터랙션** | 절정 · 해결 장면에 **미션형 인터랙션**. 동작은 탭 · 끌어서 던지기 · 끌어다 목표에 놓기 · 문지르기 · 당겼다 놓기 5개로 고정, 음성으로 정하지 않음 (§1-4) | 목적 없는 도구 두드리기에 미션 추가 |

## 1. 조장 제안 검토

### 1-1. 말로 주인공 만들기 → **좋다. 조건 셋.**

멘토가 지적한 "아이가 캐릭터와 자신을 동일시할 장치가 없다"를 정면으로 푼다. 아이가 자기 입으로 설명한 인형이라 "이게 나"가 된다.

| 조건 | 이유 |
|---|---|
| **수정은 2번까지, 그다음은 "이대로 할까, 골라서 할까?"** | 만족할 때까지 생성하면 비용이 끝이 없고, 5세는 3번째부터 지루해한다 |
| **질문은 부분별로 쪼갠다** (머리 → 옷 색 → 좋아하는 것) | "어떻게 생겼어?" 한 번에는 5세가 답을 못 한다. 부분 질문은 프리셋 조합 화면과 같은 칸을 쓰므로 두 방식의 데이터 모양이 같아진다 |
| **종이 인형 그림체로만 생성하고 사진 · 실사 얼굴은 만들지 않는다** | 아이 얼굴을 닮게 만들수록 개인정보 쪽으로 가까워진다. 닮은 건 "특징"이지 얼굴이 아니어야 한다 |

**도감 규칙 한 가지는 새로 정해야 한다.** 기존 기획안은 도감 2×3 첫 칸이 주인공 고정이었다. 주인공이 여러 개 쌓이면 **주인공 줄과 친구 줄을 나눌지** 정한다. 4~5세는 화면 밖에 숨은 것을 못 찾으므로 한 화면에 다 보여야 한다는 원칙은 유지한다.

### 1-2. 업적 보상 해금 → **방향은 맞다. 예시 셋 중 둘은 고쳐야 한다.**

| 제안 | 판단 | 이유와 대안 |
|---|---|---|
| **도구를 10회 채우면 해금 (4/10 표시)** | ⚠️ 고침 | 아이 화면에 **"4/10" 진행 막대가 보이면 잠긴 것을 보여주는 것**과 같다. 법 조항은 없고 설계 원칙 문제다 (조사 3 확인). 멘토가 말한 "결과로만 보여주기"와 기획안의 "아이 화면에 잠긴 것 없음"에 어긋난다. → **횟수는 뒤에서만 세고, 채워지는 순간 깜짝 선물로 등장**("뿅망치를 많이 썼더니 깃털이 생겼어!"). 진행 상황은 부모 모드에서만 |
| **해피엔딩이면 해금** | ❌ 바꿈 | 보상이 결말에 붙으면 **아이가 보상을 위해 이야기를 해피엔딩으로 몬다.** 상상력이 좁아지고, 교훈 · 상황 이해 동화의 슬픈 장면과도 부딪히고, 발화 기록도 오염된다. → **"결말 도감"**: 기쁜 · 슬픈 · 웃긴 · 이상한 결말을 모을 때마다 칸이 찬다. 모든 결말이 똑같이 가치 있다 |
| **업적으로 못 얻는 보상** | ⚠️ 조건부 | 사실상 **유료 전용 보상**이다. 아이 화면에 잠긴 채 보이면 멘토가 경고한 과금 유도가 된다. → **부모 모드 안에서만 보이고 부모만 산다.** 아이에게는 산 뒤에 "선물 도착"으로만 나타난다. 1차에는 결제를 구현하지 않고 발표 자료에만 쓴다 |

**추가로 지킬 것**
- **말을 많이 하면 보상 → 금지.** 어른이 "더 말해!" 하고 다그치게 되고, 발화 기록이 오염된다. 보상은 책 완성, 다시 읽기, 새 등장인물 그리기 같은 **말 이외의 행동**에 붙인다
- **랜덤 보상(뽑기) 금지.** 무료면 법 조항에 걸리지 않지만, 나중에 유료와 섞이면 게임법 확률형 아이템 표시 의무 대상이 될 수 있다. 보상은 항상 정해진 조건으로 (조사 3 확인)
- **요금제의 월 권수와 맞춘다.** 기본 요금제가 월 2권이면 "책 10권 완성" 업적은 5개월이 걸린다. 업적 조건은 권수 제한 안에서 달성 가능해야 한다

### 1-3. 발달 추정 → 템플릿 → **가장 강한 차별점이자 가장 위험한 곳**

"질문으로 아이 수준을 파악해 맞는 동화를 준다"는 이 제품을 GPT 한 번 호출과 구별해 준다. 대신 선을 넘으면 기획안이 금지한 **진단 · 선별**이 된다.

| 해도 되는 것 | 하면 안 되는 것 |
|---|---|
| 답에 맞춰 **다음 질문과 동화 난이도를 조절**한다 (게임 난이도 조절과 같다) | 부모에게 **"발달 단계 2" 같은 등급**을 보여준다 |
| 매 세션 추정을 **다시 하고 계속 바꾼다** | 한 번 정한 수준을 고정한다 |
| 부모 기록에 **"이번엔 '왜' 질문에 답을 많이 했어요"**처럼 행동을 쓴다 | "또래보다", "늦다", "발달 지연"을 쓴다 |

근거: 평균 발화 길이 같은 지표로 4세 이후 아이를 가려내는 정확도는 높지 않다는 보고가 있다(기획안 핸드오프 §6-3). **추정은 틀려도 괜찮은 용도(난이도 조절)에만 쓴다.**

### 1-4. 미션형 인터랙션 → **채택 제안. 동작은 5개로 고정, 음성으로 정하지 않는다.**

지금의 "뿅망치로 아무 데나 두드리기"는 목적이 없다. 이야기의 절정에서 **"호랑이를 쫓아내 줘!"** 같은 미션이 뜨고 아이가 손으로 해결하면, 아이가 구경꾼이 아니라 이야기를 푸는 사람이 된다.

**동작 뼈대 5개 (고정)**

| 동작 | 예시 장면 | 눈에 보이는 목표 (3단계) | 난이도 (안치영 표 · ⭐7) |
|---|---|---|---|
| **탭** (반복) | 점점 다가오는 괴물을 장난감 뿅망치로 칠 때마다 "간지러워!" 하며 뒤로 튕겨 나감 | 괴물과의 거리: 가까움 → 중간 → 멀리 사라짐 | 쉬움 |
| **문지르기** | 손가락이 지나가는 곳으로 물대포가 뿜어져 건물에 붙은 불을 끔 | 불 크기: 큰 불 → 작은 불 → 연기 | 쉬움 |
| **끌어서 던지기** | 빨간 주머니를 던지면 펑 연기가 나고 괴물이 재채기하며 도망감 | 맞힌 횟수: 0 → 1 → 2 | 보통 |
| **끌어다 목표에 놓기** | 비구름을 끌어다 우물 위에 놓으면 비가 내려 우물이 차오름 | 우물 수위: 바닥 → 반 → 가득 | 어려움 (목표 영역을 넓게 잡으면 보통) |
| **당겼다 놓기** | 새총을 당겼다 놓아 높은 나무의 열매 떨어뜨리기 | 열매 개수: 3 → 2 → 1 → 0 | 어려움 |

주머니 · 구름 · 새총은 **같은 뼈대에 그림만 바꿔 끼운다.** 물체마다 반응을 따로 만들지 않으므로 기존 기획안의 "조합 폭발 방지" 원칙을 유지한다.

**재미 규칙 — "별을 톡톡 눌러 인사하기"가 재미없는 이유와 반대로 간다** (9/15 조장)

| 규칙 | 뜻 | 예 |
|---|---|---|
| **목표가 눈에 보인다** | 행동할수록 변하는 상태가 화면에 3단계로 보인다 | 우물 수위 · 불 크기 · 괴물과의 거리 |
| **한 번 할 때마다 바로 바뀐다** | 손을 대는 순간 과장된 소리 · 흔들림 · 튕김 | 뿅! 쿵! 치익! |
| **긴장은 있지만 실패는 없다** | 괴물은 다가오지만 아이가 멈추면 같이 멈추고, 주인공에게 닿지 않는다. 타이머 없음 | 몇 초 가만히 있으면 마스코트가 "뿅망치로 콩!" 하고 시연 |
| **3~6번이면 끝난다** | 길게 반복하지 않는다 | 불 3개 · 괴물 튕기기 3번 |
| **장난칠 여지가 있다** | 목표가 아닌 곳에 해도 웃긴 반응이 나온다. 미션 성공과 상관없다 | 비구름을 주인공 위로 끌면 비를 맞고 우산이 펴짐 · 물대포를 트리케라톱스에게 쏘면 몸을 털며 "부르르!" |
| **끝은 크게 · 이야기가 풀린다** | 성공 연출 3초 뒤 이야기 문제가 해결된 장면으로 넘어간다 | 불이 꺼지고 로켓이 다시 붕 날아오름 |
| **아이 이야기와 이어진다** | 미션의 대상 · 장소는 아이가 채운 칸에서 가져온다 | 지호가 말한 "우주" · "외계인" · "트리케라톱스"가 미션에 등장 |

**렌더링 영향 (역할 3)**: 목표 상태 3단계 프레임 · 물줄기 · 비 · 튕김 같은 효과는 **미리 만든 공통 연출**이고 생성하지 않는다. 생성하는 건 미션에 등장하는 물체 그림(구름 · 물대포 · 운석)뿐이다.

**음성으로 미션을 정하지 않는다**

아이 답("빨간 주머니 던져!")을 그대로 인터랙션으로 바꾸는 방식은 쓰지 않는다.

| 위험 | 이유 |
|---|---|
| 뼈대로 옮길 수 없는 답 | "호랑이랑 춤춰!"처럼 5개 동작 어디에도 안 맞는 답이 흔하다 |
| 인식 · 해석 오류가 두 번 겹침 | 음성 인식이 틀리고, 그 결과를 동작으로 옮기는 판단이 또 틀릴 수 있다 |
| 기대와 다른 결과 | 아이가 말한 것과 다른 미션이 나오면 렌더링 괴리보다 실망이 크다 |

→ **미션은 템플릿에 미리 설계해 둔다.** 템플릿의 절정 · 해결 장면마다 "어떤 뼈대 + 어떤 물체"가 정해져 있고, 이야기 속 대상(호랑이 · 우물)만 아이 이야기에서 가져온다.

**규칙**

- **글자 대신 목소리와 표시.** 미션 문구는 마스코트가 말하고, 화면에서는 대상이 반짝이고 손가락 힌트가 움직인다. 5세는 문구를 읽지 못한다
- **실패 없음.** 타이머 없음. 몇 번 못 하면 마스코트가 도와주고 반드시 성공한다
- **책 한 권에 미션 1~2개.** 절정 · 해결 장면에만. 나머지 쪽은 기존 자유 도구(손 · 뿅망치 · 깃털 · 돋보기)
- **폭력 대신 장난감 틀.** 뿅망치 · 물대포는 장난감이다. 괴물은 아파하지 않고 "간지러워!" "재채기 나!" 하며 튕겨 나가고, 마지막엔 집으로 돌아가거나 친구가 된다. "물리치기" 대신 쫓아내기 · 끄기 · 채우기 · 도와주기
- **수준에 맞춘 난이도.** 역할 1의 수준 추정으로 뼈대를 고른다 (쉬움은 탭, 어려움은 당겼다 놓기)
- **점수로 쓰지 않음.** 성공까지 걸린 시간 · 시도 횟수를 부모 기록에 쓰면 소근육 평가가 된다. "미션 성공"은 업적 조건으로 써도 되지만 "빨리 성공"은 안 된다

## 2. 새 흐름 초안 (엔드픽처 후보)

```
① 사용자 정보 받기
   부모 동의 → 도감에서 주인공 고르기
               ├ 프리셋 조합으로 만들기
               └ 말로 만들기: 부분 질문 → 초안 → "이렇게 생긴 게 맞아?" (수정 2회)

② 동화책 만들기
   마스코트 질문 (동화 패턴에서 뽑음, 발달 추정 수준에 맞춤)
     ├ 답함 ──────────► 답 분석 → 수준 추정 갱신 → 템플릿 선택 · 다음 질문
     ├ 모호함 (공룡?) ─► 프리셋 그림 3개로 즉시 확인 (생성 없음, 대기 0초)
     └ 무응답 · 판별 불가 ─► 성향 맞춤 선택지 (최대 3번 교체) → 그래도 없으면 마스코트가 골라줌
   확정될 때마다 뒤에서 초안 그림 생성 → 2~3턴 뒤 "짠! 이렇게 생겼어?" (다시 그리기 2회)

③ 렌더링
   책 펼치기 → 만지며 놀기 (자유 도구)
```

### 조사 2 — 5세 전후 발달 · 인지 (역할 1 · 안치영) · 약 3시간

**답해야 할 질문**: 4 · 5 · 6세는 어떤 질문을 이해하고 어떻게 답하나? 답에서 무엇을 보면 수준을 가늠할 수 있나?

- [ ] ⭐ **국가 기준 먼저** (45분)
  - **2019 개정 누리과정** 5개 영역(신체운동 · 건강, 의사소통, 사회관계, 예술경험, 자연탐구) 중 **의사소통 · 사회관계**의 5세 내용
  - 이 영역이 우리의 **"키우는 능력 축"**이 될 수 있는지 판단. 국가 기준이라 발표에서 방어가 쉽다
- [ ] ⭐ **이야기 발달 논문 3편** (1시간)
  - 검색어: `narrative development preschool`, `story grammar children age 5`, `아동 이야기 산출 발달`, `학령전기 내러티브`
  - 뽑을 것: 나이별로 이야기에 무엇이 나타나나 (등장인물 · 사건 순서 · 원인 · 감정 · 해결)
- [ ] ⭐ **질문 이해 발달** (45분)
  - 검색어: `wh-question comprehension preschool`, `아동 의문사 이해 발달`, `why question children age`
  - 뽑을 것: "누가 · 어디 · 무엇"과 "왜 · 어떻게"를 이해하는 시기, 선택형 질문과 열린 질문의 차이
- [ ] **마음 이해 · 감정 어휘** (30분)
  - 검색어: `theory of mind age 4 5`, `유아 감정 어휘 발달`
  - 뽑을 것: 등장인물의 마음을 묻는 질문("토끼는 왜 슬펐을까?")이 가능한 시기
- [ ] ⭐ **수준표 만들기** (30분)

## 6. 목요일 프로토타입

### 6-1. MVP 기준

- **프런트엔드만.** 가짜 데이터로 "이렇게 동작한다"까지
- **클릭으로 한 바퀴**: 첫 화면 → 주인공 고르기 → 질문 · 무응답 · 중간 확인 → 책 → 미션 한 장면 → 결말 도감 → 부모 모드
- **가짜 아이 3명**으로 흐름이 달라지는 걸 보여준다: 말 잘하는 아이 · 짧게 답하는 아이 · 말을 안 하는 아이

### 6-2. 폴더

```
prototype/
├── index.html      ← 흐름 순서 (역할 4)
├── shared/
│   ├── theme.css   ← 색 · 글꼴 · 버튼 (역할 4)
│   └── mock.js     ← 가짜 데이터 (모양은 수요일 전원 합의, 내용은 역할 2가 채움)
├── 1-info/         ← 동의 · 도감 · 주인공 만들기 두 방식 (역할 4, 말로 만들기 화면은 역할 3)
├── 2-story/        ← 질문 · 무응답 · 선택지 3회 (역할 1)
├── 3-render/       ← 중간 확인 · 책 · 만지며 놀기 · 미션 (역할 3)
└── 4-parent/       ← 결말 도감 · 업적 · 부모 기록 (역할 4)
```

**자기 폴더만 고친다.** `shared/`는 수요일 오후 첫 한 시간 뒤로는 알리고 고친다.
