# 질문별 발화 기록과 기기 누적 — 2026-10-09

관련 결정: #343의 10-09 확정 댓글. 이번 기능은 형태소 계산 전에 필요한 기록 기반이다.

## 이번 구현

- 책을 완성해 꽂을 때 앱이 제시한 질문 문구·질문 유형·답 원문·출처를 책 ID로 기기에 남긴다.
- 열린·까닭 질문에 아이가 말한 답 후보와 카드/선택 답을 분리한다. 확인·미상·그림·어른·마스코트 답은 언어 후보에서 제외한다.
- 실제 사다리 문구와 그림카드 단계를 반영한다. 문구 규칙으로 분류한 후보이며, 사람의 질문 유형 검증을 대신하지 않는다.
- 옛 리포트의 질문 유형은 미상이다. 긴 답이라는 이유로 열린 질문 답으로 소급 분류하지 않는다.
- 뒤로/앞으로 갈 때 리포트 대화와 시작 시각도 복원한다. 같은 책을 다시 저장해도 중복 누적하지 않는다.
- 호칭을 바꿀 때 같은/다른 아이를 확인한다. 같은 아이면 유지하고, 다른 아이면 누적 기록을 새로 시작한다.
- 수동 기록 리셋은 확인 후 진행한다. 책과 책별 리포트는 보존한다. 이미 시작한 이전 기록의 책은 새 기록에 섞지 않고, 다음 새 책부터 누적한다.
- 책 삭제는 해당 책의 누적 원문도 지운다. 탈퇴의 로컬 자료 삭제에는 새 저장소도 포함한다.
- 누적 자료를 읽지 못하면 새 책으로 기존 저장값을 덮어쓰지 않는다. 화면에서 읽기 실패를 알리고 명시적 리셋을 제공한다.

미완성 책의 앱 종료 후 복구나 모든 인터럽트 답 보관을 이 PR의 결과로 주장하지 않는다.
