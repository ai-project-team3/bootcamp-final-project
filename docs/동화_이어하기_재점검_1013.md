# 동화 주인공 홈→이어하기 재점검 — #446

일반 Play 「오또」에서 주인공을 말로 만들다가 앱 안의 홈으로 나온 후 이어하기가 설정 초기 단계로 돌아간다는 민우님 보고다. 설치한 Play 버전·소스는 미확보여서 최신 main과 같은 것으로 단정하지 않는다. 개발 앱의 한도 동작은 별도 #445에서 구분한다.

최신 main `aa3f83f0`에는 #334의 `HeroCreationDraft`가 있고, 후보 확인·수정 질문·수정 두 번 소진·이름 입력·생성 중 취소의 홈→이어하기 검사가 존재한다. 이 경로의 기존 5개를 재실행하고, 부모 시작 한도와 Play 서비스 시작 상한이 모두 0인 상황에서 같은 후보를 세 번 이어 가는 검사를 보강했다.

새 검사는 Android API 26에서 실제 `Director.leaveToRoom()` → `sceneAdult` → `resume` 경로를 사용한다. 후보·수정 기회·이미지 생성 횟수·부모 사용량·서비스 사용량·`story_start` 수가 변하지 않는지 확인한다. 기존 수정이 현재 main에서 재현되는 문제를 막고 있으므로, 실패를 확인하지 않은 런타임 코드에 추가 제한이나 재설정을 넣지 않는다.

이번 범위는 일반 Play 설치본에서 보고한 증상의 원인이 해결됐다는 판정이 아니다. Play 버전 또는 최신 개발 앱에서 같은 단계를 다시 테스트한 결과가 있어야 배포 차이와 현재 코드 결함을 더 좁힐 수 있다. 기존 삭제→새로 만들기 허용은 #331의 조장 결정대로 유지한다.

실행 결과: 주인공 이어하기 6개와 호출 한도 4개, **총 10개 통과·실패/오류 0**. 새 반복 복귀 검사는 API 26에서 통과했다. 최신 개발 앱의 해당 단계는 사용자가 아직 테스트하지 않았다고 알려 주었으며, 실제 Play 소스가 오래됐다고 확정하지 않는다. 한도 설명·차감 시점·오해를 일으키는 ∞ 표시·잘못된 추가 허용 경로는 #445의 별도 수정 범위다.
