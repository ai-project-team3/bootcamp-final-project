# 동화 언어 지표 측정 계획 — #320

작성 최민우 · 2026-10-08. **실제 아동 전사문을 읽기 전에 고정한 기준**이다.
정본 계획은 `기술어필_계획_1008.md` §③이며, 이 문서는 계산 정의와 검증 절차를 구체화한다.

## 순서와 범위

1. 아이 발화에서 MLU-m · 내용어 다양성 · 까닭 표현 후보를 계산하는 순수 함수와 로컬 측정 도구.
2. 학습 PC의 AI-Hub 108 전사문으로 타당성 확인. 음성·외부 API를 쓰지 않는다.
3. 통과 뒤 별도 동화 PR에서 질문 수준 규칙에 연결하고 전/후 비교.

**이번 PR은 1번이다.** 운영 질문·모델·프롬프트·서버 계약을 바꾸지 않는다.
2번이 미검증이면 3번의 문턱을 임의로 정해 적용하지 않는다. 부모 목소리 TTS는 우선 작업 뒤의 선택 사항이다.

## 계산 정의

- 입력: `text`, `by`(`child/card/mascot`), `question_type`(`open/choice/confirmation/unknown`).
  연령 검증에는 동일 화자를 묶을 `speaker_id`, 만 나이 `age`(3~6)가 추가로 필요하다.
- **측정 단위는 한 답변이다.** 마이크 한 번의 답을 문장 부호로 잘라 발화 수를 부풀리지 않는다.
  언어 연구의 발화 분절·수작업 분석과 같다고 주장하지 않는다.
- 앱 질문 조절용 표본은 `child + open`만 쓴다. 확인·선택 질문의 짧은 답은 수준을 내리는 근거가 아니다.
  `unknown`은 열린 질문으로 추측하지 않는다. 전체 아이 발화를 별도로 볼 때는 범위를 명시한다.
- MLU-m: 로컬 Kiwi 형태소 분석기의 형태소 토큰 수 합 / 분석 가능한 답변 수.
  조사·어미는 포함하고 문장 부호·기호는 제외한다. 공백으로 센 어절 수를 MLU-m라고 부르지 않는다.
  미해석 외국 문자·숫자 토큰이 포함된 답변은 별도로 세며, 묵음·기호만 있는 답변은 분모에서 뺀다.
- NDW: `NNG/NNP/NP/NR/VV/VA/MAG/MAJ` 형태의 서로 다른 `(기본형, 품사)` 수.
  조사·어미를 붙인 같은 명사는 한 종류다. 보조 용언·접사·의존 명사는 제외한다.
  이것은 **내용어 유형 수라는 구현 정의**이며 모든 임상 NDW 계산법을 대신하지 않는다.
  표본 길이 때문에 늘어날 수 있으므로 답변 수와 내용어 토큰 수도 반드시 함께 적는다.
- 까닭 표현 후보: 접속 부사 `왜냐하면/그래서/그러므로/따라서`와 연결어미 `어서/아서/니까/으니까/므로/으므로/기에/길래`.
  `~해서`는 `하 + 어서`로 잡는다. 「가서 놀았어」처럼 시간 순서일 수도 있으므로
  **후보 검출이 S1(실제 까닭 설명) 확정을 뜻하지 않는다.** 단어 중간의 문자열 일치는 쓰지 않는다.
- 반복·ASR 오인식·비유창함을 임의로 고쳐 지표를 올리지 않는다. 수작업 검수 기준과 오류율을 따로 남긴다.

계산 도구는 빈 표본에 0점을 붙이지 않고 `MLU-m = null`을 반환한다.
이 지표는 질문 선택의 보조 자료이며 진단·연령 추정·부모 점수나 등급으로 쓰지 않는다.

## 사전 고정 성공 기준

### A. 계산 정확성

1. 출처·질문 범위 제외 검사에서 `card/mascot/choice/confirmation/unknown` 혼입 **0건**.
2. 독립적으로 적은 형태소 목록의 고정 예제에서 MLU-m·NDW 분자/분모 **100% 일치**.
3. 기호만 있는 답변·빈 입력은 표본 없음. 문장 부호 추가만으로 지표가 바뀌는 예 **0건**.
4. 어미 형태소가 없는 동형 문자열을 까닭 표현으로 검출하는 예 **0건**.

### B. 타당성 — 아직 데이터 없음

1. 3세와 6세 **각 최소 10명**, 화자당 **최소 50답변**. 중간 연령도 함께 보고한다.
2. 화자당 처음 50개의 적격 답변을 같은 범위에서 사용한다. 나이별로 발화를 합쳐 긴 화자에게 가중치를 주지 않는다.
3. 나이별 화자 MLU-m 평균의 화자 단위 부트스트랩 **95% 신뢰구간**, 2,000회, 시드 320.
   **3세 구간 상한 < 6세 구간 하한**일 때만 연령 방향 기준을 통과로 기록한다. 겹치면 동률/미확인.
4. 표본·질문 유형·연령/화자 정보가 부족하면 **검증 불가**로 남긴다. 혼합 질문 전사 분석은 탐색 결과이며
   열린 질문에서의 수준 문턱을 검증한 것으로 보지 않는다.
5. NDW는 각 화자의 같은 50답변에서 낸 값과 내용어 토큰 수를 함께 보고한다. 연령별 NDW만으로 수준을 결정하지 않는다.
6. 분석기 수작업 점검은 연령별 처음 10답변의 형태소 분절을 검토해 불일치 수를 기록한다.
   임상 표준과 동일하다는 주장은 하지 않는다.

### C. 질문 연결 전/후 — A·B 다음에 수행

- 짧은 답·긴 답·까닭 답 **각 10개의 고정 대본 세션**, 동일한 판정 입력으로 기존 규칙/후보 규칙을 비교한다.
- 단계별 칸 채움률: 그 단계에서 물은 칸 중 아이 답으로 실제 채워진 비율. 카드·마스코트 대리 채움은 제외한다.
- 짧은 답 묶음: 칸 채움률 **+10%p 이상**, 아이의 주고받기 횟수 평균 **감소 0 이하**.
- 긴 답/까닭 답 묶음: 까닭 질문에 처음 도달하는 적격 답변 순번의 중앙값 **기존보다 최소 1회 빠름**,
  칸 채움률 감소 **0%p 이하**. 도달하지 않은 세션 수도 별도로 적는다.
- 선택/확인 질문만 한 대본의 길이 신호로 내려가는 경우 **0건**.
- story_ready 이외 종료·턴 상한·슬롯 강제 완료·다른 모드 변화 **0건**.
- 합성 대본 전/후를 실제 아이의 개선 효과로 보고하지 않는다. 실제 아이 결과는 별도 평가가 필요하다.

문턱 후보 선택에 쓴 자료와 최종 비교 자료는 나눈다. 기준 변경은 결과를 본 뒤 조용히 덮어쓰지 않고 이유·날짜를 남긴다.

## 실행 방법과 결과

레포 루트에서 실행한다. 별도 로컬 Python 환경을 권장한다. backend 의존성에는 넣지 않았다.

```powershell
python -m pip install -r eval/requirements-language-metrics.txt
python -m pytest -q eval/test_language_metrics.py eval/test_language_metrics_bench.py

# 질문 유형을 직접 표시한 로컬 전사 JSONL: 열린 질문만 분석
python -m eval.language_metrics_bench --input D:/local-data/answers.jsonl

# 기존 AI-Hub 라벨 폴더: 질문 유형이 없으므로 혼합 발화 탐색으로만 분석
python -m eval.language_metrics_bench --input D:/aihub/child36 --format aihub --scope all_child
```

정규화 JSONL 한 줄의 형식은 다음과 같다. `speaker_id`는 로컬에서만 쓰는 비식별 값이다.

```json
{"speaker_id":"local-a","age":3,"text":"곰이 잤어.","by":"child","question_type":"open"}
```

- 전사·질문 유형을 추측해 채우지 않는다. JSONL에 출처/질문 유형이 없으면 입력 오류로 멈춘다.
- AI-Hub는 기존 `녹음자정보.recorderId/age`, `발화정보.stt`만 사용한다.
  음성 파일 유무를 검사하지 않으며, 질문 유형은 `unknown`이다. `(SN:...)` 같은 비발화 라벨만 기존 측정기와 동일하게 뺀다.
- 기본 결과는 Git에서 제외된 `eval/raw/language_metrics_summary.json`에 저장된다.
  나이별 집계·제외 수·질문 유형 수만 있고 원문·화자 ID는 출력하지 않는다.
- 분석기/모델은 Kiwi **0.24.0 / cong**, 받침 보정·오타 교정·복합 형태소 재분할을 끈다.
  실행 결과에 버전·설정·표본 수·부트스트랩 단위/시드를 함께 기록한다.
- 질문 유형이 섞였으면 구간이 분리되어도 `exploratory_only`, 화자가 부족하면 `insufficient_sample`이다.
  충분한 열린 질문 표본에서 기준을 충족해야 `met`이다. 이것도 임상 타당성이나 앱 적용 완료라는 뜻은 아니다.
