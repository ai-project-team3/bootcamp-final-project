# 아동 발화 — AI 보조 검토로 전환 (10-12)

민우님이 문법 전문 지식 없이 빈칸에 독립 분절을 작성하기 어렵다고 알리고, AI 제안을 보고 오케이 또는 보류 사유를 기록하는 방식을 요청했다. 현재 실제 50개 검토는 이 방식으로 진행한다.

## 화면과 기록

- AI가 작성한 분절 제안과 각 조각의 이유를 먼저 보여 준다. 설명도 검토 대상이며 정답으로 보증하지 않는다.
- **오케이 · 다음**: 제안에 동의함을 저장한다. 분절을 다시 입력할 필요가 없다.
- **보류 · 다음**: 이해되지 않거나 틀린 것 같은 이유를 한 줄 적는다. 원문이 불명확한 경우도 보류한다.
- 저장 후 닫았다 열어도 이어간다. 전체 문항 결정 후 완료하면 기록을 고정한다.
- 완료 현황에는 동의 수·보류 수를 표시한다. 동의율을 형태소 분석 정확도로 바꿔 쓰지 않는다.
- 축약의 기본형 표시, 복합 명사·접사 기준, 불완전한 전사처럼 해석이 갈릴 수 있는 부분은 제안의 주의 메모로 남긴다. 원문을 추측으로 고치지 않는다.

## 기존 독립 검수와 구분

새 기록은 `mode=ai_assisted`, `independent=false`이며 `approve`와 `hold`만 받는다. 결과의 `independent_accuracy`는 항상 `null`이다. AI 초안을 사람이 동의했다고 독립적인 사람 정답으로 인증하지 않는다.

기존 직접 작성한 검수 파일은 수정하지 않는다. 같은 문장은 이미 AI의 제안을 확인하므로, 독립 검수에 다시 사용하지 않도록 원래 폴더에 노출 표시 파일을 남기고 독립 검수 서버의 재시작을 차단한다. 기존에 실행 중인 독립 화면도 종료하고 새 화면을 안내한다.

이 검토는 오류 후보를 모으고 규칙을 이해하는 데 활용한다. 독립적인 실제 아동 정확도를 주장하려면 별도 미노출 표본과 해당 기준을 적용할 수 있는 검수자가 필요하다.

## 실행

```text
python -m eval.child_assisted_review prepare --source <old-private-review-folder> --proposals <ai-proposals.local.json> --output <new-private-folder>
python -m eval.child_assisted_review serve --directory <new-private-folder> --port 8882
```

원문과 AI 제안, 사람 판단은 PC에만 보관한다. `prepare`는 새 폴더만 만들며 기존 결과를 덮어쓰지 않는다. AI 제안에는 원문 묶음 해시·항목별 조각·설명·주의 메모·작성 주체를 포함한다. 기존 판단을 오케이로 자동 전환하지 않는다.

검증: 관련 합성 검사 53개 통과. 브라우저에서 오케이, 보류 사유 필수, 저장 후 재개, 완료 후 수정 차단과 현황 표시를 확인했다. 실제 50개에 대한 민우님 판단은 별도로 진행한다.
