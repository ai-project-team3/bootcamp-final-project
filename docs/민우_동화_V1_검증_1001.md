### 실제 서버 확인

- 앞서 `/stt`가 유효한 음성에서도 HTTP 502와 `stt failed: TypeError`를 반환하던 문제가 있었다.
- 서버 수정 뒤 이름 없는 합성 음성으로 다시 요청하니 **1.33초에 정상 전사**했다: 「우리 친구, 숲에서 누구를 만났어?」.
