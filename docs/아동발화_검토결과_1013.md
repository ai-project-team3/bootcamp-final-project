# 아동 발화 50개 검토 결과와 보류 사유 — 10-13

읽은 것: 확정된 로컬 AI 보조 검토 50개, 그때 제시한 분절 제안, Kiwi 0.24.0의 출력·설명, #320·#343 최신 댓글 및 #407·#409 병합 상태. 음성·전문가 독립 정답·실제 아동의 앱 사용 전후는 확인하지 않았다. **이 보고서는 AI 보조 검토 결과이며 형태소 정확도 인증이 아니다.**

검토 저장 시각은 10-12 23:54 KST다. 사용자의 요청에 따라 이후 분석·보고는 10-13 작업으로 구분하며 원본 시각을 바꾸지 않았다.

## 1. 검토 완료

- 전체 50개: 동의 45개, 보류 5개, 미검토 0개.
- 확정된 원본 검토를 기존 검증 함수로 다시 검증하고 저장된 요약과 일치함을 확인했다.
- 원문 묶음·사람 판단·저장 요약 3개 파일의 검사 전후 SHA-256이 모두 같았다.
- 보류를 AI가 동의로 바꾸지 않았다. 45/50을 정확도 90%로 사용하지 않는다.
- 기존 8개 검토와 이번 50개를 합쳐 58개 독립 정답이라고 부르지 않는다.

## 2. 보류 5개의 후속 판단

원문·항목 ID·검수자 식별값은 공개하지 않는다. 아래 분류는 검수자의 판단을 덮어쓰는 정답 판정이 아니라 후속 분석이다.

| 보류 유형 | 수 | 확인한 것 | 처리 |
|---|---:|---|---|
| 복합 용언·합성명사의 내부 분절 | 3 | 기본 설정은 일부 단어를 사전 단위로 묶는다. 세부 분절 설정은 용언과 어미를 더 나누지만 모든 합성명사를 분해하지는 않는다. | 현 계산 정의 아래의 출력으로 보존. 최소 단위 분절·임상 MLU 정답이라는 설명은 하지 않음. |
| 반복·말 고침 | 1 | 반복은 원문에도 있다. 분석기가 새 반복을 만든 것은 아니다. 현재 계산은 전사된 반복을 포함한다. | 원문 유지. 연구와 비교하려면 반복·미완성 발화를 제외하는 기준과 발화 경계를 먼저 맞춤. |
| 해석하기 어려운 전사 | 1 | AI 제안은 불명확한 문자열을 묶었고 분석기는 더 잘게 나눴다. 어느 것이 아이가 의도한 말인지 확인할 근거가 없다. | 정답 미확정 유지. AI 제안도 정답으로 채택하지 않음. 음성을 확인하지 않았으므로 STT 오류라고 확정하지 않음. |

사용자가 후속 판단을 위임한 뒤 위 5개 모두의 처리 방안을 확정했다. 3개는 고정 분석기 단위의 출력으로 유지하고, 반복 1개는 기존 탐색 정의에 맞게 원문 그대로 유지한다. 불명확한 1개는 사람 정답 평가에 사용할 수 없는 항목으로 분류하되 원자료와 전체 탐색 계산에는 그대로 남긴다. **후속 처리 5/5 완료**와 **사용자 원본 보류 5개 보존**은 서로 다른 상태다. AI가 판정한 처리 방안이며 추가 사람 정답 검수가 아니다.

**설명상의 개선점:** ‘뜻을 가진 가장 작은 조각’이라는 일반 설명만으로 현재 `split_complex=False`의 모든 출력을 설명할 수 없다. 현재 도구는 **고정된 Kiwi 분절 규칙에 따른 형태소 토큰 수**를 센다. 조사·어미는 세지만 일부 복합 단어·복합 어미는 묶일 수 있다. 자동 분석기의 사전 단위를 국어 문법의 유일한 정답으로 제시하지 않는다.

또한 `integrate_allomorph`에 따른 기본형 표기와 ‘의미 단위를 더 나누는 것’은 다르다. 전자는 이번 50개에서 개수를 바꾸지 않았지만 후자는 바꿨다.

## 3. 설정 민감도 — 같은 50개, 원문·계산 필터 고정

이번 측정의 목적은 정확도가 더 높은 설정을 고르는 것이 아니라 보류 사유에 해당하는 설정 차이를 확인하는 것이다. `cong`, Kiwi/model 0.24.0, `normalize_coda=False`, `typos=None`을 고정했다. 원문 선택·반복 제거·분모 변경은 하지 않았다. 비교 결과를 보고 기존 설정이나 연령 분석을 교체하지 않았다.

| 설정 | 답변당 평균 토큰 수 | 기존 대비 개수가 바뀐 답변 | 한 답변의 최대 개수 차이 |
|---|---:|---:|---:|
| 기존: 이형태 통합 켬, 세부 분절 끔 | 5.40 | 0/50 | 0 |
| 표시 대조: 이형태 통합 끔, 세부 분절 끔 | 5.40 | 0/50 | 0 |
| 세부 분절 대조: 이형태 통합 켬, 세부 분절 켬 | 6.26 | 36/50 | 3 |

세부 분절을 켜면 `요` 등의 분리까지 영향을 받는다. 평균이 0.86 커진 것은 **동일 자료의 분석 단위가 달라졌기 때문**이며 아이 발화가 늘거나 정확도가 좋아진 결과가 아니다. 이 표는 서로 다른 아동 50명의 답변 하나씩을 섞은 설정 비교다. 기존 653명 × 50답변의 연령별 평균이나 앱 사용 효과와 비교하지 않는다.

기능 설명 근거: [Kiwi 공식 문서의 split_complex](https://bab2min.github.io/kiwipiepy/v0.22.1/kr/). 공개 문서는 기능 의미 확인에만 사용했고, 위 숫자는 설치된 0.24.0 코드로 직접 측정했다. 0.24.0 공개 문서 URL 재조회는 실패했으며 설치된 함수 설명을 함께 확인했다.

## 4. 이번 단계에서 끝낸 것과 남은 것

| 항목 | 상태 |
|---|---|
| 사용자 검토 50개 및 보류 5개 원인 분류 | 완료. AI 보조 검토로 표시 |
| 계산기 합계 규칙·접미사 누락 수정 | #434에 준비. 외부 주석 385개 합계 검사는 이전 결과로 보존 |
| 독립 아동 정답 대비 정확도 | 미확정. 이번 동의·보류로 대신할 수 없음 |
| 앱 발화 기록·관찰 요약 | #407 main 병합 확인 |
| 기록 기반 맞춤 질문 | #409 main 병합 확인. 실제 아이 대상 효과는 미측정 |
| 연령별 발화 차이 | 기존 표본의 기준 미충족 유지. 설정 변경으로 증가를 만들지 않음 |
| 앱 또래 기준표 | #343의 첫 버전 포함 결정 유지. 발화 단위 호환·월령 입력·표시 통계량 연결은 남음 |

현재 바로 사용할 수 있는 설명은 ‘아이의 실제 답을 구분해 기록하고 그 신호로 질문을 조절한다’이다. 형태소 분석·연령 연구는 이를 뒷받침하기 위해 검토한 별도 근거로 제시한다. 3~6세 자동 계산 결과를 나이 판별 점수로 사용하지 않는다.

### 독립 검증을 마무리할 때 필요한 자료

검수 기준을 적용할 수 있는 검수자가 AI 답을 보지 않은 표본의 정답을 작성하고, 복합어·어미·반복·불명확 전사의 처리 기준을 함께 고정해야 한다. 승인된 자료 이용 범위 안에서 진행하며 기존 AI 노출 50개를 새 독립 표본으로 재사용하지 않는다. 원문이 불명확한 항목은 제외 여부·수량·사유를 기록하고 유리한 일치율을 만들기 위해 조용히 버리지 않는다.

민우님에게 같은 50개를 다시 검토하도록 요청할 일은 없다. 이번 사용자 검토 절차는 완료됐고, 남은 것은 다른 종류의 근거 확보다.
