## 2. 기능별 선정 이유와 대안

### 2-1. 음성 인식

**기준이 왜 아동 인식률인가**: 못 알아들으면 마스코트가 같은 질문을 반복하고 다섯 살은 그 자리에서 떠난다. 가격(세션당 0~45원)은 어느 쪽을 골라도 프로젝트를 흔들지 않는다.

**결정적 숫자** `[확인]` — AI-Hub 만 4~7세 5만 발화, Whisper base (디지털콘텐츠학회논문지 25(2), 2024)

| 조건 | CER |
|---|---|
| 파인튜닝 없음 | **120.8%** |
| **아동 50K + 성인 10K** | **19.1%** |
| 피치 증강 | 28.5% (**악화**) |

**120.8%는 "못 알아듣는다"가 아니라 "없는 말을 지어낸다"는 뜻이다.** Whisper는 오디오를 **고정 30초 창**으로 처리해서, 1.5초짜리 "공뇽 나라!"가 28.5초 무음으로 채워지고 그 위에서 텍스트를 **생성**한다. 다섯 살의 한두 어절이 Whisper에 가장 불리한 입력이다.

**파인튜닝 데이터는 무료다** — [AI-Hub 자유대화 음성(소아남여)](https://aihub.or.kr/aihubdata/data/view.do?dataSetSn=108) **만 3~6세 약 3,000시간**, 설명에 *"소아 특유의 부정확한 발음"* 명시. ⚠️ **상업 이용 조건 `[미확인]` — 신청 전 확인 필수.**

**다른 환경의 후보**

| 후보 | 원/분 | 언제 쓰나 |
|---|---|---|
| `gpt-4o-mini-transcribe` | 4.2 | 규제 무시 시 기본값 |
| `voxtral-mini-transcribe-2` | 4.2 | 동가 대항마. 반드시 같이 잰다 |
| `gpt-transcribe` | 6.3 | mini 정확도가 부족할 때 |
| Azure Speech | 23.3 | **아동 비교 논문 1위.** 오프라인 컨테이너 있음 |
| ML Kit `ko-KR` basic | **0** | **온디바이스·무료.** 오프라인 폴백 |

**탈락**: Parakeet·Canary·distil-whisper·**Picovoice**(한국어 미지원) · SeamlessM4T·MMS(CC-BY-NC) · **ETRI·Kakao**(서비스 종료) · **Deepgram·AssemblyAI**(입력을 기본으로 학습에 사용 — 아이 목소리가 타사 학습셋에 들어간다)

**⚠️ 비용의 최대 변수는 모델이 아니라 묵음이다.** CLOVA는 중간 묵음도 과금에 포함한다 `[확인]`. 마이크를 15분 켜두면 240~300원, **폰 VAD로 실발화 2분만 보내면 32~40원 — 7배 차이.**

**가장 큰 레버는 모델 밖에 있다.** 우리 앱은 자유 전사가 아니라 **선택지가 정해진 게임**이다. 자모 편집거리 매칭(§2-5)을 얹으면 **CER 20%에서도 정답 판정은 훨씬 높다.**

### 2-2. 텍스트 LLM — 한 모델, 두 설정

| | 판정 (A) | 생성 (B) |
|---|---|---|
| 횟수 | 세션당 **16회** | 세션당 **1~2회** |
| 출력 | **엄격한 JSON 스키마** | 동화 문장 · 리포트 산문 |
| 지연 | **2초 넘기면 안 됨** | **10~20초 허용** |

**요구가 정반대지만 모델을 나눌 필요는 없다.** `reasoning_effort`를 판정은 `none`, 생성은 높게 주면 한 모델로 충족된다. 두 모델을 쓰면 프롬프트·SDK·로그·장애 지점이 두 벌이 되는데, **한 모델이 둘 다 못 한다는 것을 재본 적이 없다.**

> **생성 품질이 합격선(§5)을 못 넘을 때만 생성을 떼어낸다.**

#### 규제 고려 시

| 모델 | $/M | 세션당 | 스키마 | 아동 앱 약관 |
|---|---|---|---|---|
| **`gpt-5.6-luna`** | $0.20/$1.20 | **10.9원** | **강제** `[확인]` | 🟡 18세 미만 앱 **허용**. 단 **under-13이면 ZDR + OpenAI 사전 승인** `[확인]` |
| `claude-haiku-4-5` | $1/$5 | 49.7원 | **강제** `[확인]` | ✅ **사전 승인 불필요.** 연령 확인·모더레이션·"AI와 대화 중" 고지 조건 `[확인]` |

**Luna를 고르는 이유**: 값이 Haiku의 1/4.6이고, OpenAI 문서가 `effort: none`의 용도를 *"voice, fast information retrieval, and **classification**"*이라고 명시한다 `[확인]` — **우리 판정이 정확히 그 classification이다.**
**ZDR 승인이 안 나오면 `claude-haiku-4-5`로 간다.** 사전 승인 없이 쓸 수 있는 유일한 후보라는 것이 유일한 이유이고, 품질 근거가 아니다.

#### 규제 무시 시

**판정은 답이 같다.** Gemini는 규제와 무관하게 기준에서 탈락한다 — 공식 문서가 *"출력은 문법적으로 올바른 JSON이지만 **값은 애플리케이션에서 검증하라**"*고 쓰고 `[확인]`, **Flash 계열은 thinking을 끌 수 없다** `[확인]`.

**갈리는 건 생성 한 칸뿐이다.**

| 생성 후보 | 세션당 | 근거 |
|---|---|---|
| **`gemini-3.8-flash`** | **15.8원** | Creative Writing **3위(1496±19)**로 1위 Claude(1504±9)와 **신뢰구간이 겹친다.** 표본 126만 |
| `claude-sonnet-5` | 42원 | 한국어 부문 상위 독점. 단 **CI가 4위와 겹치고 표가 183~800으로 적다** |

⚠️ **아껴지는 돈이 500세션에 1.3만원이다.** 그리고 **계정이 정지되면 발표 전날 API가 죽는다.** 쓴다면 폴백 프로바이더가 조건이다.

#### 설계 규칙 `[논문 근거]`

- **판정 규칙을 JSON 스키마 `description`에 쓰지 말 것.** 시스템 프롬프트에 둔다 (description에 넣으면 **11~13%p 낮음**)
- **스키마는 1단 평면.** 중첩이 깊으면 *"값은 맞는데 필드가 틀리는"* 실패가 지배적이 된다
- **판정 필드 앞에 짧은 근거 필드**를 둔다 (**15~24점 회복**)
- **대형 모델을 쓸 근거는 없다** — 한국어 자모 오타 강건성은 **스케일로 해결되지 않는다**(EMNLP 2026). 우리 입력이 정확히 그 깨진 한글이다

**자체 호스팅은 유료화 이후로.** HyperCLOVA X SEED 14B는 fp16 28GB로 3060의 2.3배, EXAONE은 **상업 이용 금지(Output 포함)** `[확인]`, Kanana는 별도 계약. *참고: **Mistral Small 4는 Apache 2.0 오픈 가중치**라 API → 자체 호스팅 경로가 열려 있는 유일한 상용 후보다.*

### 2-3. 이미지 — 세션 중 생성 0장

**기준이 왜 일관성인가**: 20쪽에서 주인공이 쪽마다 다르게 생기면 한 권의 책이 아니다.

**LoRA는 이 제품과 안 맞는다.** LoRA는 캐릭터가 **미리 정해져 있을 때** 쓰는 도구인데, 이 제품의 핵심은 **아이가 그 자리에서 주인공을 만드는 것**이다. 즉석 학습은 60~80분, 세션은 15분. 고정 캐릭터만 남는데 **그건 그냥 미리 그리면 된다** — 생성 0장, 학습 0분, 일관성 100%.
*(IP-Adapter FaceID·InstantID·PuLID는 전부 **얼굴 임베딩 기반**이라 인형·공룡에 원리적으로 적용 불가 `[확인]`)*

**팀이 이미 정한 답이 맞다** — `역할_재배정.md`의 *"인형 부품을 겹쳐 그리는 방식"*. **제품 이름이 「말로 짓는 인형극」이다.**

### 2-4. 음성 합성 — 고정 대사를 미리 굽는다

**대사가 이미 정해져 있다** — 안드로이드 데모 v0.9의 **질문 은행 46변형** · 템플릿 5종.

**전부 미리 합성해 APK에 번들하면**: 정액 **0원** · 네트워크 왕복 **0 → 지연 0ms** · **오프라인 동작**(서버가 죽어도 마스코트는 말한다) · 감정 파라미터도 미리 튜닝해 굽는다 · **규제 축에서 빠진다.**

**CLOVA Voice를 쓰지 않는 이유** `[확인]`: **월 90,000원 기본료 + 100만 자까지 무료.** 호출이 0건이어도 Application이 등록돼 있으면 매달 나간다. 우리 규모(월 10~100세션)면 **무료 쿼터의 4%도 못 쓰면서 9만원을 낸다.** Azure는 월 50만 자 무료로 **약 131세션까지 0원.**

**가변 자막**은 폰 `TextToSpeech`로. ⚠️ **SSML은 플랫폼이 보장하지 않는다** `[미확인]` — SSML에 의존하는 설계 금지.

### 2-5. 온디바이스 — 폰으로 내려가는 것

| 내린다 | 부분만 | 불가 |
|---|---|---|
| **VAD** (`android-vad:silero`, MIT, ~2MB) | S1 (까닭) — `~서`가 인과·순차 중의성 | **판정 LLM 전체** |
| **프리셋 매칭** (자모 편집거리) | STT (ML Kit `ko-KR` basic, 아동 정확도 `[미측정]`) | **이야기 생성** |
| **S2** (어절·연결어미 카운트) | TTS 가변 자막 | **부모 리포트 산문** |

**핵심 — 프리셋 매칭은 LLM 판단이 아니라 문자열 문제다.**

```
"공뇽나라" vs 프리셋 "공룡나라"
  음절 편집거리 = 1/4  → 25% 차이 (애매)
  자모 편집거리 = 1/11 →  9% 차이 (확실)
```

한글 자모 분해는 `(코드포인트 − 0xAC00)` 산술 한 줄. **순수 Kotlin 약 100줄, 라이브러리·모델·권한 불필요.**
**판정 필드의 약 70%가 규칙으로 처리된다** → 세션당 16회 중 프리셋 칸 호출이 통째로 사라지고, **인터넷이 끊겨도 게임의 절반이 돈다.**

**판정 LLM이 못 내려가는 이유** `[확인]`: Prompt API가 도는 삼성 기기가 **S26 이상**이다(기능형 API만 S25까지). 부모 폰이 S24 이하면 `UNAVAILABLE`이라 **서버 경로를 반드시 함께 만들어야 하고, 그건 두 벌을 만드는 것이다.** 구조화 출력은 **alpha**, 한국어 지원 표는 **없고**, **에뮬레이터에서 안 돈다.**

| **S2·수준·미션 난이도·리포트 집계** | 없음 — 앱 안의 규칙 | 해당 없음 |
| 폰 TTS (가변 자막) | `TextToSpeech` | 기기별 **음질 편차**. 심하면 그 대사도 사전 합성 |
| ML Kit `ko-KR` STT | API 31 (2021). ⚠️ **한국어 오프라인 팩의 기기별 기본 탑재 여부 `[확인 실패]`** | **서버 STT로 폴백** → 세션당 +8원 |
| ~~Gemini Nano 판정~~ | ~~S26+~~ | **채택 안 함** |

> **우리 앱에 S25 이상을 요구하는 기능은 없다.** S26 제약은 채택하지 않은 Gemini Nano의 것이다.
> 최악의 경우가 "안 돌아감"이 아니라 **"세션당 8원 더 냄"**이 되도록 설계한다.
> ⚠️ **앱이 실행 시점에 `isLanguageAvailable()`·`checkStatus()`로 물어보고 경로를 고르게 짠다.** 빌드 타임에 가정하지 않는다.

*형태소 분석기(KOMORAN 등)는 1차에 넣지 않는다 — 나아지는 게 S1 정밀도 한 항목뿐이고, 나중에 끼워도 구조가 안 깨진다.*

### 2-6. 체감 지연 — 모델을 안 바꾸고 줄이는 법

**우리 1순위 기준이 "판정 2초"인데, 그건 모델 선택으로만 푸는 문제가 아니다.**

같은 RTX 3060에서 로컬 음성 에이전트를 만든 공개 사례([Codacus, 2026-09-14](https://www.youtube.com/watch?v=xbedfuqYQYA))가 **10~11초를 2~3초로** 줄인 과정을 전부 공개했다. 모델은 안 바꿨다. **파이프라인만 바꿨다.**

| 기법 | 내용 | 우리 적용 |
|---|---|---|
| **① 말하는 도중에 전사** | 발화 끝나길 기다리지 않고 **2초마다** 전사. 말이 끝나면 전사할 게 없다 | STT 대기가 통째로 사라진다 |
| **② 문장 단위로 쪼개 먼저 재생** | 전체 답을 기다리지 않고 문장이 끝나는 대로 음성으로. **3단어 미만 조각은 다음 문장과 합침**(끊겨 들려서) | 동화 낭독·마스코트 대사 |
| **③ 재생하면서 다음 문장 생성** | 완성 문장 **최대 2개**를 큐에 대기. 모델은 쓰고, 음성은 만들고, 아이는 듣는 것이 **동시에** | 단, **생성이 재생보다 빨라야** 한다 |
| **④ 첫 응답만 추론 끄기** | 첫 답은 `effort: none`, 이후 작업은 추론 켬. *"인사하는 법을 계획하느라 기다리지 않게"* | **우리 §2-2 "한 모델 두 설정"과 같은 패턴** — 독립 확증 |

**그가 공개한 최종 시간 내역**: 1초는 **일부러 남긴 대기**(더 줄이면 아이가 생각하려고 멈출 때마다 끼어든다) + 0.5초 모델 첫 단어 + 나머지는 음성 첫 소리. **첫 오디오 0.94초.**
*파이썬 런타임 대신 `audio.cpp`로 바꾼 것만으로 8.40초 → 3.05초였다 — **모델이 아니라 구현이 지연을 지배한다.***

**그리고 마지막 문제는 기술이 아니었다.** 에이전트가 일하는 동안의 침묵을, 그는 속도가 아니라 **말하기**로 풀었다 — 도구를 부르기 전에 뭘 할 건지 소리 내어 말하게 하고, 대기 중에는 **미리 만들어 둔 문구를 무작위로** 재생했다. *"이 중 어느 것도 모델을 빠르게 만들지 않는다. 다만 침묵 속에 앉아 있게 하지 않는다."*

> **우리 2초 예산의 성격이 바뀐다.** 판정이 2초 안에 **끝날** 필요가 없다. **2초 안에 무슨 소리든 나면 된다.**
> 마스코트가 "오~" 하고 먼저 반응한 뒤 판정 결과로 이어 말하면, 다섯 살이 느끼는 대기는 1초 아래다.
> **그리고 우리는 그가 나중에 덧붙인 것을 처음부터 갖고 있다 — 캐릭터다.** 침묵을 메우는 장치가 곧 아이와의 상호작용이 된다.

⚠️ **STT만은 복사하면 안 된다.** 그는 Whisper `base`를 쓰는데, 그게 **한국어 아동 CER 120.8%**를 낸 바로 그 모델이다(§2-1). 성인 화자용 파이프라인이다.

## 3. 이 선택들을 결정한 제약 셋

**① 하드웨어 — 3060에 들어가는 "큰 모델"은 하나뿐이다**

실사용 10.8~11.5GB. SDXL fp16 1024px가 **8.5~10GB**를 혼자 먹는다. 그 자리를 SDXL이 가져가면 다른 것을 못 올린다.
*(같은 3060에서 LLM 4GB + TTS 8.5GB + Whisper 0.14GB를 올린 공개 사례가 있다. expert를 전부 CPU로 보내 LLM을 2GB로 만들고 TTS를 Q8로 양자화한 구성이다. **모델 개수가 아니라 덩치가 제약이다.**)*
**세션 중 GPU에 남는 것은 faster-whisper(1.5~2GB) 하나다.**

**② 규제 — 자체 호스팅해도 남는 것**

| 남는 것 | 내용 |
|---|---|
| **법정대리인 동의** | 개인정보보호법 **제22조의2** — 만 14세 미만. **단말 내 처리도 처리라 면제 없음** |
| **가중치 라이선스** | SDXL은 **OpenRAIL++-M** — 사용 제한을 하위 배포물에 **전파할 의무** |
| **콘텐츠 안전 책임** | 상용 API의 연령 제한은 **제공자가 안전 필터를 지는 대가**다. 자체 SDXL에는 그 필터가 없다 |
| **Play AI 콘텐츠 정책** | ⚠️ **앱 내 신고 기능 필수.** 온디바이스여도 면제 안 됨. **현재 어느 화면 문서에도 없다** |
| 국외 이전 고지 | 해외 LLM을 쓰는 한 남는다 |

> **자체 호스팅은 약관을 없애는 게 아니라 "4명이 지는 안전 책임"과 맞바꾸는 것이다.** 그래서 답은 자체 호스팅이 아니라 **런타임에서 빼기**다.

**③ 6주 — 실질 구현 인력 3명, 안드로이드 튜토리얼도 아직**

멘토 지시: **"시연보다 덱이 중요. 실제 동작 안 해도 됨."** 평가받는 건 파이프라인이 아니라 킬러 피처와 서사다.

## 4. 확정된 것 / 아직 아닌 것

**지금 확정** — 바꾸지 않는다
1. **VAD는 폰에서** (`android-vad:silero`)
2. **세션 중 이미지 생성 0장.** ComfyUI+SDXL은 오프라인 에셋 공장으로
3. **마스코트 고정 대사는 사전 합성 번들**
4. **판정·수준 계산·미션 난이도·리포트 계산은 앱 안의 규칙**
5. **텍스트 LLM은 한 모델로 시작**, 모델 ID는 **반드시 설정값으로**

**측정 전 기본값** — W1 결과로 확정
- 판정·생성 `gpt-5.6-luna` (ZDR 승인 실패 시 `claude-haiku-4-5`)
- 음성 인식 자체 GPU faster-whisper (+ ML Kit 폴백)

**표를 바꾸는 것은 측정값뿐이다.** 가격만으로 안 바꾸고(6주 총액 차이 3만원), 추천만으로 안 바꾸고(추천은 **측정 우선순위**를 바꿀 뿐이다), 신뢰구간이 겹치면 동률로 읽는다.

| 측정 결과 | 그러면 |
|---|---|
| Luna TTFT ≤ 1.5초 & 판정 F1 ±3%p | Luna 확정 |
| Luna TTFT > 2초 | Haiku로 |
| `gpt-5-nano`가 F1 ±3%p 이내 | nano로 (1.7원) |
| 문체 블라인드에서 Gemini 유의하게 우세 | 규제 감수 여부가 **그때** 진짜 의사결정이 된다 |
| 문체 블라인드 동률 | Sonnet/Luna 유지 — 동률이면 계정 정지 리스크가 유일한 변별점 |

## 5. 합격 기준

| 항목 | 합격선 | 못 넘으면 |
|---|---|---|
| 판정 JSON 성공률 | **≥ 99%** | 스키마를 더 평평하게 → 상위 모델 |
| 아이 발화 핵심 키워드 보존율 | **≥ 90%** | STT 상향 또는 자체 파인튜닝 |
| 프리셋 매칭 정답률 | **≥ 95%** | 발음 규칙 정규화 추가 |
| **아이가 듣는 첫 소리** | **≤ 2초** | §2-6 기법 먼저 → 그래도 안 되면 모델 교체 |
| 판정 완료 | **≤ 4초** | 첫 소리가 먼저 나가므로 여유가 있다 |
| 이미지 생성 시간 | **≤ 10초** | 런타임 생성 포기 |
| 캐릭터 동일성 (5점) | **평균 ≥ 4** | 부품 합성 비중 확대 |
| 이야기 금지 표현 | **0건** | **타협 없음** |
| 한 권 총 AI 원가 | **≤ 200원** | 런타임 생성 장수 축소 |

**한 권당 원가 — 이미지가 90%다**

| 구성 | STT | 텍스트 | 이미지 | 합계 |
|---|---|---|---|---|
| **규제 고려 · 전량 사전 제작** | 0원 | 10.9원 | **0원** | **약 11원** |
| 규제 고려 · 런타임 3장 | 8.4원 | 10.9원 | 59~141원 | 78~160원 |
| 규제 무시 · Gemini Lite | 8.4원 | 10.9원 | 141원 | 약 160원 |

> **모델보다 중요한 결정은 "한 권에 몇 장을 새로 그리느냐"다.** 텍스트 모델 교체로 아끼는 건 권당 몇 원이고, 런타임 3장은 최대 141원이다.
