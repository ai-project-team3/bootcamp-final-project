# 역할 재배정 — 프로토타입을 안치영이 맡은 뒤

> 2026-09-17 · 조장 · 앞 배정은 `정렬회의_프로토타입_계획.md` §3. 이 문서가 그것을 대체한다

## 무엇이 바뀌었나

**초안(프로토타입) 제작을 안치영이 전담한다.** 그러면 두 가지가 비게 된다.

- 안치영이 들고 있던 **음성 인식 비교**와 **수준 판단 일치도 측정**
- 최민우가 렌더링만 하기에는 손이 남는다 (초안 화면을 안 만들게 되므로)

아래처럼 옮긴다. **한 사람이 숫자 하나씩** 들고 가는 원칙은 그대로다.

---

## 새 배정

| 역할 | 담당 | 무엇을 만드나 | 자기 숫자 |
|---|---|---|---|
| **초안 · 화면** | 안치영 | 흐름 전체를 한 벌로. 두 초안에서 고른 것을 합친다 | 세션 완주율 · 한 바퀴 도는 데 걸린 시간 |
| **이야기 엔진** | 박진웅 | 프롬프트를 **실제로 호출해** 돌려본다. 템플릿 3개 확정. 자막 문장 | JSON 형식 성공률 · 규칙 준수 루브릭 점수 |
| **그림 공장 · 측정** | 최민우 | 그림체 2종 × 프리셋 세계 3곳 + 소품. 생성 시간과 GPU 메모리 실측 | 장당 생성 시간 · 새 세계 띄우는 데 걸린 초 |
| **음성 · 법 · 통합** | 이종훈 (조장) | 음성 인식 비교. 부모·아이 섭외. 문서·발표·병합 | 인식 글자 오류율 · 영상 대비 발화 횟수 |

## 겹치지 않게 하는 선

- 화면에 들어가는 **그림 파일**은 최민우가 만들고, **화면에 붙이는 것**은 안치영이 한다
- **프롬프트 문장**은 박진웅이 정하고, **호출 코드**는 안치영의 화면에서 부른다
- `구현대본.md`와 `프롬프트_모음.md`를 고칠 때는 조장에게 말한다. 두 사람이 같은 줄을 고치면 합칠 때 터진다
