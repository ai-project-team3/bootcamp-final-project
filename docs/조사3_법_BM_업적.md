## 0. 결론

### 이렇게 한다

1. **아이 화면에는 돈과 연결된 잠금을 두지 않는다.** 보상은 활동으로만 열리고, 아이에게는 깜짝 선물로만 보인다. 유료 보상은 부모 PIN 뒤에만 둔다. 1차는 결제를 구현하지 않는다
2. **아이 목소리와 이름은 외부 AI 회사로 보내지 않는다.** 음성 인식과 이미지 생성은 우리 서버(GPU)에서 끝내고, 밖으로 나가는 건 이야기 AI에 보내는 이름을 가린 문장뿐이다. 공룡 소리 녹음은 폰 밖으로 나가지 않는다
3. **광고가 없다.** 부모가 잠금 모드에서 허용해도 우회 통로가 되지 않는 앱이라는 점을 차별점으로 쓴다
4. **기획안의 동의 문구를 고친다.** "아이 목소리는 서버로 보내지 않습니다"는 이제 사실이 아니다 (§2-2)
5. **발표에서 "우회"라고 말하지 않는다.** "약관을 확인하고 아이 데이터가 외부 AI 회사에 가지 않도록 설계를 바꿨다"고 말한다 (§5)

### 단계별로 무엇을 쓰나

| 단계 | 선택 | 제외 | 절 |
|---|---|---|---|
| 음성 인식 | **우리 서버 Whisper vs CLOVA Speech** — W1에 아이 녹음으로 비교해 확정 | OpenAI 음성 API · Google Cloud STT · 리턴제로(약관 확인 불가) | §3-1 |
| 이야기 AI | **Anthropic** + 이름 필터 | OpenAI(ZDR 승인 필요) · Gemini API(18세 미만 앱 금지) | §3-2 |
| 이미지 | **ComfyUI 자체 서버** (GPU 제공). 모델 1순위 FLUX.2 klein 4B, 초안도 같은 모델 | OpenAI · Gemini · FLUX API · AI Horde | §3-3 |
| 목소리 읽어주기 | **CLOVA Voice**, 이름 없는 문장만 | OpenAI TTS | §3-5 |

## 2. 아이 데이터와 동의

### 2-1. 지켜야 할 법

| 의무 | 내용 | 확인 |
|---|---|---|
| 만 14세 미만 법정대리인 동의 | 개인정보보호법 제22조의2 — 동의를 받고, 동의했는지 확인하고, 아이도 알기 쉬운 말로 고지 | `[확인]` (확인 방법을 정한 시행령은 `[미확인]`) |
| 국외 이전 고지 | 이야기 AI(Anthropic)가 해외 사업자라 필요. 음성 인식 · 이미지는 우리 서버라 해당 없음 | `[해석]` |
| 우리 서버의 처리 책임 | 음성을 잠깐이라도 우리 서버가 처리하므로 처리방침 · 즉시 삭제 · 로그 무기록을 우리가 지킨다 | `[해석]` |

### 2-2. 기획안 동의 문구 수정 — 반드시

기획안 §2 · §4 · §9의 **"아이 목소리는 서버로 보내지 않습니다"**와 **"음성 · 이름 · 그림이 국외에 전송됩니다"**는 지금 설계와 둘 다 다르다. 동의 문구가 사실과 다르면 법정대리인 동의의 전제가 무너진다.

> **수정안**: *"아이 목소리와 그림은 이 기기 안에만 저장됩니다. 말을 글자로 바꾸고 그림을 만드는 동안만 저희 서버(국내)를 거치고, 끝나는 즉시 지워집니다. 이야기를 만들기 위해 이름을 가린 문장이 해외 AI 회사로 전송됩니다."*

### 2-3. 무엇이 어디로 가나

```
[폰]  녹음 ─┬─ 대화 녹음 ──► 원본은 폰에만
           │        ↓ 음성 사본
           │  [우리 서버 · 국내]  말소리 구간만 자름 → Whisper → 텍스트 → 사본 즉시 삭제
           │        ↓
           │  이름 필터 (지호 → {주인공})
           │        ↓ 가린 문장                   ↓ 영어 키워드
           │  이야기 AI (Anthropic · 해외)   [우리 서버] ComfyUI 이미지 생성
           │        ↓
           │  [폰]  {주인공} → 지호 되돌리기 → 그림책 · 기록 (폰에만)
           │
           └─ 소리 녹음 (공룡 소리) ──► 폰 안에서만. 서버로 안 감 (§2-4)
```

| 데이터 | 어디로 | 규칙 |
|---|---|---|
| 아이 대화 음성 | 우리 서버 Whisper (국내) | 말소리 구간만 · 변환 후 즉시 삭제 · 로그에 안 남김 |
| 아이 발화 전사 | 이야기 AI | 이름 필터로 가림. 호칭("엄마 · 선생님")은 안 가림 |
| 아이 · 친구 · 도감 이름 | **어디에도 안 보냄** | `{주인공}` `{친구1}` 자리표시자로 보내고 폰에서 되돌림. 조사 붙은 형태("민준이") · 비슷한 발음("지오")도 잡음 |
| 주인공 묘사 | 우리 서버 ComfyUI | **발화 원문 금지.** "머리색 · 옷색 · 좋아하는 것" 정해진 속성값을 영어 키워드로. 우리 서버라도 원칙은 유지 |
| 장면 · 친구 슬롯 | 우리 서버 ComfyUI | 영어 키워드만 (dinosaur land, paper cutout). 친구 슬롯 값이 실제 친구 이름이어도 절대 안 넣음 |
| 아이 그림 | **안 보냄** | 원본 그대로 쓰므로 보낼 이유가 없다 |
| 마스코트 대사 · 자막 | 목소리 읽어주기 | 이름 없는 문장만. 이름은 폰 기본 음성 합성 또는 "우리 주인공" |

### 2-4. 공룡 소리 녹음

"공룡이 어떻게 울어?" → "크아아앙!"

| 단계 | 어디서 | 무엇을 |
|---|---|---|
| 1 녹음 | 폰 | 소리 슬롯 화면은 **대화 녹음과 다른 경로**. 음성 인식으로 보내지 않는다 |
| 2 검사 | 폰 | 길이 · 음량만 본다. 무음이거나 0.3초 미만이면 "한 번 더!" 한 번, 그래도 없으면 기본 효과음 |
| 3 저장 | 폰 | 원본 그대로 캐릭터 소리로 저장. 변조 없음 |
| 4 재생 | 폰 | 책에서 공룡을 누르거나 등장할 때 재생 |

**서버로 안 보내는 이유**
- **글자로 바꿀 게 없다.** 의성어라 인식할 낱말이 없다
- **Whisper가 없는 문장을 지어낼 위험이 가장 크다.** 짧은 비언어 소리가 그 조건이다
- **목소리 식별에 쓰지 않는다.** 이전 핸드오프는 이 녹음을 "아이 목소리 등록"에 쓰려 했다. 특정 아이 목소리 특징을 뽑는 건 민감정보 해석 문제가 남아 1차에서는 쓰지 않는다
- **발화 기록에 세지 않는다.** 말이 아니라 소리다

## 3. 단계별 AI 선택

### 3-1. 음성 인식

**후보와 조건**

|---|---|---|
| **Whisper 우리 서버** (turbo · large-v3) | OpenAI 공개 모델을 우리 서버에서 돌리므로 **OpenAI API 약관과 ZDR 조건이 걸리지 않는다.** 코드 · 가중치 MIT `[확인]` | **후보 1** |

**읽는 법**
- **업체 표는 순위를 믿지 않는다.** 리턴제로 표는 리턴제로가 만들었고 전부 성인 데이터다
- **CLOVA가 아동에서 Google의 절반 오류**였다. 다만 7~8세 긴 이야기라 5세 단답과 다르다
- **Whisper는 작은 모델이면 아이 말을 거의 못 알아듣지만 파인튜닝하면 크게 좋아진다.** 우리 서버에서 돌리면 나중에 파인튜닝할 수 있다
- **Whisper는 무음 · 짧은 소리에서 없는 문장을 지어내는 사례가 있다** (사례 수준 `[미확인]`). 5세 단답이 그 조건이다 → 말소리 구간 감지만으로는 부족하고, 도감 이름 · 선택지 후보와 맞춰보는 후처리와 신뢰도 기준이 필요하다

**Whisper 서버 조건** `[확인]`

| | large-v3 | turbo | faster-whisper (실행 도구) |
|---|---|---|---|
| GPU 메모리 | 약 10GB | 약 6GB | large-v2 기준 int8로 약 2.9GB |
| 속도 | 기준 | 약 8배 빠름, 품질 저하 "minor" | 같은 모델을 2배 이상 빠르게 |

→ **turbo + faster-whisper + 말소리 구간 감지** 조합으로 비교한다.

- 확정된 초안은 최종 생성의 참조 이미지로 넣는다
- 초안에는 투명 배경이 필요 없다

**ComfyUI 운영 원칙**
- **부적절 이미지 검사를 두 번 한다.** ComfyUI 안의 분류 노드(Falconsai, Apache-2.0)와 백엔드 검사. 둘 다 5세 대상 검증 근거가 없다 `[확인]`
- **커스텀 노드는 가능하면 쓰지 않는다.** 2026-01 커스텀 노드가 등록 검사를 우회해 정보 탈취 악성코드를 퍼뜨린 사례가 있다 (ComfyUI 이슈 #11791 `[확인]`). 써야 하면 코드를 보고 커밋을 고정한다
- **ComfyUI 포트는 외부에 열지 않는다.** FastAPI만 호출한다. 외부 유료 API 노드는 끈다
- **AGPL 노드는 붙이지 않는다.** ComfyUI 자체(GPL-3.0)는 서버에서만 쓰면 공개 의무 없음 `[해석]`
- **GPU 메모리를 실측한다.** Whisper와 이미지 모델이 같은 GPU를 쓰면 모자랄 수 있고, ComfyUI는 다른 프로그램의 GPU 메모리를 관리하지 못한다
