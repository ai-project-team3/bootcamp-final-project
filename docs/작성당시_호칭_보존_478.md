# 작성 당시 호칭 보존 (#478)

2026-10-14. 로컬 저장·초안·되돌리기·책장 읽기와 부모 리포트의 작성자 표시를 다룬다.
실기기 확인·서버 연결·운영 배포 결과를 보증하는 문서는 아니다.

## 저장과 호환 읽기

- 새 세션을 시작할 때 `DemoState.sessionAuthorCall`에 현재 `ChildCall.call`을 캡처한다.
  새 `DemoState`도 현재 호칭으로 시작한다. 초안 복원은 그 초안의 값을 그대로 쓰며,
  필드 없는 옛 초안은 null로 남긴다. 되돌리기·앞으로 가기에도 같은 스냅샷을 복원한다.
- 동화·그림일기·협업 책과 `SessionReport`에는 선택 필드 `authorCall: String? = null`을 저장한다.
  완성 책과 리포트는 같은 세션 스냅샷을 사용한다. JSON에 null도 명시하여 다시 저장해도 미확인 상태가 유지된다.
- 옛 동화·일기·리포트에 호칭이 없으면 현재 아이나 주인공 이름으로 추측하지 않는다.
  화면에서는 null·빈 호칭을 「아이」로 표시한다.
- 옛 협업 책만 `authorCall` 필드가 **없을 때** 이미 명시 저장된 `coop.childName`을 호환 읽기로 사용한다.
  `authorCall: null`이 명시된 새 자료는 그 호칭으로 채우지 않는다.

## 화면과 복원

저장된 책 표지·작성자 보조 문구와 부모 리포트·대화 전체는 저장 호칭을 쓴다.
새 리포트의 「집에서 이어 갈 질문」도 세션 작성자 호칭을 사용한다.
이미 저장된 질문·제목·자막·대화 원문을 다시 쓰거나 이름을 치환하지 않는다.

책장 동화·협업 읽기는 별도 상태를 사용한다. 그림일기는 읽는 동안만 작성자 표시 컨텍스트를 바꾸고
`finally`에서 현재 값을 되돌린다. 기존 그림일기 표지에는 작성자 줄을 새로 추가하지 않는다.

부모의 전체·누적 기록 머리말과 `DemoState.childName`, 실제 대사·서버 요청의 이름 처리는 현재 아이 영역이다.
12슬롯·HTTP·계정 동기화·나이·윤문 생성·신고 첨부 정책과 미디어 정리는 이 변경으로 바꾸지 않는다.
