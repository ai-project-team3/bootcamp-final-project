| | |
|---|---|
| **증상** | 협업(일기도 같음) 그림판에서 아이 화면의 **[그리기 싫어]**를 눌러도 아무 일도 없다. 두 번 눌러도 그대로 |
| **재현** | [같이 만들기] → 질문 답하기 → "오늘 만난 ○○를 그려 줄래?" 화면 → [그리기 싫어] 탭 |

| **급한가** | 아니다 — 시연 경로에서는 [다 그렸어]로 지나간다. 다만 실제 아이는 [그리기 싫어]를 누른다 |
