# 조사 6 — 정정된 연구 요약과 자기 맥락 실험 계획 (2026-09-22)

조사 이종훈 · 멘토 검토(09-22) 「함께 해볼 조사 순서」 6번

**멘토가 정정을 요청한 지표는 화자 분리 DER인데, 그 기능이 09-22 설계 변경으로 범위에서 빠졌다.** 그래서 이 조사는 두 조각이 된다 — **① 인용 정정은 그대로 한다**(문서에 남아 있고, 잘못 옮긴 서술이 재인용될 수 있다). **② 「자기 맥락에서 직접 재라」는 지적은 대상을 옮긴다.** 지금 우리 맥락에서 남의 수치를 근거로 쓰고 있는 자리는 화자 분리가 아니라 **아이 음성 받아쓰기**다. 그것이 이 문서의 실험 계획이다.

---

## 이 조사의 범위

**근거로 쓴 것** — 멘토 검토 보고서 6절 · `eval/results.md`의 DER 항목(09-21 기록과 09-22 취소선) · `guidelines/6` §6-3 막고 있는 것 · `eval/stt_eval.py`(치영님이 만든 것).

**근거로 쓰지 않은 것** — **원 논문을 직접 다시 읽지 않았다.** 아래 정정은 멘토가 인용한 범위(III-A2·IV-B절)를 그대로 옮긴 것이다. 그리고 **아이 음성을 아직 한 건도 재지 않았다.**

**따라서 ①은 정정의 정리이고 ②는 계획이며, 둘 다 새 측정이 아니다.**

## 1. 정정 — DER을 「셋에 하나」로 옮긴 것이 틀렸다

### 확인된 정정

우리가 쓴 서술: *"한국어 엄마+아이에서 최고 모델이 셋에 하나를 틀린다"* (덱 18장 · `README` · `results.md`)

**틀린 이유가 셋이다.**

| | 우리가 쓴 것 | 실제 |
|---|---|---|
| **지표의 뜻** | 발화 세 개 중 하나가 틀림 | **DER은 기준 화자 시간 대비 누락·오검출·화자 혼동을 합산한 비율.** 분모가 발화 개수가 아니라 **시간**이고, 분자에 혼동 말고 **두 종류가 더** 있다 |
| **어느 모델** | (우리가 올린 pyannote 3.1인 것처럼 읽힘) | **33.04%를 낸 것은 NeMo SortFormer.** 우리가 올린 것은 pyannote 3.1 |
| **표본** | 53명 녹음 | **조건을 만족한 34개 녹음의 부분집합** |
| **과업** | 자유로운 부모-아동 대화 | **아동의 단어 반복 상호작용** |

### 조건부 함의

**인용의 역할이 「근거」에서 「동기」로 바뀐다.** 다른 과업·다른 표본·다른 모델의 수치는 *"이 정도 어려운 문제다"*는 주지만 *"우리 앱에서 이만큼 틀린다"*는 예측이 못 된다.

**그리고 우리가 그 수치로 결정을 내린 적은 없다** — 확인해 보니 화자 분리는 *"자리는 확보했고 정확도는 이 숫자가 상한"*으로만 쓰였고, 그 위에 세운 판단이 없다. **다행이다.**

⚠️ **다만 어제 내가 문장만 다듬고 내용은 틀린 상태로 뒀다.** *"셋에 하나"* → *"세 번 중 한 번"*으로 고쳤는데, **표현이 어색한 것이 문제가 아니라 지표를 잘못 옮긴 것이 문제였다.** 멘토 지적을 받고서야 알았다.

### 처리 상태

| 어디 | 상태 |
|---|---|
| `eval/results.md` | ✅ **취소선 + 정정 세 줄** (09-22) |
| `README.md` | ✅ *"우리 조건에서 아직 안 재봤다"*로 교체 |
| 발표 덱 | ✅ 화자 분리 장이 **통째로 빠졌다**(설계 변경) |
| `guidelines/` | 인용이 없다 — 확인함 |

### 같이 생각해 볼 질문

- 남의 측정치를 인용할 때 **근거인지 동기인지 구분하는 기준**을 무엇으로 하겠어요? `guidelines/0`에 한 줄로 적을 수 있나요?
- 표현만 고치고 내용을 못 고친 일이 또 있을까요? **숫자를 인용한 자리를 전수로 훑어야** 하나요?

## 2. 대상 이동 — 지금 자기 맥락에서 재야 할 것은 받아쓰기다

### 확인된 것

화자 분리는 09-22 설계 변경으로 빠졌다 — **아이가 혼자 쓰고, 부모는 질문을 미리 넣는다.** 그래서 *"화자 귀속"*은 화면이 알고 있고, 모델이 가릴 일이 없다.

**그런데 남의 수치를 근거로 쓰고 있는 자리가 하나 남아 있다.**

> *"어른 모사로는 순위가 안 나온다 — **성인 7.8% vs 아동 120.8%**"* (`guidelines/6` §6-3)

이 숫자가 **받아쓰기 모델 선정 전체를 막고 있는 근거**다. 그리고 **우리가 잰 것이 아니다.**

### 조건부 함의

**멘토 6절의 교훈이 여기에 그대로 적용된다.** *"다른 과업·다른 표본·다른 모델에서 나온 수치는 감각은 주지만 예측은 되지 못한다."*

→ **성인 7.8% / 아동 120.8%도 동기이지 근거가 아니다.** 우리 조건(만 3~7세 · 거실 소음 · 프리셋 낱말)에서 얼마인지는 **재야 안다.**

**다행히 하네스가 이미 있다** — 치영님이 `eval/stt_eval.py`(166줄)를 만들어 뒀다. **막고 있는 것은 코드가 아니라 음성이다.**

### 확인되지 않은 것

- **아이 목소리 30발화가 언제 오나.** AI-Hub 신청 중이고 승인까지 며칠
- `stt_eval.py`가 **무엇을 재는지** — 내가 코드를 열어보지 않았다. 치영님이 만든 것이고, 프리셋 매칭인지 키워드 보존율인지 확인이 필요하다

### 같이 생각해 볼 질문

- AI-Hub 승인을 기다리는 동안 **합성 음성으로 미리 재 볼 수 있나요?** 그건 어른 모사와 같은 함정 아닌가요?
- 아이 음성 30발화로 **모델 순위가 갈릴 만한가요?** 30건이면 신뢰구간이 얼마나 넓나요?

## 3. 실험 계획 — 아이 음성 받아쓰기

### 확인된 것

`guidelines/6` §6-4 합격선에 **아이 발화 핵심 키워드 보존율 ≥ 90%**가 있고, 못 넘으면 *"STT 상향 또는 자체 파인튜닝"*으로 적혀 있다. 그리고 §2에서 **폰 온디바이스가 프리셋 매칭 65%**로 합격선 95%에 미달한 것이 이미 측정됐다.

### 계획 — 작아도 된다. 설계가 맞는지가 먼저다

| | 무엇 | 왜 이 순서 |
|---|---|---|
| **1** | **조건을 먼저 적는다** — 나이 · 녹음 기기 · 거리 · 소음 · 발화 종류(프리셋 낱말 / 자유 발화) | 조건을 안 적으면 나중에 **무엇과 비교하는지 모른다**. 09-19 측정이 *"성인 남성·조용한 방·프리셋 안"*이라 적어 둔 것이 좋은 전례다 |
| **2** | **후보를 둘로 좁힌다** — 자체 `faster-whisper large-v3-turbo` vs 외부 API 하나 | 셋 이상이면 30발화로 순위가 안 갈린다 |
| **3** | **같은 음성으로 둘을 돌린다** | 다른 음성으로 재면 모델 차이인지 음성 차이인지 모른다 |
| **4** | **두 지표를 따로 센다** — 프리셋 매칭률 · 키워드 보존율 | 합격선이 각각 95% · 90%로 다르다 |
| **5** | **부끄러운 베이스라인을 남긴다** — 폰 온디바이스 65%가 이미 그것이다 | §6-7 *"고치기 전 숫자가 먼저 있어야 「무엇이 느렸고 어떻게 고쳤다」가 성립한다"* |

**규모**: 30발화 × 2모델 = 60건. **순위를 정하기엔 적고, 「합격선을 넘나 못 넘나」를 보기엔 충분하다.**

⚠️ **30건으로 두 모델이 5%p 차이면 그건 동률이다.** `CLAUDE.md`가 *"신뢰구간이 겹치면 동률로 읽는다"*고 정했다. **미리 그렇게 읽기로 정해 두는 것**이 측정 뒤에 정하는 것보다 정직하다.

### 확인되지 않은 것

- **아이 음성을 어떤 동의와 이용 권한으로 얻나.** AI-Hub 데이터셋이면 그 이용 조건, 직접 녹음하면 보호자 동의. **조사 2·3번과 이어진다**
- 거실 소음 조건을 **어떻게 재현하나.** 실제 거실에서 녹음하나, 소음을 섞나

### 같이 생각해 볼 질문

- 30발화가 **어느 나이대 몇 명**에서 나와야 하나요? 다섯 살 한 명 30발화와 세 살~일곱 살 여섯 명 5발화는 다른 측정입니다
- 합격선을 못 넘으면 *"STT 상향 또는 자체 파인튜닝"*인데, **부트캠프 기간에 파인튜닝이 현실적인가요?** 아니라면 그 선은 무엇을 뜻하나요?

## 이 조사가 정한 것 / 안 정한 것

**정했다**
- **DER 인용은 정정했고, 역할을 근거에서 동기로 옮겼다.** 처리 상태는 §1 표
- **화자 분리가 빠졌으므로 「자기 맥락 실험」의 대상은 받아쓰기로 옮긴다**
- 성인 7.8% / 아동 120.8%도 **동기이지 근거가 아니다** — 같은 잣대를 우리에게도 댄다
- 실험은 **후보 둘 · 같은 음성 · 두 지표 · 30발화**. 5%p 차이는 **동률로 읽기로 미리 정한다**

**안 정했다**
- **아이 음성을 언제, 어떤 동의로 얻나** — 이것 하나가 전부를 막고 있다
- `stt_eval.py`가 무엇을 재는지 (치영님 확인 필요)
- 합격선을 못 넘었을 때 **파인튜닝이 현실적인지**
