# 동작 하나하나에 데이터가 어디로 가는가

> 2026-09-17 · 조장 · 근거: `기술개요.md` · `조사3_법_BM_업적.md` §2·§3 · `구현대본.md` §0-4
> 아이가 손을 대는 동작마다, **무엇이 폰을 떠나고 · 어디에 얼마나 머물고 · 무엇이 남는지**를 적는다.

## 읽는 법

| 표시 | 뜻 |
|---|---|
| 🟢 **지금 데모** | `finalproject_demo` v0.9에서 실제로 일어나는 일. 네트워크를 쓰지 않는다 |
| 🔵 **실제 앱** | 우리가 만들 것. 아래 설명의 본문 |
| 📦 남는 것 | 그 단계가 끝난 뒤에도 남아 있는 것 |
| 🔥 지우는 것 | 그 자리에서 없어지는 것 |

**지금 데모에는 음성 인식도 이야기 AI도 그림 생성도 없다.** 마이크를 끄면 미리 써 둔 답 다섯 중 하나가 들어갈 뿐이다. 아래 🔵 는 전부 설계이고, 아직 코드가 아니다.

## 1. 앱을 처음 켠다 (동의)

🔵 부모가 한 번만 본다. 여기서 **무엇이 나가는지**를 글로 밝히고 동의를 받는다.

| 동의 항목 | 왜 받나 |
|---|---|
| 만 14세 미만 법정대리인 동의 | 개인정보보호법 제22조의2 |
| 음성을 글자로 바꾸려고 **우리 국내 서버**를 잠깐 거친다 | 처리 위탁 |
| 이야기를 만들려고 **이름을 가린 문장**이 국외로 간다 | 국외 이전 (제28조의8) |

동의 화면에 쓰는 말은 `부모용_안내문구.md` 그대로다. "서버로 보내지 않습니다"라고 쓰면 거짓이 된다.

📦 폰에 남는 것: 동의한 날짜 · 동의한 항목
🔥 법정대리인 확인에 쓴 정보는 확인 뒤 지운다

🟢 데모에는 동의 화면이 없다.

---

## 2. 부모가 설정을 만진다

🔵 부모 모드는 **비밀번호 네 자리** 뒤에 있다. 여기서 정하는 것이 이야기 내내 따라간다.

| 설정 | 어디에 쓰이나 |
|---|---|
| 시작 방식 (아이가 바로 / 어른 비밀번호) | 걸음 3 |
| 하루 몇 권 | 별 개수 |
| 그림체 | 걸음 12의 영어 키워드 앞에 붙는다 |
| 다시 그리기 상한 | 중간 확인에서 몇 번까지 |

📦 전부 폰에만. 서버로 안 간다
🔥 비밀번호는 **원문으로 저장하지 않는다**

---

## 3. [이야기 만들기]를 누른다

🔵 별이 하나 줄고 이야기가 시작된다. **네트워크를 쓰지 않는다.**

- 별은 폰 안의 숫자다. 결제는 1차에 없다
- 0이면 마스코트가 한 번만 안내한다. 두 번째로 눌러도 다시 안 뜬다
- 아이 화면에 가격도 구매 버튼도 없다

📦 폰에 남는 것: 남은 권수 · `story_start` 기록

---

## 4. 주인공을 만든다 (＋ 를 눌렀을 때)

🔵 두 갈래가 **데이터 흐름이 완전히 다르다.**

**골라서 만들기** — 미리 만들어 둔 부품을 겹쳐 그린다. **아무것도 안 나간다.** 0초.

**말로 만들기** — 세 번 묻고, 나가는 것은 **속성값뿐**이다.

```
아이가 한 말:  "짧아!" "파랑!" "동글 안경!"     ← 나가지 않는다
ComfyUI로:     hair=short, shirt=blue, glasses=round, style=felt3d
```

발화 원문을 보내지 않는다. 폰이 말에서 값만 뽑아 영어로 바꿔 보낸다.

📦 만든 인형은 폰에 저장되고 이야기 내내 같은 그림을 쓴다
🔥 서버에 남기지 않는다

---

## 5. 🎤 를 누른다 (켜기)

🔵 폰이 마이크를 연다. 16kHz · 모노 · 16비트로 받는다.
동시에 **말소리 구간 감지(VAD)** 가 돌면서 "지금 말하고 있다 / 조용하다"만 표시한다.

- 이 단계에서 **밖으로 나가는 것은 없다.** 아직 아무 데도 안 보낸다.
- 화면의 파형은 마이크 음량을 그린 것이지 인식 결과가 아니다.
- 시간 제한을 두지 않는다. 아이가 뜸 들이는 것을 끊지 않기 위해서다.

📦 폰 메모리에 소리가 쌓인다 (아직 파일 아님)

🟢 데모는 녹음하지 않는다. 파형은 가짜 움직임이다.

---

## 6. 아이가 말한다

🔵 말하는 동안에도 아무것도 보내지 않는다. **끊길 때까지 기다렸다가 한 번에 보낸다.**

왜 실시간으로 안 보내나 — 한 마디씩 보내면 "공뇽"과 "나라"가 따로 도착해 뜻이 깨진다.
아이 말은 짧고 끊기므로 문장이 끝난 뒤 통째로 보내는 쪽이 정확하다.

📦 아직 폰 메모리

---

## 7. 🎤 를 다시 누른다 (끄기) · **여기가 핵심**

🔵 순서대로 이렇게 된다.

**3-1. 폰이 자른다**
VAD가 "말소리"로 표시한 구간만 남기고 앞뒤 정적을 버린다.
15분 세션에서 실제로 말한 시간은 2분 안팎이다. 자르면 보낼 양이 7분의 1로 준다. *(추정)*

**3-2. 폰이 압축한다**
Opus로 압축한다. 자른 2분이 원본 약 3.8MB에서 **약 250KB**로 준다. *(추정 · W1에 실측)*

**3-3. 폰이 보낸다**
HTTPS로 우리 백엔드에. 보내는 것은 이 셋뿐이다.

| 보내는 것 | 예 |
|---|---|
| 압축한 소리 | (바이너리) |
| 이 턴이 무엇을 묻는 질문인지 | `slot=place` |
| 인식을 도울 낱말 목록 | `["지호","뿌뿌","티라노","긴목공룡","뿔공룡"]` |

세 번째가 **키워드 바이어싱**이다. 화면에 떠 있는 선택지와 도감 이름을 미리 알려주면 "뜨리게라"를 "뿔공룡"으로 맞힐 확률이 오른다.
주의 — 앞 턴 대화를 통째로 넣는 방식은 아동 대화에서 오히려 정확도를 떨어뜨린 보고가 있어 **쓰지 않는다.**

**3-4. 백엔드는 지나가게만 한다**
API 키를 앱에 넣을 수 없어서 두는 중계소다. 소리를 **디스크에 쓰지 않고** 메모리로 흘려보낸다.

📦 백엔드에 남는 것: `2026-09-17 18:04 / stt / 1.9초 / 200` — 시각 · 종류 · 걸린 시간 · 결과 코드
🔥 백엔드에 안 남는 것: 소리 · 글자 · 아이 이름

**3-5. GPU 서버가 글자로 바꾼다**
faster-whisper(Whisper large-v3-turbo)가 돌아 글자와 신뢰도를 낸다.

```
{ "text": "로켓 타고 우주 갈래 별 보러 가고 싶어서",
  "confidence": 0.83,
  "duration_sec": 3.4 }
```

🔥 **변환이 끝나면 그 자리에서 소리 파일을 지운다.** 임시 폴더에도 남기지 않는다.
이게 우리가 자체 서버를 쓰는 이유다. 남의 서버로 보내면 언제 지워지는지 우리가 정할 수 없다.

**3-6. 글자가 폰으로 돌아온다**

📦 폰에 남는 것 — 전사 한 줄 · 신뢰도 · 말한 시각 · 말한 길이
📦 폰에 남는 것 — **음성 원본** (지울 때까지)

음성 원본을 폰에 남기는 건 부모가 나중에 다시 들을 수 있게 하려는 것이다.
다만 15분마다 250KB씩 쌓이므로 **몇 회분까지 둘지는 아직 안 정했다.** (맨 아래 '아직 안 정한 것')

🟢 데모는 3-1부터 3-6까지 전부 건너뛰고, 답 후보 다섯 중 하나를 그 자리에서 고른다.

## 8. 이름을 가린다

🔵 글자가 돌아온 **직후, 폰 안에서** 이름을 바꿔치기한다. 밖으로 나가기 전이다.

```
"뿌뿌가 로켓을 흔들었어"   →   "{친구1}가 로켓을 흔들었어"
```

세 겹으로 찾는다.

1. **사전** — 도감에 등록된 이름 (지호 · 뿌뿌 · 티라노…). 가장 정확하다
2. **규칙** — "○○야", "○○가" 같은 부르는 꼴
3. **탐지 모델** — 사전에도 규칙에도 안 걸린 사람 이름

📦 이름 표 `{주인공}=지호 · {친구1}=뿌뿌` 는 **폰에만** 있다. 서버로 안 간다.

## 9. 이야기 AI에 보낸다 ① 답을 판정한다

🔵 이름을 가린 문장만 LLM 사업자로 간다. 국외로 나가는 유일한 데이터다.

**보내는 것**

```
지금 채우는 칸: place
지금까지 채운 칸: {}
마스코트가 한 질문: "오늘은 어디로 가 볼까?"
아이가 한 말: "로켓 타고 우주 갈래 별 보러 가고 싶어서"
```

**받는 것**

```json
{ "fits": true, "value": "우주",
  "s1_reason": true, "s2_addition": true,
  "emotion": null, "unclear": false }
```

**보내지 않는 것** — 소리 · 아이 이름 · 아이 그림 · 나이 · 기기 번호.

**LLM이 정하지 않는 것** — 수준. LLM은 "이유를 붙였다 / 안 붙였다"만 말하고,
그걸 세어 단계를 옮기는 건 폰 안의 규칙이다.

📦 LLM 사업자에 남는 것: 사업자 정책을 따른다. **국외 이전 고지 대상**이라 동의 화면에 적는다.
📦 폰에 남는 것: 판정 결과 · 칸 값 · 신호

---

## 10. 이야기 AI에 보낸다 ② 마스코트 대사를 받는다

🔵 판정과 **따로** 부른다. 판정이 틀려도 마스코트는 말을 해야 하기 때문이다.

**보내는 것**

```
아이가 방금 한 말: "{주인공}은 로켓 타고 우주 갈래 별 보러 가고 싶어서"
그 말에서 뽑은 값: 우주
다음에 물을 칸: friend
아이 수준: 이어 짓기          ← 폰이 계산해서 넣어 준다
이야기 템플릿: (아직 없음)
```

**받는 것**

```json
{ "받아주기": "우주로 가는구나!",
  "되돌려주기": "별을 보러 폭신폭신 우주에 갔어.",
  "질문": "거기서 누굴 만났어?" }
```

**수준은 보내기만 하고 묻지 않는다.** "이 아이 수준이 뭐냐"고 LLM에게 묻지 않는다.
폰이 신호를 세어 정한 값을 **질문의 결을 고르라고 알려주는 것**뿐이다.

| 수준 | 질문이 이렇게 바뀐다 |
|---|---|
| 고르며 짓기 | "거기서 누굴 만났어?" (무엇 · 누구 · 어디) |
| 이어 짓기 | "그래서 어떻게 됐어?" (그래서 · 그다음) |
| 까닭 짓기 | "{친구1}는 왜 그랬을까?" (왜 · 어떻게) |

📦 폰에 남는 것: 마스코트가 한 말 (부모 기록의 "함께하기" 계산에 쓴다)

🟢 데모는 대사를 전부 미리 써 뒀다. 부르는 곳이 없다.

---

## 11. 이야기 AI에 보낸다 ③ 위험한 말인지 본다

🔵 규칙 기반 금칙어를 통과한 문장만 여기로 온다. **이것도 이름을 가린 뒤에** 보낸다.

```json
{ "block": false, "soften": "(원문 그대로)" }
```

- 걸리면 조용히 순화해서 이야기에 넣는다. **아이에게 알리지 않는다**
- 화면에 경고가 뜨지 않는다. 부모 기록에도 표시하지 않는다
- 🔥 순화된 문장은 **부모 기록의 인용 후보에서 뺀다.** 인용은 아이가 실제로 한 말이어야 한다

## 12. 한 턴에 몇 번 부르나

🔵 지금 설계대로면 한 턴에 **세 번** 부른다.

| 언제 | 무엇 | 크기 |
|---|---|---|
| 매 턴 | 판정 (칸에 맞나 · 신호) | 작다 |
| 매 턴 | 마스코트 대사 3조각 | 작다 |
| 매 턴 | 안전 검사 | 작다 |
| 책당 1회 | 어른을 부르는 말 | 작다 |
| 책당 1회 | **책 자막 6~8쪽 + 제목 후보** | 크다 |
| 세션당 1회 | 부모에게 줄 질문 카드 3장 | 작다 |

8턴이면 **한 권에 약 26번**이다. 이야기 AI 비용 70~360원이 여기서 나온다.

**아직 안 정했다** — 판정과 대사를 한 번에 합칠지. 합치면 호출이 3분의 2로 줄지만, 판정이 실패하면 대사도 같이 날아간다. W1에 재보고 정한다.

## 13. 아이가 말을 안 한다 (무응답)

🔵 카드 세 장이 나오는데, **그 카드는 어디서 오나.**

| 순서 | 무엇 | 네트워크 |
|---|---|---|
| 1 | 더 쉬운 질문을 한 번 더 | 대사 호출 1번 |
| 2 | 그림 카드 3장 | **프리셋. 안 나간다** |
| 3 | 그래도 없으면 마스코트가 고른다 | 안 나간다 |

카드를 그 자리에서 만들지 않는다. 기다리게 하면 아이가 떠난다.
프리셋에 없는 것을 골라야 할 때만 뒤에서 만들고, 그동안 대화는 계속된다.

📦 폰에 남는 것: 이 턴은 "골라서 답함"으로 기록된다 (원그래프 재료)
**카드로 고른 답은 수준 신호로 세지 않는다.** 아이가 스스로 말한 게 아니기 때문이다.

---

## 14. 그림이 마음에 안 든다 (중간 확인)

🔵 무엇을 바꾸느냐에 따라 **나가기도 하고 안 나가기도 한다.**

| 아이가 말한 것 | 네트워크 | 걸리는 시간 | 횟수를 쓰나 |
|---|---|---|---|
| "빨간 게 좋아" (색) | **안 나간다** | 0초 | 안 쓴다 |
| "더 크게" (크기) | **안 나간다** | 0초 | 안 쓴다 |
| "웃는 얼굴로" (표정) | **안 나간다** | 0초 | 안 쓴다 |
| "뿔이 더 커야 돼" (모양) | 나간다 | 몇 초 | **쓴다** |
| "다른 공룡 할래" (종류) | 나간다 | 몇 초 | **쓴다** |

앞의 셋은 폰에서 색 영역을 갈아 끼우거나 레이어 크기를 바꾸거나 눈 스티커를 교체한다.
다시 만드는 것은 **두 번까지**다. 다 쓰면 만든 그림 셋을 늘어놓고 고르게 한다.

---

## 15. 그림을 만든다

🔵 칸이 확정되면 **영어 낱말만** 우리 GPU의 ComfyUI로 간다.

```
보내는 것:  "space, rocket, triceratops, felt 3d"
보내지 않는 것: 아이 말 원문 · 아이 이름 · 아이 그림
```

📦 만든 그림은 **폰에 저장**된다. 같은 책에서 다시 쓰고 다음 이야기에서도 쓴다.
🔥 서버에는 그림을 캐시하지 않는다. 다른 집 아이와 그림을 공유하지 않기 위해서다.

색 · 크기 · 표정을 바꿀 때는 **아예 보내지 않는다.** 폰에서 색 영역만 갈아 끼우거나 눈 스티커를 바꾼다. 그래서 0초에 바뀐다.

---

## 16. 마스코트가 말한다

🔵 대사에서 **이름을 뺀 문장만** CLOVA Voice로 보내고 소리를 받아 온다.

```
보내는 것:  "우주로 가는구나! 거기서 누굴 만났어?"
안 보내는 것: "지호야, 우주로 가는구나"   ← 이름이 들어가면 안 보낸다
```

이름을 불러야 하는 자리는 폰에 내장된 음성으로 읽거나 "우리 주인공"으로 바꾼다.

📦 받은 소리는 폰에 잠깐 두고 재생 뒤 버린다.

---

## 17. 공룡 소리를 녹음한다 (**길이 다르다**)

🔵 이 녹음만은 **음성 인식 경로를 아예 타지 않는다.**

- 폰이 녹음하고, 폰이 길이와 음량만 재서 "소리가 들어왔나"를 판단한다
- 0.3초보다 짧으면 "한 번 더!" 한 번, 그래도 없으면 기본 효과음
- 글자로 바꾸지 않는다. **말한 횟수에도 세지 않는다**

📦 녹음 원본이 폰에 남아 책 6쪽에 그대로 붙는다
🔥 **폰 밖으로 한 번도 나가지 않는다**

---

## 18. 그림판에 그린다

🔵 손가락 자국을 폰이 그림 파일로 만든다.

📦 폰에 저장. 책 표지와 본문에 **원본 그대로** 들어간다
🔥 나가지 않는다. AI로 다시 그리지 않는다

입 위치는 아이가 누른 **점 하나의 좌표**만 저장한다. 얼굴을 인식하는 게 아니다.

---

## 19. 책을 만든다 (**가장 큰 호출**)

🔵 필수 칸 여섯이 다 차면 **한 번만** 부른다. 화면에는 "책을 만드는 중…"이 뜨고, 그 사이 마스코트가 제목을 묻는다. **기다림을 질문으로 덮는 것**이다.

**보내는 것** — 이름은 전부 가려서

```
채워진 칸: { "place":"우주", "problem":"{친구1}이 로켓을 흔듦",
            "reason":"친구가 없어서 심심했어", "solution":"별을 땄어요",
            "companion":"뿔공룡", "adult":"떡을 싸 오셨어요" }
템플릿: A 도전-성취형
속성 축: 상황 이해
```

**받는 것**

```json
{ "title_candidates": ["...5개..."],
  "pages": [ {"n":1, "text":"{주인공}은 로켓을 타고 반짝이는 우주로 떠났어요."}, ... ] }
```

**폰이 하는 일**

1. `{주인공}` → 지호, `{친구1}` → 뿌뿌로 **되돌린다**
2. 쪽마다 어느 그림을 쓸지 고른다 — **이미 있는 그림은 다시 만들지 않는다**
3. 새로 만드는 것은 **미션 물체와 쪽별 소품뿐**

📦 폰에 남는 것: 책 한 권 (자막 · 그림 자리 · 소리 · 미션)
🔥 서버에는 책이 남지 않는다

**쪽수는 템플릿이 정한다.** 고르며 짓기면 6쪽, 이어 짓기면 7쪽, 까닭 짓기면 8쪽이다.
쪽 수를 LLM이 정하는 게 아니라 **폰이 정해서 알려준다.**

🟢 데모는 템플릿별 자막을 전부 미리 써 뒀다. 칸 값만 끼워 넣는다.

---

## 20. 부모 기록을 만든다

🔵 책이 끝나면 **폰 안에서** 만든다. 여기가 제일 중요한 구분이다.

### 폰이 만드는 것 (LLM이 손대지 않는다)

| 무엇 | 어떻게 |
|---|---|
| 6축 횟수 | 세션에 쌓인 이벤트 11가지를 **센다** |
| 3단계 표시 | 0회 · 1~2회 · 3회 이상 |
| 말한 방식 원그래프 | 말로 · 골라서 · 그려서 턴 수 |
| **축마다 붙는 인용** | 아이가 한 말 **원문 그대로**. 다듬지 않는다 |
| "13번 중 12번을 셌어요" | 신뢰도가 낮은 발화를 뺀 수 |

**숫자와 인용은 한 번도 밖으로 나가지 않는다.** 전부 폰에서 계산하고 폰에 저장한다.

### LLM이 만드는 것 (딱 하나)

부모가 다음에 물어볼 **질문 카드 3장**뿐이다.

**보내는 것**

```
오늘 나온 축: 말하기 · 이유 말하기 · 이야기 채우기 · 만들기 · 함께하기
오늘 안 나온 축: 마음 말하기
아이가 한 말 중 가장 긴 것: "{친구1}이 장난쳐서 로켓을 잡고 흔들었어"   ← 이름 가림
```

**받는 것**

```json
{ "cards": ["{친구1}는 어떻게 집에 돌아갔을까?",
            "그때 지호 마음은 어땠어?",
            "다음엔 어디로 가고 싶어?"] }
```

### 금지어 가드

받은 문장에 아래가 하나라도 있으면 **그 답을 버리고 미리 만들어 둔 카드를 쓴다.**

```
또래 · 평균 · 백분위 · 정상 · 수준 · 등급 · 단계 · 발달지수 · 지연 · 선별 ·
진단 · 검사 · 향상 · 증진 · 늘었 · 부족 · 떨어지 · 잘하 · 못하
```

LLM이 "지호는 또래보다 어휘가 풍부해요" 같은 문장을 낼 수 있기 때문이다.
**그런 문장이 부모 화면에 뜨는 순간 우리 제품은 의료기기 쪽으로 넘어간다.** 그래서 걸러내는 것이 아니라 아예 버린다.

📦 폰에 남는 것: 오늘의 기록 한 장
🔥 서버에는 기록이 남지 않는다. 부모 기록은 **한 번도 폰을 떠나지 않는다**

🟢 데모는 이 계산을 실제로 한다. 오늘 대화로 숫자와 인용이 채워진다. 질문 카드만 미리 써 둔 것을 쓴다.


---

## 21. 친구를 평가하고 책을 꽂는다

🔵 **전부 폰 안에서 끝난다. 네트워크를 쓰지 않는다.**

- [또 만날래]를 고른 친구는 다음 이야기의 확인 카드 후보가 된다
- [안녕]을 골라도 지워지지 않는다. 그 책을 열면 그대로 있다
- 책이 책장에 꽂히고 화면이 어두워진다. **다음 책을 권하지 않는다**

📦 폰에 남는 것: 책 한 권 · 친구 평가 · `friend_rating` · `session_end`

---

## 22. 앱을 지우거나 기기를 바꾼다

🔵 **전부 사라진다.** 1차에서는 백업이 없다.

| 무엇 | 어떻게 되나 |
|---|---|
| 책 · 그림 · 소리 · 기록 | 없어진다 |
| 우리 서버에 있던 것 | 원래 없다. 되살릴 것도 없다 |

동의 화면에 이 문장을 적는다. "기기를 바꾸거나 앱을 지우면 함께 사라집니다."

서버에 아무것도 안 두기로 한 대가다. **되찾을 수 없는 대신 샐 수도 없다.**
책 내보내기와 백업은 2차 범위다.

---

## 23. 인터넷이 없다

🔵 어디까지 되나.

| 되는 것 | 안 되는 것 |
|---|---|
| 앱 켜기 · 책장 · 지난 책 읽기 · 미션 · 도구 | 새 이야기 만들기 |
| 부모 기록 보기 | 음성 인식 · 이야기 AI · 새 그림 |

새 이야기는 음성 인식부터 막히므로 시작 화면에서 미리 알린다.
**이야기 도중에 끊기면** 한 번 다시 보내고, 그래도 안 되면 프리셋으로 채워 책까지는 끝낸다.
아이에게 오류를 보여주지 않는다.

## 아직 안 정한 것

| 무엇 | 왜 남아 있나 |
|---|---|
| 폰에 음성 원본을 **몇 회분** 둘지 | 부모가 다시 듣게 하려면 남겨야 하고, 쌓이면 용량과 위험이 는다 |
| 압축 방식과 실제 전송량 | 위 250KB는 추정이다. W1에 실측한다 |
| 자체 Whisper냐 CLOVA Speech냐 | W1 비교 결과로 정한다. **CLOVA로 가면 위 그림에서 GPU 자리가 남의 서버로 바뀐다** |
| 이름 탐지 모델을 폰에 둘지 서버에 둘지 | 폰에 두면 안전하고, 서버에 두면 정확하다 |
| 그림 생성을 못 따라갈 때 몇 장까지 프리셋으로 대체할지 | 생성 시간 측정 뒤 |
