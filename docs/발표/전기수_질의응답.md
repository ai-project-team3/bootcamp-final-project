# 지난 기수 발표 질의응답

지난 기수(6~15기) 발표에서 나온 질문을 모으고, 같은 질문이 우리에게 오면 어떻게 답할지 적는다. 숫자는 [숫자_정본.md](숫자_정본.md)에서만 가져온다.

## 쓰는 법

한 질문에 한 블록. 비슷한 질문은 한 블록에 기수만 더한다.

```
### 질문 (짧게, 실제 들은 말투로)
- 나온 곳: 13기 ○○팀
- 왜 나왔나: 그 팀 발표의 어떤 점을 찔렀나
- 우리 답: 두세 문장. 숫자는 정본 표의 값
- 먼저 답할 사람: 종훈 / 치영 / 진웅 / 민우
```
