# 발화 계산기 정확도와 연령 근거 점검 — 10-12

## 결론과 적용 범위

**낯선 분절 표기만으로 계산기가 잘못됐다고 판단할 수 없다.** 기본형·어미 정규화는 정상 동작이었고, 별도로 부사 파생 접미사 `XSM`을 세지 않던 실제 오류를 발견해 수정했다. 합계 계산은 외부 기준 형태소 목록 385개 입력에서 일치했다. 그러나 **AI-Hub 아동 발화의 형태소 분석 정확도가 입증된 상태는 아니다.** 공개 일반 텍스트에서는 기준 주석과 불일치도 측정됐다.

이 보고서의 계산기는 `eval/language_metrics.py`의 **오프라인 Kiwi 계산기**다. 현재 앱의 공백 기준 관찰값과 다르며, 이번 수정으로 앱에 Kiwi나 연령 점수를 넣지 않는다. 앱 지표 정의는 [관찰값 문서](발화지표_관찰과_검증_1012.md), 맞춤 질문은 [구현 문서](동화_기록기반_맞춤질문_1012.md)를 따른다.

| 검증 대상 | 현재 확인한 상태 |
|---|---|
| 출처 제외·합계·평균·표본 집계 | 관련 자동 검사 36개 통과. 외부 주석 목록 385개 입력의 합계 일치 |
| 기존 50개 분석 재현 | 저장된 분절·개수 50/50 재현. 사람 정답 대비 정확도가 아님 |
| 일반 텍스트 기준 주석 대조 | 네 자료별 개수 일치율·절대오차 측정 완료. 아래 결과 공개 |
| AI-Hub 아동 발화의 독립 정답 대비 정확도 | 미확정. 사람 검수 8개(좋음 5·나쁨 2·보류 1) 보존, 자동 표를 본 검수 |
| 연령별 발화 길이 차이 | 기존 653명 분석에서 뚜렷하지 않음. 수정 후에도 동일한 결론 |
| 맞춤 질문 구현 | PR #409 병합, backend·Android CI 통과. 실제 아동 효과는 미측정 |

## 1. 어색한 표기와 오류를 분리한 결과

- Kiwi 기본 설정은 이형태를 통합한다. `하/어요` 같은 출력은 발음을 그 모양대로 하라는 뜻이 아니다. 축약된 어간·어미가 원문의 같은 위치에 겹쳐 대응할 수도 있다.
- 기존 아동 전사문 50개에서 이형태 통합을 끈 설명용 대조를 수행했다. **19개에서 형태 표기가 바뀌었지만 형태소 수는 50개 모두 같았다.** 실제 계산 설정은 바꾸지 않았다.
- 28개에서 토큰 원문 범위가 겹쳤고, 범위를 벗어난 토큰은 없었다. 위치 겹침 자체를 잘못된 중복 집계라고 판정하지 않는다.
- 50개 중 한 원문에는 `요` 반복 자체가 있었다. 반복 표시는 원문 반복·정규화·실제 오분석을 구별해야 한다. 모든 반복이 정상이라는 뜻도 아니다.
- 저장된 분석표와 현재 출력이 같다는 것은 **재현성**이다. 분석표 자체를 정답으로 삼아 정확도 100%라고 계산하지 않았다.

근거: [Kiwi 공식 품사·분석 설명](https://github.com/bab2min/Kiwi), 로컬 Kiwi·model 0.24.0, `cong`, `normalize_coda=False`, `split_complex=False`, `typos=None`.

## 2. 발견한 계산 누락과 수정 영향

`MORPHEME_TAGS`에 부사 파생 접미사 `XSM`이 빠져 있었다. 조사·어미·접사를 포함하는 기존 계산 정의에 맞게 추가했다. 내용어 종류 수에는 추가하지 않았다. 공급된 `건강/NNG 히/XSM` 주석이 1개로 계산되던 회귀 검사를 먼저 실패시킨 뒤 2개로 통과시켰다. 이 예는 검사용 주석이며 기본 설정이 모든 `건강히`를 이렇게 분석한다는 주장이 아니다.

실제 선정 자료 **35,746답변** 중 4답변에서 접미사 한 개씩 누락됐고, 모두 기존 653명×50답변 창에도 들어 있었다. 같은 입력으로 수정 전후를 비교했으며, 원문과 기존 결과 파일을 덮어쓰지 않았다.

| 나이 | 아동 수 | 수정 전 평균 | 수정 후 평균 | 수정 후 아동 재표집 95% 구간 |
|---|---:|---:|---:|---|
| 3세 | 47 | 5.679574 | 5.679574 | 5.458298~5.899149 |
| 4세 | 113 | 5.600885 | 5.600885 | 5.443186~5.753451 |
| 5세 | 200 | 5.633000 | 5.633300 | 5.522900~5.742600 |
| 6세 | 293 | 5.729147 | 5.729215 | 5.636177~5.822867 |

기존 조건(아동마다 처음 50개, 동일 가중치, bootstrap 2,000회, seed 320)을 유지했다. **누락은 실제 버그지만, 연령 차이가 작았던 현상을 설명할 크기는 아니었다.** 내용어 수·답변 포함 여부는 이 자료에서 변하지 않았다.

## 3. 외부 주석으로 계산과 분석을 따로 검증

자료: [Kiwi 공식 eval_data](https://github.com/bab2min/Kiwi/tree/280302af5ff9e739bec1ce56d6df5f9436ac41d4/eval_data), 고정 커밋 `280302af5ff9e739bec1ce56d6df5f9436ac41d4`.

외부 형태소/POS 주석은 수정하지 않았다. 먼저 그 목록을 계산기에 직접 넣어 **385개 입력 모두 합계가 기준과 같음**을 확인했다. 다음으로 원문을 기존 Kiwi 설정으로 분석하여 기준의 개수와 비교했다. 이 검사는 분절·품사 정확도 자체가 아니라 **입력 전체의 형태소 개수 일치**다. 단어가 틀려도 개수는 같을 수 있다.

| 자료 | 입력 수 | 수정 후 개수 완전 일치 | 수정 후 평균 절대오차(개/입력) | 기준 평균 개수/입력 |
|---|---:|---:|---:|---:|
| 문어 | 33 | 20/33 (60.6%) | 0.545 | 45.091 |
| 웹 | 158 | 78/158 (49.4%) | 0.829 | 37.316 |
| 오타 웹 | 97 | 31/97 (32.0%) | 1.186 | 24.412 |
| 연속 오타 웹 | 97 | 30/97 (30.9%) | 1.289 | 24.412 |

수정 전 동일 자료의 완전 일치는 20/33·80/158·32/97·30/97, 평균 절대오차는 0.545·0.816·1.175·1.278이었다. **접사 누락 수정이 외부 주석 일치율까지 개선한 것은 아니다.** 분석기가 접사로 나눈 것을 기준 주석은 다르게 나눈 경우도 있어, 일부 개수의 우연한 일치가 사라졌다. 불일치를 전부 전문가가 판정한 오류로 부르지는 않는다. 유리한 수치가 나오도록 접사를 다시 빼거나 분석 설정을 튜닝하지 않았다.

리뷰 과정에서 새 검사 도구가 `#`로 시작하는 유효 TSV 한 행을 주석으로 건너뛰는 것을 발견했다. 회귀 검사를 추가해 고친 뒤 수정 전후 모두 같은 385행으로 재측정했다. 초기 384행 결과를 최종 결과로 사용하지 않는다.

해석 한계:

- 긴 입력에는 여러 문장이 들어갈 수 있다. 위 비율을 토큰 정확도·아동 발화 정확도·STT 정확도로 쓰지 않는다.
- 분석기 개발자가 공개한 자료이므로 개발에 사용됐을 수 있다. 독립 미공개 평가 자료라고 부르지 않는다.
- 오타 자료는 정상 자료와 연결될 수 있어 네 자료를 합쳐 독립 표본 수나 단일 정확도를 만들지 않는다.
- 부호·구분 표식은 제외하고 형태소는 포함한다. 모르는 품사는 조용히 버리지 않고 검사를 실패시킨다. 자료 정의가 연구의 임상 MLU 규칙과 같다는 뜻은 아니다.

## 4. 연령 근거 전체 점검

**외부 연구 근거는 있고, 우리 자료에서 뚜렷한 연령 차이를 재현한 것은 아니다.** 두 결과를 함께 제시한다.

- [이윤경·임수아(2025)](https://www.kci.go.kr/kciportal/ci/sereArticleSearch/ciSereArtiView.kci?sereArticleSearchBean.artiId=ART003294496): 2~5세 240명, 반구조화 대화 50발화. MLU·LLU의 연령 증가를 보고하며 특히 2세 후반~4세 전후의 변화가 컸다. 6세까지 외삽하거나 앱의 공백 낱말 관찰값과 직접 비교하지 않는다.
- [이희란(2010)](https://kci.go.kr/kciportal/ci/sereArticleSearch/ciSereArtiView.kci?sereArticleSearchBean.artiId=ART001433332): 3세9개월~6세4개월의 소규모 가정 대화 종단 자료에서 MLU-m·MLU-w의 발달 차이가 없고 구문 유형의 변화가 보고됐다. 연령·과제에 따라 길이만으로 차이를 잡기 어렵다는 제한 근거다. 국문·영문 초록의 표본 수가 달라 여기서는 인원 수를 인용하지 않는다.
- [AI-Hub108 공식 구축 가이드](https://aihub.or.kr/file/down.do?fileSn=7988&cnstcPrcuseFileSn=7988&dataSetSn=108): 짧은 대본, 이름 대기·따라 말하기·질문응답·주제 발화 등이 함께 있다. 개별 문항의 과제 유형은 확인한 문서만으로 전부 대응시키지 못했다. `I`를 모두 낭독으로 단정하지 않는다.
- 기존 653명에서 선정 방식·분절 방식 여섯 가지를 대조해도 6세−3세의 재표집 구간은 0을 포함했다. 문항을 맞춘 사후 분석의 작은 양의 관계를 기존 사전 검증 통과로 바꾸지 않았다. 상세 수치·기준은 [#320 추가 실험 기록](https://github.com/ai-project-team3/bootcamp-final-project/issues/320#issuecomment-6124023705)에 있다.

### 확보한 P 자료와 기존 자료를 합칠 수 있는가

P 메타데이터 후보는 14명·716개 비어 있지 않은 기록이다. 수정 전 설정의 아동 동일 가중 탐색 평균은 3~6세 순서로 8.657·6.695·9.511·13.854였다. 하지만 나이별 아동은 3·5·3·3명이고 3세는 50개를 채운 아동이 없다. 6세는 한 명을 빼면 평균이 8.489~18.708까지 바뀐다(영향 범위이며 신뢰구간이 아님). 음성·질문·발화 경계의 자발성 확인도 아직 없다.

**14명 중 13명은 기존 653명에도 포함된다.** 그냥 더하면 독립 아동 667명이 되는 것이 아니다. 50개 미만 아동을 버리지 않고 별도 분석할 수는 있지만 정밀도가 다른 짧은 기록을 기존 창과 동일한 조건이라고 합칠 수 없다. P·비P 자료는 출처를 유지한 별도 층 또는 같은 아동 내 대조로 사용할 수 있고, 한 덩어리로 합쳐 자유발화 연령 검증이라고 부르지 않는다.

현재 완료한 것은 자료 적합성·중복·표본 민감성·외부 문헌의 대조다. 부족한 원문을 AI로 만들거나 반복 추출하여 아동 수를 늘리지 않는다. 실제 독립 아동 자료 없이는 보충되지 않는 검증을 구현 완료와 구분한다.

## 5. 맞춤 질문과 발표에 사용할 상태

[PR #409](https://github.com/ai-project-team3/bootcamp-final-project/pull/409)는 10-12 병합됐고 backend·Android CI가 통과했다. 실제 답·질문 유형·출처·판정 신호를 기기 기록과 연결하며, 이 오프라인 형태소 점수를 런타임 발달 등급으로 쓰지 않는다. 기존 정책에서 카드만 고른 답이 연속되는 경우도 별도로 처리한다. 구현을 다시 중복 작성할 필요는 없다.

발표에는 다음처럼 구분할 수 있다.

> 발화 출처를 구분하는 기록과 관찰 지표, 기록에 기반한 맞춤 질문을 구현했다. 형태소 계산기의 합계·제외 규칙을 검증하고 접미사 누락을 수정했으며 공개 주석 자료의 개수 일치율과 오차를 측정했다. 아동 자료의 독립 정답 정확도와 서비스 사용 효과는 아직 검증하지 않았다. 발화 길이의 연령 관련성은 외부 자발화 연구를 근거로 제시하되, 혼합 과제인 AI-Hub108의 우리 표본에서는 뚜렷한 증가를 재현하지 못했다.

민우님이 기존 검수 42개를 억지로 이어서 채울 필요는 없다. **아동 정확도 숫자**까지 완성하려면 분절 기준을 적용할 수 있는 사람이 자동 답을 보지 않고 만든 정답이 필요하다. 기존 8개 판단과 참고용 AI 분석표는 보존한다. 이는 조장 리뷰·병합을 기다려야 하는 구현 작업과 별개의 증거 조건이다.
