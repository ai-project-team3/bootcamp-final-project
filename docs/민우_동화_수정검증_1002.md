# 10-02 민우 동화 수정 및 검증

## PR 제출을 위한 분리 — 10-02 오후 추가

- 조장이 #37에서 공용 연결용 임시 브랜치를 승인했다. `feature/minwoo` PR은 동화 슬롯·종료·저장 API만 포함하며, `Director.kt`·`Scenes.kt` 연결, 그 연결에 의존하는 선택 흐름과 통합 검사는 공용 연결 PR에 둔다.
- 순서는 동화 PR → main 수신 → 공용 연결 PR이다. 두 PR을 병합하기 전에는 연결까지 완성됐다고 판단하지 않는다. 공용 PR은 동화 PR을 기반으로 한 초안이므로 첫 병합 전에는 선행 동화 변경이 diff에도 보인다. 병합 전 공용 변경만 남는지 확인한다.
- 공용 연결을 포함한 전체 구현과 main `5af4cfe`의 통합 검사: **457개 중 455개 통과, 협업 기준 그림 2개 실패**, 13분 52초. 같은 협업 클래스가 main만 있는 복사본에서도 5개 중 동일한 2개 실패했다. `coop_template_saved.png`·`coop_template_delete_ask.png`의 그림 비교이며 앱 코드를 고쳐 없애지 않았다.
- 공용 연결을 분리한 동화 변경은 관련 검사 **20개 통과**, APK 빌드 성공(1분 4초)을 확인했다. 최신 main `280cb27`에서 추가된 변경은 CI 워크플로뿐이다. 백엔드 **104개 통과**(19.02초).
- 아래 430개 전체 통과 기록은 앞선 앱 코드 `2d4f376`의 기록이며, 새 main 통합 후 전체 검사가 통과했다는 뜻이 아니다. 새 PR의 GitHub CI도 별도로 확인한다.
- S7 edge에 설치한 것은 분리 전 `514d29e`다. 이번 PR 분리를 하며 폰의 앱을 다시 설치하거나 실행하지 않았다. 질문·책 전개와 게이지·마지막 쪽의 보이지 않는 공룡 안내는 #50에 추가 관찰로 남겼다.

## 구현 내용

### #63 답하지 않은 칸과 현재 계약

- 침묵이나 닫힌 선택지를 받지 못한 경우 슬롯을 채우지 않는다. 임의의 장소나 「아직 정하지 않았어요」를 아이가 한 말처럼 기록하지 않는다.
- 실시간 동화 흐름에서 빠져나간 뒤 실행될 수 없던 이전 장면 경로와 비밀번호의 사용되지 않는 입력 분기를 정리했다.
- 실제 측정 없이 기록하던 `duration=15분`을 제거했다. 종료 조건은 `story_ready` 하나로 맞췄다.
- 현재 서버·이름 가리기·음성 동의 계약에 맞춰 오래된 안내를 고쳤다.
- 다른 모드에 영향을 주는 추가 공통 API 추출은 진행하지 않았다.

### #61 저장된 그림 보존과 남은 파일 정리

- 시작할 때와 책 저장에 성공한 뒤 동화 이미지 폴더를 정리한다. 직접 들어 있는 UUID 이름 PNG 중 참조되지 않는 파일만 대상이다.
- 저장된 책의 배경과 주인공, 현재 세션·도감·책장에 필요한 그림을 보존한다. 다른 폴더나 하위 폴더, 임의 이름 파일은 삭제하지 않는다.
- 저장 정보의 그림 참조를 읽을 수 없으면 정리를 건너뛴다.
- 검토 중 발견한 추가 문제도 보완했다. 손상된 JSON, 읽을 수 없는 책 항목·그림 구조, 지원하지 않는 그림 버전이 있으면 기존 목록을 덮어쓰는 저장·교체를 거부한다. 이 경우 기존 책·녹음·PNG를 그대로 둔다.

### #37 동화 13권째 교체 선택

- 동화 책장 용량은 12권이다. 새 책을 추가할 수 없으면 기존 표지를 하나씩 넘겨 뺄 책을 고르고, 책 제목을 다시 보여 주며 확인한다.
- 취소하거나 확인을 거부하면 아무 책도 지우지 않는다. 저장 실패도 기존 책과 녹음을 유지한다.
- 선택한 책을 새 책으로 바꾸는 목록을 한 번에 저장한 뒤 화면을 갱신한다. 저장 성공 후에만 선택한 책의 녹음을 지운다.
- 같은 완성 책을 다시 저장해도 중복으로 늘어나지 않는다. 저장 JSON 형식과 SharedPreferences 이름은 그대로다.
- 기존 CardsRow·Confirm을 사용했다. 다른 모드 저장소와 `Shelf.kt`는 수정하지 않았다.

## 병합 및 기기 검증에서 남은 것

- 공용 연결 PR과 동화 전용 PR 분리는 추가 임시 브랜치 허락을 받은 뒤 진행한다. 직접 main에 푸시하지 않는다.
- 문서 PR #67의 Android CI에는 기존 그림일기 검사 5개 실패가 있다. 수정 PR #68은 CI가 통과했지만 확인 시점에 아직 main으로 병합되지 않았다. 다른 팀원 브랜치를 직접 가져오지 않고 main 병합을 기다린다.
- 이번 최종 변경을 사용자 기기나 Play 배포 앱에서 다시 실행한 결과는 아니다. 실제 기기에서는 13권째 선택·취소·저장·재시작·재열기와 남아야 할 그림·녹음을 확인해야 한다.
- 자동 검사 통과만으로 실제 서버 AI 품질이나 전체 V1 완성을 주장하지 않는다.
