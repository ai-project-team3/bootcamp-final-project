## 1. 한 장 요약

```
[Android 앱 · Kotlin]                    아이 폰 한 대
  녹음 · 그림판 · 책 · 미션 · 부모 모드
  저장: 책 · 전사 · 그림 · 소리 · 기록  ← 전부 기기 안에만
        │
        │ https
        ▼
[FastAPI 백엔드]  API 키 보관 · 중계 · 무저장(요청 수 · 지연 · 오류만 기록)
        │
   ┌────┴─────────────┬─────────────────────┬──────────────────┐
   ▼                  ▼                     ▼                  ▼
[GPU 서버 · 국내]   [에셋 사전제작]        [LLM · 해외]       [사전합성 · 번들]
faster-whisper      ComfyUI               이야기 판정 · 자막   마스코트 목소리
음성 → 글자          그림 생성 · 편집        (이름 가린 문장)     (이름 없는 문장)
사본 즉시 삭제       배경 제거 · 안전 검사
```

**밖으로 나가는 것은 이름을 가린 문장과 이름 없는 대사뿐이다.** 아이 목소리 · 이름 · 그림 · 소리 녹음은 나가지 않는다.

## 3. 한 세션이 도는 순서

| 단계 | 어디서 | 무엇 |
|---|---|---|
| 1 | 앱 | 마스코트가 열린 질문. 아이가 말한다 |
| 2 | 앱 → 백엔드 → GPU | 말소리 구간만 잘라 Whisper로 글자 변환 → **음성 사본 즉시 삭제** |
| 3 | **폰** | 이름 필터 — 아이 · 친구 · 도감 이름을 `{주인공}` `{친구1}`로. **매핑표는 폰에만 있고 서버로 안 간다** (9/18 개정 — 아래) |
| 4 | LLM | 답이 칸에 맞는지 · 앞 칸과 모순인지 · 신호(S1 · S2)를 JSON으로. **수준 계산은 우리 규칙이 한다** |
| 5 | 앱 | 마스코트 반응(받아주기 → 되돌려주기 → 다음 질문) |
| 6 | GPU | 칸이 확정되면 영어 키워드로 ComfyUI에 그림 요청 (뒤에서) |
| 7 | 앱 | 2~3턴 뒤 "짠! 좋아, 싫어?" 중간 확인 |
| 8 | LLM → 앱 | 칸이 다 차면 장면 6개와 자막을 받고, 폰에서 이름을 되돌린다 |
| 9 | 앱 | 이미 있는 그림을 합쳐 책을 만든다. 새로 만드는 건 미션 물체와 쪽별 소품뿐 |
| 10 | 앱 | 부모 모드 기록은 폰 안에서 계산 |

## 4. 지연 예산

| 자리 | 목표 | 방법 |
|---|---|---|
| 선택지 · 사건 그림 | **0초** | 미리 만들어 둔 프리셋 |
| 중간 확인 그림 | 2~3턴 뒤 도착 | 칸 확정 즉시 뒤에서 생성. 저해상도 · 적은 단계 |
| 색 · 크기 · 표정 변경 | **0초** | 생성하지 않고 색 영역 · 레이어 · 스티커 교체 |
| 그림이 늦을 때 | 8초 | "그림은 조금 뒤에 올 거야" 후 진행 |
| 그림 취소 | 15초 | 프리셋으로 확정 |
| 아이 답 대기 | 쉬운 5초 · 어려운 8초 | 말하는 중 침묵으로는 끊지 않는다 |

**GPU 한 대에 Whisper와 이미지 모델을 같이 올린다.** ComfyUI는 다른 프로세스의 GPU 메모리를 관리하지 못하므로 W1에 메모리와 지연을 실측한다.

## 5. 저장과 프라이버시

| 데이터 | 어디에 | 얼마나 |
|---|---|---|
| 아이 음성 원본 · 소리 녹음 | 폰 | 계속 (사용자가 지울 때까지) |
| 음성 사본 (변환용) | GPU 서버 | **변환 직후 삭제** |
| 전사 · 기록 · 책 · 그림 | 폰 | 계속 |
| 이름을 가린 문장 | LLM 사업자 | 사업자 정책에 따름 (국외 이전 고지 대상) |
| 영어 키워드 | 우리 GPU | 남기지 않음 |
| 요청 수 · 지연 · 오류 | 백엔드 | 운영용, 내용 없음 |

- 서버에 그림을 캐시하지 않는다 (결정 26)
- 만 14세 미만 법정대리인 동의 · 국외 이전 고지 · 쉬운 말 고지 (개인정보보호법 제22조의2)

| 규칙 | 어디에 |
|---|---|
| 수준 3단계 계산 (신호 2턴 연속이면 이동) | 앱 |
| 템플릿 선택 (3턴째 확정) | 앱 |
| 무응답 흐름 (대기 → 쉬운 질문 → 카드 3번 → 마스코트) | 앱 |
| 짧은 답 후처리 (선택지 후보와 맞춰보기) | 앱 |
| **이름 필터 — 2층으로 확정** (9/18) | **폰** |
| 미션 난이도 (혼자 성공 → 올림 / 도움 → 내림) | 앱 |
| 리포트 6축 계산 | 앱 |

**LLM에게 맡기지 않는 것**: 수준 판정 · 미션 난이도 · 업적 · 리포트 문장의 사실 부분

## 7. 기록하는 이벤트 (리포트의 재료)

리포트 6축은 사람 판단이 아니라 **아래 기록을 세어서** 만든다. 전부 폰 안에 쌓인다.

| 이벤트 | 언제 | 어느 축으로 |
|---|---|---|
| `story_start` | 책 시작 | 세션 구분 |
| `utterance` | 아이가 말할 때마다 (글자 · 낱말 수 · 신뢰도) | 말하기 |
| `slot_filled` | 칸이 채워질 때 (어떤 칸 · 말로/골라서/그려서) | 이야기 채우기 · 원그래프 |
| `signal` | 이유 말함(S1) · 안 물은 것 덧붙임(S2) | 이유 말하기 |
| `emotion_mention` | 마음을 가리키는 말이 나올 때 | 마음 말하기 |
| `make` | 그림 그리기 · 소리 녹음 · 미션 성공 | 만들기 |
| `image_request` | 그림 요청 (프리셋/생성 구분 · 걸린 시간) | 운영 지표 |
| `redraw` | 다시 그리기 (몇 번째 · 이유) | 운영 지표 |
| `mission` | 미션 시도 · 성공 · 도움 여부 | 만들기 · 난이도 |
| `friend_rating` | 책 끝 친구 평가 | 도감 조건 |
| `session_end` | 끝 (총 시간 · 완주 여부) | 완주율 |

- 신뢰도가 낮은 `utterance`는 세지 않고 "13번 중 12번을 셌어요"로 밝힌다
- 축 하나라도 3단계 규칙(횟수 → 단계 → 인용)을 벗어나지 않는다. 점수 · 또래 비교 없음

## 8. 비용

| 항목 | 상태 |
|---|---|
| 음성 인식 | **0원** (자체 GPU). CLOVA로 가면 15분에 약 50~240원 |
| 이미지 | **0원** (자체 GPU). 전기 · 대여만 |
| 이야기 AI | 책 한 권 약 70~360원 (턴 수 · 길이에 따라) |
| 목소리 | CLOVA Voice 종량 |
| 합계 가정 | 기본 2권 ≈ 720원 / 프리미엄 30권 ≈ 10,800원 |

GPU를 부트캠프에서 제공받으므로 **변동비 대부분이 사라진다.** 이것이 자체 호스팅을 고른 두 번째 이유다(첫째는 아이 데이터).

## 9. W1에 재는 것

| 무엇 | 어떻게 | 담당 |
|---|---|---|
| 음성 인식 정확도 | 자체 Whisper vs CLOVA. 아이 녹음 + 무음 클립 50개. 글자 오류율 · 뜻한 낱말 정답률 · 헛출력 비율 · 응답 시간 | 안치영 |
| 수준 판단 일치도 | 가짜 세션 5개에 사람이 단계를 붙이고 규칙과 비교 | 안치영 |
| 이미지 | 같은 프롬프트로 모델별 3장. 장당 시간 · 그림체 유지 · 배경 제거 품질 | 최민우 |
| GPU 메모리 | Whisper + ComfyUI 동시 구동 | 최민우 · 안치영 |
| 이야기 엔진 | 같은 답에 속성만 바꿔 3버전. 규칙 준수 루브릭 채점 | 박진웅 |
| 영상 대비 발화 횟수 | 같은 아이에게 영상 15분과 앱 15분. 말한 횟수 비교 | 전원 · 평가 세션 |
