> 10-12 초안 · 치영(ComfyUI 세션) · 기준 main `80d23e2e` 이후 · **③ 실제로 그려 본 결과는 비용 허락 뒤 채움**
> 범위: 조사와 측정까지. 앱 · 서버 코드는 바꾸지 않는다.

## 0. 한 줄 결론 (초안 — ③ 측정 뒤 다시 씀)

`background` 는 **그림 API 로 대체 가능 후보**(값은 장당 수~수십 원), `character` 는 **조건부**(자세 틀 · 투명 · 발 93% 선을 우리 후처리로 맞춰야 함), `redraw` 는 **외부 API 불가 · 우리 계정의 서버리스 GPU(C) 가 유일한 후보** — 콜드 스타트가 45초 안에 드는지만 재면 된다.

## 1. 책 한 권에 그림이 몇 장 만들어지나

**전부 코드에서 센 추정이다.** 책마다 실제 장 수는 폰이 책 끝에 남기는 `callSummary`(`net/Server.kt:385-401` → `Scenes.kt:1855` · `PictureDiary.kt:1825`)에만 있고, 그 값을 모은 문서 · 로그는 없다. 운영 서버 `/stats` 를 읽거나 실기기 로그를 모으면 실측으로 바꾼다.

| 모드 | 종류 | 최소 / 보통 / 최대 | 근거 |
|---|---|---|---|
| 동화 | background | 0 / 0~1 / 장소마다 1 | 장면 키트가 맞으면 요청 없음(`StoryLiveFlow.kt:44-51`). 그림체 조각이 없으면 키트 꺼짐(`:249` · `WorldStyle.kt:19`). 같은 장소 재요청 없음(`:39`). 장소가 비면 첫 장면에서 1장 더(`:212-225`) |
| 동화 | character (주인공) | 0 / 0~1 / 3 | 도감 주인공 · 프리셋을 고르면 0(실측 0, `docs/동화_주인공_재사용_검증_1008.md:25`). 말로 만들면 1 + 다시 그리기 `redrawMax`=2(`Model.kt:1335`) |
| 동화 | character (새 친구 · 문제 인물) | 0 / 0~1 / 2+ | 프리셋 없는 새 인물만, 아이가 그릴지 정한 뒤(`StoryCharacters.kt:59-62` · `FriendArt.kt:28-33`). 실패는 캐시돼 다시 안 부름(`FriendArt.kt:66`) |
| 같이 만들기 | background | 0 / 1 / 장소 바뀔 때마다 1 | 오또가 채운 장소 · 키트 장소는 요청 없음(`CoopServerLine.kt:96-126`) |
| 같이 만들기 | character | 0 / 0~1 / 1 | 동반자만, 책 만들 때 그리기로 정했을 때(`DiaryScenes.kt:373-375`) |
| 그림일기 | redraw | 0 / 1~2 / 오또 제안 4 + 아이가 「그려줘」 한 만큼 | 오또 제안 상한 `OTTO_OFFERS`=4(`PictureDiary.kt:41`), 아이 요청은 상한 없음(`:213` · `:683-727`) |

- 서버는 요청 한 번에 ComfyUI 그림 **한 장**, 다시 시도 없음(`comfy.py:69` batch 1 · `image.py:85,93`). 요청마다 장면 LLM 1회 · `omni-moderation` 1회가 따로 붙는다.
- 아래 값 계산은 **책 한 권 = 2장**(보통)과 **5장**(많을 때)으로 한다.

## 3. 실제로 그려 본 결과 — **⏸ 비용 허락 뒤**

같은 장소 6개(공원 · 바닷속 · 우주 · 할머니 집 · 미래 도시 · 피자마을) · 인물 4개(로봇 · 공룡 · 문어 · 괴물)를 선택지마다 그려 걸린 시간과 그림을 나란히 둔다.

- 기준선: 지금 서버 워크플로(SDXL base + Lightning 8-step · `comfy.py`)를 내 PC(RTX 4060 노트북)에서 그대로. 서버 PC2 와 GPU 가 달라 시간은 따로 적는다.
- 블라인드 자료: 출처를 가린 무작위 라벨 판 + 정답표는 따로(팀 4명이 직접 고름 · 3명 이상 「같거나 낫다」).
- 측정용 비용 어림: A OpenAI 약 $1~2 · A Google 약 $1 · B 약 $0.5 · C RunPod/Modal 시험 약 $3~5(무료 크레딧이면 0) → 합계 약 $6~10.

## 4. 종류별 판정 (초안)

| 종류 | 판정 | 이유 |
|---|---|---|
| `background` | **대체 가능 (③ 통과 조건)** | 글→그림만이라 어느 API 든 된다. 남은 것은 그림체 블라인드와 13초. 실패해도 프리셋이 있어 위험이 작다 |

| `redraw` | **외부 API 불가 · C 만 후보** | §5 |

## 5. `redraw` — 원본을 안 내보내고 할 수 있나

규칙(`guidelines/1` §1-5 · 공개 처리방침): 아이 그림 원본은 **우리 서버까지만**. 그래서 A · B 는 값과 무관하게 탈락.

| 길 | 원본이 어디까지 | 45초 안 | 판단 |
|---|---|---|---|
| C 서버리스 GPU(우리 계정) | 우리가 빌린 GPU 메모리 — 지금처럼 메모리로만 받고 기록을 지우는 워크플로(`backend/comfy_nodes/otto_memory.py` · `guidelines/3` API 명세) 그대로 | 콜드 스타트 포함 실측 필요 · 45초면 여유 큼 | **유력.** 다만 「우리 서버」에 빌린 GPU 를 넣을지는 종훈 판단(처리방침에 위탁 업체로 적어야 할 수 있음) |
| 클라우드 CPU | 우리 서버 | SDXL 8-step 1장 CPU 시간 **미측정**(내 PC CPU 로 무료 측정 예정) | 몇 분 걸리면 탈락 |
| 기기 안(S10) | 폰 밖으로 안 나감 | SDXL 은 폰에서 현실적이지 않음(추정 · 측정 안 함) | 불가 |
| 아무 길도 안 되면 | — | — | 「오또가 그려 줘」를 끄거나, 아이 그림 대신 **이름 글자만** 보내 글→그림으로 그림(원본 안 나감 · 아이 그림의 모양은 포기) |
