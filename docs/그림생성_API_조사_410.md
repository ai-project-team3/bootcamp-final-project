## 0. 결론 (예측 기준)

| 종류 | 판정 | 가장 유력한 길 |
|---|---|---|
| `background` | **대체 가능** | 우리 ComfyUI 워크플로를 그대로 쓰는 서버리스 GPU(C · Modal 또는 RunPod) — 그림체 그대로 · 책 한 권 ≈ 4~5원(예측). 그림 API(A)는 그림체 블라인드를 통과해야 해서 다음 순위 |

## 1. 책 한 권에 그림이 몇 장 만들어지나

**전부 코드에서 센 추정이다.** 책마다 실제 장 수는 폰이 책 끝에 남기는 `callSummary`(`net/Server.kt:385-401` → `Scenes.kt:1855` · `PictureDiary.kt:1825`)에만 있고, 그 값을 모은 문서 · 로그는 없다. 운영 `/stats` 나 실기기 로그를 모으면 실측으로 바꾼다.

**답: 받을 수 있다.** 우리 워크플로를 노드까지 그대로 올리는 길은 **Modal · RunPod**(우리 컨테이너) 와 **Comfy API · RunComfy · fal**(호스팅 SaaS) 두 갈래다.

## 6. 라야 CPU (자리만)

라야 세션의 CPU 조사 결과를 받아 한 절로 넣는다 — 클라우드 비용을 한 표로 보려는 것.

## 남은 일 · 확인 못 한 것

1. **실측으로 확정할 것(허락 뒤)**: Modal 또는 RunPod 에 우리 워크플로를 올린 첫 요청 시간 · 장당 시간 — 결론이 이 숫자 하나에 걸려 있다
