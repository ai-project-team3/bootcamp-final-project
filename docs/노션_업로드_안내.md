- **제대로**: 붙인 뒤 노션에서 `@페이지이름`으로 다시 건다

**우선 간단하게. 시간 나면 `@`로.**

### ② 표 안의 `<br>`

셀 안 줄바꿈용인데 노션은 **글자 그대로 표시한다.** 붙인 뒤 **Ctrl+F로 `<br>`을 찾아** 지운다. **9·15번에 주로 있다.**

### ③ 체크박스는 그대로 둔다

`- [ ]`가 노션에서 **할 일 블록으로 자동 변환**된다. 3번 문서의 완료 기준이 체크 가능한 목록이 된다.

9·10번의 턴 엔진 그림, 3번의 하루 일정 그림은 **코드블록 안에 있어야** 정렬이 유지된다. 붙인 뒤 확인한다.

## 4. 붙여넣는 법

1. 노션에서 **빈 페이지**를 만든다 — **기존 페이지를 덮어쓰지 않는다**
2. 파일을 편집기로 열어 **Ctrl+A → Ctrl+C**
3. 노션 본문에 **Ctrl+V**
4. **§3의 넷을 확인**한다
5. 새 페이지가 멀쩡하면 **그때** 옛 페이지를 보관으로 옮긴다

> **⚠️ 자동화하지 않는다.** 합성 Ctrl+V는 진짜 클립보드를 못 건드린다. 9/16에 스크립트로 붙여넣다 본문이 통째로 지워졌다.
