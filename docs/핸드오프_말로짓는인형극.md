## 2. Claude가 이 사용자와 일하는 법

- **답변은 한국어.** 코드·커밋·로그·식별자는 영어. 문서는 한국어.
- 사용자는 조장이고 기획자+개발자 둘 다 어필하려 한다.
- **검증 없이 제안하지 않는다.** 숫자·서비스명·논문은 출처를 확인하고 쓴다. 확인 못 한 것은 `[미확인]`으로 남긴다.
- **에이전트 보고서는 판정이 아니라 근거를 읽는다.** 1판의 "폰 2대" 실수는 에이전트의 한 줄 판정을 검산하지 않아 생겼다.
- 파일을 남발하지 않는다. 필요할 때만, 한 곳에.
- 폰은 **한 대**다. 이모 폰·초대·기기 간 전송 설계를 다시 꺼내지 않는다.
- 리포트에 또래 비교·규준·백분위·"지연"·"선별"·발음 판정을 넣지 않는다.
- 노션에는 md를 올린다. Artifact는 비공개가 기본.
- 데일리로그는 취몽 MCP로 올린다 (전역 CLAUDE.md). category는 `final`.

**이 사용자가 실제로 되돌린 것 (같은 제안을 반복하지 말 것)**

| 내가 한 것 | 사용자 반응 | 지금 방침 |
|---|---|---|
| "평가는 우리 일이 아닙니다"로 윤리 방어 | "그게 싫다. 교육적인 부분이 어필돼야 죄책감을 덜어낸다. 방법을 하나도 제시하지 못했다" | 제약이 아니라 **증명 가능한 근거**로 답한다 (§6-5) |
| 별을 톡톡 눌러 인사하는 미션 | "너무 재미없는데" | 비구름으로 우물 채우기, 뿅망치로 괴물 밀어내기 같은 **목표 있는 동작** |
| 질문마다 그림 카드 상시 노출 | "우리가 상상한 시나리오가 아니야" | **열린 질문으로 통일.** 카드는 폴백일 때만 |
| 어른이 책을 읽어주기 | "반대야. 사회자는 마스코트가 했으면" | 마스코트가 진행하고 읽는다 |
| 5세 타깃 | "평균 연령이 5세인 거지 5세만 타깃하는 건 아니야" | 범위 3~7세, 중심 5세 |
| 결정 30건을 gaps로 옮기기 | "gaps는 새 프로젝트에 필요 없는 사항 아니야?" | 중복 생성 금지 |
| 다시 그리기를 그냥 재생성 | "어떤 게 마음에 안 들어? 정도는 물어보고 진행해야" | 한 번 묻고 다시 그린다. n/2 표시 |

**기술적으로 되풀이된 실패**
- 긴 한국어를 Bash 히어독으로 쓰면 깨진다. **Write 도구를 쓴다.**
- Edit의 앵커 문자열은 grep으로 실제 본문을 확인하고 쓴다.
- JS로 렌더되는 페이지(노션·law.go.kr·ncloud 가격)는 WebFetch가 실패한다. Chrome 도구나 에이전트로 우회한다.

## 3. 사용자와 등장인물

- **아이**: 3~7세, 중심 5세. 예시 이름 지호. 화면에 잠긴 것·점수·기록·가격이 보이면 안 된다.
- **어른(놀이 상대)**: 짧게 봐주는 이모·삼촌·조부모가 1순위. 폰은 부모 폰. 어른용 버튼 없음. 마스코트가 어른에게 말을 거는 칸이 하나 있다.
- **부모**: 동의·설정·기록의 주인. 부모 모드는 비밀번호 4자리.
- **마스코트(이름 미정)**: 진행자. 질문하고, 되묻고, 책을 읽어준다. 이야기 안에 들어가지 않는다. 한 턴은 **받아주기 → 늘려서 되돌려주기 → 질문**.

프레임: **돌봄을 대신하지 않는다. 함께 놀 소재를 준비해 준다.**

## 4. 제품 스펙

전체 스펙은 `말로짓는인형극_기획안.md` 2판, 화면별 대사는 `구현대본.md`. 여기서는 뼈대만.

**한 세션 약 15분**: 시작 화면(별 숫자) → 열린 질문 대화 8턴 → 중간 확인 → 책 6쪽 → 미션 2개 → 친구 평가 → 끝내기 → (부모 모드) 오늘의 기록.

**칸(슬롯) 7개**: 장소 · 친구 · 문제 · 소리 · 등장인물(그림) · 해결 · 어른(선택). 채움 방식은 말 / 소리 / 그림 / 그림 3장(폴백) / 프리셋. 턴 예산 8.

**수준 3단계**: 고르며 짓기 · 이어 짓기 · 까닭 짓기. 신호 S1(이유를 붙임) · S2(묻지 않은 것을 덧붙임)를 LLM이 판정하고 **단계 계산은 규칙이 한다.** 2턴 연속일 때만 옮기고, 매 세션 다시 판단한다.

**템플릿**: 동화 21권 분석에서 뽑은 패턴 A~G. 3턴째에 확정.

**미션 동작 5종**: 탭 · 끌어서 던지기 · 끌어다 놓기 · 문지르기 · 당겼다 놓기. **음성 조작 없음.** 목표 상태가 3단계로 보인다.

**오늘의 기록**: 6축(말하기 · 이유 말하기 · 마음 말하기 · 이야기 채우기 · 만들기 · 함께하기) 3단계 도형 + 원그래프(말로 · 골라서 · 그려서) + 축마다 원문 인용. **점수 없음, 또래 비교 없음.**

**기록하는 이벤트 11가지**가 리포트의 재료다: story_start · utterance · slot_filled · signal · emotion_mention · make · image_request · redraw · mission · friend_rating · session_end.

## 6. 검증 근거

### 6-1. 음성

- **한국어 유아 화자 분리**: [arXiv 2606.10213](https://arxiv.org/html/2606.10213) 한국 2~5세 53녹음, 보호자 44명 중 42명 여성. 클러스터링 DER pyannote 154% · SpeechBrain 136% · Sortformer 33%. 원인은 "여성 보호자 애교 톤과 유아 음성의 음향 유사성". **지도학습 분류기는 시도 안 함.**
- **Whisper 인코더 프레임 분류** (아이/어른/겹침/무음 4클래스): [Xu et al. Interspeech 2024, arXiv 2406.07890](https://arxiv.org/html/2406.07890) 영어 73세션, 라벨 130분으로 DER <20%. 공개 모델 [usc-sail/child-adult-diarization](https://github.com/usc-sail/child-adult-diarization), HF `AlexXu811/whisper-child-adult`, "6세 이하 zero-shot 잘 됨". **한국어 성능 미확인 → W1.**
- **아동 STT 저하**: [Kid-Whisper 2309.07927](https://arxiv.org/html/2309.07927) 성인 낭독 WER 3.0 → 아동 자유발화 31.9. 오류 원인 발화 길이 > 나이 > SNR ([2502.08587](https://arxiv.org/html/2502.08587)). 한국어 4~7세 Whisper-Base CER 1.208 vs 성인 0.177 ([한국음성학회지](https://www.eksss.org/archive/view_article?pid=pss-15-3-75)).
- **문맥 교정은 역효과**: [USC 2505.16212](https://arxiv.org/html/2505.16212) 이전 1~3턴을 넣으면 WER 37.09→38.06. → 도감 이름 + 칸 값 **키워드 바이어싱만** 쓴다.
- F0: 성인 여성 205Hz vs 아동 223±35Hz 겹침. 남성 116Hz와만 확실히 구분.
- 상용 성인 CER (RTZR 2023): RTZR 6.18 · Clova 9.52 · ETRI 10.19 · Whisper 11.39 · Google 11.50.

### 6-2. 아이 데이터와 약관 (2026-09-14 확인, 이 프로젝트의 분기점)

| 사업자 | 13~18세 미만 조항 | 결과 |
|---|---|---|
| **OpenAI** | 13세 미만 개인정보를 처리하려면 **승인제 ZDR**(영업팀 승인) | 음성·이미지 API 제외 |
| **Google Gemini API** | **18세 미만이 쓸 앱에 사용 금지** (2026-03-23 시행) | 제외 |

| **Anthropic** | 연령 확인 · 모더레이션 · "AI와 대화 중" 고지를 걸면 사전 승인 불필요 | 차순위 (ZDR 실패 시) |
| **BFL FLUX API** | 입력을 학습에 사용, 18세 미만 관련 데이터 업로드 금지 | API 제외. **공개 가중치 자체 구동은 별개** |
| **AI Horde** | 자원봉사자가 결과를 볼 수 있고 익명 요청은 공개 데이터셋에 공유 | 제외 |

이것이 **자체 호스팅(Whisper + ComfyUI)을 고른 첫 번째 이유**다. 우회가 아니라 데이터 최소화다. 조건이 되돌아오는 경우는 둘뿐: ① OpenAI 음성·이미지 API를 다시 쓰거나 ② 13세 미만 데이터를 승인 없이 그쪽으로 보내는 경우.

### 6-3. 생성

- **ComfyUI 자체 서버 확정** (결정 10, GPU 제공). 생성·편집·배경 제거가 한 파이프라인.
- 모델 후보: **FLUX.2 klein 4B**(1순위, Apache [미확인]) · FLUX.1 schnell(Apache [확인]) · SD 3.5 Medium · Qwen-Image · SDXL. 제외: FLUX.1 dev/Kontext dev(비상업) · FLUX.2 klein 9B · BRIA RMBG-2.0(비상업).
- 배경 제거는 **BiRefNet (MIT)**. layerdiffuse는 SDXL 전용이고 1년 넘게 갱신 없음.
- **ComfyUI는 다른 프로세스의 GPU 메모리를 관리하지 못한다.** Whisper와 같은 GPU에 올리므로 W1에 메모리와 지연을 실측한다.
- **일관성 지표**: 정체성 DINOv2 코사인 + 스타일 CSD + 같은/다른 캐릭터 쌍 격차. ArcFace 계열은 종이 인형에 부적합.
- AnimatedDrawings: 세그 실패 24.7%, 전체 40.6%, 2025-09 아카이브. 쓰지 않는다.

### 6-4. 법·윤리

- 개인정보보호법 22조의2: 만 14세 미만은 법정대리인 동의 + 확인. "개인정보처리자"에 법인 요건 없음 → 팀도 대상.
- 음성 = 생체정보. 식별 목적 특징 추출(임베딩 저장)만 민감정보. 원본 녹음은 아님.
- 국외 이전(28조의8): 별도 동의 항목 하나.
- **전자상거래법 제21조의2** (다크패턴): 반복 간섭 2회 제한. 아이 화면에 결제 유도 금지.
- **식약처 웰니스 vs 의료기기**: **평가·분석 후 맞춤 피드백**을 주면 의료기기. 그래서 리포트는 점수·등급·또래 비교 없이 "오늘 한 것을 적는다"에 머문다.
- **표시광고법 제5조**: 효과 주장에는 실증 책임. 공정위 2020년 편두리·수인재 제재가 선례.
- 게임산업법 확률형 조항은 게임물 + 유료에만 적용 → 우리 업적에는 걸리지 않음.
- IRB: "제품 평가"는 법정 대상 아님. 논문화하면 아동 대상이라 면제 불가 → **논문화하지 않는다.**
- 어린이집: 원장 승인 + 학부모 개별 동의 + 별도 공간. 6주 불가.

### 6-5. 리포트를 어디까지 쓸 수 있나 (부모 신뢰 문제)

`리포트_상세도와_부모신뢰.md`가 원본. 결론만:

- **한국 아동 규준은 존재한다** (이윤경·임수아 2025 등). 그러나 **우리 자동 숫자를 거기 비교할 수 없다.** 자동 전사에서 뽑은 MLU는 사람 전사와 r=0.27, TTR은 r=0.26으로 유의하지 않다. **발화 횟수만 r=0.98.** 규준 비교에는 50~100발화가 필요한데 한 세션은 그보다 적다.
- 그래서 리포트는 **횟수 + 인용 + 본인 대비**로만 간다. 이것은 윤리적 자제가 아니라 **측정상의 결론**이다.
- 레이더 차트는 가능하다. 단 **축이 행동 횟수**이고 **3단계**로만 그리고 **축마다 인용**이 붙을 때.
- **부모 죄책감 대응**: ① 어른이 옆에 있을 때 효과가 크다는 구조(Strouse 2013) ② 화면을 끄면 남는 결과물 ③ 누리과정 연결 표시 ④ 광고·인앱결제·데이터 반출 없음 ⑤ **우리가 직접 잰 숫자**(영상 15분 대비 앱 15분의 발화 횟수). 효과 주장은 하지 않는다.
- 참고 수치: 한국 유아 하루 미디어 이용 185.9분, 과의존 위험군 25.9%. 학습지 업계는 2025년 적자 전환.

## 15. 쓰면 안 되는 문구·숫자

**사실이 틀린 것**
- "Tandem 4만 가족" → 4,000
- "ㅅ·ㄹ은 다섯 살 무렵 완성" → 삭제
- "이 조합은 아직 없다" → 경쟁표로
- "아이는 4초를 못 기다린다" → 근거 없음
- "CER 11.49% 베이스라인" → 방송 음성(14세 이상 포함), 부적합
- "상용 API 5종" → 3종
- "폰 2대" · "이모 폰" · "초대"
- **"아이 목소리와 그림은 서버로 보내지 않습니다"** → 음성은 글자로 바꾸는 동안 우리 서버를 거친다
- **"세션당 640원"** → ComfyUI 자체 서버로 0원
- **"오늘 별 47개"** → 활동 점수는 폐지. 별은 남은 제작 권수

**법적으로 위험한 것**
- 규준·비교: 또래 · 평균 · 백분위 · 정상 범위 · ○세 수준 · 등급 · 레벨 · 발달지수
- 진단·선별: 진단 · 평가 · 선별 · 검사 · 발달지연 · 언어지연 · 위험도
- 효과 주장: 언어발달 향상 · 어휘력 증진 · 표현력이 늘어납니다 · 두뇌발달
- 권위: 과학적으로 검증된 · 의학적으로 검증된 · 국내 최초
- 없는 인증: KC · 교육부 · 스마트교육
- 아이 규정: "○○형 아이" · 말이 늦은 편

## 16. 용어

| 용어 | 뜻 |
|---|---|
| 칸(슬롯) | 이야기에 필요한 정보 칸. 6 필수 + 1 선택(어른) |
| 턴 | 마스코트 질문 하나 + 아이 답. 예산 8 |
| 3단 반응 | 마스코트 한 턴의 구조. 받아주기 → 늘려서 되돌려주기 → 질문 |
| 수준 3단계 | 고르며 짓기 · 이어 짓기 · 까닭 짓기. 규칙이 계산 |
| S1 · S2 | 이유를 붙인 답 / 묻지 않은 것을 덧붙인 답. LLM이 판정하는 두 신호 |
| 템플릿 A~G | 동화 21권에서 뽑은 이야기 구조. 3턴째에 확정 |
| 미션 | 책 안에서 손으로 푸는 문제. 동작 5종, 목표 3단계 |

| 별 | 남은 제작 권수. **활동 점수가 아니다** |
| 6축 | 말하기 · 이유 말하기 · 마음 말하기 · 이야기 채우기 · 만들기 · 함께하기 |
