# 말로 짓는 인형극 — 기획안 (2판)

> 부트캠프 최종 프로젝트 · 4인 · 6주
> 1판 2026-09-14 → **2판 2026-09-16**. 그 사이 정렬 회의 안건 30건, 조사 4건, 멘토링 1회가 지나갔다
> **바뀐 것만 보려면 §0.** 기술 상세는 `기술개요.md`, 화면·대사는 `구현대본.md`, 흐름은 `엔드픽처_초안.md`, 리포트는 `부모리포트_설계.md`

**영상을 보던 15분이, 어른과 아이가 함께 짓는 이야기 한 권이 된다.**

아이와 어른이 마주 앉아 말로 이야기를 지으면 종이 인형극 그림책 한 권이 나옵니다. 아이가 낸 소리가 그대로 캐릭터 소리가 되고, 아이가 그린 그림이 그대로 등장인물이 되고, 완성된 책은 만지면 반응합니다. 놀이가 끝나면 부모 폰에 오늘 아이가 한 말이 남습니다.

## 1. 왜 만드는가

**저녁에 아이에게 영상을 틀어주게 되는 그 순간**이 출발점입니다. 부모는 지쳤고, 아이는 뭔가를 원하고, 결국 화면을 켭니다. 삼촌·이모·조부모가 아이를 봐줄 때는 더합니다.

이 앱은 돌봄을 대신하지 않습니다. **함께 놀 소재를 준비해 줍니다.** 우리가 늘리려는 것은 화면 시간이 아니라 **그 시간 안에서 아이가 말한 횟수**입니다.

AI 동화 앱은 이미 많고, 아이가 마이크에 말하면 책이 나오는 앱(Tellmemore)도 있습니다. 그런데 전부 **한 사람이 입력하고 완성본을 구경하는 구조**입니다. 마주 앉은 두 사람의 대화가 입력이 되고, 아이의 소리와 그림이 원본 그대로 책에 들어가고, 완성된 책을 만지며 노는 것, 그리고 그 놀이가 부모에게 기록으로 남는 것. 이 넷을 한 번에 하는 앱은 없습니다.

**부모의 죄책감을 무엇으로 덜어내는가.** "교육적이다"라고 주장하지 않습니다. 대신 셋을 보여 줍니다. ① 어른이 옆에 있을 때 아이가 훨씬 많이 말하도록 구조를 짰고 ② 화면을 끄면 손에 남는 결과물이 있고 ③ 오늘 아이가 한 말을 그대로 적어 드립니다. 효과 주장은 하지 않고 **우리가 직접 잰 숫자만 말합니다** (§8, `리포트_상세도와_부모신뢰.md`).

## 2. 한 세션은 이렇게 흘러갑니다

등장인물은 지호(5세), 이모, 진행자 마스코트입니다. 폰은 부모 폰 한 대, 시간은 약 15분입니다.

**처음 한 번 — 3분**
부모가 앱을 열고 **동의**합니다. 그리고 **지호 주인공을 만듭니다.** 말로 만들거나 골라서 만듭니다. 사진은 찍지 않습니다.

**시작 화면**
[이야기 만들기] [책장], 오른쪽 위에 **별 숫자**(오늘 만들 수 있는 남은 권수). 아래에 "어른과 함께 하는 놀이예요" 한 줄. 별이 0이면 만들기를 눌렀을 때 마스코트가 한 번 안내하고 책장으로 보냅니다. 가격도 구매 버튼도 아이 화면에 없습니다.

**이야기 짓기 — 10분**
마스코트가 **열린 질문**을 던집니다. 고르는 카드를 상시로 띄우지 않습니다.

> 마스코트: "지호는 오늘 어디로 가?"
> 이모: "지호야, 어떤 나라야?"
> 지호: "공뇽 나라!"
> 마스코트: "공룡 나라구나! 공룡들이 사는 곳에 지호가 갔어. 거기서 누굴 만났어?"

마스코트의 한 턴은 셋으로 이뤄집니다. **받아주기 → 늘려서 되돌려주기 → 다음 질문.** 답을 알려주지 않고 묻기만 합니다. 아이가 답을 못 하면 기다렸다가 더 쉬운 질문을 하고, 그래도 없으면 그림 3장을 보여주고, 그래도 없으면 마스코트가 골라서 이어갑니다. **말을 안 해도 책은 완성됩니다.**

두 번째 턴에는 그림 속 사건을 보여주고 "왜 그럴까?"를 묻습니다(결정 25). 이 답에서 나오는 두 신호 — **이유를 붙였는가(S1)**, **묻지 않은 것을 덧붙였는가(S2)** — 로 다음 질문의 난이도와 이야기 구조를 고릅니다. 판정은 LLM이 하고 **단계 계산은 우리 규칙이 합니다.**

"공룡이 어떻게 울어?" 지호가 마이크에 **"크아아앙!"** 하면 그 소리가 그대로 공룡 소리가 됩니다. 변조하지 않고, 이 녹음은 폰 밖으로 나가지 않습니다.

칸이 확정되면 뒤에서 그림을 만듭니다. 2~3턴 뒤 **중간 확인**이 뜹니다. "짠! 이거 어때?" [좋아] [싫어] [직접 그리기]. 싫다고 하면 **어떤 게 마음에 안 드는지 한 번 묻고** 다시 그립니다. 아래에 2/2로 남은 횟수를 보여줍니다.

**책 — 6쪽**
『지호와 공룡 나라』가 펼쳐집니다. 종이 인형들이 흔들리고, 공룡은 지호 소리로 웁니다. 지호가 그린 괴물이 원래 그림체 그대로 등장합니다. 아래에 자막, 스피커를 켜면 **마스코트 목소리**로 읽어줍니다. 어른에게 읽으라고 시키지 않습니다.

**미션 2개**
책 안에서 손으로 해결합니다. 비구름을 끌어다 우물을 채우고, 물대포를 당겼다 놓아 불을 끕니다. 목표 상태가 3단계로 눈에 보입니다. 음성으로 조작하지 않습니다.

**끝 — 친구 평가와 끝내기**
"오늘 만난 친구, 또 만날래?" [또 만날래 💛] [안녕 👋]. 마음에 든 친구만 다음에 다시 나옵니다. 책은 책장에 꽂히고 화면이 어두워집니다. **다음 책을 권하지 않습니다.**

**부모 모드**
비밀번호 4자리로 들어가 **오늘의 기록**을 봅니다. 아이 화면에는 기록도 점수도 보이지 않습니다.

## 4. 지켜야 할 결정

**흐름**
- 결과물은 마지막에 한 번에. 한 턴 = 한 칸.
- **모든 질문은 열린 질문.** 고르는 카드를 상시로 띄우지 않는다 (결정 30).
- 마스코트의 한 턴 = 받아주기 → 늘려서 되돌려주기 → 질문. 답을 알려주지 않는다.
- 마스코트는 진행자이지 등장인물이 아니다. 책도 마스코트가 읽는다. **어른에게 낭독을 시키지 않는다.**
- 마스코트가 말하는 동안 마이크는 열려 있다. 마스코트 대사는 10어절 이하.
- 기다리는 시간은 쉬운 질문 5초, 어려운 질문 8초. 말하는 중 침묵으로는 끊지 않는다.
- 세션은 중간에 끊어도 칸 상태가 남아 이어서 할 수 있다.
- 활동은 2~3분마다 바뀐다. 말·말·소리·말·그림·말.
- **끝이 있다.** 책 한 권으로 끝나고 다음 책을 권하지 않는다.

**수준** *(계산 규칙 전문은 `구현대본.md` §3)*
- 단계는 셋. 고르며 짓기(고른다) · 이어 짓기(잇는다) · 까닭 짓기(까닭을 댄다).
- 신호 S1(이유)·S2(덧붙임)를 LLM이 판정하고 **단계 계산은 규칙이 한다.**
- **신호가 가리키는 단계가 지금보다 높고 2턴 연속일 때만 한 칸 올린다.** 두 칸은 안 뛴다 — 못 답하면 실패 경험이 된다.
- **첫 두 턴은 프로브다.** 기준 질문 ①(어디)·②(왜)를 고정으로 던지고 2턴 답으로 초기 수준을 정한다. **나이를 묻지 않는다.**
- 내림이 올림보다 빠르다. 무응답·카드 2연속 또는 **`mascot_pick` 1회**면 한 칸 내린다. 신호를 놓치는 것보다 **못 따라가는 경험이 나쁘다.**
- **미션 난이도는 수준과 분리한다.** 말하기와 손 쓰기는 다른 능력이고, 미션 실패가 리포트에 "말하기가 줄었다"로 잘못 읽히면 안 된다.
- 매 세션 다시 판단한다. 아이에게 단계를 저장해 꼬리표를 붙이지 않는다.

**캐릭터와 그림**
- 아이 그림은 절대 바꾸지 않는다. AI가 다시 그리지 않는다.
- **세계는 한 그림체, 아이 것은 원래 그림체.** 섞이는 것이 연출이다 (결정 27).
- 확정한 캐릭터는 책 전체에서 같은 그림. 폰에 저장해 다시 쓴다. **서버 공용 캐시는 안 한다** (결정 26).
- 색·크기·표정 변경은 생성하지 않고 레이어·스티커 교체로 0초에 처리한다.
- 배경·캐릭터·오브젝트는 투명 PNG로 따로 만들어 합친다. 터치는 알파 히트테스트.
- 성별은 프리셋 기본값에만. 주제·질문에 쓰지 않는다.

**소리**
- 아이 소리는 원본 그대로. 변조 없음. **이 녹음은 폰 밖으로 나가지 않는다.**
- 무음이거나 0.3초 미만이면 "한 번 더!" 한 번, 그래도 없으면 기본 효과음.

**미션**
- 동작은 다섯 가지뿐. 탭 · 끌어서 던지기 · 끌어다 놓기 · 문지르기 · 당겼다 놓기.
- **음성으로 조작하지 않는다.** 인식 실패가 실패 경험이 된다.
- 목표 상태가 3단계로 눈에 보인다. 실패해도 되돌아가지 않는다.
- 난이도는 수준에서 고른다. 쉬우면 탭, 어려우면 당겼다 놓기.

**기록**
- 지난번의 우리 아이와만 비교. 또래·규준·백분위·"지연"·"선별" 금지.
- **점수를 매기지 않는다.** 활동 점수(별)는 폐지했다 (결정 16).
- 축은 능력이 아니라 오늘 한 행동의 횟수다. 3단계로만 그린다.
- 아이 화면에 잠긴 것·점수·기록·가격을 보이지 않는다.

**저장**
- 아이 그림·전사·책·소리 녹음·기록은 **폰 안에만.**
- 음성은 글자로 바꾸는 동안만 **우리 국내 서버**를 거치고 **사본은 바로 지운다.**
- 이야기 AI에는 **이름을 가린 문장만** 보낸다.

## 5. 이야기 엔진

이야기에 필요한 정보를 칸(슬롯)으로 정해두고, 칸이 찰 때까지 마스코트가 질문을 만듭니다. **칸은 고정(골격), 질문 문구는 생성(변주).** 리포트가 세션 간 비교 가능한 이유이자, 무응답을 자연스럽게 처리하는 방법입니다.

```json
{
  "story_id": "s_0916",
  "hero": {"ref": "doc_hero1"},
  "level": "이어 짓기",
  "template": "B",
  "slots": {
    "place":     {"required": true,  "fill": "voice",  "value": null, "attempts": 0, "max": 3, "fallback": "choice"},
    "friend":    {"required": true,  "fill": "voice",  "value": null, "attempts": 0, "max": 3, "fallback": "choice"},
    "problem":   {"required": true,  "fill": "voice",  "value": null, "attempts": 0, "max": 2, "fallback": "choice"},
    "sound":     {"required": true,  "fill": "record", "value": null, "attempts": 0, "max": 3, "fallback": "default_sfx"},
    "newcomer":  {"required": true,  "fill": "draw",   "type": null,  "value": null, "attempts": 0, "max": 1, "fallback": "preset"},
    "solution":  {"required": true,  "fill": "voice",  "value": null, "attempts": 0, "max": 2, "fallback": "choice"},
    "adult":     {"required": false, "fill": "voice",  "value": null, "attempts": 0, "max": 1, "fallback": "skip"}
  },
  "signals": {"s1_reason": 0, "s2_addition": 0},
  "turn_budget": 8,
  "title": null
}
```

- **채움 방식**: voice(말) · record(소리) · draw(그림) · choice(그림 3장, 폴백일 때만) · preset.
- **어른 칸**: 마스코트가 어른에게 한 번 말을 겁니다. 어른용 버튼은 없습니다.
- **템플릿**: 동화 21권 분석에서 뽑은 패턴 A~G. 3턴째에 수준과 답을 보고 하나로 확정합니다. 짧게 답하면 반복이 많은 구조, 이유를 말하면 문제를 푸는 구조.
- **턴 예산 8**: 필수가 다 안 차도 8턴이면 끝냅니다. 아이의 지루함이 완성도보다 우선. 별 6개 = 필수 칸 수.
- **답 판정**: 칸에 맞는지·앞 칸과 모순인지·신호 S1/S2를 LLM이 구조화 출력(JSON)으로 판정. 모순이면 채우지 않고 되묻습니다. **수준 계산·미션 난이도·업적은 LLM이 하지 않습니다.**
- **되묻기**: 인식 신뢰도가 낮으면 마스코트가 되묻습니다. 화면에 오류 표시는 없습니다. 도감 이름과 앞 칸 값이 인식 키워드 후보가 됩니다.
- **질문 가드**: 12어절 이하, 한 질문에 하나, 도감 어휘 우선, 칸마다 예문 3개 고정.
- **쪽수**: 기본 6쪽. 기 1(장소·친구) / 승 1~2(문제) / 전 2(소리·등장인물) / 결 1(해결) / 에필로그 1.
- **자막**: 동화 말투로 다듬은 문장. 15어절 이하, 아이가 낸 의성어는 그대로. **리포트의 인용은 다듬기 전 원문.**
- **이름 필터 3겹**: 사전(도감에 등록된 이름) → 규칙 → 탐지 모델. 아이·친구 이름은 `{주인공}` `{친구1}`로 바꿔 보내고 폰에서 되돌립니다.
- **안전 필터 2겹**: 인식 직후 규칙 기반 금칙어 → LLM이 폭력·성·혐오 판정 후 조용히 순화. 이미지 쪽은 ComfyUI 분류 노드 + 백엔드에서 한 번 더. 아이에게 알리지 않고 부모 기록에도 표시하지 않습니다. 순화된 문장은 인용 후보에서 뺍니다.
- **에필로그**: 열린 결말. 이어서 짓기는 2차.

## 6. 캐릭터·그림·소리

**주인공**: 말로 만들기 또는 골라서 만들기. 도감 단계에서 **한 번 생성**하고 이야기 중에는 고정 스프라이트로 씁니다 (결정 20).

**도감**: 주인공 4칸. 마지막 칸은 점선 ＋. 친구는 도감에 쌓이지 않고, 책 끝 **친구 평가**에서 [또 만날래]를 고른 친구만 다음 이야기에 선택지로 다시 나옵니다 (결정 8).

**등장인물과 연출**: 아이가 유형을 고르고 그립니다. 그리기 싫으면 프리셋.

| 유형 | 등장 연출 (≤3초) |
|---|---|
| 친구 | 손 흔들며 옆에서 뛰어 들어옴 |
| 괴물 | 화면 흔들림 + 배경 건물 흔들림 + 불 뿜기 (입 위치는 아이가 탭) |
| 탈것 | 달려 들어오며 먼지 |
| 보물 | 상자 열림 + 빛나는 배경 + 그림이 위로 떠오름 |

**그림체**: 부모가 부모 모드에서 세계의 그림체를 고릅니다. 1차는 2종. 아이 그림은 **바꾸지 않고 그대로** 얹습니다. 둘이 섞이는 것이 이 앱의 모양입니다. 스톡 이미지를 참조로 쓰지 않습니다.

**장소**: 프리셋 3곳은 미리 만들어 두어 0초에 뜹니다. 그 밖의 장소만 생성합니다.

**소리**: 원본. 도구 반응 소리는 공통 효과음.

**책장**: 2열 격자, 최신순.

## 7. 미션 — 만지며 놀기

책 한 권에 **미션 2개**가 들어갑니다. 이야기의 문제를 손으로 해결하는 자리입니다.

| 동작 | 예 |
|---|---|
| 탭 | 뿅망치로 다가오는 괴물 때리기 (맞을 때마다 뒤로 물러남) |
| 끌어서 던지기 | 빨간 주머니를 괴물에게 던지기 |
| 끌어다 놓기 | 비구름을 우물 위로 끌어다 채우기 |
| 문지르기 | 얼어붙은 문을 문질러 녹이기 |
| 당겼다 놓기 | 물대포를 당겼다 놓아 불 끄기 |

**재미 규칙**
- 목표 상태가 **3단계로 눈에 보인다** (우물 1/3 → 2/3 → 가득).
- 한 번의 동작마다 즉시 반응한다. 열 번 하면 열 번 다 반응한다.
- 실패해도 되돌아가지 않는다. 다시 하면 된다.
- 음성으로 조작하지 않는다.
- 난이도는 수준에서 고른다. 혼자 성공하면 올리고, 도움을 받으면 내린다.

미션에 나오는 물체 그림(구름·물대포·운석)만 생성하고, 효과(물줄기·비·튕김)는 미리 만든 공통 연출입니다.

도구 4종(손·뿅망치·깃털·돋보기)은 미션 밖에서 자유롭게 씁니다. 해금 도구는 2차. 아이 화면에 잠긴 도구는 보이지 않습니다.

## 8. 오늘의 기록

부모 모드 안에만 있습니다. 상세 규격은 `부모리포트_설계.md`.

**여섯 축 — 능력이 아니라 오늘 한 행동의 횟수**

| 축 | 무엇을 세나 | 신뢰도 |
|---|---|---|
| 말하기 | 아이가 말한 횟수 | 높음 (자동 전사와 사람 전사 상관 0.98) |
| 이유 말하기 | "왜·어떻게"에 이유·방법을 담아 답한 횟수 | 중간 (LLM 판정) |
| 마음 말하기 | 인물이나 자기 마음을 말한 횟수 | 중간 |
| 이야기 채우기 | 묻지 않았는데 배경·원인·시도·결과를 덧붙인 횟수 | 중간 |
| 만들기 | 그리기·소리 녹음·직접 그리기 | 가장 높음 (앱 이벤트) |
| 함께하기 | 어른 말을 받아 이어간 횟수 | 중간 |

**그리는 규칙**
- 도형은 **3단계**로만. 없음 · 있었음(1~2) · 여러 번(3회 이상). 실제 횟수는 축 이름 옆 작은 글씨.
- **0인 축은 회색 점 + "오늘은 안 나왔어요."** 낮은 점수가 아니라 없었던 활동이다.
- 0~100 정규화 금지. 정규화하는 순간 점수가 된다.
- 지난 세션을 흐리게 겹친다. 또래 평균은 없다.
- 도형 아래 한 줄: "이야기마다 모양이 달라요. 오늘은 마음을 많이 말한 이야기였어요."

**원그래프 — 오늘 말한 방식**: 말로 답함 · 골라서 답함 · 그려서 답함. 앱 이벤트라 오류가 없습니다. 아래 한 줄: "고르기도 이야기를 짓는 방법이에요."

**인용이 이 기록의 중심입니다.** 축마다 대표 인용 하나를 다듬기 전 전사 그대로 붙입니다. 발음을 고쳐 적지 않습니다. 마스코트·어른 말은 인용하지 않습니다.

**질문 카드**: "다음에 이렇게 물어보세요." 이번 세션에 없던 유형에서 한 문장.

**규칙**
- **센 발화만 센다.** 구분 신뢰도가 낮은 발화는 빼고 "13번 중 12번을 셌어요"로 밝힌다.
- 10발화 미만이면 도형 없이 인용과 기록만.
- 발음 판정은 없다. 나이는 안내문에만 쓰고 판정에 쓰지 않는다.
- 세션이 끝나면 만들되 아이에게 보이지 않는다.

**고지 (고정)**
> 놀이 대화 요약이며 언어발달 평가·진단이 아닙니다. 본 제품은 의료기기가 아니므로 질병 유무를 판단할 수 없으며, 질병 유무 판단을 위해서는 의사의 검진이 필요합니다. 궁금한 점은 영유아건강검진(K-DST)이나 언어재활사와 상담하세요.

부모용 문구 전체는 `부모용_안내문구.md`.

## 9. 저장·동의·법

**저장**: 아이 그림·전사·책·소리 녹음·지표는 **부모 폰 안에만.** 팀은 이 데이터를 받지 않습니다. 기기 변경·앱 삭제 시 소실은 1차에서 감수하고 동의 화면에 씁니다.

**전송**: 이야기를 만드는 동안 팀 백엔드 프록시를 거쳐 나갑니다.

| 나가는 것 | 어디로 | 남는가 |
|---|---|---|
| 음성 구간 | 우리 국내 GPU 서버 | **변환 직후 삭제** |
| 이름을 가린 문장 | LLM 사업자 (국외) | 사업자 정책. 국외 이전 고지 대상 |
| 영어 키워드 | 우리 국내 GPU 서버 (ComfyUI) | 남기지 않음 |
| 이름 없는 대사 | CLOVA Voice (국내) | 사업자 정책 |

**나가지 않는 것**: 아이 이름 · 아이 그림 · 소리 녹음 · 음성 원본 · 기록.

**동의 문구 (수정판)**
> 아이가 그린 그림과 아이가 낸 소리는 이 기기 안에만 저장되고 밖으로 나가지 않습니다. 기기를 바꾸거나 앱을 지우면 함께 사라집니다.
> 말을 글자로 바꾸는 동안에만 음성이 저희 서버(국내)를 거치고, 변환이 끝나면 곧바로 지워집니다.
> 이야기를 만들 때는 아이 이름을 가린 문장만 ○○(국외)에 전송됩니다.

**법**
- 개인정보보호법 제22조의2 — 만 14세 미만 법정대리인 동의, 쉬운 말 고지.
- 음성 원본은 생체정보이지만 식별 목적 특징 추출을 하지 않으면 민감정보가 아닙니다.
- 전자상거래법 제21조의2 — 다크패턴. 반복 간섭 2회 제한. 아이 화면에 결제 유도를 두지 않습니다.
- 식약처 기준 — **평가·분석 후 맞춤 피드백을 주면 의료기기**입니다. 그래서 점수·등급·또래 비교를 두지 않고 "오늘 한 것을 적는다"에 머무릅니다.
- 표시광고법 제5조 — 효과 주장에는 실증 책임이 있습니다. "언어발달에 도움"을 쓰지 않습니다.
- 게임산업법 확률형 조항은 게임물 + 유료에만 적용되어 우리 업적에는 걸리지 않습니다.
- 초대·공유 계정 없음. 폰 한 대, 부모 모드는 비밀번호 4자리.

**평가 세션 (제품과 별개)**: 팀원 지인 자녀 5명, A4 2장 동의서(국외 전송 항목 포함), 부모 동석, 아이 구두 동의 기록, 파일명 코드화, 원본은 지표 산출 직후 삭제. 논문화하지 않습니다. 성인이 아동 흉내를 낸 데이터는 정확도 지표에 쓰지 않습니다.

## 10. 플랫폼·기술

상세는 `기술개요.md`. 여기서는 요약만 둡니다.

**플랫폼**: **Android 앱, Kotlin 네이티브 + Compose** (결정 19). Android Studio에서 빌드·서명·실기기 실행. APK 직접 설치, 스토어 없음. iPhone은 1차 대상이 아닙니다.

**구성**

```
[Android 앱 · Kotlin]  →  [FastAPI 프록시]  →  [국내 GPU 서버]  faster-whisper · ComfyUI
                                            →  [LLM 사업자]     이야기 판정 · 자막
                                            →  [CLOVA Voice]    마스코트 목소리
```

API 키는 앱에 넣지 않습니다. 프록시는 중계만 하고 음성·전사·그림을 저장하거나 로그에 남기지 않습니다. 남기는 것은 요청 수·지연·오류 코드뿐입니다.

**1순위 모델**

| 역할 | 1순위 | 대안 |
|---|---|---|
| 음성 인식 | 자체 Whisper large-v3-turbo + faster-whisper + VAD | CLOVA Speech |
| 이야기 | `gpt-5.6-luna` | `claude-haiku-4-5` · `mistral-small-4` |
| 이미지 | ComfyUI + FLUX.2 klein 4B | FLUX.1 schnell · SD 3.5 Medium |
| 배경 제거 | BiRefNet (MIT) | — |
| 목소리 | CLOVA Voice | 폰 기본 TTS |
| 형태소 | kiwi | — |

**제외**: OpenAI 음성·이미지 API(13세 미만 승인제 ZDR) · Gemini API(18세 미만 앱 금지) · Google Cloud STT(아동 음성 오류) · BFL FLUX API(입력 학습, 18세 미만 금지) · AI Horde(결과 공개).

**아이/어른 구분**: 클러스터링은 한국어 유아+여성 보호자에서 실패 보고가 있어 쓰지 않습니다. Whisper 인코더 프레임 분류 + 세션 내 등록 + 텍스트 후처리(질문하는 쪽=어른)를 구간별 투표로 합칩니다. 한국어 성능은 미확인이라 W1에 실측합니다.

**지연 예산**: 프리셋 0초 · 중간 확인 그림 2~3턴 뒤 · 색·크기·표정 변경 0초 · 그림 지연 8초에 안내 · 15초에 프리셋 확정 · 아이 답 대기 5초/8초.

**기록하는 이벤트 11가지**가 6축 리포트의 재료입니다 (`기술개요.md` §7).

| | Tandem | Tellmemore | Draw to Life | 모리아이·토닥북 | **우리** |

## 15. BM·원가

**원가 — 1권당 약 70~360원.** GPU를 제공받아 **음성 인식과 이미지 생성 비용이 0원**이 되었습니다. 남는 것은 이야기 AI와 목소리입니다.

| 항목 | 1권 | 비고 |
|---|---|---|
| 음성 인식 | **0원** | 자체 GPU. CLOVA로 가면 약 50~240원 |
| 이미지 | **0원** | 자체 ComfyUI. 전기·대여만 |
| 이야기 AI | 약 70~360원 | 칸 판정·질문·자막 |
| 목소리 | 약 20~60원 | CLOVA Voice 종량 |
| **합계** | **약 70~360원** | 상한 기준으로 요금제를 잡는다 |

**요금제 (월 정액, 1차는 발표 자료에만)**

| | 기본 · 예 3,900원 | + · 예 9,900원 | 프리미엄 · 미정 |
|---|---|---|---|
| 이야기 제작 | 월 2권 | 월 5권 | 무제한 |
| 캐릭터·배경 | 기본 프리셋 | 확장 | 전체 |
| 미션·도구 | 기본 | + 해금 도구 | 전체 |
| 오늘의 기록 | 간단 | 전체 | 전체 |
| 이어서 짓기 | ✗ | ✗ | ○ |

원가 대비(상한 360원): 기본 2권 ≈ 720원 / 3,900원. 프리미엄 무제한은 월 30권이면 약 10,800원이라 **가격을 원가 상한 × 예상 최대 권수로 잡아야 합니다.**

**남은 권수를 어떻게 보이나 (결정 28)**: 시작 화면 오른쪽 위에 **별 아이콘 + 숫자**로 보여줍니다. 0이면 0으로 보이고, [이야기 만들기]를 누르면 마스코트가 한 번 돌려 말하고 책장으로 보냅니다. **아이 화면에 가격·구매 버튼·반복 팝업은 없습니다.**

- 결제 자체는 2차. 1차는 코드에 넣지 않습니다.
- 광고 없음, 아이 화면 잠금 없음 — 유지.
