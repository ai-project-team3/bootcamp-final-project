## 자료와 선정 과정

- 출처: [AI-Hub 108 자유대화 음성(소아남여, 유아 등 혼합)](https://aihub.or.kr/aihubdata/data/view.do?dataSetSn=108).
  이용약정 동의·자동 승인 후 2026-10-08 수령. 전사 라벨만 사용하며 음성 원본은 받지 않았다.
- Training `48685/48686/48687`, Validation `48620/48621/48622`: JSON **2,807,994개**.
  ZIP 6개 전체 CRC 검사 통과. 각 ZIP SHA-256은 집계 JSON에 있다.
- 3~6세 레코드 **567,999개**, 범위 밖 **2,239,995개**. 3~6세는 이번 파일 목록에서 AI챗봇 수집 경로에만 있었다.
- 3~6세 화자 ID **811개**. 50답변 확보 653명, 1~49답변 157명, 분석 가능한 답변이 없는 화자 1명.
  나이가 서로 다른 동일 화자 ID가 발견되면 합치지 않고 중단하도록 했으며 이번 실행은 끝까지 완료됐다.
- 원문을 보기 전에 기존 #320의 50답변·10명·2,000회·시드 320 기준을 유지했다.
  ZIP 선택 순서는 위 Training 3개 → Validation 3개, ZIP 안에서는 파일 경로 사전순이다.
  **시간순·무작위 표집을 뜻하지 않는다.** `recorderId`로 묶고 처음 50개의 분석 가능한 답을 사용했다.
- `stt`의 `(대문자:...)` 비발화 표기와 공백만 기존 리더와 똑같이 처리했다.
  인식 오류·반복·짧은 답을 유리하게 교정하지 않았다. 창을 채우기 전 분석 불가 167개,
  이미 50개를 채운 뒤의 532,086개는 형태소 분석하지 않았다.
- 50개 미만 화자까지 포함해 로컬 선택 파일에는 35,746답변이 있다. 이 수와 최종 32,650답변을 혼동하지 않는다.
- 메타데이터 전체에서 `question`/`prompt`/`질문` 관련 키는 발견되지 않았다.
  이것만으로 모든 보조 문서에도 질문 정보가 없다고 단정하지 않는다. 이번 라벨 분석에서는 `unknown`으로 고정했다.

## 계산과 재현 확인

- 계산기: main `8feeb657d18094b357884d0205b1373565ddc686`의 `eval/language_metrics.py`와
  `eval/language_metrics_bench.py`. Kiwi / 모델 **0.24.0**, `cong`, 오타·받침 보정 및 복합 형태소 재분할 끔.
- 화자별 50답변 MLU-m를 구한 뒤 화자들을 같은 가중치로 평균했다. 화자 단위 2,000회 재표집, 시드 320.
- ZIP을 로컬에서 순서대로 읽어 3~6세만 선정하는 어댑터로 계산한 다음, 동일 로컬 JSONL을
  기존 `python -m eval.language_metrics_bench --scope all_child`에 넣었다.
  **연령별 수치·화자 수·표본 조건·제외 통계가 정확히 일치**했다. 같은 계산기로 입력 경로를 교차 확인한 것이며
  독립 분석기나 사람의 검증을 대신하지 않는다.
- 관련 자동 검사 **25개 통과**. 앱·서버 코드는 바꾸지 않았다. Android 전체 검사나 실제 기기 효과를 이번 결과로 대신하지 않는다.
- 원문·화자 ID·키·선정 JSONL·사람 검수표는 저장소 밖 로컬에만 보관했다. 공개 산출물은 집계 숫자와 방법이다.

재실행(라벨 이용 승인을 가진 로컬 환경에서만):

```powershell
python -m eval.language_metrics_bench --input <로컬에서_선정한_전사문.jsonl> --scope all_child --output <로컬_집계.json>
```

ZIP에서 선정하는 절차는 위 순서와 제외 조건을 따른다. 다운로드 도구의 파일 순서에 임의로 의존하지 않는다.

## 확인한 한계와 원인 후보

1. **질문을 구분하지 못한다.** 짧은 대답이 선택·확인 질문 때문인지 알 수 없다. 열린 질문 문턱으로 쓰지 않는다.
2. **파일순 선정의 영향은 미확인이다.** 한 화자의 처음 50파일에 특정 수집 과업이 몰릴 수 있다.
   본 분석 뒤 순서를 바꿔 재면 사후 탐색으로 따로 기록해야 한다.
3. **공통 문장 반복을 관찰했다.** 최종 32,650답변 중 27,393답변은 선택 표본 안에 같은 텍스트가 두 번 이상 있었고,
   서로 다른 텍스트는 7,208개였다. 가장 많이 반복된 텍스트는 103회다. 원문은 공개하지 않는다.
   이것만으로 낭독 자료나 데이터 오류라고 확정할 수 없다. 공통 질문·짧은 답·대본 가능성을 구분해야 한다.
4. 공식 페이지에서 `stt`는 **음성인식결과**, `scriptId`는 스크립트 ID로 설명한다.
   이 필드가 전사 최종 검수본인지, 어떤 질문/과업과 연결되는지는 아직 확인하지 못했다.
5. 녹음 레코드 하나를 답변 하나로 간주했다. 실제 대화 턴이나 임상 발화 분절과 같다는 보장은 없다.
