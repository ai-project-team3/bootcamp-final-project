## 0. 무엇이 바뀌었나

| | 1판 | 2판 |
|---|---|---|
| 중심 | 6축 레이더 차트 | **주고받기 횟수 + 아이가 한 말 원문** |

## 2. 머리 숫자 — 주고받기 횟수

**이 하나가 리포트의 중심이다.** 다른 건 다 부속이다.

### 세는 규칙 (LENA LTR-12 그대로)

- 아이 발화 하나 + 어른 발화 하나가 **5초 안에** 이어지면 1턴
- 한 발화는 **한 턴에만** 쓴다 — `어른-아이-어른` = 1턴, `어른-아이-어른-아이` = 2턴
- **울음 · 비명 · 감탄사만 있는 발화는 안 센다**
- 마스코트 말은 **어른으로 치지 않는다.** 사람끼리 주고받은 것만 센다

### 같이 보여주는 것

**"그중 N번은 아이가 먼저 말을 걸었어요"**

LENA가 8년째 못 하는 숫자다. 종일 녹음이라 누가 먼저인지 모른다.
우리는 전사에 화자가 찍혀 있어 공짜로 나온다. **경쟁 서비스가 못 주는 것이라 여기를 키운다.**

### 왜 이 지표인지 부모에게 한 줄

> 아이가 말을 많이 듣는 것보다, **주고받는 횟수**가 더 중요하다는 연구가 있습니다.

효과를 주장하지 않는다. "연구가 있다"까지만 쓴다.

## 3. 오늘 지호가 한 말 — 원문

**다듬지 않는다.** 발음이 틀려도 그대로 쓴다. "공뇽"을 "공룡"으로 고치지 않는다.

### 고르는 규칙 (LLM 안 쓴다)

| 자리 | 무엇을 고르나 |
|---|---|
| 1 | 가장 긴 말 |
| 2 | 까닭이 담긴 말 (그래서 · 왜냐면 · ~서) |
| 3 | 오늘 처음 쓴 낱말이 들어간 말 |

셋이 겹치면 다음 순위로 내린다. 없으면 그 자리를 비운다.

### 빼는 것

- 안전 필터가 순화한 문장 — **아이가 실제로 한 말이 아니다**
- 카드로 고른 답 · 그림으로 답한 것 — 말한 게 아니다
- 인식 신뢰도가 낮은 발화

### 대화 전부 보기

접어 둔다. 펼치면 오늘 나눈 말이 시간순으로 전부 나온다.
Curio가 하는 방식이다. **부모가 가장 원하는 것이고 경쟁 서비스가 못 준다.**

## 3-2. 오늘 이런 말을 했어요 — 수준을 **사실로** 보여준다

*(2026-09-18 신설. 1판은 수준을 부모에게 아예 보여주지 않았다. 조장 판단으로 연다 — 단 **등급 이름이 아니라 관찰 사실로만**.)*

앱은 안에서 수준 3단계(고르며 짓기 · 이어 짓기 · 까닭 짓기)를 계산해 질문과 템플릿을 고른다. **그 단계 이름은 부모 화면에 쓰지 않는다.** 대신 **그 단계를 판단한 근거 자체**를 보여준다.

| 무엇 | 오늘 | 지난 세 번 평균 |
|---|---|---|
| **까닭을 말한 것** (`~해서` · `~니까` · `왜냐하면`) | 4번 | 2번 |
| **묻지 않은 걸 스스로 덧붙인 것** | 6번 | 5번 |
| **마음을 나타낸 말** | 3번 | 2번 |

**각 줄에 오늘 한 말을 하나씩 그대로 붙인다.**

> **까닭을 말한 것** — *"무서워서 도망갔어."*
> **스스로 덧붙인 것** — *"공룡나라 갈래. 근데 뿌뿌도 데려갈 거야."*

### 같은 질문, 달라진 답 — 이게 가장 좋은 증거다

**기준 질문 두 개는 매 세션 같은 자리에 온다.** 그래서 답만 나란히 놓으면 **단계 이름을 한 글자도 안 쓰고** 무엇이 달라졌는지 보인다.

```
"오늘은 어디로 가 볼까?"
  9/10  "우주!"
  9/14  "바닷속에 가 볼래."
  9/17  "로켓 타고 우주 갈래! 별 보러 가고 싶어서."
```

**1판에서는 이걸 「접어 두는 것」(§7)에 넣어 뒀다. 기본 화면으로 올린다.** 부모가 얻어 갈 게 가장 많은 자리다.

### 지킬 것

| | |
|---|---|
| **등급 이름을 안 쓴다** | "까닭 짓기 단계"가 아니라 **"까닭을 말한 것 4번"** |
| **해석을 붙이지 않는다** | "인과 추론이 발달했습니다" ✗ → 숫자와 원문만 (§8) |
| **줄어든 날은 말하지 않는다** | 지난 평균보다 적으면 **그 줄을 숨긴다.** 지적하지 않는다 (§5와 같은 규칙) |
| **세 번 안 쌓였으면 비교 열을 숨긴다** | 오늘 숫자만 보여준다 |
| **`mascot_pick`은 세지 않는다** | 마스코트가 대신 정해 준 것은 아이 말이 아니다. **주고받기 횟수에도 안 들어간다** |

## 4. 활동량 묶음

호두잉글리시 방식이다. **능력이 아니라 기록**이라 틀릴 위험이 없다.

| 항목 | 예 |
|---|---|
| 만든 이야기 | 8권 |
| 오늘 주고받기 | 12번 |
| 오늘 말한 횟수 | 9번 |
| 연속으로 논 날 | 3일 |

**연속일은 아이 화면에 안 보인다.** 부모 화면에만 둔다. 아이에게 보이면 빠뜨린 날이 실패가 된다.

---

## 5. 자기 기준선 + 별

Providence Talks 방식에서 또래 조건만 뺐다.

> **지난 세 번 평균보다 10% 이상 늘면 별 하나.**

- 비교 대상은 **우리 아이의 지난 세 번**뿐이다
- 줄어든 날은 아무 말도 하지 않는다. **별이 안 생길 뿐 지적하지 않는다**
- 세션이 세 번 안 쌓였으면 이 줄을 통째로 숨긴다

## 6. 오늘 이렇게 해 보세요 — 딱 하나

Ready4K의 3단 구조다. RCT로 검증됐다 (n=935, +0.11 SD).

| 단계 | 쓰는 법 | 예 |
|---|---|---|
| **왜** | 한 줄 | "주고받기는 단어를 많이 들려주는 것보다 중요합니다." |
| **오늘** | 그대로 읽을 대사 | "'그 다음엔 어떻게 됐을까?' 하고 물어보세요." |
| **한 걸음 더** | 칭찬 + 확장 | "지난번보다 3번 더 주고받았어요. 이번엔 아이가 답할 때까지 셋을 세며 기다려 주세요." |

**추상적인 조언을 쓰지 않는다.** "개방형 질문을 하세요"가 아니라 **큰따옴표 안에 그대로 읽을 문장**을 준다. LENA의 부모 자료가 전부 이 형식이다.

**하나만 준다.** 여러 개 주면 부모가 아무것도 안 한다.

## 7. 접어 두는 것

### 자세히 보기

- 오늘 대화 전문
- 말한 방식 (말로 · 골라서 · 그려서)
- 만든 것 (그림 · 녹음 · 미션)
- 세션별 주고받기 추이 — **세 번 이상 쌓였을 때만**
- 기준 질문 지난 답 vs 오늘 답

**기준 질문**은 매 세션 같은 자리에 오는 둘뿐이다. "오늘은 어디로 가 볼까?"와 "누가 흔들었을까?"다. 나머지는 매번 문장이 달라 비교하면 안 된다.

```
"오늘은 어디로 가 볼까?"
  9/10  "우주!"
  9/14  "바닷속에 가 볼래."
  9/17  "로켓 타고 우주 갈래! 별 보러 가고 싶어서."
```

### 또래와 견주어 보기

**1차에는 비워 둔다.** 규준이 없어서다.

세션이 수천 개 쌓이면 **"우리 앱을 쓰는 또래 아이들 중"** 이라는 한정어를 붙여 연다. 공인 규준이라고 말하지 않는다.

**왜 기본 화면에 두지 않나** — 누리과정과 표준보육과정이 유아 평가에서 또래 비교를 지양한다. 금지는 아니지만 기본값으로 둘 자리는 아니다.

## 8. 관찰과 해석을 나눈다

키즈노트 공식 관찰기록 양식이다.

| 칸 | 무엇 | 누가 만드나 |
|---|---|---|
| **관찰** | 아이가 한 말과 한 일. 사실만 | 앱이 센다 |
| **해석** | 그게 무엇을 뜻하는지 | LLM 또는 규칙 |

해석 칸은 **접어 둔다.** 펼치지 않으면 사실만 보인다.

**AI 해석이 틀려도 부모가 원문을 보고 스스로 판단할 수 있다.** 사실과 해석이 한 문장에 섞이는 순간 이 방어선이 사라진다.

## 9. 1판의 6축을 왜 버렸나

| 문제 | |
|---|---|
| 국내 아동 서비스 중 레이더 차트를 쓰는 곳을 **하나도 못 찾았다** | 통념과 달랐다 |
| 축이 여섯이면 **능력 프로필처럼 읽힌다** | 찌그러진 모양이 부족함으로 보인다 |
| 한 세션에 축당 0~3회라 **모양이 들쭉날쭉** | 표본이 너무 적다 |
| 축 넷이 LLM 판정이라 **틀리면 그림 전체가 틀린다** | |

**주고받기 횟수 하나로 바꾸면** 계산이 정확하고, 근거 논문이 여섯 편이고, 북극성을 그대로 잰다.

## 10. 전달 — 푸시 세 줄

부모는 리포트를 보러 앱에 들어오지 않는다. 토도영어는 매주 월요일 카톡, 스픽은 주간 이메일을 보낸다.

**놀이가 끝나면 그날 밤 푸시 세 줄.**

```
오늘 지호와 12번 주고받았어요. 7번은 지호가 먼저 걸었고요.
"외계인이 장난쳐서! 로켓을 잡고 흔들었어!"
내일은 "그 다음엔 어떻게 됐을까?" 하고 물어보세요.
```

숫자 하나 · 아이 말 하나 · 할 일 하나. 상세는 앱으로 들어와야 본다.

## 11. 쓰지 않는 말

발달검사 결과지와 부모상담 지침에서 가져왔다.

> "쉽게 단정짓거나 섣불리 예측하지 않기" · "가치판단을 하지 않기(사실만을 말하기)"

| 금지 | 대신 |
|---|---|
| 또래보다 · 평균 · 백분위 · 정상 범위 | (기본 화면에 쓰지 않는다) |
| 부족합니다 · 늦습니다 · 떨어집니다 | 오늘은 안 나왔어요 |
| 향상 · 증진 · 발달했습니다 | 지난번보다 3번 더 |
| 등급 · 레벨 · ○○세 수준 · 단계 이름 | **그 단계를 판단한 근거를 사실로** (§3-2) — "까닭 짓기 단계" ✗ → **"까닭을 말한 것 4번"** ✓ |
| 진단 · 평가 · 선별 · 검사 | 기록 |

LLM이 만든 문장에 이 말이 하나라도 있으면 **그 답을 버리고 미리 만든 것을 쓴다.**

---

## 12. 고지

> 이 기록은 아이가 앱에서 어른과 나눈 대화를 **있는 그대로 정리한 것**입니다.
> 아이의 언어 발달을 **진단하거나 평가하지 않으며**, 또래와 비교하지 않습니다.
> 언어치료나 전문가 상담을 **대체하지 않습니다**.
> 아이의 말이 걱정되신다면 언어재활사 또는 소아청소년과 전문의와 상담하세요.

**"또래와 비교하지 않습니다"를 명시한다.** 백분위가 없는 약점이 신뢰 자산으로 바뀐다.

## 13. 데이터는 어디에

| 무엇 | 어디 |
|---|---|
| 주고받기 · 활동량 · 인용 | **폰에서 계산. 폰에만 저장** |
| 전사본 | 폰. 보관 기간은 아래 |
| 음성 원본 | 글자로 바꾼 뒤 서버에서 즉시 삭제. 폰에만 남음 |
| "오늘 이렇게" 세 줄 | LLM이 만들되 금지어 가드 통과한 것만 |

Curio 방식을 따른다. **오디오 즉시 삭제 · 전사본만 기간 한정 보관 · 부모 수동 삭제 버튼.**

## 14. 아직 안 정한 것

|---|---|
| 전사본 보관 기간 | Curio는 90일. 우리는 미정 |
