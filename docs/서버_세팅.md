## 4. 켜기 — 순서대로 창 두 개

```powershell
# 창 1 — ComfyUI (먼저)
cd C:\ComfyUI
.\venv\Scripts\python main.py --port 8188

# 창 2 — 백엔드 (ComfyUI 가 뜬 다음)
cd <레포>\backend
py -m uvicorn main:app --host 0.0.0.0 --port 8010
```
- `--host 0.0.0.0` 이어야 **다른 기기(폰)** 가 붙는다. ComfyUI 는 그 PC 안에서만 쓰니 기본값(127.0.0.1) 그대로.
- 켜지면 백엔드가 **받아쓰기 모델과 그림 모델을 미리 올린다** — 첫 그림이 48.9초 걸리던 것을 막으려고. **켠 뒤 1~2분 기다린 다음** 시연한다.
- 확인: 그 PC 브라우저에서 `http://127.0.0.1:8010/health` → `{"status":"ok","mock":false}`

**방화벽** — Windows 가 처음 켤 때 「액세스 허용」을 물으면 **개인 네트워크 허용**. 안 물었으면 관리자 PowerShell 에서:
```powershell
New-NetFirewallRule -DisplayName "otto 8010" -Direction Inbound -Protocol TCP -LocalPort 8010 -Action Allow -Profile Private
```

**그 PC 의 IP** — `ipconfig` 의 「IPv4 주소」(예: `192.168.0.23`).

## 5. 폰 · 에뮬레이터에서 붙기

| 어디서 | 앱 켜는 법 |
|---|---|
| **같은 와이파이의 폰** | `adb shell am start -n kr.clap.otto/com.example.finalproject_demo.MainActivity -e server http://<서버 IP>:8010 -e live all` |
| 서버 PC 에 USB 로 꽂은 폰 | `adb reverse tcp:8010 tcp:8010` 뒤 `-e server http://127.0.0.1:8010 -e live all` |
| 서버 PC 의 에뮬레이터 | `-e server http://10.0.2.2:8010 -e live all` |
| 다른 PC 의 에뮬레이터 | `-e server http://<서버 IP>:8010 -e live all` |

- 개발용(debug) 빌드만 http 로 붙는다. 스토어판은 서버에 안 붙는다(https 가 필요 — 「한 바퀴 이후」).
- 앱 안에서도 켤 수 있다: 시연 서랍(오른쪽 위 길게 누르기) → 「서버 연결」 칩.

**GPU 없이 흐름만 붙여 볼 때** — `MOCK=1` 로 켜면 키도 GPU 도 없이 명세 모양대로 가짜 응답을 준다:
```powershell
$env:MOCK="1"; py -m uvicorn main:app --host 0.0.0.0 --port 8010
```

## 두 대로 나누기 (09-30 결정) — 받아쓰기와 그림을 다른 GPU 에

**왜** — 한 카드에서 받아쓰기와 그림이 **동시에** 돌면 받아쓰기가 0.71초 → **2.54초(3.6배)** 느려진다(`eval/results.md` 09-21). 지금은 「아이가 말하는 동안 그림을 안 만든다」로 피하고 있지만, 여러 명이 붙으면 못 피한다. 두 PC 사양이 같아서(RTX 3060 12GB) 나누면 둘 다 제 속도가 난다.

| | **PC1 — 백엔드 + 받아쓰기** (폰이 붙는 곳) | **PC2 — 그림(ComfyUI)** |
|---|---|---|
| 설치 | §2 백엔드만 · 받아쓰기 모델(2.9GB) | §3 ComfyUI 만 · 그림 모델 두 개(7.3GB) |
| `.env`(키) | **여기에만** 둔다 | 필요 없다 — 키가 한 곳에만 있다 |
| 켜기 | `py -m uvicorn main:app --host 0.0.0.0 --port 8010` | `.\venv\Scripts\python main.py --port 8188 --listen 0.0.0.0` |
| 방화벽 | 8010 을 개인 네트워크에 연다(폰용) | 8188 을 **PC1 IP 에서만** 연다(아래) |

**PC1 의 `.env` 에 한 줄 더**
```
COMFY_URL=http://<PC2 IP>:8188
```
코드는 그대로다 — 그림 서버 주소가 원래 설정값(`backend/app/config.py` `comfy_url`)이다.

**PC2 방화벽 — PC1 만 들어오게** (관리자 PowerShell). ComfyUI 는 비밀번호가 없어서 와이파이 전체에 열면 누구나 그림을 돌릴 수 있다.
```powershell
New-NetFirewallRule -DisplayName "otto comfy 8188" -Direction Inbound -Protocol TCP -LocalPort 8188 -RemoteAddress <PC1 IP> -Action Allow -Profile Private
```

**켜는 순서** — PC2(ComfyUI) 먼저 → PC1(백엔드). PC1 이 켜지면서 PC2 에 준비 그림을 한 장 부탁해 모델을 올린다.
**확인** — PC1 에서 `curl http://<PC2 IP>:8188/queue` 가 `{"queue_running": [], ...}` 를 돌려주면 연결됨.

⚠️ **두 대가 다 켜져 있어야** 그림이 나온다. PC2 가 꺼져 있으면 그림은 전부 프리셋으로 간다(앱은 멈추지 않는다 — 규칙 8).
⚠️ IP 는 와이파이에 다시 붙으면 바뀔 수 있다 — 바뀌면 PC1 `.env` 의 `COMFY_URL` 과 폰의 서버 주소를 같이 고친다.

## PC별 작업 순서 — 「이 컴퓨터는 PC1 / PC2」 한 마디로 시작한다

**AI 세션(Claude Code · Codex)에게** — 사람이 「이 PC 는 PC1」 또는 「PC2」라고 하면 **해당 칸의 순서를 위에서부터** 진행한다. 각 단계는 `[세션]` 이 직접 하는 것과 `[사람]` 이 해야 하는 것으로 나뉜다. `[사람]` 단계에서는 **무엇을 해 달라고 말하고 멈춘다.** 각 단계의 「됐다」 기준을 확인한 뒤에 다음으로 간다.

세션이 지킬 것:
- **`.env` 의 내용을 읽거나 출력하지 않는다.** 있는지(`Test-Path`)와 `COMFY_URL` 줄을 **덧붙이는 것**만 한다. 키를 채팅에 받지 않는다 — `.env` 는 사람이 USB 로 옮긴다
- 방화벽은 **관리자 PowerShell** 이 필요하다 — 명령을 보여 주고 사람이 실행한다
- 레포는 **읽기만** 한다. 이 PC 에서 커밋 · 푸시할 일은 없다(문서가 틀렸으면 사람에게 알린다)

### PC1 — 백엔드 + 받아쓰기 (폰이 붙는 곳)

| # | 누가 | 할 일 | 됐다 |
|---|---|---|---|
| 1 | 세션 | `nvidia-smi` · `py --version` · `git --version` | GPU 12GB · CUDA 12 이상 · Python 3.12 이상 |
| 2 | 세션 | 레포 받기(§1). 이미 있으면 `git checkout main; git pull` | `backend/` 폴더가 있다 |
| 3 | 세션 | `cd backend; py -m pip install -r requirements.txt` | 오류 없이 끝남 |
| 4 | **사람** | 조장 PC 의 `.env` 를 USB 로 **레포 맨 위**에 복사 · 받아쓰기 모델 폴더(§2)를 같은 경로로 복사(안 하면 첫 실행 때 2.9GB 를 받는다) | 세션이 `Test-Path <레포>\.env` → `True` |
| 5 | 세션 | 사람에게 **PC2 IP** 를 묻는다. `ipconfig` 로 **이 PC 의 IP(PC1 IP)** 를 찾아 사람에게 알려 준다 — PC2 방화벽에 필요하다 | 두 IP 를 안다 |

| 8 | **사람** | 관리자 PowerShell 에서 폰용 방화벽(§4 의 `otto 8010` 규칙) | 규칙이 생김 |
| 9 | 세션 | 백엔드 켜기: `cd <레포>\backend; py -m uvicorn main:app --host 0.0.0.0 --port 8010` — **백그라운드로** 띄우고 로그를 본다 | 로그에 `stt model loaded` |
| 10 | 세션 | 확인 두 개 — `curl.exe http://127.0.0.1:8010/health` → `"mock":false` · 그림 한 장: `Invoke-RestMethod -Method Post -Uri http://127.0.0.1:8010/image -ContentType 'application/json; charset=utf-8' -Body ([Text.Encoding]::UTF8.GetBytes('{"kind":"background","place":"바닷가"}'))` 의 `preset` | `preset` 이 `False` (그림이 PC2 에서 왔다). `True` 면 `reason` 을 보고 「막혔을 때」 |
| 11 | **사람** | 폰에서 붙기(§5) — 서버 주소 `http://<PC1 IP>:8010` · 말해 보고 받아쓰기 확인 | 폰 화면에 한 말이 뜬다 |

## 지켜야 할 것

- **아이가 쓰는 서버에서는 `STT_DEBUG_DIR` 을 켜지 않는다.** 녹음을 디스크에 남기는 조장 전용 시험 스위치다(차별점 1 — 목소리는 받아쓰자마자 지운다).
- 서버를 켜 두기만 하는 건 돈이 안 든다. **목소리(TypeCast) · 판정(OpenAI) 은 폰이 서버 모드로 쓸 때만** 나간다. 쓰지 않는 모드는 서버 연결 칩을 꺼 둔다.
- `.env` · 키는 이 PC 밖으로 옮기지 않는다(USB 복사 뒤 USB 에서 지운다).
- GPU 를 다른 일에 쓰려면 두 창을 닫는다(두 모델이 VRAM 을 잡고 있다).

## 막혔을 때

| 증상 | 원인 · 해결 |
|---|---|
| `cublas64_12.dll is not found` | `nvidia-cublas-cu12` · `cudnn` 이 안 깔림 → `pip install -r requirements.txt` 다시 |
| 첫 `/stt` 가 502 | 받아쓰기 모델이 아직 올라가는 중 — 켠 뒤 로그에 `stt model loaded` 가 뜰 때까지 기다린다 |
| 그림이 늘 프리셋 | ComfyUI 가 꺼져 있거나 모델 파일 이름이 다름(`backend/app/config.py` 의 `image_ckpt` · `image_lora`) |
| 폰이 안 붙음 | 같은 와이파이인지 · 방화벽 8010 · IP 가 바뀌지 않았는지(와이파이 재접속 시 바뀐다) |
| (두 대) PC1 에서 `:8188/queue` 가 시간 초과 | PC2 에서 `--listen 0.0.0.0` 을 빠뜨렸거나 · 방화벽의 `-RemoteAddress` 가 지금 PC1 IP 와 다르거나 · 두 PC 가 다른 와이파이 |
| (두 대) `/image` 가 늘 `preset: true` | PC1 `.env` 의 `COMFY_URL` 이 옛 IP — 고친 뒤 **백엔드를 다시 켠다**(설정은 켤 때 한 번 읽는다) |
| 포트 8010 사용 중 | 다른 파이썬이 쓰는 중 — 작업 관리자에서 끄거나 `--port` 를 바꾸고 앱 주소도 같이 바꾼다 |
