# 동화 발화 지표: 관찰값과 검증 상태 — 10-12

## 이번 앱 연결

#343과 #391의 질문·답·출처 기록을 이용해 동화 책별 리포트와 부모 설정에 관찰값을 표시한다. 원문은 기존 기기 저장소에서 읽고 새 서버 요청을 만들지 않는다. 다른 모드의 책별 지표 연결은 각 모드 담당이 한다.

- **답당 평균 낱말 수:** 열린·까닭 질문에 아이가 직접 답한 말의 공백 기준 낱말 수 평균. 발화 분절을 검증하지 않았으므로 ‘문장당’이라고 부르지 않는다.
- **서로 다른 낱말:** 같은 답 창 안의 서로 다른 공백 기준 표현 수. 앞뒤 문장부호와 영문 대소문자를 정리한다. `곰이`·`곰을`·`곰에게`는 서로 다른 표현이며, 표제어 기반 NDW가 아니다.
- **까닭 표현이 들어간 답:** 기존 리포트와 같은 `왜냐`·`때문에`·`니까`·`라서` 표현이 있는 답 수. 표현이 여러 번 있어도 답 하나는 한 번 센다. 의미를 판정하는 인과 능력 점수가 아니다.
- **고른 답:** 선택 질문에서 아이가 말하거나 카드를 고른 표현의 빈도. 원문을 표시하며 관심사 범주를 임의로 만들어 붙이지 않는다.

확인·미상 질문, 카드·그림·어른·오또의 말은 언어 계산에서 제외한다. 공백·문장부호만 있는 답과 독립적인 `몰라`·`더 없어`도 제외한다. 선택 답은 고른 답 빈도에만 들어간다.

한 권에서 답이 50개를 넘거나 여러 권의 기록이 모이면 **저장 순서상 최근 유효 답 50개**로 평균·표현 다양성·까닭 표현을 계산하고 전체 유효 답 수를 따로 표시한다. 이는 창 크기를 제한하는 규칙이지 50개가 모이면 또래 비교를 허용하는 규칙이 아니다. 어휘 종류 수는 표본 크기에 영향을 받으므로 5개 답과 50개 답을 발달 차이로 해석하지 않는다.

같은 책 재저장은 기존 기록을 대체한다. 책 삭제·다른 아이로 변경·명시적 초기화는 기존 `AnswerHistory` 동작을 따르고 재계산한다. 책별 리포트는 그 책의 원문만 사용하므로 다른 아이의 현재 누적 기록이 과거 책에 섞이지 않는다.

## 측정하지 않은 것

이 PR은 앱의 Kiwi MLU-m 계산, 표제어 기반 NDW, 연령 규준 비교, 임상적 판정, 앱 이용 효과를 구현하거나 검증한 결과가 아니다. 별도의 맞춤 질문 PR은 실제 판정 신호와 질문 유형을 근거로 기존 규칙을 연결한다.

## 기존 AI-Hub 분석 재확인

기존 AI-Hub 108 탐색 분석은 653명×50개 답을 Kiwi 0.24.0으로 다시 계산했을 때 기존 연령별 인원·평균·구간과 정확히 일치했다. 평균 MLU-m은 3세 5.680, 4세 5.601, 5세 5.633, 6세 5.729이며 연령에 따른 증가를 입증하지 못했다. 사후 진단의 6세−3세 차이는 0.0496, 아동 재표집 95% 구간은 −0.1831~0.3027이다. 기존 합격 기준을 바꾸지 않았다.

질문 유형이 모두 미상이고, 녹음 JSON 하나를 답 하나로 보며 파일 이름 순서에서 처음 50개를 고르는 방식이다. 공식 구축 가이드는 이름 대기·문장 따라 말하기·질문 응답 등 서로 다른 과제를 설명한다. 전체 3~6세 메타데이터 567,999개 중 무대본 `P` 표식은 717개(3세 38, 4세 290, 5세 268, 6세 121)였다. 이 표식만으로 선정하면 3세는 전체를 합쳐도 한 명의 50개 창을 채울 수 없다.

`P`가 없다고 모든 답이 낭독이라고 단정하지 않는다. 전체 메타데이터 조사와 기존 선정 답의 개별 과제 연결은 서로 다른 작업이다. 과제·선정 조건은 연령 효과가 관찰되지 않은 유력한 원인 후보이며 인과적으로 확정하지 않았다. 반복 문장도 주로 아동 간 같은 표현의 집계이지 한 아이가 답의 84%를 반복했다는 뜻이 아니다. 연령 차이를 만들려고 같은 문장을 임의로 삭제하지 않는다.
