# 멘토 발표 순서표 (2026-09-17)

> 문장을 외우는 대본이 아니다. **순서와 각 장면에서 할 한 문장**, 그리고 예상 질문이다.
> 화면을 돌리는 것이 설명보다 빠르다. 말은 줄이고 손을 움직인다. 목표 10분.

## 3. 왜 두 벌인가 (2분)

> "하나만 있으면 이게 맞는지 물어볼 수가 없어서, **같은 대본으로 다섯 가지를 다르게** 만들어 봤습니다."

| 축 | A | B |
|---|---|---|
| 그림체 | 펠트 3D | 오린 색종이 |
| 책 | 마지막에 한 번에 | 말할 때마다 한 쪽씩 |
| 어른 자리 | 건너뛸 수 있음 | 답해야 넘어감 |
| 턴 수 | 8턴 | 5턴 |
| 배경 | 그림 한 장 | 배경판 + 소품 |

**미션 2개와 부모 리포트 6축은 일부러 똑같이 뒀습니다.** 한 번에 여러 개를 바꾸면 무엇 때문에 좋았는지 알 수 없어서입니다.

내일 부모·아이에게 둘 다 보여주고, 순서를 아이마다 바꿔서 앞에 본 게 유리해지지 않게 합니다.

## 5. 데모가 깨질 수 있는 곳 (미리 확인)

| 위험 | 대비 |
|---|---|
| 서버가 안 떠 있음 | `python -m http.server 8778`을 **발표 전에 미리** 띄워 두고 한 바퀴 돌려 본다 |
| 인터넷이 끊겨 글꼴이 바뀜 | 구글 폰트를 쓴다. 안 되면 글꼴만 달라질 뿐 동작은 멀쩡하다고 한 마디 |

| 답이 무작위라 이상한 조합이 나옴 | 시연 서랍(오른쪽 위 구석 길게 누르기)에서 장면을 바로 옮길 수 있다 |

## 7. 하지 말 것

- 문서를 화면에 띄워 읽지 않는다. **앱을 돌린다**
- "아직 안 됐는데요"로 시작하지 않는다. 된 것부터 보여주고 안 된 것은 1번 표로 한 번에
- 기술 이름을 먼저 말하지 않는다. 화면을 보여준 뒤 물으면 답한다
- 두 초안 중 하나를 편들지 않는다. **고르는 건 내일 아이들이 한다**고 말한다
