## 0. 공통 규칙

### 0-1. 질문은 모두 열린 질문 (결정 30)

카드를 처음부터 띄우지 않는다. 카드가 나오는 경우는 셋뿐이다.

| 경우 | 화면 |
|---|---|
| 무응답 | 쉬운 질문 1회 → 그림 3장 (최대 3번 교체) → 마스코트가 골라줌 |
| 모호한 말 확인 | "공룡!" → 티라노 · 긴목 · 뿔공룡 3장 |
| 아이가 원할 때 | [직접 그리기 🖍️] 버튼은 늘 보인다 |

### 0-2. 마스코트 한 턴 = 세 조각, 두 문장 이내

```
① 받아주기   "우와, 외계인이었구나!"
② 되돌려주기  (발음이 어긋났으면 고쳐 말해 주되 지적하지 않는다)
③ 다음 질문   의문사 하나, 10어절 이하
```

- 어른 목소리가 들리면 **2~3초 기다렸다가** 이어간다
- "잘했어요" 같은 평가 대신 구체적 반응. 재촉하지 않는다
- 진행과 낭독은 언제나 마스코트가 한다 (어른에게 넘기지 않는다)

### 0-3. 기다리는 시간

| 상황 | 시간 |
|---|---|
| 쉬운 질문 | 5초 |
| 어려운 질문 ('왜 · 어떻게') | 8초 |
| 그림 3장을 띄운 뒤 | 7초 |
| 말하는 중 침묵 | **끊지 않는다.** 마이크 토글 또는 [다음]으로 끝낸다 |

데모에서는 마이크 온/오프가 기본이고, 위 타이머는 시연 서랍의 **[무응답 타이머 켜기]** 로 켠다 (결정 6)

### 0-4. 데이터 경로 (조사3)

```
녹음 ─┬─ 대화 → 우리 서버 Whisper → 텍스트 → 음성 사본 즉시 삭제
      │        → 이름 필터({주인공} · {친구1}) → LLM (칸 판정 · 자막)
      │        → 영어 키워드 → 우리 서버 ComfyUI (그림)
      └─ 소리 슬롯(공룡 소리) → 폰 안에서만. 서버로 안 감
```

- 아이 그림 · 아이 이름 · 소리 원본은 폰 밖으로 나가지 않는다
- 서버에는 그림도 남기지 않는다 (공용 캐시 없음 · 결정 26)

### 0-5. 남겨야 할 이벤트 (리포트 6축의 재료)

| 이벤트 | 필드 | 쓰이는 곳 |
|---|---|---|
| `story_start` | star_before, star_after | 별 차감 |
| `utterance` | speaker(child/adult/unsure), confidence, text, mode(voice/card/draw) | 말하기 · 함께하기 · 말한 방식 |
| `slot_filled` | slot, value, source(voice/card/draw/mascot) | 이야기 진행 |
| `signal` | S1(bool), S2(element) | 이유 말하기 · 이야기 채우기 |
| `emotion_mention` | text | 마음 말하기 |
| `make` | kind(draw/sound/direct_draw) | 만들기 |
| `image_request` | type(draft/final/background), reason, elapsed | 대기 시간 측정 |
| `redraw` | index(1~2), reason_text | 다시 그리기 1/2 · 2/2 |
| `mission` | id, motion, result(solo/helped) | 다음 미션 난이도 |
| `friend_rating` | friend_id, keep(bool) | 다음 이야기 선택지 |
| `session_end` | duration, counted, total | "13번 중 12번" |

## 2. 칸(슬롯) 규격

| 칸 | 질문 | 채우는 법 | 신호 | 그림 |
|---|---|---|---|---|
| place | "오늘은 어디로 가 볼까?" | 말 → **장소 유형에 매핑** | 기준 질문 ① | 배경 1장 (프리셋 또는 생성) |
| problem | "어? {사건}. 왜 그럴까?" | 말 | **S1** · 기준 질문 ② | 새 친구 등장 |
| reaction | "그래서 어떻게 됐어?" | 말 | 마음 말하기 재료 | – |
| cause | "{친구}는 왜 그랬을까?" | 말 | S1 · S2 | – |
| newcomer | "{친구}를 그려 줄래?" | 그림판 (또는 프리셋) | 만들기 | 아이 그림 그대로 |
| name | "이름은 뭐야?" | 말 | – | – |
| companion | (아이가 먼저 말할 때) "어떤 공룡이야?" | 말 → 모호하면 확인 3장 | – | 초안 생성 → 중간 확인 |
| sound | "{공룡}은 어떻게 울어?" | 녹음 | – | – |
| adult | "{어른}은 ○○하면 뭐 하고 싶어?" | 어른 말 | 함께하기 | 책에 등장 |
| solution | "{친구}랑 어떻게 친해질까?" | 말 | S2 | – |
| title | "이 책 이름은 뭐라고 할까?" | 말 | – | – |

> **2026-09-18 개정 — 필수 칸은 고정이 아니다.**
> 슬롯은 **채워야 할 폼이 아니라 이야기에 지금 필요한 재료**다. 아이가 *"혼자 갔어"*라고 하면 `companion`이 필요 없어지고, *"친구랑 싸웠어"*라고 하면 화해 방법이 새로 필요해진다.
> **칸 이름은 위 목록 + `extra`로 고정**하되, **필수 여부와 수집 순서는 LLM이 맥락으로 정한다**(`프롬프트_모음` §2). 목록에 없는 요소는 `extra`에 원문 그대로.

- **진행 별 6개**는 화면 표시용 기준이며, place · problem · cause · newcomer · sound · solution을 기본값으로 둔다. **아이 답에 따라 빠지거나 다른 칸으로 바뀐다**(`no_longer_needed`)
- **턴 상한을 두지 않는다.** 8턴 상한은 우리 핵심 지표인 **「주고받기 횟수」를 스스로 깎는다.** 아이가 신나서 계속 말하는 것은 제품이 원하는 일이다

**끝나는 조건 셋**

| 조건 | 동작 |
|---|---|
| **`story_ready: true`** — 템플릿 기준으로 이야기 재료가 찼다 | 책으로 넘어간다 |
| **`mascot_pick` 2회 연속** — 아이가 지친 신호 | 남은 칸을 마스코트가 채우고 마무리 |
| 15분 경과 | 부드럽게 마무리 유도 |

## 3. 턴 엔진 (한 턴의 상태 흐름)

```
ASK (마스코트 질문, 카드 없음)
  ↓
LISTEN  ── 아이 발화 감지 ──► JUDGE
  │  (쉬운 5초 · 어려운 8초)
  │
  ├─ 어른만 말함 ──► "지호는 어떻게 생각해?" 1회 ──► LISTEN
  └─ 무응답 ──► EASIER (쉬운 질문 1회) ──► 무응답 ──► CARDS(3장, 최대 3회 교체)
                                                        └─ 무응답 ──► MASCOT_PICK

JUDGE  (LLM 구조화 출력 — 슬롯 전체 + 템플릿을 같이 준다)
  · 어느 칸을 채웠나 (최대 2개) / 앞 칸과 모순인가
  · S1 (왜·어떻게에 이유·방법) / S2 (묻지 않은 요소) / emotion
  · 모호한 낱말인가 → CONFIRM(3장)
  · next_slot — 다음에 뭘 물을지 · no_longer_needed — 뭐가 필요 없어졌는지
  · story_ready — 이야기 재료가 찼는지
  ↓
REACT  (받아주기 + 되돌려주기 + 질문)
  ↓
NEXT   (story_ready면 책으로 · 아니면 next_slot 으로 · 또는 그림 확인 끼워 넣기)
```

### 이름 필터 — 폰에서, 2층으로 (2026-09-18 확정)

**미정이던 "사전 · 규칙 · 탐지 모델" 중 앞의 둘만 쓴다. 탐지 모델은 1차에 안 넣는다.**

| 층 | 무엇 | 예 |
|---|---|---|
| **1 사전** | 등록된 이름 전부 — 주인공 · 도감 친구 · 어른 호칭 | "지호" → `{주인공}` |
| **2 규칙** | **호칭 + 이름** 패턴 · 조사가 붙은 미등록 고유명사 | "엄마 지은이가" → "엄마 `{사람1}`가" |

**재현율을 정확도보다 앞에 둔다.** 이름인지 애매하면 **가린다.**
→ 자리표시자는 **폰에서 되돌리므로**, 일반 명사를 잘못 가려도 **아이는 원문을 그대로 본다.** 잘못 가리는 대가가 거의 없고, 못 가리는 대가는 **아동 개인정보 국외 유출**이다.

**⚠️ 필터를 백엔드가 아니라 폰에서 한다** (기술개요 §3 개정)
- 백엔드가 필터하려면 **백엔드가 실명을 받아야 한다.** 그러면 필터의 의미가 절반 사라진다
- **매핑표(`{주인공}` ↔ 지호)는 폰에만 저장한다.** 서버가 가지면 서버가 개인정보를 갖는 것이다
- 서버 STT를 쓸 때 전사 텍스트에 실명이 잠깐 있지만 **우리 서버이고, 폰으로 보낸 뒤 즉시 삭제**한다

**순서** — 이름 필터가 **금칙어·안전 필터보다 먼저**다. 안전 검사를 하려고 외부 LLM을 부르는데 거기 실명이 들어가면 필터를 한 의미가 없다.

```
폰 VAD → STT → [폰] 이름 필터 → [백엔드] 금칙어(규칙) → [LLM] 안전 필터 → [LLM] 판정
```

**MASCOT_PICK — 카드도 안 고를 때**

무응답 → 쉬운 질문 1회 → 무응답 → 카드 3장(최대 3회 교체) → **그래도 안 고르면 마스코트가 정한다.**

- **말없이 채우지 않는다.** *"음… 내 생각에는 공룡나라가 좋을 것 같아!"* 처럼 **고른 것을 소리 내어 말한다**
- **되묻지 않는다.** 여기서 또 물으면 아이가 더 움츠러든다
- 다음 턴은 **한 단계 쉬운 질문**으로 시작
- **2회 연속이면 남은 칸을 채우고 책으로**

**발화 출처 세 가지를 끝까지 구분해 기록한다** (2026-09-18 확정)

`slot_filled` 이벤트에 **`by`** 를 같이 남긴다. 이걸 안 나누면 **아이가 한 말과 우리가 채운 말이 리포트에서 섞인다.**

| | `by: child` (말로) | `by: card` (골라서) | `by: mascot` (대신 정해 줌) |
|---|---|---|---|
| **책 자막** | ✅ | ✅ | ✅ 이야기의 일부다 |
| **주고받기 횟수** | ✅ | ✅ 아이가 골랐다 | ❌ |
| **수준 신호(S1·S2)** | ✅ | ❌ | ❌ |
| **리포트 원문 인용** | ✅ | ❌ **아이가 한 말이 아니다** | ❌ |
| **「말한 방식」 원그래프** | 말로 | 골라서 | **표시하지 않는다** |
| **이름 필터** | ✅ 거친다 | 불필요 (프리셋) | 불필요 (우리가 만든 말) |
| **금칙어·안전 필터** | ✅ 거친다 | 불필요 | ✅ **LLM이 만든 말이면 거친다** |

> **`by: mascot`을 「말한 방식」에 안 넣는 이유**: 원그래프에 *"마스코트가 대신함 30%"*가 뜨면 부모가 **아이의 실패로 읽는다.** 그건 우리 필터 설계가 만든 숫자이지 아이의 행동이 아니다. 대신 **연속 `mascot_pick`은 다음 세션 시작 수준을 낮추는 데만** 쓴다.

**수준과 템플릿** *(2026-09-18 — 미정이던 넷을 확정)*

**수준은 규칙이 계산한다. LLM은 신호만 표시한다.** 이 원칙은 그대로다.

**① 신호가 가리키는 단계**

각 신호는 **아이가 할 수 있다는 증거**다. 신호가 가리키는 단계가 **지금보다 높을 때만** 올린다.

| 단계 | 할 수 있는 것 | 그 증거 |
|---|---|---|
| 고르며 짓기 | 고른다 | (신호 없음) |
| 이어 짓기 | **잇는다** | **S2** — 묻지 않은 것을 덧붙임 |
| 까닭 짓기 | **까닭을 댄다** | **S1** — 이유·방법을 스스로 말함 |

- **신호가 2턴 연속**이고 그 신호가 가리키는 단계가 **지금보다 높으면 한 칸 올린다**
- **한 번에 한 칸만.** 고르며 짓기에서 S1이 나와도 이어 짓기까지만 올린다
  → 두 칸을 뛰면 갑자기 "왜"를 묻게 되고, 못 답하면 **실패 경험**이 된다. 능력이 진짜면 다음 2턴에서 또 나온다
- 이어 짓기에서 **S2는 올림 신호가 아니다**. 지금 단계를 가리킬 뿐이다

**② 첫 두 턴 — 프로브로 정한다. 나이를 묻지 않는다**

기준 질문 두 개가 **일부러 난이도를 벌려 놓았다.**

| 턴 | 칸 | 질문 | 결 |
|---|---|---|---|
| 1 | `place` | "오늘은 어디로 가 볼까?" | **어디** — 누구나 답한다 |
| 2 | `problem` | "어? {사건}. 왜 그럴까?" | **왜** — 여기서 갈린다 |

- **1~2턴은 수준과 무관하게 이 두 질문을 고정**으로 던진다
- **2턴 답으로 초기 수준을 정한다** (여기서는 2연속 규칙을 쓰지 않는다)

| 2턴째 답 | 초기 수준 |
|---|---|
| 까닭을 말함 (S1) | **까닭 짓기** |
| 답은 했으나 까닭 없음 | **이어 짓기** |
| 무응답 · 카드 · 한 어절 | **고르며 짓기** |

- **3턴째에 템플릿을 확정**한다. 그 뒤에는 질문 결만 바뀐다
- **나이를 묻지 않는다.** 만 3~7세는 개인차가 커서 나이가 능력을 잘 예측하지 못하고, *"아이에게 꼬리표를 저장하지 않는다"*는 원칙과도 어긋난다

**③ 올림·내림 — 비대칭이 맞다. 유지가 기본값이다**

| 상황 | 동작 |
|---|---|
| 신호 **2턴 연속** (①의 조건) | **한 칸 올림** |
| 무응답 · 카드 **2턴 연속** | **한 칸 내림** |
| **`mascot_pick` 1회** | **한 칸 내림** ← 카드조차 못 고른 것은 무응답보다 강한 신호다 |
| **그 밖에 전부** (신호 없는 평범한 답) | **유지** — 지금 단계가 맞다는 뜻이다 |

- 고르며 짓기 **아래로 안 내려가고**, 까닭 짓기 **위로 안 올라간다**
- 내림이 올림보다 빠른 것은 **의도**다. 신호를 한 번 놓치는 것보다 **못 따라가는 경험이 나쁘다**

**④ 미션 난이도는 수준과 분리한다**

**대화 수준과 미션 난이도는 다른 능력이다.** 말은 잘 하는데 손이 서툰 아이가 있고 반대도 있다.

| | 무엇으로 움직이나 | 무엇을 정하나 |
|---|---|---|
| **대화 수준** | **대화 신호만** | 질문 결 · 템플릿 |
| **미션 난이도** | **미션 결과만** | 동작 종류 (탭 → 문지르기 → 당겼다 놓기) |

- **미션 1은 수준과 무관하게 쉬움(탭) 고정.** 미션 2만 미션 1 결과로 정한다 (미션은 2개뿐이라 사다리가 필요 없다)
- **미션 실패가 대화 수준을 내리지 않는다.** 내리면 부모 리포트에 *"말하기가 줄었다"*로 잘못 읽힌다

## 4. 장면별 대본

### S1 · 시작

```
화면   커튼 배경 · 왼쪽 마스코트 · [이야기 만들기] 큰 버튼 · [책장]
       오른쪽 위 ⭐ 3        아래 작은 글씨 "어른과 함께 하는 놀이예요"
```

> 🗣 이모: "지호야, 유튜브 말고 우리 이야기 만들기 할까?"
> 🗣 지호: (이야기 만들기 탭)
> 📱 ⭐ 하나가 흔들리며 커져 화면 가운데로 날아옴 → ⭐ 3 → **⭐ 2** → 이야기 시작

- **부모 설정이 "부모 비밀번호 필요"이면** 여기서 비밀번호 4자리를 먼저 받는다 (결정 2)
- **⭐ 0에서 누르면**: 마스코트 말풍선 *"오늘 만들 이야기는 다 썼어! 책장에 가서 지난 이야기 볼까?"* + [책장 보기] [괜찮아] · **누를 때 한 번만**
- 아이 화면에 구매 버튼 · 가격 없음 (결정 28)

### S2 · 도감

```
화면   가로 한 줄 4칸 — [안경 쓴 지호] [파란 옷 지호] [점선 ＋] [점선 ＋]
```

> 🗣 마스코트: "안경 쓴 지호, 파란 옷 지호가 있어. 오늘은 누구랑 갈까?"

- 고른 주인공은 **고정 스프라이트**로 이야기 내내 재사용 (결정 20 · 26)
- 주인공은 만들어진 그림체 그대로. 세계 그림체와 달라도 된다 (결정 27)
- ＋ 를 누르면 S2b

### S2b · 주인공 만들기 (첫날 · ＋ 버튼)

> 🗣 마스코트: "우리 주인공을 만들자! 말로 만들까, 골라서 만들까?"

**A. 골라서 만들기** — 머리 3 · 옷 3 · 눈 3 · 안경 3 토글. 누를 때마다 미리보기가 바로 바뀐다. 생성 없음

**B. 말로 만들기**

| 질문 | 답 후보 5개 (데모용) | 저장값 |
|---|---|---|
| "머리는 짧아, 길어, 묶었어?" | 짧아! / 길어! / 묶었어! / 짧게 짧게! / 긴 머리가 좋아! | hair |
| "빨강, 파랑, 노랑 옷이 있어. 무슨 색 입을까?" | 파랑! / 빨간 거! / 노랑! / 파란색 좋아! / 빨강 빨강! | shirt |
| "안경은 어때? 동글 안경, 네모 안경, 안 쓸래?" | 동글 안경! / 네모 안경! / 안 써! / 동그란 거! / 안경 싫어! | glasses |

> 📱 답할 때마다 그 속성이 붙은 인형이 미리보기로 보인다 → 완성 → **[좋아 🙂] [싫어 ✏️]**
> 🗣 마스코트: "짠! 이렇게 생겼어. 좋아, 싫어?"

- **"싫어"** → "어떤 게 마음에 안 들어?" → 말로 답 → 반영해 다시 만들기 · **1/2 · 2/2** → 다 쓰면 만든 3장 중 고르기 (결정 29)
- 속성값만 영어 키워드로 ComfyUI에. 발화 원문은 보내지 않는다

### S3 · 1턴 — 어디로 갈까 (기준 질문 ①)

```
화면   마스코트 + 마이크. 카드 없음 + [직접 그리기 🖍️]
```

> 🗣 마스코트: "오늘은 어디로 가 볼까?"

| 답 후보 | 매핑 |
|---|---|
| 우주! | space |
| 바닷속! | sea |
| 공룡 나라! | dino |
| 로켓 타고 우주 갈래! | space (+S2 탈것) |
| 눈 오는 데! | snow (프리셋 없으면 배경 생성) |

> 🗣 지호: "우주!"
> 🗣 마스코트: "폭신폭신 우주로 가는구나!" (받아주기)
> 📱 펠트 우주 배경 + 주인공이 흰 테두리를 달고 올라옴 + 로켓

- 아이 말을 **장소 유형**에 맞춘다. 유형에 없으면 배경을 새로 생성하고 폰에 남긴다 (§6)
- 무응답 → "우주, 바닷속, 공룡 나라가 있어. 어디로 갈까?" → 카드 3장

### S3 · 2턴 — 사건과 원인 (기준 질문 ② · 결정 25)

> 📱 {장소 사건}이 일어난다 — 우주면 로켓이 덜컹덜컹 + "쿵!" (프리셋 · 대기 0초)
> 🗣 마스코트: "어? 로켓이 흔들려. 왜 그럴까?"

| 답 후보 | 새 친구 | 신호 |
|---|---|---|
| 외계인이 흔들어서! | 외계인 | S1 |
| 운석이 부딪혀서! | 운석 | S1 |
| 바람이 세게 밀어서! | 바람 | S1 |
| 외계인이 장난쳐서! 로켓을 잡고 흔들었어! | 외계인 | S1 + S2 |
| 운석이 날아와서 쿵 했어! | 운석 | S1 + S2 |

> 🗣 마스코트: "우와, 외계인이었구나! 그래서 어떻게 됐어?"

| 답 후보 | 마음 |
|---|---|
| 로켓이 빙글빙글 돌았어. 그래서 무서웠어. | 무서웠어 |
| 로켓이 쿵 떨어졌어! 깜짝 놀랐어. | 놀랐어 |
| 덜컹덜컹 하다가 멈췄어. | (없음) |

| 나 울 뻔했어. | 울 뻔했어 |

- 되물어서 나온 답은 S2가 아니다 (물어봤으므로)
- 마음 말하기는 수준 판단에 쓰지 않고 부모 기록 문장 재료로만

### S3 · 3턴 — 까닭 (템플릿 확정)

> 🗣 마스코트: "외계인이 창문에서 쳐다봐. 외계인은 왜 흔들었을까?"
> 🗣 이모: "혹시 같이 놀고 싶었던 거 아닐까?"
> 🗣 마스코트: "지호는 어떻게 생각해?" (어른만 말했을 때 1회)

| 답 후보 | 책 5쪽에 들어갈 말 | 신호 |
|---|---|---|
| 심심해서! 친구가 없어서. | 친구가 없어서 심심했어 | S1 + S2 |
| 같이 놀고 싶어서! | 같이 놀고 싶었어 | S1 |
| 배가 고파서 그랬어! | 배가 고팠어 | S1 |
| 길을 잃어서! 집을 못 찾아서. | 길을 잃었어 | S1 + S2 |
| 인사하고 싶어서! | 인사하고 싶었어 | S1 |

- **3턴째 템플릿 확정**: 오해-화해형 · 속성 축 상황 이해 · 장면 6개 (결정 4 · 13)

### S5 · 그림판 — 새 친구

> 🗣 마스코트: "외계인을 그려 줄래? 크레용이 여기 있어."
> 🗣 이모: "다 그렸네! 이름은 뭐야?" → 이름 후보: 뿌뿌! / 삐삐! / 몽몽이! / 초코! / 별이!
> 🗣 마스코트: "뿌뿌 입은 어디야? 입을 콕 눌러 줘."

- 그린 부분만 잘라 인형 크기로 키운다. 입은 **한 점만** 저장한다 (얼굴 인식이 아니다)
- 이름은 이름 사전에 넣고 LLM에는 `{친구1}`로 보낸다
- 그리기 싫어하면 프리셋 3장. 프리셋을 골라도 "아이 것"으로 취급한다
- 이름 무응답 → 마스코트가 "외계인 친구"로 부른다 (사전에는 안 넣음)

### S3 · 동행 — 모호한 말 확인

> 🗣 지호: "공룡도 데려갈래!"
> 📱 확인 카드 3장 (프리셋 · 대기 0초) + [직접 그리기]
> 🗣 마스코트: "티라노, 긴목공룡, 뿔공룡이 있어. 어떤 공룡이야?"

| 답 후보 | 매핑 |
|---|---|
| 뜨리게라! | 뿔공룡 (짧은 답 후처리) |
| 티라노! | 티라노 |
| 목 긴 거! | 긴목공룡 |
| 뿔 달린 거! | 뿔공룡 |
| 제일 큰 거! | 티라노 |

- **폰 소품함 먼저** 본다. 지난 책에서 "또 만날래"로 고른 친구가 있으면 카드 한 장을 그 친구로 바꾼다 (결정 26)
- 없으면 영어 키워드로 초안 생성 시작 (뒤에서)

### S6 · 소리

> 🗣 마스코트: "트리케라톱스는 어떻게 울어? 마이크를 누르고 소리 내 봐!"

| 공룡 | 소리 후보 |
|---|---|
| 티라노 | 크아아앙! · 어흥! · 쿠오오오! · 크르릉! · 으르렁 쿵! |
| 긴목공룡 | 우우웅~ · 뿌우우~ · 우와아~ · 음머어~ · 우우 우우~ |
| 뿔공룡 | 뿌우우우웅! · 뿌뿌뿌! · 끼야아! · 뿌웅 뿌웅! · 부우우! |

- 음성 인식 경로를 끄고 녹음. 길이 · 음량만 폰에서 검사
- 0.3초 미만 → "한 번 더!" 1회 → 그래도 없으면 기본 효과음
- 말한 횟수에 세지 않는다

### S7 · 중간 확인

> 📱 그림 + **[좋아 🙂] [싫어 ✏️] [직접 그리기 🖍️]** · 버튼 아래 **다시 그리기 0/2**
> 🗣 마스코트: "짠! 우주에 온 트리케라톱스야. 좋아, 싫어?"
> 🗣 지호: (싫어)
> 🗣 마스코트: "어떤 게 마음에 안 들어?"

| 답 후보 | 반영 | 생성 |
|---|---|---|
| 빨간 게 좋아! | 색 | **안 함** (색 영역만) |
| 더 크게! | 크기 | 안 함 (레이어) |
| 웃는 얼굴로! | 표정 | 안 함 (눈 스티커) |
| 뿔이 더 커야 돼! | 모양 | **다시 생성 1회** |
| 다른 공룡 할래! | 종류 | 다시 생성 1회 |

- 색 · 크기 · 표정은 대기 0초이고 횟수를 쓰지 않는다 (결정 26 · 29)
- 다시 생성은 최대 2회. 다 쓰면 만든 3장을 늘어놓고 "어떤 게 제일 좋아?"
- 8초 안에 안 오면 "그림은 조금 뒤에 올 거야", 15초 넘으면 취소하고 프리셋 확정

### S3 · 해결 + 어른 칸

> 🗣 마스코트: "뿌뿌는 친구가 없어서 심심했대. 뿌뿌랑 어떻게 친해질까?"

| 답 후보 | 책 6쪽 | 신호 |
|---|---|---|
| 같이 별 따기 놀이 해! {공룡} 등에 태워 줄 거야. | …등에 타고 별을 땄어요 | S2 |
| 선물 줄 거야! 반짝이는 돌! | …반짝이는 돌을 선물했어요 | – |
| 우리 집에 놀러 오라고 해! | …집에 초대했어요 | – |
| 같이 춤추면 돼! | …손을 잡고 춤을 췄어요 | – |
| 맛있는 거 나눠 줄래! 딸기! | …딸기를 나눠 주었어요 | S2 |

> 🗣 마스코트: "이모는 별을 따면 뭐 하고 싶어?" ← **어른 전용 칸** (책마다 1개)
> 🗣 이모: "나는 별로 목걸이 만들래!" → 책 6쪽에 목걸이가 등장

- 어른이 답하지 않으면 3초 뒤 마스코트가 프리셋에서 고르고 넘어간다

### S8 · 책 만드는 중

> 🗣 마스코트: "책을 만들고 있어! 이 책 이름은 뭐라고 할까?"
> 제목 후보: 지호랑 뿌뿌랑 우주 놀이! / 뿌뿌와 로켓 모험! / 우주에서 만난 뿌뿌! / 지호의 우주 여행! / 뿌뿌야, 같이 놀자!

- 이름 가린 칸 → LLM → 장면 6개 · 자막(−어요체 15어절 이하) JSON → 폰에서 이름 되돌림
- **이미 있는 그림은 다시 그리지 않는다.** 여기서 새로 만드는 건 미션 물체와 쪽별 소품뿐
- 무응답이면 마스코트가 칸으로 제목을 짓는다

### S9 · 책

```
화면   위 왼쪽 도구 4종(손 · 뿅망치 · 깃털 · 돋보기) · 위 오른쪽 쪽 표시
       양옆 ◀ ▶ · 아래 자막 띠 + 🔊
```

| 쪽 | 자막 (칸으로 채워짐) | 화면 |
|---|---|---|
| 표지 | 『{제목}』 | 주인공 + 아이 그림 |
| 1 | {주인공}은 {탈것}을 타고 반짝이는 {장소}로 떠났어요. | 탈것이 뒤뚱뒤뚱 |
| 2 | 그런데 갑자기 {사건}. 쿵! | 화면 흔들림 |
| 3 | 창문 밖에서 {친구1}가 쳐다보고 있었어요. | 친구 등장 연출 |
| 4 | {친구1}가 너무 세게 흔드는 바람에 {탈것}에 불이 붙었어요! | **미션 1** |
| 5 | {친구1}는 "{까닭}. 미안해" 하고 말했어요. 그런데 {친구1} 별의 우물이 말랐대요. | **미션 2** |
| 6 | {해결}. 셋은 다음에도 같이 놀기로 했어요. | 공룡을 누르면 녹음한 소리 |

**미션 1 — 문지르기 (쉬움)**
> 🗣 "큰일이야, {탈것}에 불이 났어! 손가락으로 슥슥 물을 뿌려 줘!"
> 불 3개 → 문지르면 작은 불 → 연기 → 성공 연출 3초
> 공룡 쪽을 문지르면 "부르르! {녹음한 소리}" (장난 반응 · 저장 안 함)

**미션 2 — 끌어다 놓기 (보통 · 판정 영역 넓게)**
> 🗣 "{친구1} 별 우물이 말랐어. 비구름을 끌어서 우물 위에 놓아 줄래?"
> 주인공 위에 놓으면 우산이 펴진다 (장난 반응)
> 수위: 바닥 → 반 → 가득 → 성공

- 미션은 **2개** (결정 7). 첫 미션은 쉬움. 혼자 성공 → 다음 한 칸 올림, 도움 → 한 칸 내림
- 실패 없음 · 타이머 없음. 시간 · 시도 횟수 저장 안 함
- 자유 도구: 손 "히히!" · 뿅망치 "간지러워!" · 깃털 "깔깔깔!" · 돋보기 → 칸 값을 읽어줌

### S10 · 친구 평가

> 📱 오늘 만난 친구들이 나란히 · 각각 아래 **[또 만날래 💛] [안녕 👋]**
> 🗣 마스코트: "오늘 만난 친구들이야. 또 만나고 싶은 친구는 누구야?"

- "또 만날래"로 고른 친구만 **다음 이야기의 확인 카드 후보**가 된다
- "안녕"을 골라도 지워지지 않는다. 폰에 남고 책장에서 그 책을 열면 그대로 있다

### S11 · 끝내기

> 📱 선물이 하나씩 — 해결 방법 도감 첫 칸 → 무지개 크레용
> 🗣 마스코트: "책 다 만들었다! 엄마한테 보여주러 가자!"
> 📱 [책장에 꽂기] → 화면이 어두워지며 "오늘은 여기까지!" · 오른쪽 위 ⭐ 2

- 다음 책을 권하지 않는다 (결정 2)

### S12 · 부모 모드

비밀번호 4자리 → 오늘의 기록. **화면 구성은 `부모리포트_설계.md` 그대로**
- 6축(말하기 · 이유 말하기 · 마음 말하기 · 이야기 채우기 · 만들기 · 함께하기) · 3단계 표시 · 축마다 원문 인용
- 말한 방식 원그래프 · 기준 질문 본인 대비 · 누리과정 대응 · 질문 카드 3장 · 고지 3줄
- 탭: [오늘의 기록] [업적 보기] [설정]
- 설정: 시작 방식 · 하루 별 개수 · 그림체 · 다시 그리기 상한

## 5. 무응답 흐름 (모든 열린 질문 공통)

```
질문 → 대기(쉬운 5초 · 어려운 8초)
 ├ 아이 말함 ─────────────► 판정 → 반응 → 다음
 ├ 어른만 말함 ──► "지호는 어떻게 생각해?" 1회 → 대기
 └ 없음 ──► 편들기 + 쉬운 질문 ("어려웠구나. 그럼 뭐가 흔들렸어?")
              └ 없음 ──► 그림 3장 (7초) ─ 최대 3번 교체 ─► 마스코트가 골라줌
```

- 벌점 · 아쉬움 표현 없음. 화면에 오류 표시 없음
- 무응답 · 카드가 2턴 연속이면 수준을 한 칸 내린다
- 카드로 고른 답은 수준 신호로 세지 않는다 (`mode: card`로 기록)

## 6. 장소 유형 (열린 답을 받는 자리)

**프리셋으로 미리 만드는 3곳** (데모 구현)

| | 우주 | 바닷속 | 공룡 나라 |
|---|---|---|---|
| 배경 | 펠트 우주 · 별 | 펠트 바닷속 · 산호 | 펠트 초원 · 화산 |
| 탈것 | 로켓 | 거북이 | 기차 |
| 도착 대사 | 폭신폭신 우주에 왔어! | 출렁출렁 바닷속에 왔어! | 쿵쿵 공룡 나라에 왔어! |
| 사건 | 로켓이 덜컹덜컹 | 물살이 소용돌이 | 땅이 쿵쿵 흔들림 |
| 새 친구 후보 | 외계인 · 운석 · 바람 | 문어 · 상어 · 인어 | 아기 공룡 · 원숭이 · 화산 |
| 미션 1 소품 | 로켓의 불 ← 물대포 | 거북이 등의 진흙 ← 스펀지 | 기차의 불 ← 물대포 |
| 미션 2 소품 | 비구름 → 별 우물 | 진주 → 조개 | 비구름 → 연못 |

**그 밖의 답** (숲 · 하늘 · 놀이터 · 눈 오는 데 …)
- LLM이 가장 가까운 유형으로 맞춘다 → 프리셋 배경 사용
- 맞는 유형이 없으면 **배경 1장을 생성**하고 폰 소품함에 남긴다 (결정 26 · 30)
- **미션은 장소에 묶지 않는다.** 뼈대(문지르기 · 끌어다 놓기)는 그대로 두고 소품 그림만 바꾼다
