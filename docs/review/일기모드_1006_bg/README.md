# 그림일기 배경 조각을 오또가 다시 그리기 (10-06 · 진웅 · #168)

**결론(안) — 배경 조각은 잘라 보내지 않고 판 전체 크기로 보내고, 선이 나타내는 띠(하늘 · 땅 · 바다)를 옅게 채운 뒤 색연필 배경 문구로 다시 그린다.** 세기는 0.85(배치를 지킴)와 0.9(그림이 풍성함) 사이에서 고른다.

수치와 조건은 `eval/results.md` 「10-06 — 일기 배경 조각 다시 그리기」에 있다. 이 폴더에는 비교표만 둔다.

## 비교표
`sheet_ground.png` · `sheet_sky_ground.png` · `sheet_sea.png` · `sheet_hills.png` — 줄마다 보내는 방식 하나, 맨 왼쪽이 서버로 보낸 그림, 오른쪽 셋이 씨앗 7 · 11 · 23 의 결과

- **0 지금 경로** — 앱이 물건처럼 잘라 보내면 가는 띠가 정사각형 가운데에 놓인다. 땅 선 하나는 3/3 오려 내기 실패(빈 그림), 나머지도 작은 띠 · 산 소묘라 배경으로 못 쓴다
- **1 판 전체 · 0.85** — 선 자리는 지키지만 선만 조금 꾸며서 돌아온다. 화면 대부분이 빈 종이
- **2 판 전체 · 0.9** — 장면이 차지만 배치가 흔들린다(언덕 혹이 사라짐 · 바다 수평선이 올라감)
- **3 판 전체 + 띠 채움 · 0.85** — 배치를 가장 잘 지킨다(하늘 띠 · 땅 높이 · 바다/모래 띠 · 왼쪽 언덕 혹). 일부는 평평하게 칠한 느낌
- **4 판 전체 + 띠 채움 · 0.9** — 가장 그림책 같다. 땅 높이 · 바다 · 하늘은 지키지만 언덕 혹은 1/3 만 남고, 아이가 안 그린 나무가 들어간다
