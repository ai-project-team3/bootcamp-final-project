# 일기 모드 프로토타입 브라우저 확인 (2026-09-29)

`docs/일기모드_UI.html`을 크롬에서 아이처럼 한 바퀴 돌린 기록이다.
화이트보드에는 마우스로 직접 그렸고, 아이 말은 입력 칸에 넣었다.

- `00_전체흐름_영상.gif`: D0부터 D5까지 녹화(50프레임 한도).
- 마지막 장면(기분 고르기, 표지)은 영상에 다 안 들어갔을 수 있어서 스크린샷으로 따로 남겼다.

## 확인 중에 고친 것

- 오또 대사의 "나 → 너", 오또 관점의 "네가 그린"
- 오또 그림을 보느라 끊긴 질문이 나중에 다시 옴
- "우리 집이랑 무슨 일이 있었어?" → "거기서 무슨 일이 있었어?"
- 되받기를 오또 관점으로 ("너 혼자 뛰다가 넘어졌구나!")
- 조합 중 Enter 처리
- 장소로 쓰인 조각은 걷지 않음
- 제목 말풍선이 화면 밖으로 잘림
- 질문마다 입력 칸에 자동 포커스를 주던 동작을 뺌
