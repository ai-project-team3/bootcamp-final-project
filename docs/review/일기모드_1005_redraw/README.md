# 그림일기 「오또가 그려 줘」 그림 품질 (10-05 · 진웅)

**결론 — 일기 redraw 는 색연필 그대로 두고, 다시 그리기 전에 아이가 닫은 칸을 그 테두리 색으로 옅게 채운다(`character.fill_closed`).** 모델 · 문구 · 세기(0.85)는 그대로다.

수치와 회차별 비교는 `eval/results.md` 「10-05 — 일기 「오또가 그려 줘」」에 있다. 이 폴더에는 비교표만 둔다.

## 비교표
- `s1_dog_house.png` · `s2_mom_sun.png` — 4회차, 스크립트 그림(앱 조각과 같은 굵기). 줄마다 설정 하나, 맨 왼쪽이 아이 그림, 오른쪽 셋이 씨앗 7 · 11 · 23 의 오려 낸 결과
  - **0 지금** — 테두리만 그린 집 · 엄마 · 해가 같은 선 그림으로 돌아온다
  - **F 채움** — 파란 벽 · 빨간 지붕 집, 분홍 치마 엄마, 노란 해, 갈색 강아지
  - **S 순한 색연필** — 지금과 동률이라 넣지 않았다
- 실제 아이 그림(Meta Amateur Drawings 공개 데이터 9장) 비교표는 원 그림이 들어 있어 레포에 넣지 않았다. 다시 보려면 `eval/redraw_1005/real_pieces.py` 로 조각을 만들고 `bench.py --r4 --real <조각 폴더>` 를 돌린다

## 넣지 않은 것과 이유
| 안 | 이유 |
|---|---|
| A 앱이 1024 로 그려 보냄 | 지금과 같다 — 서버가 이미 1024 종이로 키운다 |
| B 아이 색 이름을 문구에 | 실제 그림에서 검은 선이 「주된 색」이 돼 드레스 · 무당벌레 색이 바뀌었다 |
| C 펠트 | 가장 예뻤지만 그림일기에 안 어울린다 |
| S 순한 색연필 문구 | 지금과 동률 — 사실적인 고양이 털 · 무당벌레 다리가 그대로 |
