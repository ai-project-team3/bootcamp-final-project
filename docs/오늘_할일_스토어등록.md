## 3. 내부 테스트에 빌드 올리기 (10분)

왼쪽 메뉴 **테스트 → 내부 테스트**

1. [새 버전 만들기]
2. **App Bundle**에 `otto-0.1-demo-vc3.aab` 를 끌어다 놓는다
   - "Play 앱 서명" 안내가 나오면 **계속/동의** — 구글이 배포용 키를 관리하고 우리 키는 업로드용이 된다. 정상이다
3. 출시명: 자동으로 `3 (0.1-demo)` — 그대로
4. 출시 노트:
   ```
   <ko-KR>
   내부 테스트용 데모 빌드입니다. 화면 흐름 확인용이며 실제 음성 인식·AI 기능은 아직 연결되지 않았습니다.
   </ko-KR>
   ```
5. [저장] → [버전 검토] → [내부 테스트로 출시 시작]

✅ 끝난 표시: 버전 상태가 「사용 가능」
