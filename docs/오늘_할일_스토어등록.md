## 1. 개인정보처리방침 공개 URL 만들기 (15분) — **먼저 한다**

앱 콘텐츠 선언에서 URL 을 요구하므로 이게 없으면 3번에서 멈춘다.

1. GitHub 에서 **새 공개 저장소**를 만든다 — 이름 예 `otto-privacy`, **Public**, README 체크
2. 저장소에서 [Add file] → [Create new file] → 파일명 `index.md`
3. `docs/개인정보처리방침.md` 내용을 붙여넣는다. 단 **[확인 필요]** 를 먼저 채운다:
   - 보호책임자 성명: 이종훈 / 연락처: 쓸 이메일 주소
   - OpenAI ZDR · TypeSafe 보존: **지금은 네트워크 미연결이므로 그대로 두고, 붙일 때 채운다**
   - 맨 위 「초안이다」 인용 블록과 「09-23 수정」 문단은 **지우고 올린다** (내부 메모다)
4. [Commit changes]
5. 저장소 [Settings] → 왼쪽 [Pages] → Source: `Deploy from a branch` → Branch: `main` / `/(root)` → [Save]
6. 2~3분 뒤 `https://<계정>.github.io/otto-privacy/` 가 열린다. **이 주소를 메모한다**

✅ 끝난 표시: 브라우저 시크릿 창에서 그 주소가 열린다

## 3. 내부 테스트에 빌드 올리기 (10분)

왼쪽 메뉴 **테스트 → 내부 테스트**

1. [새 버전 만들기]
2. **App Bundle**에 `otto-0.1-demo-vc2-sdk36.aab` 를 끌어다 놓는다
   - "Play 앱 서명" 안내가 나오면 **계속/동의** — 구글이 배포용 키를 관리하고 우리 키는 업로드용이 된다. 정상이다
3. 출시명: 자동으로 `2 (0.1-demo)` — 그대로
4. 출시 노트:
   ```
   <ko-KR>
   내부 테스트용 데모 빌드입니다. 화면 흐름 확인용이며 실제 음성 인식·AI 기능은 아직 연결되지 않았습니다.
   </ko-KR>
   ```
5. [저장] → [버전 검토] → [내부 테스트로 출시 시작]

✅ 끝난 표시: 버전 상태가 「사용 가능」
