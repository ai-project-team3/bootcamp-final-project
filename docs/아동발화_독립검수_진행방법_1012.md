# 아동 전사문 독립 정답 검수 — 10-12

> 10-12 후속 결정: 민우님 요청으로 현재 50개는 [AI 보조 검토](아동발화_AI보조검토_1012.md)로 전환했다. 아래는 독립 검수 도구의 설계 기록이며, 현재 AI 제안을 공개한 50개에 적용해 독립 정확도를 주장하지 않는다.

## 현재 상태

검수 준비와 자동 비교 도구를 구현했다. **실제 사람이 확정한 새 정답은 아직 0/50개**이며, 아동 정확도 검증 완료가 아니다. 기존 자동 참고표를 보며 검토한 8개는 그대로 보존한다. 이 도구가 검수자의 전문성이나 정답의 언어학적 타당성을 인증하지는 않는다.

## 표본을 먼저 고정

- 보유 AI-Hub108 선정 전사문 35,746개에서 기존 참고표 50개의 문장을 제외한다. 비교 전 NFC·공백 정규화만 하며 원문 자체는 고치지 않는다.
- 3·4·5·6세 각각 13·13·12·12명, **총 50명에게서 한 답변씩** 뽑는다. 동일 아동과 동일 정규화 문장은 중복 선택하지 않는다.
- seed `1012321`의 SHA-256 순위로 뽑는다. 답변 길이·자동 점수·오류 여부로 고르지 않는다. 필요한 인원이 없으면 표본 수를 몰래 줄이지 않고 실패한다.
- 나이는 검수 화면에서 숨긴다. 원문만 보여 주며 자동 분절·개수는 정답 확정 전까지 전달하지 않는다.
- 이는 이전에 분석했던 자료에서 새 검수 문장을 고른 **1차 오류 점검 표본**이다. 분석기 개발에서 완전히 독립된 자료 또는 아동 전체를 대표하는 표본으로 부르지 않는다. 과제는 혼합되어 있고 질문 유형은 미상이다.
- 원문·기존 표·자동 예측과 검수 파일은 로컬에 둔다. GitHub에는 재사용 코드·합성 테스트·이 안내만 올린다.

## 정답 작성 기준 v1

1. 녹음 JSON의 전사문 한 개를 한 답변으로 본다. 임상 연구의 발화 경계와 같다고 가정하지 않는다.
2. 명사·어간, 조사, 선어말 어미·종결/연결/전성 어미, 명확한 파생 접사를 구별한다. 문장부호·이모지 등 비언어 기호는 제외한다.
3. 복합 어미를 추가로 잘게 분해하지 않는 계산 계약이다. 예를 들어 설명용 `먹어요`는 `먹 / 어요`, `곰이 잤어.`는 `곰 / 이 / 자 / 았 / 어`로 적는다. 표기 정규화와 개수 판단은 구분한다.
4. 원문의 반복·말실수를 임의로 지우거나 없는 말을 보완하지 않는다. 원문이 불명확하거나 합성/파생·어미 경계를 이 기준으로 확정하기 어렵다면 사유와 함께 보류한다.
5. 이 기준을 적용할 수 있는 사람이 자동 답을 보지 않고 분절을 직접 작성한다. 어려운 항목은 다른 검수자와 기준을 먼저 맞춘 뒤 별도 판정한다. AI가 대신 작성한 답을 사람 정답으로 인증하지 않는다.

위 정의는 우리 오프라인 계산기의 개수 계약을 점검하는 운영 기준이며, 임상 MLU의 표준화·전문가 인증을 대신하지 않는다. 언어학적 분절 기준을 변경한다면 기존 파일을 고치지 말고 새 버전의 표본/예측/검수로 평가한다.

## 화면에서 하는 일

1. 실제 검수자 이름이나 별칭을 입력한다.
2. 직접 나눈 조각을 `/`로 구분하고 **이 분절 저장 · 다음**을 누른다. 개수는 입력한 조각으로 계산된다.
3. 모르겠다면 이유를 적고 **판단 보류 · 다음**을 누른다. 억지 정답은 필요 없다.
4. 중간에 닫아도 서버에 저장한 항목은 남는다. 저장 전 입력을 버리고 이동하려 하면 확인한다. 여러 탭이 오래된 상태로 덮어쓰려 하면 막는다.
5. 모든 항목을 정답 또는 보류로 결정한 뒤, 기준 적용과 독립 작성 확인란을 실제 사실대로 체크한다.
6. **전체 정답 확정 · 비교 결과 열기**를 누르면 사람 정답을 고정한다. 이후 같은 화면에서 정답을 바꿀 수 없다.

검수 도중 검수자 이름을 바꿔 타인의 판단을 자기 것으로 덮어쓰지 않는다. 다른 검수자의 독립 판정은 별도 검수 묶음으로 받고, 불일치 조정은 자동 답을 공개하기 전에 한다. 사용자가 직접 조작하는 작업이라 검수자 진술의 진실성은 도구가 보증할 수 없다.

## 결과의 의미

- **정답 확보 비율:** 전체 50개 중 사람이 분절을 확정한 비율. 보류 수를 반드시 함께 표시한다.
- **개수 완전 일치율:** 확정 항목에서 사람과 계산기 형태소 개수가 같은 비율.
- **평균 절대오차:** 확정 항목에서 형태소 개수 차이의 절댓값 평균.
- **평균 부호 오차:** 과대/과소 집계 방향. JSON 결과에 남긴다.
- 항목별 차이는 로컬 JSON의 익명 항목 번호로 확인할 수 있다. 원문·분절·검수자 이름은 집계 결과에 넣지 않는다.

보류한 문장이 어려운 문장에 몰릴 수 있으므로 확정 항목의 높은 정확도를 전체 50개로 일반화하지 않는다. 모두 보류하면 정확도는 `null`이며 0%나 100%가 아니다. 개수가 같아도 분절이 틀릴 수 있다. **토큰/POS 정확도·STT 정확도·연령 규준·오또 사용 효과와 구분**한다.

오류를 보고 수정한 뒤 같은 50개만 다시 통과시킨 결과는 회귀 검증이다. 수정 후의 새로운 정확도를 주장하려면 다음 표본과 정답을 다시 고정해야 한다. 실제 독립 정답 없이 도구만으로 이 단계를 완료할 수 없다.

## 실행 및 파일

```text
python -m pip install -r eval/requirements-language-metrics.txt
python -m eval.child_blind_review prepare --input <private-selected-answers.jsonl> --seen-reference <private-old-analysis.json> --output <new-private-folder>
python -m eval.child_blind_review serve --directory <private-folder> --port 8880
```

준비 명령은 기존 출력 폴더를 덮어쓰지 않는다. 로컬 폴더 안에는 `pack.local.json`(검수 문장), `predictions.private.json`(숨긴 자동 개수), `review.local.json`(사람 판단)이 생긴다. 정답 확정 후 `comparison.local.json`이 생긴다. 기존 검수 파일과 다른 폴더를 사용한다.

서버는 `127.0.0.1`에만 연결한다. Host·Origin 검사, 명시적 경로만 제공, 캐시 금지를 적용한다. 원문 파일을 웹 공개 경로로 직접 제공하지 않고 숨긴 예측 파일에도 GET 경로가 없다. 같은 PC의 파일 접근 권한을 가진 사람이 파일을 직접 여는 것까지 막는 보안 경계는 아니다.

이미 사용 중인 포트는 공유하지 않고 시작을 거부한다. 특히 Windows에서도 독점 바인딩을 사용한다. 기존 검수 서버와 충돌하면 기존 프로세스를 임의로 종료하지 말고 비어 있는 다른 포트를 지정한다. 이 PC의 새 50개 검수 주소는 `http://127.0.0.1:8880/`이다.

실제 준비 결과: 50개/50명, 나이별 13·13·12·12명, 초기 검수 0개. 기존 원자료와 8개 판단을 덮어쓰지 않았다. 프로그램 검사는 합성 자료만으로 수행하며, 합성 QA의 정답·일치율을 아동 성과로 보고하지 않는다.
