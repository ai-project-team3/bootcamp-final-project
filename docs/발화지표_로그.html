다음에 할 일 — 정해 둔 순서

  1. 수집·질문 조건을 확인한다. 메타데이터에는 질문 유형이 없었다. 스크립트 정보와 전사 검수 수준을 확인하고 공통 답·낭독·선택 질문 가능성을 구분한다.

  4. 근거 확보 뒤 질문 규칙을 비교한다. 지금 앱 수준 문턱을 바꾸지 않는다. 합성 대본 전/후 결과와 실제 아동 효과는 분리한다.

계산기는 실제 아이 말을 정확히 나누나?

기존 검사 25개는 다시 통과했고, 전사문 50개의 자동 결과도 재현됐다. 하지만 문장 끝에 마침표를 붙이자 1개에서 어미가 다르게 나뉘어 형태소 수가 6개에서 7개로 바뀌었다. 반복 실행 결과가 같다는 것과 정답이라는 것은 다르다. 사람 정답 비교가 남아 있다.

기존 자동 분절표를 보고 그대로 승인한 것은 독립적인 사람 정답이 아니다. 익숙한 검수자가 기준에 맞춰 직접 나누거나, 자동 결과를 참고했다면 그 사실을 기록해야 한다. 원문은 외부로 올리지 않는다.

10-13 · 50개 검토 완료, 보류 원인 확인

배경·기준: AI 제안과 설명을 본 사용자의 판단을 확정해 확인했다. 모든 50개를 유지하고 보류를 AI가 동의로 바꾸지 않는다. 목적은 오류 후보 분류이며 독립 정확도 계산이 아니다.

결과: 동의 45개 · 보류 5개 · 미검토 0개. 보류는 복합 단어 분절 3개, 반복·말 고침 1개, 해석하기 어려운 전사 1개다. 원본 파일 3개의 검사 전후 해시가 같았다.

설정 대조: 같은 답변 50개에서 기본 설정은 평균 5.40토큰, 이형태 표시만 바꿔도 5.40이었다. 세부 분절을 켜면 36개의 개수가 바뀌어 평균 6.26이 됐다. 이는 단위 변화이며 정확도 개선이나 아이 말의 증가가 아니다.

판정: 사용자 검토와 보류 사유 분석은 완료했다. 45/50을 정확도 90%로 쓰지 않는다. 앱 말 기록·맞춤 질문은 병합됐고, 독립 아동 정답 및 실제 사용 효과는 별도 근거가 필요하다.
