## 1. 커밋 규칙 — 자주, 작게

**너무 멀리 가면 꼬인다. 되돌리기는 커밋뿐이다.**

- **한 덩어리가 끝날 때마다 커밋한다.** 기준: 테스트가 통과하는 작은 단위(파일 한두 개 · 기능 한 조각). 여러 기능을 한 커밋에 섞지 않는다
- **파괴적인 작업(파일 대량 수정 · 되돌리기 · 병합) 전에 먼저 커밋한다**
- 조장 작업은 `feature/leejonghoon` 에 커밋 → `git fetch` → main 을 `--ff-only` 로 올려 **main 에 바로 푸시**해도 된다(조장 허락, 메모리 `lead-may-push-main`). **force push 금지**
- 팀원 브랜치는 **확인 → 충돌 검사 → 테스트 → `--no-ff` 병합 커밋**(메시지 `merge: 이름 — 한 줄`)
- 커밋 메시지는 **영어**, 끝에 시스템이 알려 준 `Co-Authored-By` · `Claude-Session` 두 줄
- 표준 흐름:
  ```
  git add <파일> && git commit -m "..." \
  && git fetch -q && git checkout -q main && git merge -q --ff-only origin/main \
  && git merge -q --ff-only feature/leejonghoon && git push -q origin main \
  && git checkout -q feature/leejonghoon && git push -q origin feature/leejonghoon
  ```
- **이 문서(§4 · §5)도 작업 커밋과 함께 갱신한다** — 다음 요약 뒤의 내가 읽는다

- 권한 확인 서버가 가끔 응답하지 않는다(연속 실패가 쌓이면 턴이 끊긴다) → 두 번 실패하면 멈추고 알린다
- Play Console · pen.dev 업로드는 누를 때 파일 선택 창을 여는 방식 → **조장이 직접**. 끌어다 놓기 흉내는 탭을 멈추게 했다
- uiautomator 는 따옴표가 든 버튼 글자를 목록에서 빼먹는다 → 좌표로 누른다
- 긴 한국어는 Bash 히어독으로 쓰지 않는다(Write 도구) · `py -c "..."` 안에 백틱을 넣지 않는다 · PowerShell `Out-File` 은 BOM 을 붙인다
- `eval.run_team_eval` 은 돌릴 때마다 `eval/raw/<모델>.jsonl` 을 덮어쓴다 → 비교하려면 먼저 복사해 둔다
