# 동화 주인공 다시 쓰기 — 2026-10-08

확인 범위: #342의 Android 저장·선택 흐름, 관련 자동 검사와 디버그 APK 빌드. 실기기에서 아이의 선택 비율과 시간 절감은 측정하지 않았다.

## 동작

- 동화의 주인공 만들기 입구에서 현재 책장 메타데이터를 읽고 최근 주인공 세 명과 「새로 만들기」를 보여 준다. 같은 이름과 같은 그림은 한 번만 보인다. 그림이 없는 프리셋은 이름·속성·생김새 설명으로 중복을 제거한다.
- 「또 할래」는 오또가 방금 부른 첫 주인공을 고른다. 카드나 주인공 이름으로 다른 인물을 고를 수 있고 「새로」는 기존 말로/골라서 만들기로 간다.
- 재사용은 이름·로컬 이미지·속성·생김새 설명을 복원하고 생김새 질문과 이미지 생성을 건너뛴다. 새 인물도 이름을 확정하면 그 인물로 이야기로 이동한다. 협업 도감 흐름은 유지한다.
- 후보는 별도 저장하지 않는다. 해당 주인공을 쓰는 마지막 책을 지우면 후보에서도 빠지고, 모두 지우기는 기존 `story_books` 삭제에 포함된다. 이미 열려 있는 화면 객체도 선택 입구에서 다시 읽는다.
- 새 책은 실제 주인공 이름과 생김새 원문을 저장한다. 예전 책에 아이 호칭만 저장됐거나 생김새 원문이 없으면 사라진 정보를 복원할 수 없다. 그 책에 남아 있는 이름·그림·속성을 사용한다. 그림 메타데이터 자체가 없는 오래된 책은 후보에서 제외한다.

## 로그 읽기

- `hero_choice choice=reuse|new eligible=true|false input=voice|card|automatic`: 선택 순간 기록. `eligible=true`인 선택 중 `reuse`의 비율이 지난 주인공 선택 비율이다. 첫 책의 자동 새로 만들기는 분모에서 제외한다.
- `hero_setup choice=reuse|new eligible=true|false turns=N elapsed_ms=N`: 이야기로 넘어가기 직전 기록. 시간은 주인공 선택/생성 입구부터의 실제 경과 밀리초이고 1,000으로 나누면 초다. 턴은 그 구간에 받은 아이의 음성·탭 응답 수이며 확인·수정 탭을 포함하고 무응답·마스코트 선택은 제외한다. 부모 리포트의 이야기 턴 수와 별개다.
- 디버그 `OttoTrace` 로그를 사용한다. 실제 아이의 선택 비율·새로 만들기 시간·재사용 시간 절감은 실기기 세션 로그를 모은 후 계산해야 한다. 일시정지나 이탈 후 다시 시작한 구간은 별도로 확인한다.

## 자동 확인

- 이름 저장 결함, 재사용 카드 부재, 전체 삭제 직후 남는 후보, 새로 만들기 완료 후 도감에 머무르는 경로, 대본 마이크 미응답을 실패 테스트로 재현한 후 보완했다.
- 카드/음성 재사용, 기존 새로 만들기, 이름·생김새 저장/재열기, 최근 중복 제거, 마지막 책 삭제, 전체 삭제, 협업 흐름 보존을 검사했다.
- 로컬 HTTP 수신 기록을 이용한 서버 모드 검사에서 재사용 선택부터 첫 이야기 질문까지 `/image` 요청 0건을 확인했다.
- 관련 Android 검사와 `assembleDebug`를 실행했다. 전체 Android·backend 검사는 PR CI 결과로 별도 확인한다. S7 설치와 실기기 측정은 하지 않았다.
