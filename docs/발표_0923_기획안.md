## 1. 표지

# 오또 · OTTO

**말로 짓는 인형극** — 만 3~7세 · 종이 인형극 그림책
팀 4명 · 2026.09~10 · 배경 그림 한 장(`android/.../drawable/bg_dino.png`)

**이름 풀이 — 표지에 작게 한 줄, 또는 2장 넘어가며 말로**

| | |
|---|---|
| **오** | 아이가 놀라고 신날 때 내는 소리 |
| **또** | **아이가 더 해달라고 할 때 하는 말** |
| **OTTO** | **O**ur **T**ale, **T**old **O**ut loud |

**「또」가 이 제품이 성공했을 때 아이 입에서 나오는 말입니다.** 부모 리포트의 첫 숫자가
*"오늘 아이가 몇 번 말했나"*이고, 마지막 화면이 *"또 만날래?"*로 끝납니다.

> 🚫 **일본어 어원을 말하지 않는다** — 「소리」는 `oto`(音, おと)이고 **`otto`(夫, おっと)는 「남편」**이다.
> 표기가 뜻과 안 맞아서, 일본어를 근거로 대면 바로 짚힌다. 한국어 풀이만으로 충분하다.

## 2. 아이가 말하면 그림책이 됩니다

**한 줄** — 그림책 앱은 읽어 줍니다. 이 앱은 아이가 짓게 합니다.

**넣을 것** — 대화 한 토막을 화면 가운데 크게

```
🗣  마스코트   "오늘은 어디로 가 볼까?"
🧒  아이       "공룡나라 갈래! 근데 뿌뿌도 데려갈 거야."
                  └ 묻지 않은 걸 스스로 덧붙였다  ← 이게 기록된다
🗣  마스코트   "공룡 나라구나! 거기서 누굴 만났어?"
```

**맺음** — 끝나면 부모에게 「오늘 아이가 한 말 그대로」가 남습니다.

## 8. 말이 끝난 걸 알아채기 · 글자로 바꾸기

**한 줄** — 둘 다 정했습니다. 받아쓰기는 09-22~23 측정으로 정해졌습니다.

| | 쓰는 것 | 잰 값 | |
|---|---|---|---|
| ① 말 끝 감지 | **Silero VAD** (폰) | **p50 550ms** — 폰 내장보다 **8.4배 빠름** | **정함** |
| ② 받아쓰기 | **자체 GPU whisper (large-v3-turbo)** | 폰 내장은 **프리셋 65%** → 같은 폰 마이크 녹음을 whisper 는 **23/23 (100%)**, 0.31초. **7세 아이 2,000발화 CER 8%** | **정함** |

**②의 맞바꿈**

| | 자체 인프라 | 외부 처리자 |
|---|---|---|
| 실제로 놓이는 것 | 원본 음성 · 전사 | 전사 텍스트 (함께 실리는 것 확인 필요) |
| 보존과 삭제 | 우리가 정한다 | 엔드포인트 설정을 확인해야 안다 |
| 그래픽카드 | 그림과 나눠 쓴다 | **그림 전용이 된다** |
| **남는 의무** | **접근 통제 · 열람·삭제 대응은 그대로** | 위탁이면 관리·감독 |

**아이 목소리로 잰 것이 처음 생겼습니다** (09-23, AI-Hub 7세 여아 2,000발화): **CER 8.1% · 어절 보존 80%**. 「아동 120.8%」는 옛 모델(whisper base) 전례였고, 지금 모델은 파인튜닝 전례(19.1%)보다 이미 낮습니다. 다만 어절 5개 중 1개가 바뀌어 **키워드 보존 합격선 90% 에는 아직 못 미칩니다** — 3~6세 데이터로 다시 잽니다.

> ✅ **말한다** — *"외부 STT 도 같은 녹음으로 재봤고(96~100%), 앞선 것은 무음 처리 하나였다. 그건 우리 쪽 필터로 막았다."* 외부 이름은 말하지 않는다.
> 🚫 **말하지 않는다** — *"아이 목소리도 해결됐다."* 화자 1명 · 7세 · 실내 · 문장 발화다. 3~6세와 짧은 답은 안 쟀다.

> 🚫 **말하지 않는다** — *"자체 서버니까 안전하다."* 축은 처리 위치가 아니라 **자체 인프라냐 외부 처리자냐**이고, 자체 인프라에서 돌려도 보존·삭제·접근 통제 의무는 남는다(멘토 09-22).
> ✅ **말한다** — 아이 원본 음성을 우리 인프라에만 두는 건 **우리가 고른 제품 원칙**이다. *"그럴 수밖에 없다"*고 하면 원칙으로서의 설득력이 약해진다.

## 12. 그래픽카드 한 장에 셋을 올리기

**한 줄** — 자리는 되는데 같이 돌리면 안 됩니다. 그래서 시간을 나눠 씁니다.

- **셋이 다 올라갑니다** — 그림 + 받아쓰기 + 음성 처리로 **10,437 / 12,287 MiB**
- **동시에 돌리면 받아쓰기가 0.71 → 2.54초(3.6배)** 느려집니다. 그림을 쥔 쪽이 이기고 **작은 계산을 많이 하는 받아쓰기가 줄을 섭니다**
- **최종 결정** — **아이가 말하는 동안에는 그림을 만들지 않습니다.** 마스코트가 말하는 6.4~7.0초 동안 만들고, 한 장이 2.4초라 **한 턴에 두 장**이 들어갑니다
