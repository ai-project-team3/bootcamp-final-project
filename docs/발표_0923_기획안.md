## 1부 · 무엇을 만드는가

### 1. 표지

- 배경 그림 한 장 (`assets/assets/`)

### 2. 아이가 말하면 그림책이 됩니다

**한 줄** — 그림책 앱은 읽어 줍니다. 이 앱은 **아이가 짓게 합니다.**

**들어갈 것** — 실제 대화 한 토막을 화면 가운데 크게

```
🗣  마스코트   "오늘은 어디로 가 볼까?"
🧒  아이      "공룡나라 갈래! 근데 뿌뿌도 데려갈 거야."
                 └ 묻지 않은 걸 스스로 덧붙였다  ← 이게 기록된다
🗣  마스코트   "공룡 나라구나! 거기서 누굴 만났어?"
```

**맺음** — 끝나면 부모에게 「오늘 아이가 한 말 그대로」가 남습니다.

### 3. 다른 점은 둘뿐입니다

**한 줄** — 기능을 늘린 게 아니라 두 가지를 다르게 했습니다.

| ① 아이가 만든 건 AI가 다시 그리지 않습니다 | 아이 그림은 그대로 책에. **아이가 녹음한 소리는 폰을 떠나지 않습니다** |
|---|---|
| **② 질문 순서가 고정이 아닙니다** | *"혼자 갔어"* → 「누구랑?」이 사라지고, *"친구랑 싸웠어"* → 화해 방법이 새로 필요해집니다. **무엇을 물을지는 방금 한 말이 정합니다** |

**아래 띠** — 세 모드: **동화** / **일기**(오늘 하루를 재료로) / **부모 협업**(부모가 질문을 미리 넣어 둡니다)

## 3부 · 어디까지 왔나

### 7. 시연 — 프로토타입 한 바퀴

**한 줄** — 말 한 마디가 그림책이 되는 전 과정입니다.

- **세 모드가 모두 한 바퀴 돕니다.** 모드 선택 → 동화 한 바퀴(30~40초) → 일기·협업은 각 10초씩
- 자막은 단계 이름만: *말한다 → 알아듣는다 → 판단한다 → 되묻는다 → 그린다 → 책이 된다*
- 협업 모드는 **질문하는 사람이 바뀌는 것**이 보이게 — 부모가 미리 넣은 질문이 아이 화면에 뜨는 순간
- **지금 시연은 대본으로 돕니다.** 각 단계에 무엇이 들어가는지는 다음 장부터 — 먼저 말하고 넘어갑니다
- 화면 검사 **52개가 통과**한 상태에서 녹화합니다

### 8. 아이가 한 번 말하면 이 순서로 돕니다

**한 줄** — 이 그림이 3부의 지도입니다. 다음 장들이 이 위를 왼쪽부터 짚습니다.

가로 흐름도. 칸마다 **어디서 도는지**를 색으로 (폰 / 우리 서버 / 밖)

```
🧒 말한다
   → ① 말이 끝난 걸 안다        [폰]
   → ② 글자로 바꾼다            [검토 중]
   → ③ 이름 가리기 · 금칙어      [폰]
   → ④ 무슨 말인지 판단          [밖]
   → ⑤ 마스코트가 대답한다        [폰 + 밖]
   → ⑥ 그림을 만든다            [우리 서버]
📖 책이 된다 → 👨‍👩‍👧 부모에게 남는다
```

**맺음** — 실명은 **폰에서** 가리고 매핑표도 폰에만 둡니다.

⚠️ **「글자만 나가니 개인정보는 안 나간다」고 쓰지 않습니다.** 멘토 검토(9/22) 정정 — 텍스트만 담긴 요청도 개인정보를 실어 나릅니다. 이 장에서는 **어디서 도는지만** 말하고, 무엇이 함께 실리는지는 14장에서 다룹니다.

### 9. 말이 끝난 걸 알아채기 · 글자로 바꾸기

**한 줄** — 하나는 정했고, 하나는 **고민 중**입니다.

| | 쓰는 것 | 잰 값 | |
|---|---|---|---|
| ① 말 끝 감지 | **Silero VAD** (폰) | **p50 550ms** — 폰 내장 방식보다 **8.4배 빠름** | **정함** |
| ② 받아쓰기 | 후보 둘 | 폰만으로 해봤더니 **프리셋 매칭 65%** (합격선 95%) | **고민 중** |

**②를 왜 아직 못 정했나 — 두 길의 맞바꿈이 팽팽합니다**

| | **자체 인프라** | **외부 처리자** |
|---|---|---|
| 실제로 놓이는 것 | 원본 음성 · 전사 | 전사 텍스트 (+ 함께 실리는 것 확인 필요) |
| 보존과 삭제 | 우리가 정한다 | 엔드포인트별 보존 설정을 확인해야 안다 |
| 그래픽카드 | 그림과 나눠 쓴다 | **그림 전용이 된다** |
| 값 | 전기값 | 분량만큼 과금 |
| **남는 의무** | **접근 통제 · 열람·삭제 대응은 그대로** | 위탁이면 관리·감독 의무 |

⚠️ **축을 「어디서 도느냐」로 잡지 않습니다.** 멘토 검토(9/22) 정정 — 처리 위치만으로는 갈리지 않고,
**자체 인프라에서 돌려도 보존·삭제·접근 통제 의무는 그대로 남습니다.**

그리고 **「제품 원칙」과 「그럴 수밖에 없음」을 구분해서 말합니다.** 아이 원본 음성을 우리 인프라에만
두는 건 **우리가 고른 원칙**이고, 법적으로 가능한 유일한 구현이라서가 아닙니다 — 강제였다고 말하면
원칙으로서의 설득력이 오히려 약해집니다.

**어느 쪽이든 아이 목소리 30발화가 있어야 정합니다.** 어른 목소리로 재면 순위가 안 나옵니다 — 같은 모델이 **성인 7.8% · 아동 120.8%**로 갈립니다.

### 10. 무슨 말인지 판단하기

**한 줄** — 여기가 이 앱의 심장입니다. **정했습니다.**

- 슬롯 12칸 중 **어디가 찼고 다음에 뭘 물을지**를 매 턴 정합니다
- **JSON 성공률 100% · p95 2.4초 · 권당 21.6원**
- 같은 한국어 프롬프트인데 모델에 따라 **토큰이 6,129 vs 3,987**로 갈려 값이 **7배** 차이 났습니다 → 값도 같이 잽니다
- **수준은 규칙이 계산합니다. 모델은 신호만 표시합니다** — *"이 아이 수준이 어때?"*라고 묻지 않습니다

**작게** — 이야기 틀 **7가지 중 5가지**를 데모에 넣었고, 아이 수준에 따라 틀과 쪽수(6~8쪽)가 달라집니다.

### 11. 마스코트가 대답하기

**한 줄** — 폰 목소리는 **탈락**했습니다. 귀로 들어보니 셋 다 아니오였습니다.

**핵심 그림** — 시간 막대 하나

```
아이 말 끝 ──▶ [리액션 재생 0초 시작] ──────────────▶ 마스코트 본 대사
                 "잠깐만, 생각 좀 하고!" + "음~" = 4.11초
                 └ 이 뒤로 받아쓰기·판단·목소리가 숨는다 (3.72초)
```

- **리액션은 미리 구워 앱에 넣습니다** — 6개에 **184KB**, 재생 지연 **0초**
- **본 대사는 매번 만듭니다** — 아이가 한 말이 문장에 들어가서 미리 못 굽습니다. 첫 소리까지 **1.32초**
- **한 마디로는 모자랍니다**(가장 긴 게 2.86초) → **두 마디를 잇습니다**

### 12. 그림 만들기

**한 줄** — 아이를 기다리게 하지 않으려고 **대화 뒤에서** 만듭니다.

| 만드는 것 | 전 | 지금 |
|---|---:|---:|
| 배경 1장 | 19.07초 | **3.74초** |
| 등장인물 후보 3장 | 35.8초 | **8.0초** |
| 입 벌린 그림 1장 | — | **2.32초** |
| 만지는 것(바위·나무·별) | — | **0초** (미리 만들어 얹습니다) |

- **손잡이는 세기가 아니라 스텝 수**였습니다. 더 내리면 **종이 결이 물감처럼 뭉개져서** 지금 값으로 정했습니다
- **말하는 입** — 캐릭터를 쪼개려는 시도는 전부 실패했고, **쪼개지 않고 입만 다시 그려** 두 장을 번갈아 보여주는 방식으로 풀었습니다 → 입 다문/벌린 그림 2장 나란히
- **어느 그림 모델을 쓸지는 아직입니다** — 지금까지 하나만 재봤습니다

### 13. 그래픽카드 한 장에 셋을 올리기

**한 줄** — 자리는 되는데 **같이 돌리면 안 됩니다.** 그래서 시간을 나눠 씁니다.

- **셋이 다 올라갑니다** — 그림 + 받아쓰기 + 음성 처리로 **10,437 / 12,287 MiB**
- **동시에 돌리면 받아쓰기가 0.71초 → 2.54초(3.6배)** 느려집니다. 그림을 쥔 쪽이 이기고, **작은 계산을 많이 하는 받아쓰기가 줄을 섭니다**
- **최종 결정** — **아이가 말하는 동안에는 그림을 만들지 않습니다.** 마스코트가 말하는 동안(6.4~7.0초) 만들고, 그림 한 장이 2.4초라 **한 턴에 두 장**이 들어갑니다

### 14. 아이를 다루기 때문에 지키는 것

**한 줄** — 만 3~7세 앱이라 **기능보다 먼저 정해야 하는 것**이 있습니다.

| | 지금 상태 |
|---|---|
| **아이 원본 음성** | 우리 인프라에만 둡니다 — **우리가 고른 제품 원칙**입니다 |
| **실명** | 폰에서 가리고, 매핑표도 폰에만 둡니다 |
| **법정대리인 동의** | 만 14세 미만은 동의와 **그 사실의 확인**이 필요합니다(개인정보 보호법 제22조의2) — **설계 중** |
| **보존과 삭제** | 음성·전사·기록이 언제 생기고 언제 지워지는지 — **설계 중** |
| **보호자 열람·정정·삭제** | 부모 모드에 자리는 있고 **아직 동작하지 않습니다** |
