- `[반응 N]` = 아이가 반응해야 하는 순간의 누적 번호
- `[확인 필요]` = 회의에서 명시적으로 정하지 않아 초안대로 둔 곳

- **구현 언어는 Kotlin으로 정해졌다** (결정 19). 목요일 HTML 프로토타입은 앱에 그대로 옮기지 않고 **화면 흐름을 확인하는 대본**으로 쓴다

## 마스코트 말하기 규칙 (2026-09-16 조장)

**마스코트가 진행을 맡는다.** 책 읽어주기도 마스코트가 한다. 어른에게 진행을 넘기지 않는다. 대신 마스코트가 **친절한 가족처럼** 받아주고, 아이가 막히면 부드럽게 끌어주고, 가끔 어른에게 말을 건넨다.

### 한 턴은 세 조각

| 조각 | 무엇 | 예 |
|---|---|---|
| **① 받아주기** | 아이 말을 인정하고 반응한다. 평가하지 않는다 | "우와, 외계인이었구나!" |
| **② 늘려서 되돌려주기** | 아이 말에 한 겹만 얹어 다시 들려준다. 발음이 어긋났어도 고쳐 말해 주되 지적하지 않는다 | "공뇽!" → "초록 공룡이 왔구나!" |
| **③ 다음 질문** | 의문사 하나, 10어절 이하 | "공룡은 어디서 왔을까?" |

- **세 조각을 합쳐 두 문장을 넘지 않는다.** 마스코트가 길어질수록 아이 말할 기회가 줄어든다 (에이전트 앞에서 아이 발화가 줄어든다는 연구 · 안치영 #15 · #28)
- **어른이 말하는 중에는 끼어들지 않는다.** 어른 목소리가 들리면 2~3초 기다린 뒤 이어간다

### 질문은 모두 열린 질문 (결정 30 · 9/16)

**카드를 처음부터 띄우지 않는다.** 모든 칸을 말로 묻는다. 카드는 세 경우에만 나온다.

| 카드가 나오는 때 | 무엇 |
|---|---|
| **무응답** | 쉬운 질문 한 번 → 그래도 없으면 그림 3장 (최대 3번 교체) → 마스코트가 골라줌 |
| **모호한 말** | "공룡!" → 티라노 · 긴목 · 뿔공룡 3장으로 좁히기. **확인 절차이지 선택지가 아니다** |
| **아이가 원할 때** | [그려서 알려줄래?] · [직접 그리기] 버튼은 늘 보인다 |

- **왜 통일하나**: 카드가 늘 떠 있으면 아이가 말 대신 탭한다. 탭한 답은 수준 신호로 세지 않아 판단할 재료도 사라진다. "말로 짓는다"는 제품 정체성과도 어긋난다. 기획안 화면 5의 원안("무응답 · 시도 초과 시 그림 3개")으로 돌아가는 것이기도 하다
- **자유롭게 답한 말은 정해진 유형으로 옮긴다.** 장소를 예로 들면 미리 만들어 둔 장소 유형(우주 · 바닷속 · 공룡 나라 · 숲 · 하늘 · 놀이터 …)에 LLM이 맞춘다. 맞는 유형이 없으면 그때 배경을 새로 생성한다 (GPU 자체 서버라 가능)
- **미션은 장소에 묶지 않는다.** 불 끄기 · 물 채우기 같은 뼈대를 두고 소품 그림만 장소에 맞춰 바꾼다. 장소가 자유로워져도 미션이 무너지지 않는다
- 데모에서 마이크를 끄면 답 후보 5개 중 하나가 들어간다 (안치영 대본 방식). 카드가 없어도 시연은 돌아간다

### 리액션 톤

| 한다 | 안 한다 |
|---|---|
| 구체적으로 반응: "눈이 세 개나 있네!" | 남발하는 평가: "잘했어요", "최고예요" |
| 아이가 만든 것을 다시 불러주기: "지호가 만든 뿌뿌 말이지?" | 정답 · 오답 판정 |
| 놀람 · 웃음 · 감탄 같은 소리 반응 | 발음 지적: "공룡이지, 공뇽 아니고" |
| 못 했을 때도 편들어 주기: "괜찮아, 같이 생각해 볼까?" | 재촉: "빨리 말해 볼까?" |

### 아이가 막혔을 때 (부드럽게 끌어주기)

무응답 흐름(결정 5 · 22)에 톤을 입힌다.

1. 기다린다 (쉬운 질문 5초 · 어려운 질문 8초). 화면에 오류 표시 없음
2. **편들기 + 쉬운 질문**: "어려웠구나. 그럼 뭐가 흔들렸어?"
3. **어른에게 넘기기**: "이모는 어떻게 생각해?" — 어른이 답하면 그 말을 받아 다시 아이에게 "이모는 이렇게 생각한대. 지호는?"
4. 그림 선택지 3장 (최대 3번 교체)
5. 마스코트가 골라주고 이야기를 잇는다: "그럼 ○○로 할까? 재밌겠다!"

### 어른을 부르는 자리 (어른이 있으면 더 좋아지는 구조)

진행을 어른에게 넘기지 않으면서 어른을 끌어들이는 지점은 셋이다.

| 자리 | 마스코트 대사 | 없으면 |
|---|---|---|
| 아이가 막혔을 때 | "이모는 어떻게 생각해?" | 3초 기다린 뒤 선택지로 |
| 어른 전용 칸 (책마다 1개) | "이모는 어떤 친구가 나왔으면 좋겠어?" | 마스코트가 프리셋에서 고름 |
| 아이가 짧게 답했을 때 | (말하지 않고) 화면에 작은 손 아이콘 3초 — 어른이 되물을 자리 | 마스코트가 이어서 질문 |

- 어른이 답한 내용은 **이야기 칸에 들어가고 책에 등장**한다. 어른도 만든 사람이 된다
- 어른 참여는 부모 기록의 "함께하기"에 횟수로 남는다 (판정 아님)

### 구현 메모

- **정형 리액션 40~60개는 미리 합성해 둔다** ("우와!", "정말?", "재밌다!", "괜찮아, 같이 생각해 보자"). 실시간 음성 합성은 늘려서 되돌려주는 문장과 질문에만 쓴다 → 대기 시간과 비용이 준다
- 늘려서 되돌려주기는 아이 말을 그대로 쓰므로 **이름 필터를 거친 뒤** 생성한다
- 리액션 문장은 리포트 인용 후보가 아니다 (아이 말이 아니므로)

## 장면 1. 이모가 앱을 연다 — 약 30초

> 🗣 **이모**: "지호야, 유튜브 말고 우리 이야기 만들기 할까?"
> 🗣 **지호**: "공룡 나오는 거!"

📱 첫 화면: 큰 **[이야기 만들기]** · 옆에 [책장] · **오른쪽 위에 ⭐ 3** (별 아이콘 + 숫자) · 아래 작은 글씨 *"어른과 함께 하는 놀이예요"*

> 🗣 **지호**: (이야기 만들기 탭) `[반응 1]`
> 📱 오른쪽 위 별 하나가 **좌우로 흔들리며 점점 커져 화면 가운데로 날아오고**, 화면에 가득 차는 순간 이야기가 시작됨. 표시가 ⭐ 3 → **⭐ 2** (결정 2 · 28)

⚙️ 뒤에서
- **시작 방식은 부모 모드 설정에 따라 둘 중 하나** (결정 2)
  - **아이가 시작해도 됨** — 지호네 방식. 아이가 바로 누름
  - **부모 비밀번호 필요** — 이야기 만들기를 누르면 어른이 비밀번호를 넣어야 시작
- **별은 재화다** (결정 28). 만들 수 있는 이야기 권수이고, **아이 화면과 어른 화면에 똑같이 아이콘 + 숫자**로 보인다. 부모가 사면 개수가 는다 (결제는 1차 미구현)
- **별이 0일 때** (결정 28): ⭐ 0 으로 그대로 표시된다. 아이가 [이야기 만들기]를 누르면 **마스코트가 말풍선으로 알려준다** — *"오늘 만들 이야기는 다 썼어! 책장에 가서 지난 이야기 볼까?"* · 버튼 두 개 **[책장 보기] [괜찮아]**
  - 알림은 **누를 때 한 번만.** 가만히 있는데 다시 뜨지 않는다 (반복 팝업 금지)
  - 구매 안내 · 가격 · "지금 사면" 문구는 아이 화면에 없다
- ⚠️ **아이 화면에 사면 늘어나는 숫자를 두는 설계다.** 조사3 §1 "아이 화면에 결제와 연결된 잠금을 두지 않는다"와 맞닿아 있으므로 셋을 지킨다
  - 아이 화면에 **구매 버튼과 가격을 두지 않는다.** 사는 건 부모 모드에서만
  - 0일 때 문구는 **구매 안내가 아니라 다른 놀이 안내**로 끝낸다
  - "지금 사면" 같은 재촉과 반복 팝업을 넣지 않는다 (전자상거래법 반복간섭 · 조사3 §1-1)
- 동의는 엄마가 지난주에 받음: *"아이 목소리와 그림은 이 기기 안에만 저장됩니다. 말을 글자로 바꾸고 그림을 만드는 동안만 저희 서버(국내)를 거치고, 끝나는 즉시 지워집니다. 이야기를 만들기 위해 이름을 가린 문장이 해외 AI 회사로 전송됩니다."* (조사3 §2-2)

## 장면 2. 주인공 고르기 — 약 1분

📱 **도감 — 주인공 4칸** (결정 8)
- 가로 한 줄에 4칸. 1번 "안경 쓴 지호", 2번 "파란 옷 지호", 3~4번은 **점선 테두리 + 가운데 ＋ 버튼**

- 주인공은 각자 만들어진 그림체 그대로(크레용). 모두 흰 오려낸 테두리가 있는 종이 인형 카드

> 🗣 **마스코트**: "안경 쓴 지호, 파란 옷 지호가 있어. 오늘은 누구랑 갈까?"
> 🗣 **지호**: (안경 쓴 지호 탭) "이거!" `[반응 2]`

📎 선택지를 먼저 말하고 질문은 마지막 (안치영 #27)

↳ **＋ 버튼을 누르면 — 말로 주인공 만들기** (도감에서만, 이야기 중에는 안 함 · 결정 20)

> 🗣 **마스코트**: "머리는 짧아, 길어, 묶었어?" → "짧아!"
> 🗣 **마스코트**: "빨강, 파랑, 노랑 옷이 있어. 무슨 색 입을까?" → "파랑!"
> 🗣 **마스코트**: "공룡, 자동차, 별이 있어. 뭘 좋아해?" → "공룡!"
> 📱 (몇 초 뒤) 짧은 머리 · 파란 옷 · 공룡 티셔츠 종이 인형 + **[좋아 🙂] [싫어 ✏️]**
> 🗣 **마스코트**: "짠! 이렇게 생겼어. 좋아, 싫어?"

- **"싫어"를 누르면 바로 다시 만든다.** 2번까지. 다 쓰면 만든 3장을 늘어놓고 고르게 한다 (결정 24)
- 확인은 예/아니오가 아니라 **그림 카드 두 장** (결정 21 · 안치영 #11)
- 확정한 그림은 도감 칸에 저장하고, 다른 그림 나라에 가도 **이 모습 그대로 데려간다** (결정 26 · 27)

⚙️ 뒤에서 (말로 만들 때만)
- 음성 → **우리 서버 Whisper** → 속성값 `hair=short, shirt=blue, likes=dinosaur`
- 발화 원문이 아니라 속성값만 영어 키워드로 → **우리 서버 ComfyUI** (그때의 세계 그림체)
- 음성 사본은 변환 즉시 삭제

## 장면 3. 어디로 갈까 — 1턴 · 약 40초 · **기준 질문 ①**

📱 마스코트와 마이크만. **카드 없음** (결정 30)

> 🗣 **마스코트**: "오늘은 어디로 가 볼까?"
