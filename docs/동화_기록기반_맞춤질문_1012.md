# 동화: 기록 기반 맞춤 질문 — 10-12

## 구현 범위

#343의 현재 아이 기록을 새 동화의 질문 난이도 시작점에 연결한다. 나이·연령별 평균·MLU 문턱을 사용하지 않는다. 단계 이름은 저장하지 않고, 원문에 대응하는 **실제 질문 규칙 입력**을 기기에 남겨 재계산한다. 다른 모드의 과거 기록은 동화의 시작점 계산에 넣지 않는다.

## 현재 답의 판단

- 원래 질문 은행의 `Kind`가 아니라 실제 `TalkLine.questionType`을 사용한다. 서버 모드가 선택 질문을 열린 질문으로 바꾸거나 사다리에서 선택으로 바꾸기 때문이다.
- 동화의 선택·확인·미상·마음 질문(기존 `emotion` 표식) 답은 언어 신호에서 제외한다. 단, 아이가 직접 고른 카드 답은 조장 10-12 결정에 따라 질문을 쉽게 하는 하향 신호로만 쓴다. 차례 수에 포함하도록 정한 질문의 차례 수는 유지하며, 템플릿 확정 시점과 `story_ready` 종료를 바꾸지 않는다.
- 실제 서버 답의 S1·S2를 그대로 사용한다. 기존에 빠져 있던 A1은 독립된 `그래서`·`그리고`·`그다음에`·`그러니까`·`그런데`를 원문에서 확인한다. `숲에서`·`가서`·`그리고싶어`를 같은 신호로 처리하지 않는다. A1은 연결 표현일 뿐 S1 인과를 새로 만들어 내지 않는다.
- 기존 두 차례 연속 규칙을 공유한다. 고르며→이어는 S1 또는 S2, 이어→까닭은 S1과 구조 요소 또는 A1이다. 짧은 답·무응답 규칙도 같은 문턱을 유지한다. 실제 선택 답으로 말이 짧다는 판정을 하지 않는다.
- 되돌리기·다시 하기에서는 상승 신호 연속 횟수까지 함께 복구한다.

### 10-12 리뷰 후 확인 — 카드만 고르는 경우

조장 10-12 18:38 결정으로 앞선 카드 단계 유지 제안을 바꿨다. 현재 대화에서는 아이가 고른 카드 답 두 번마다 한 단계 쉽게 내려가며 `PICK` 아래로 내려가지 않는다. 올림 신호나 저장 언어 사실로 쓰지 않는다. `PICK`·`CHAIN`·`REASON` 각각에서 카드 네 번을 이어 고르는 검사로 차례 수와 세 번째 차례의 템플릿 확정도 함께 확인한다. 마스코트가 대신 고른 답과 음성 확인 답은 카드 하향 신호로 취급하지 않는다.

**과거 기록 재생:** 카드 답은 다음 새 동화의 시작 단계를 낮추는 근거로 이월하지 않는다. 질문에서 제시한 선택지에 따른 반응을 다음 이야기의 지속적인 언어 능력으로 해석하지 않기 위해서다. 기존대로 측정된 직접 답 사이의 연속 신호만 끊는다. 카드뿐인 과거 기록은 새 시작 단계를 제공하지 않으며 기본 시작점을 사용한다. 진행 중인 동화를 이어할 때는 이미 쉽게 바뀐 현재 단계를 그대로 복원한다. 최신 main과 병합하면서 `TurnHistory`의 끝맺기 질문 복원과 상승 신호 복원을 모두 보존했다.

## 저장하는 사실

`TalkLine.languageEvidence`에 S1 여부, S2 요소, A1 여부, 기존 질문 규칙의 어절 수, 해당 질문을 판단 차례로 세는지(`counted`)를 선택적으로 남긴다. `SessionReport`와 `AnswerHistory`의 기존 원문·질문·출처에 붙으며 서버로 전송하지 않는다. `AnswerHistory` 저장 버전은 2이고, 옛 자료는 계속 읽을 수 있다.

보고용 `reason` 태그는 정규식 보강이 포함되므로 실제 판정의 S1으로 재사용하지 않는다. 언어 사실이 없거나 형식이 잘못된 옛 항목은 미상으로 남긴다. 단계명·연령 추정·발달 점수는 이 저장 객체에 없다.

10-12에 main에 들어온 이어하기 저장(`SessionDraft`)에도 같은 선택적 언어 사실과 차례의 언어 판단 대상 여부를 보존한다. 앱을 완전히 종료한 뒤 이어 책을 저장해도 기록이 누락되지 않는다. 초안은 원래 책의 아이 구분 값도 함께 저장한다. 다른 아이로 바꾸거나 기록을 초기화한 뒤 이전 책을 이어 저장해도 새 누적 기록에 넣지 않는다. 소유자를 저장하지 않았던 옛 초안은 미상으로 두며 현재 아이 것으로 추측하지 않는다. 책과 책별 리포트는 보존한다. 옛 초안의 언어 사실은 미상으로 읽고, 차례 기록의 새 대상 표식이 없으면 기존 처리와 호환한다. 기존 이어하기가 게임 상태로 저장하던 현재 질문 단계·연속 횟수는 그대로이며 새로 단계 이력을 만들지 않는다.

## 새 동화 시작

현재 프로파일의 동화 답에서 마지막 50개 **측정된 열린·까닭 직접 답**을 포함하는 구간을 읽는다. 최소 두 개가 있어야 기존 연속 규칙을 재생할 수 있다. 그 사이의 선택·미상·비언어 항목은 연속 신호를 끊는다. 기존 규칙이 판단 차례에서 제외한 질문은 `counted=false` 사실을 이용해 대화 중 규칙처럼 건너뛴다. 한두 어절이라는 이유로 선택 답을 하향 신호로 쓰지 않는다.

기본 질문 단계에서 시작해 기존 규칙 입력을 재생하여 시작점을 정한다. 나이, 선택 관심사, 부모 리포트 문구를 단계의 대용값으로 쓰지 않는다. 자료 읽기/쓰기 실패나 유효 신호 부족이면 기본 시작점을 사용한다. 약 50개는 보관 창의 제한이며 또래 비교나 발달 타당성 통과 조건이 아니다.

이야기가 이미 시작됐거나 차례 기록이 있으면 재초기화하지 않는다. 같은 아이의 호칭 변경은 프로파일을 유지하고, 다른 아이·명시적 초기화·책 삭제는 기존 `AnswerHistory` 정책대로 재계산한다. 이전 아이의 진행 중 책은 새 아이의 기록으로 취급하지 않는다.

## 서버 연결과 한계

현재 `/turn`의 `level` 필드에 재계산된 질문 단계가 전달되고 LLM은 그 단계에 맞는 대사를 쓴다. 새 엔드포인트·필드·추가 호출은 없다. 과거 원문이나 누적 신호를 요청에 붙이지 않는다.

`/turn`은 다음 질문까지 만든 뒤 돌아오므로 이번 답으로 단계가 바뀌어도 이미 만들어진 질문은 이전 단계의 문구다. 다음 요청부터 새 단계가 반영된다. 문구 하나를 다시 만들기 위한 유료 호출을 추가하지 않았다.

이번 구현은 질문 조절 규칙과 기록 연결이다. 실제 아동에서 적절한 난이도인지, 앱 이용으로 언어가 증가하는지, 임상적 또는 연령 규준과 맞는지는 별도의 검증이다. 새 맥락을 창작하거나 무한 질문 문제를 턴 상한으로 숨기지 않는다.
