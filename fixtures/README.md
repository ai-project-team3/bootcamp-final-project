## 계획 (`guidelines/6` §6-6)

```
목표 재발 사례        40건
세션당 심는 수         2건   ← 3건 이상은 부자연스럽다
양성 세션             20세션
+ 음성 대조군          5세션  ← 재발 0건. 오탐 측정용
총                   25세션 × 12분
```

라벨링은 전량 1명이 하고 **20%(5세션)를 2명이 독립 라벨링**해 Cohen's κ를 계산합니다.
평가 단위는 **발화**입니다.

🔴 **"심어서 측정했다"를 발표에서 먼저 말합니다.** 자연 발생만 기다리면 50세션 이상이 필요합니다.
