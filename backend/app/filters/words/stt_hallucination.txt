# whisper 가 말소리 없는 오디오에 지어내는 문장 — 전사가 **통째로** 이것이면 버린다.
# 공백 · 문장부호는 무시하고 비교한다. `*` 로 끝나면 앞부분이 같기만 하면 된다.
#
# 왜 이런 문장인가: whisper 는 유튜브 자막으로 학습해서, 소리가 없으면 영상 끝 인사를 채워 넣는다.
# 이 문장들은 **무해해 보여서 금칙어 필터에 안 걸린다** — 그래서 따로 막는다 (규칙 5).
#
# [관측] = 09-22 우리 녹음(eval/stt_bias_bench.py)에서 실제로 나온 것.
# [알려진] = 관측은 안 됐지만 whisper 한국어 헛문장으로 널리 보고된 것. 관측되면 [관측]으로 옮긴다.
#
# ⚠️ 아이가 정말 이 말만 했어도 버린다. 버리면 마스코트가 한 번 더 묻고 끝나지만,
#    안 버리면 **아이가 하지 않은 말이 아이 말로 남는다.** 비용이 다르다.
# ⚠️ 이야기 재료가 될 만한 낱말(「고춧가루」 같은)은 넣지 않는다. 한 번 헛나왔다고 넣으면
#    아이가 그 말을 했을 때 이야기가 사라진다.

감사합니다            # [관측] 무음 · 강의실 소음 · 작은 말소리
고맙습니다            # [관측] 1차 강의실 녹음
시청해주셔서감사합니다  # [관측]
다음영상에서만나요      # [관측] 폰 무음 2회
아멘                  # [관측] 폰 무음 2회 · 「몰라」를 이렇게 받아쓴 적도 있다
한글자막by*            # [관측] 「한글자막 by 한효정」 등
구독과좋아요*          # [알려진]
